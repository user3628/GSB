当前为空工作区，需从零构建一个本地可运行的表格数据降维与聚类诊断工作台，围绕交叉组合与降维场景做数据规模变化下的算法取舍。输入为固定随机种子生成的本地 CSV 样本集，分为小规模（约 400 行、8 列）、中规模（约 4000 行、24 列）与大规模（约 20000 行、48 列）三档，列含连续特征、类别特征、含缺失值列与相关冗余列，并附带一份分档清单记录每个样本的文件名、行数、列数与声明的特征语义。工作台需对每档样本执行列预处理、降维（PCA 与截断 SVD 及随机投影的候选取舍）、在降维空间上做 KMeans 或层次聚类、再以轮廓系数与重构误差等指标诊断并给出算法选择建议。工作台要求支持交互查询与诊断报告，可查看降维维度选择理由、聚类质量与每档规模下的算法取舍依据。

任务环境与准备：
安装 Python 3.11 及以上版本，并安装 numpy 与 scikit-learn，版本需在主依赖清单中固定。
确认工作区可写，预先创建样本目录、状态存储目录与演示输出目录。
运行本地样本生成脚本，按固定随机种子产出三档 CSV 与分档清单，并核对生成摘要。
在 Windows 上确认文件锁与原子替换可用，HTTP 接口绑定本地回环地址与未占用端口。

业务要求：
1. 实现预处理与降维候选阶段：依据分档清单与非空取值统计识别连续列、类别列与缺失列，连续列做标准化、类别列做独热、缺失值按配置填充；在此基础上实现 PCA、截断 SVD 与固定随机投影三种降维候选项，输入与配置相同必须产生逐字节一致的降维结果与载荷矩阵，禁止依赖任何外部数据集。
2. 实现基于数据规模的自动降维取舍：依据行数、原始维度、缺失比例与可配置的算力预算，为每档样本在三种降维候选中选定方案与目标维度，并记录选择理由、候选打分明细与被淘汰原因；小规模档须避免明显过高的目标维度，大规模档须在保持重构误差约束下选择更低维表示，选择规则须为确定性的。
3. 实现降维空间上的聚类阶段：对选定降维表示执行 KMeans 或层次聚类，支持可配置簇数或由诊断指标自动建议簇数；记录每次迭代的簇心移动量、簇大小与空簇处理，聚类结果须与降维表示对齐，簇标签在重复运行时保持一致编号规则，空簇须按显式策略重定位而非静默丢弃。
4. 实现聚类与降维质量诊断：计算轮廓系数、簇内平方和、降维重构误差与累积解释方差，并按分档汇总成诊断报告；对各指标给出与样本规模相关的误差带估计，当某档样本的轮廓系数低于可配置阈值或出现单簇占比过高时，须在报告中标记该档建议回退到其他降维或簇数方案并说明依据。
5. 实现增量重算与全量一致性校验：当配置中的目标维度、簇数、降维候选或预处理方式变化时，依据版本指纹识别受影响的最早阶段，仅重算该阶段及其下游，未受影响上游结果继续复用；增量结果须与从零全量构建的诊断报告与聚类标签在允许重排意义下逐字段一致，不一致时返回 E_INCREMENTAL_MISMATCH 并附差异详情。
6. 实现持久化状态与优雅停止恢复：每个阶段完成时以原子方式写入含阶段名、分档标识、输入指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分分档单元后退出，恢复时从最近一致记录继续，最终诊断报告须与一次完整运行的结果逐字节一致，且不声称强制终止后一定生成退出报告。
7. 实现版本变化检测与并发发布保护：检测记录被整体替换、序号回退或摘要不匹配的版本变化情形并加以区分，仅允许正常推进；多工作进程对同一工作区发布阶段产物时使用文件锁并比较序号，落后或重复发布返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_INVALID_STAGE，非法维度或簇数返回 E_INVALID_CONFIG。
8. 提供诊断工作台应用与本地确定性演示：命令行与本地 HTTP 接口支持导入分档样本、触发降维与聚类、查询各阶段状态与版本指纹、查看算法取舍理由与诊断报告、请求停止、执行恢复；演示数据至少覆盖三个规模档、含相关冗余列与缺失列，一次完整运行生成固定摘要，并演示一次阶段间停止后恢复与一次非法配置注入。
