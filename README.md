当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的文生视频分镜脚本语义核查管线，交付数据处理管线与结果验证工具。输入为固定随机种子生成器产出的本地确定性样本：一份 JSONL 分镜脚本，每条含 shot_id、提示词（中英混排的自由文本）、分镜时长描述短语（如“约三秒半”“2.5s”“八帧”）、必须出现的主体与场景关键词清单、可选的否定约束词清单；另附一份 JSON 主体表声明每个 shot 的必须主体与禁入主体。生成器还产出与脚本同源的参考标注（每个 shot 的语义单元切分结果、时长解析目标值与覆盖率目标区间），作为验证唯一真值来源；系统不依赖任何真实生成模型、GPU 或外部服务。管线按四个阶段执行：提示词规范化与语义单元切分、时长短语解析与统一刻度归一、覆盖率计算与违规判定、规模自适应取舍（依据 shot 数、提示词总长度与可选检查深度选择解析策略）。所有校验只用输入中显式声明或生成器同源产出的信息推断。

任务环境与准备：
安装 Python 3.10 或以上版本，并确保 NumPy 可正常导入。
准备本地工作区目录，全部样本、参考标注、检查点与导出产物均在该目录下生成与读写。
使用固定随机种子的本地生成器在运行前产出两档分镜脚本及同源参考标注，不下载外部数据集与模型。
为命令行启动的本地 HTTP 接口预留一个可访问的本地端口，无需外部网络。

业务要求：
1. 实现提示词规范化与语义单元切分：对提示词做 Unicode NFKC、空白折叠、全半角统一，按中文句读、逗号与连接词切分为带字符偏移的语义单元，并为每个单元标注单元类型（主体描述、场景描述、约束、时长）；空提示词或切分后无任何主体描述单元的 shot 须返回带 shot_id 与切分位置的 E_EMPTY_PROMPT，且不得生成部分阶段产物。
2. 实现时长短语解析与统一刻度归一：识别中文数字量词、阿拉伯数字加单位与直接给出的帧数三类时长表达，统一归一为毫秒整数并记录解析来源标记与精度位数；单位未知、时长为零或负、同一 shot 出现互相矛盾的两个时长短语须返回带 shot_id 与短语偏移的 E_DURATION_PARSE，不得静默取第一个可解析值。
3. 实现必须主体与否定约束的开闭区间匹配：依据主体表在语义单元上做最长匹配，命中必须主体时记录占用的字符区间，命中否定约束词时把其后可配置窗口内出现的必须主体标记为禁入；同一主体既被要求出现又落在否定窗口内须判定为语义冲突并输出冲突主体、两处偏移与原因，且该 shot 覆盖率按冲突规则扣减，不得直接判通过。
4. 实现覆盖率计算与违规判定：按参考标注声明的语义单元真值统计必须主体覆盖率、场景覆盖率与时长解析一致率，结合可配置权重合成 shot 级语义得分并映射为通过、复核、驳回三级结论；各项分母为零时须显式记为不适用并计数，结论须依赖真值覆盖率目标区间，不得从缺失标注推断。
5. 实现基于数据规模的解析策略取舍：依据 shot 数、提示词总长度、否定约束词数与可配置检查深度预算，在逐单元全量匹配、关键词优先截断匹配与分块增量匹配三种策略中选择一种，记录选择理由、候选打分明细与被淘汰原因；小规模须避免选用仅为大规模设计的截断策略，且三种策略对同一输入在预算允许时必须给出逐字节一致的判定结论。
6. 实现版本指纹、阶段检查点与优雅停止恢复：每阶段完成时以原子方式写入含阶段名、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；当提示词、时长短语、主体表、否定词表、权重或预算任一变化时，通过内容摘要构成的版本指纹识别受影响的最早阶段并使其及全部下游失效重建，未受影响上游继续复用；收到停止请求时完成当前不可拆分 shot 单元后退出，恢复后判定结果须与一次从零完整运行逐字节一致。
7. 实现并发发布保护与稳定业务错误码：多个工作进程对同一工作区发布阶段产物时使用真实文件锁并比较阶段内序号，仅允许序号连续推进，落后、重复或跨阶段错位发布须被拒绝并返回 E_STALE_CHECKPOINT；缺失前置阶段产物或请求非法阶段跳转须返回 E_INVALID_STAGE；错误码须携带 shot_id 或阶段名等定位信息，且不得破坏已写入的检查点。
8. 提供本地确定性演示与结果验证工具：生成器产出至少两个规模档（数个 shot 与数十个 shot）的脚本与参考标注，含中英混排、否定约束、冲突主体与解析失败样本；验证工具须对比两档的语义单元切分、时长解析值、覆盖率与三级结论，核对未受影响 shot 在增量重算后与全量结果逐字节一致，并统计各单元类型与各失败错误码的数量分布。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用两档本地脚本验证语义单元切分、时长解析、覆盖率判定与增量重算恢复一致性，并核对错误码。
