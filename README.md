当前是空白工作区，需要在 Windows 本地从零构建一个面向本地回环环境的负载均衡健康检查组件，供上层流量网关集成，交付可交互的专业应用与可重复演示。后端池由若干后端实例（实例标识、地址、权重、所属可用区）组成，健康检查分为主动探测（HTTP 状态码与响应体标记、TCP 拨号）与被动观测（真实转发结果）两类；每条实例的健康状态在 UNKNOWN、HEALTHY、SUSPECT、UNHEALTHY、DRAINING、REMOVED 之间演进，连续成功与失败次数阈值、探测间隔与超时共同决定迁移。系统需维护每个后端池的可用实例集合与权重快照，按可用区与权重复算流量分配比例，并在探测结果、权重调整、实例摘除与恢复之间保持跨模块一致。进程可能在任何时刻被强制终止，重启后必须依据持久化事实恢复状态并输出恢复报告。所有数据来自本地确定性样本与本地测试端点，不依赖外部网络。

任务环境与准备：
Windows 10/11，Python 3.11 已安装并可在命令行调用
创建空白工作目录，使用 venv 建立虚拟环境
在虚拟环境中安装 fastapi、uvicorn、httpx 与 pytest，版本以本地 wheel 或内网镜像可获取为准
准备或由脚本生成固定本地 JSON 后端池样本与本地测试端点配置，所有地址限 127.0.0.1 回环端口
确认 SQLite 可用（Python 内置 sqlite3 即可），无需外部数据库或容器环境

业务要求：
1. 实现后端池与实例模型：实例包含标识、地址（本地回环端口）、权重、可用区与探针类型；解析本地 JSON 样本时校验权重为正整数、地址端口合法与可用区非空，解析失败或实例标识重复返回业务码 E_INSTANCE_INVALID 且整份样本不加载；后端池整体加载须识别样本版本变化并整体替换旧池，不得把新旧样本的实例混合使用。
2. 实现主动探测与真实超时：HTTP 探针以本地测试端点返回的约定状态码与响应体标记判定成功，TCP 探针以真实连接成功或拒绝判定；每次探测具备独立超时，超时后必须真实关闭 HTTP 客户端连接或 TCP 拨号并记录超时，不得以等待冒充超时，超时结果计入失败次数并返回结构化探测结果。
3. 定义实例健康状态机，至少包含 UNKNOWN、HEALTHY、SUSPECT、UNHEALTHY、DRAINING、REMOVED 六种状态并规定合法迁移路径；连续成功与失败次数阈值、探测间隔与超时参数共同决定迁移，非法迁移返回 E_INVALID_TRANSITION 且不修改已持久化状态；DRAINING 只能手工进入并须在完成在途请求后转 REMOVED。
4. 实现被动观测融合：真实转发结果（成功、超时、连接拒绝、上游 5xx）与主动探测结果共同决定健康状态，同一轮内主动与被动结论冲突时按声明的融合规则裁决并输出冲突双方与最终依据；被动失败不得在未达阈值时直接摘除实例，避免单次抖动导致可用集合抖动。
5. 实现可用集合与权重快照的跨模块一致：每次健康状态迁移须在同一事务边界内更新实例状态、后端池可用实例集合与按可用区与权重复算的流量分配比例，禁止出现实例已标记 UNHEALTHY 而分配比例仍计入其权重的中间可见状态；查询只能看到某一完整提交版本，不得读到半更新集合。
6. 实现单写者探测调度与多读者查询：探测轮次与状态迁移按后端池单写者串行执行，多个只读查询可并发读取已提交状态；同一实例在同一轮中不得被重复探测，并发触发同一后端池轮次时仅一个实际执行、其余等待复用结果；不同后端池的轮次可并行，但共享的探测客户端资源须受全局并发上限约束，超出返回 E_PROBE_BUDGET_EXHAUSTED。
7. 使用 SQLite 持久化实例状态、可用集合版本、探测历史与意图日志，所有写操作先落意图记录再提交事务；进程在探测轮次或可用集合重建中途被强制终止后重启，必须扫描未完成意图把对应轮次标记为已中止并将状态回滚到最后一个完整版本，恢复报告只基于已持久化事实，不得承诺强制终止后仍生成完整退出报告。
8. 提供本地 HTTP API 与可重复演示脚本：API 覆盖样本加载、触发探测轮次、按后端池查询实例状态与分配比例、查询探测历史与恢复报告，统一失败响应为含业务码的 JSON（至少覆盖 E_INSTANCE_INVALID、E_INVALID_TRANSITION、E_PROBE_TIMEOUT、E_PROBE_BUDGET_EXHAUSTED、E_POOL_NOT_FOUND）；脚本启动本地测试端点，完成全健康演进、连续失败摘除、恢复重入与一次强制终止后恢复，输出状态迁移记录与分配比例前后差异。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地测试端点验证健康状态迁移、可用集合与分配比例一致、超时与强制终止后恢复，并输出恢复报告。
