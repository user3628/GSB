当前是空白工作区，需要在 Windows 本地从零构建一个面向主从复制延迟治理的领域数据编辑与操作应用。运维人员通过本地 HTTP 接口编辑一张「延迟治理策略」数据集：每条策略针对一个复制从库（标识、所属复制组、延迟判定阈值毫秒、可容忍延迟毫秒、预期从库版本、降级动作与优先级），并通过本地确定性样本注入一批主从复制延迟观测（从库标识、采样时刻、复制位点差、延迟毫秒、从库上报版本）。应用需要把策略与观测结合，计算每个从库的延迟状态与应执行的降级动作，并输出可编辑、可回放的裁决结果。核心业务问题是格式互操作与版本兼容：策略数据集需要两种可互换的本地持久化格式（带魔数、版本字节、长度前缀与 CRC32 的紧凑二进制格式，以及分片 JSON 行格式），两种格式在字段可选性、时间精度与版本标记上并不对齐；同时从库上报版本与策略预期版本可能跨多个版本段，旧版本字段缺失、新版本新增必填字段都必须被显式裁决而不是静默丢弃或覆盖。

任务环境与准备：
确认 Windows 本地已安装 Python 3.11 或以上版本，并可使用 venv 创建隔离虚拟环境。
在虚拟环境中安装 FastAPI、uvicorn、NumPy 与 pytest，版本以本地可安装的稳定版为准，不依赖外部数据库服务。
在工作区准备固定本地确定性样本：一份策略样本、一份延迟观测样本、一份旧版本降级样本与一份含未知必填字段的高版本样本，均以文件形式随项目提供。
本机允许监听 127.0.0.1 的本地回环端口用于 HTTP 接口，SQLite 数据库文件位于工作区目录内。
准备一个用于模拟强制终止的本地演示流程说明，演示脚本以子进程方式启动服务并在指定阶段终止进程。

业务要求：
1. 实现策略数据集与观测样本的加载与归一化：解析量纲为毫秒整数与版本段字符串（形如 8.0.32-24）的字段，延迟阈值与可容忍延迟必须为非负整数且可容忍延迟不小于判定阈值，不满足时返回业务码 E_POLICY_INVALID；版本段解析为可比较的数值元组并保留原始字符串用于回显，无法解析的版本返回 E_VERSION_MALFORMED。
2. 实现两种持久化格式的编解码：紧凑二进制格式含魔数、版本字节、每条记录长度前缀、CRC32 校验与可选字段存在位图；分片 JSON 行格式每行含策略标识、复制组、阈值、可容忍延迟、预期版本、降级动作与毫秒级更新时间；两种格式往返导出导入后，策略数据集必须逐字段等价，除时间精度按声明的截断规则归一化外不得丢失任何字段。
3. 实现格式协商与版本兼容裁决：导入前检测输入格式与版本，按显式声明的兼容矩阵给出接受、降级接受或拒绝的结论；旧版本缺字段的数据走降级接受并补齐为声明的默认值并记录降级明细，高版本含未知必填字段的数据返回 E_FORMAT_INCOMPATIBLE 且整批不导入；协商结论须随导入报告输出。
4. 实现跨版本从库观测的状态判定：将从库上报版本与策略预期版本按版本段规则比较，判定为低于、等于或高于预期；高于预期时若策略未声明前向兼容则标记为需人工复核并返回业务码 E_VERSION_AHEAD，低于预期时按延迟阈值给出延迟状态；同一从库在同一采样时刻的多条观测按位点差最大者为准，不得因到达顺序不同产生不同状态。
5. 实现导入冲突解决与批次原子生效：导入策略与现有策略标识相同时，按版本号、优先级与最后写入时间打破平局的确定规则解决，结局分为覆盖、跳过与拒绝三类并写入导入报告；整批导入必须原子生效，任一条被拒绝则整批回滚且不改变现有数据集。
6. 实现主从延迟状态机与降级动作裁决，状态至少包含 HEALTHY、DELAYED、DEGRADED、RESTORED 四种并规定合法迁移路径，非法迁移返回 E_INVALID_TRANSITION 且不修改已持久化状态；由连续延迟观测窗口与可容忍延迟共同驱动迁移，降级动作须与状态和优先级一致地裁决并输出触发依据。
7. 使用 SQLite 持久化策略数据集、观测样本、状态与意图日志，写操作先写意图记录再提交事务；进程在导入或状态重算中途被强制终止后重启须扫描未完成意图，把数据集回滚到最后一个完整版本或把批次标记为已中止，恢复报告只包含已持久化事实，不承诺强制终止后仍生成完整退出报告。
8. 实现单写者并发控制与统一错误响应：策略编辑、导入与状态重算按提交串行执行，多个只读查询可并发读取已提交版本；同一批次标识重复提交只执行一次、其余等待并复用结果；携带基础版本的增量编辑若基础版本非当前版本返回 E_STALE_BASE；所有失败响应为含业务码的 JSON，至少覆盖 E_POLICY_INVALID、E_VERSION_MALFORMED、E_FORMAT_INCOMPATIBLE、E_STALE_BASE、E_INVALID_TRANSITION。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
