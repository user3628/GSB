当前是空白工作区，需要在 Windows 本地从零构建一个面向本地模型服务的推理网关路由组件，交付数据处理管线与结果验证工具。网关接收推理请求（请求标识、模型标识、输入样本数、期望延迟上限毫秒、优先级、租户标识），依据带版本号的模型路由表把请求路由到本地模型后端测试端点（以本地 HTTP 测试服务模拟，具备确定性延迟与显存占用语义），并在全局并发上游上限、每后端并发上限与每轮时间预算的多重约束下并行调度。调度需同时维护请求状态在 PENDING、QUEUED、DISPATCHED、COMPLETED、FAILED、SHED 之间的演进，记录每个后端的显存预算与在途计数，产出每轮调度轨迹与结果验证报告。核心难点在于并行调度与资源预算高度耦合：预算耗尽时的降级顺序、后端显存与并发上限同时约束时的准入裁决、请求取消与超时后的真实资源释放，以及进程被强制终止后基于持久化事实恢复在途请求，任一环节不一致都会导致结果验证工具判定失败。

任务环境与准备：
确认 Windows 本地已安装 Python 3.11 及以上版本，并可在命令行调用 python 与 pip。
在空白工作区创建虚拟环境并安装 fastapi、uvicorn、numpy、pytest 与 requests，记录安装命令与版本以便复现。
准备本地确定性样本：两份模型路由表 JSON（含版本号、后端端点与显存预算）、请求批次样本（含优先级与租户标识）以及固定随机种子的输入样本张量。
准备本地模型后端测试服务脚本，能够按模型标识返回确定性延迟、显存占用标识与可注入的成功、失败、挂起三类响应，监听本地回环端口。
确认本地 SQLite 可用（Python 标准库 sqlite3 即可），并预留本地回环端口用于网关 API 与模型后端测试服务。

业务要求：
1. 实现模型路由表与服务规格模型：路由表为带单调递增版本号、生成时间、模型到后端端点映射、每后端显存预算与并发上限、整体校验摘要的本地 JSON；提交时若版本号不大于当前已提交版本则返回 E_STALE_ROUTE，校验摘要失败返回 E_ROUTE_INVALID，加载须整体替换旧版本且不得混用新旧后端规格。
2. 实现请求准入与状态机：定义 PENDING、QUEUED、DISPATCHED、COMPLETED、FAILED、SHED 六种状态与合法迁移路径，非法迁移返回 E_INVALID_TRANSITION 且不改动已持久化状态；准入须同时校验全局并发上限、目标后端并发上限与请求样本数折算的显存需求，任一不足时进入有界等待队列或返回 E_CAPACITY_EXCEEDED 并附当前余量明细。
3. 实现并行调度器：以全局上游并发上限与每轮时间预算双重约束推进，预算内按优先级与租户轮转取请求，超出上限者进入有界队列，队列满返回 E_QUEUE_FULL；同一后端同一请求不得被重复派发，同一轮内派发决策须确定性可复现，并输出本轮派发顺序、被跳过请求清单与跳过原因（容量不足、预算耗尽或队列溢出）。
4. 实现真实超时与资源释放：每个派发到本地模型后端的请求具备独立超时，超时后必须真实关闭 HTTP 客户端连接并释放其占用的后端并发名额与显存预留，不得以等待冒充超时，也不得把线程超时描述为已终止失控代码；挂起请求不得阻塞其他派发，超时须计入后端失败统计并可能触发后端熔断降级返回 E_BACKEND_DEGRADED。
5. 实现预算耗尽降级裁决：当时间预算或后端容量不足以覆盖全部待处理请求时，按优先级、租户公平轮转与已消耗预算给出确定性降级顺序，被降级请求迁移为 SHED 并附降级依据；降级后仍须保证已派发请求不被无谓中断，且降级不得使在途并发超过任何上限，查询须能区分被跳过与因超时失败的不同结局。
6. 实现跨模块一致与幂等：请求准入、后端在途计数、显存预留与调度派发须共同生效，禁止出现请求已 DISPATCHED 而后端在途计数未增加、或请求已 COMPLETED 而显存预留未释放的中间可见状态；同一请求标识重复提交只处理一次、其余等待复用结果，内容不一致返回 E_CONFLICTING_REQUEST；查询只能看到某一完整提交版本。
7. 使用 SQLite 持久化路由版本、请求状态、后端预留与每轮调度记录，写操作先落意图记录再提交事务；进程在派发或释放中途被强制终止后重启须扫描未完成意图，把在途请求恢复为 QUEUED 重排或标记为 ABORTED，并重建后端在途计数与显存预留使之一致，恢复报告只基于已持久化事实，不得承诺强制终止后仍生成完整退出报告。
8. 提供数据处理管线与结果验证工具：本地 HTTP API 覆盖路由表提交、请求提交与批量回放、按轮次查询调度轨迹与后端状态、查询恢复报告，统一失败响应为含业务码的 JSON（至少覆盖 E_STALE_ROUTE、E_ROUTE_INVALID、E_CAPACITY_EXCEEDED、E_QUEUE_FULL、E_CONFLICTING_REQUEST、E_BACKEND_DEGRADED）；验证工具读取持久化状态，检查在途计数与显存预留闭合、状态迁移合法性与预算未越界并输出结构化结论，附固定本地样本与本地模型后端测试端点的端到端脚本，输出两轮调度轨迹与验证结论。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地模型后端样本完成并行派发、预算降级、超时释放与强制终止恢复，输出调度轨迹由验证工具判定一致。
