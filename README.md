在 Windows 空白工作区中，需要从零构建一个面向本地分块列存文件的拉取式点查服务，交付数据处理管线与结果验证工具。与整段扫描不同，业务侧以“分页拉取”的方式消费结果：客户端先提交点查请求（主键等值集合、需要的列、可接受页大小与结果截止时间），服务端返回一个结果句柄与首页；随后客户端反复调用拉取接口取后续页，直到结果耗尽。服务端需按主键范围把请求切成取数任务，在全局并发上限、单任务内存预算与整轮时间预算三重约束下调度，解压编码块后按主键过滤并投影，把命中的行按主键稳定顺序写入分页结果缓冲。核心业务问题是拉取式会话的预算裁决与分页边界恢复：页是在多次拉取之间逐步物化的，会话可能在两次拉取之间被强制终止；重启后已物化的页必须可继续拉取，未完成的主键范围必须重新排队，且继续拉取得到的页序列与从未中断时逐页逐行一致。所有数据来自本地确定性样本，无外部依赖。

任务环境与准备：
确认 Windows 上可用 Python 3.11 及以上版本，并可使用 venv 创建隔离虚拟环境。
在虚拟环境中安装 fastapi、uvicorn、numpy 与 pytest，版本固定写入依赖清单。
准备本地确定性分块列存样本与三种编码的块样本，包含空值位图、跨块主键命中、损坏块样本与不同解压开销分布。
启动本地 uvicorn 服务前确认 SQLite 可写目录与分页结果缓冲临时目录存在，端口使用本机未占用的回环端口。

业务要求：
1. 实现分块列存文件加载与版本识别：文件声明单调递增版本号、生成时间、列定义（数据类型与空值位图）、按主键升序排列的行分块索引与整体校验摘要；加载时校验版本单调与摘要，失败返回 E_SNAPSHOT_INVALID 并保留旧文件可继续服务，加载成功后整体替换，不得把新旧文件的分块索引混合使用。
2. 实现三种编码块的解码：定长编码、游程编码与字典编码各提供确定性解码，解码前校验块头的主键区间、原始行数、编码类型与摘要，损坏块返回 E_BLOCK_CORRUPT 并指明块号；解码结果须带空值位图与行内主键升序偏移，同一块多次解码得到逐位一致的行值。
3. 实现点查取数任务切分：按目标主键集合在升序主键空间中定位命中的分块，把相邻命中块合并为取数任务并保证任务间主键区间不重叠且覆盖全部命中块；主键集合为空时返回空结果句柄而非错误，主键集合数量超过配置阈值时返回 E_QUERY_TOO_LARGE 并附当前上限，任务切分结果须输出供预算裁决使用。
4. 实现三重预算调度：取数任务在全局并发上限、单任务内存预算与整轮时间预算约束下执行；预算内按主键区间升序取任务，超并发上限者进入有界等待队列，队列满返回 E_SCAN_QUEUE_FULL；单任务解压后内存估计超过单任务预算时须按块内行范围拆分为子任务重试或降级跳过并记录原因，轮时间预算耗尽时剩余任务标记为未执行而非静默丢弃，裁决轨迹输出选择依据与任务编号。
5. 实现拉取式分页会话：提交查询返回结果句柄、总命中估计与首页，后续拉取按页序号递增返回，页大小受客户端可接受页大小与配置上限共同约束；首次拉取必须在结果截止内给出首页或明确告知尚未就绪，页边界不得切断同一主键的命中行；页序号越界或对已耗尽句柄继续拉取返回 E_PAGE_OUT_OF_RANGE，不可续拉时返回确定的耗尽状态而非空页混淆。
6. 实现会话部分结果持久化与强制终止后恢复：每个取数任务完成并把命中行写入分页结果缓冲后先写意图记录再提交，已物化页与会话进度（下一个可取页序号与已消费主键上界）一并持久化；进程被强制终止后重启须扫描未完成意图，把已提交任务标记为可复用、未提交任务恢复为就绪并继续物化，恢复报告只基于已持久化事实，已完成任务不得重算，也不得承诺强制终止后仍生成完整退出报告。
7. 实现单写者物化与多读者拉取的并发一致：同一会话的结果缓冲写入与页提交按会话单写者串行，多个只读查询（页状态、已物化页数、任务进度）可并发；同一页被并发拉取时只允许一个客户端消费该页，其余返回 E_PAGE_CONSUMED；同一查询标识重复提交只创建一个会话、其余等待复用句柄，内容不一致返回 E_CONFLICTING_QUERY；查询不得看到某页已可拉取而其预算占用尚未登记的中间状态。
8. 提供稳定归并分页、统一错误码与本地结果验证工具：命中行按主键升序稳定归并，分页拼接后的行集合必须与不分页一次取尽的结果逐行一致且不重不漏；失败响应为含业务码的 JSON，至少覆盖 E_SNAPSHOT_INVALID、E_BLOCK_CORRUPT、E_SCAN_QUEUE_FULL、E_PAGE_OUT_OF_RANGE、E_CONFLICTING_QUERY；验证工具用同一固定样本分别执行一次不间断分页拉取与一次中途强制终止后恢复继续拉取，逐页逐行比对并输出预算裁决轨迹。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用固定样本比对中断恢复后续拉的分页结果与不间断拉取逐页逐行一致，并核验裁决轨迹与业务码。
