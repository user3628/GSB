当前为空工作区，需从零构建一个本地可运行的指令微调数据构造与诊断工作台，面向 LLM 指令数据的质量度量与构造流水线。输入为本地确定性 JSONL 指令样本，每条含 id、instruction、input、output、source、lang 与可选质量标注分；由固定随机种子的本地生成器产出，覆盖中英混排、长输出、重复指令模板与少量异常样本。流水线按四个阶段执行：规范化与去重（Unicode NFKC、空白折叠、指令-输入-输出拼接指纹与近似重复判定）、逐样本质量评分（长度惩罚、指令输出词汇重叠、模板多样性、来源先验加权的加权几何均值）、语料级配比与采样（按 source 与 lang 分层、目标权重按最大余数法分配）、构造混合集并与标注分做一致性校验。所有评分与聚合在对数域与定点量化下计算，需要提供误差来源分解。工作台需输出各阶段产物摘要、版本指纹、误差传播诊断与混合集统计，支持停止、恢复、增量重算与并发发布保护。

任务环境与准备：
安装 Python 3.11 或以上版本，并创建本地虚拟环境。
安装 NumPy 与 FastAPI，版本以本地 wheel 或离线可获取的最新稳定版为准，安装后记录版本号。
确认工作区为空目录，由本地固定随机种子的生成器脚本产出至少 3 个 JSONL 指令分片与可选的标注分文件。
准备可写的本地工作目录用于检查点、锁文件与混合集输出，并确认文件锁在当前 Windows 文件系统上可用。

业务要求：
1. 实现规范化与近似去重阶段：对每条样本做 Unicode NFKC、空白折叠与小写化后，以指令+分隔符+输入+分隔符+输出拼接文本计算 64 位 SimHash，并用 4 个 16 位桶索引候选、海明距离阈值确认近似重复；同输入同参数必须得到逐字节一致的分组与保留集合。
2. 实现逐样本多因子质量评分：将长度惩罚、指令与输出词汇重叠率、模板多样性、来源先验按可配置权重合成，采用加权几何均值并要求全程在对数域计算；任一因子为零或空样本须回退到可配置下限并记录回退原因，禁止直接连乘产生下溢。
3. 实现数值精度与误差传播诊断：对每个样本输出各因子对最终分值的对数贡献、定点量化误差界与结果有效位数；当出现 NaN、Inf 或非正因子时以业务码 E_NUMERIC 报告样本 id 与因子名；语料级聚合须说明顺序求和与成对求和的差异并给出与高精度参考的偏差上界。
4. 实现分层配比与采样阶段：按 source 与 lang 计算保留样本数与 token 估计（按空白切分为近似 token），依据目标权重以最大余数法分配采样数并处理余数并列的确定性裁决；输出各层分配数、实际采样数与混合集，并保证同输入同配置结果逐字节一致。
5. 实现质量分数与标注分的一致性校验：将逐样本质量分与可选标注分做分桶比较，输出分桶偏差、Spearman 秩相关与越界样本清单；当偏差超过可配置阈值时须标记该 source 的权重为待复核并给出复核建议，不得静默通过或直接丢弃样本。
6. 实现版本指纹与增量失效传播：当样本内容、去重参数、评分权重、配比权重或量化精度任一变化时，计算各阶段版本指纹并识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建；未受影响上游产物继续复用，失效原因与指纹须在查询接口中可观测。
7. 实现持久化检查点、优雅停止与并发发布保护：每阶段完成时以原子方式写入含阶段名、输入指纹、配置版本、产物摘要与单调序号的记录，任意时刻中断不得留下半写记录；收到停止请求时完成当前不可拆分单元后退出，恢复后最终混合集须与一次完整运行逐字节一致；多进程发布须用文件锁与序号比较，落后或重复发布返回 E_STALE_CHECKPOINT，缺前置产物返回 E_INVALID_STAGE。
8. 提供本地 HTTP 与命令行诊断工作台：支持导入样本、查看各阶段状态与版本指纹、查询误差传播诊断与配比明细、请求停止、执行恢复、导出混合集；演示数据至少含 3 个分片、中英混排、跨分片近似重复与异常样本，一次完整运行生成固定摘要，并用注入的非法量化精度、越界权重与缺前置阶段请求验证业务错误码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证去重、评分、配比、误差诊断与停止恢复一致性，并核对异常注入的业务错误码。
