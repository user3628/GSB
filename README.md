这项需求没有既有代码，需要在 Windows 空白工作区中从零构建一个面向本地对象存储场景的分片上传事务日志与元数据重建引擎。对象以对象键唯一标识，上传会话把对象切分为有序分片，每个分片携带序号、字节大小、SHA-256 摘要与到达毫秒时刻，组件维护上传会话、分片记录与对象元数据（键、总大小、分片数、对象摘要与上传代际）。真实运维中存在大量并发上传同一对象键、分片乱序到达、取消与重传、进程被强制终止等情形，因此需要在 SQLite 之上实现可重放的事务日志与可验证的元数据重建：写入、合并与取消先追加意图记录再提交数据事务，重启后依据持久化日志重建一致状态并输出恢复报告。此外，同一对象键在任意时刻只允许一个生效上传会话，取消或超过存活期的会话必须被回收并使其分片不再计入任何重建结果，系统还需在全局并发分片校验上限与每轮时间预算下完成合并前的摘要复核。

任务环境与准备：
Windows 环境，安装 Go 1.22 或以上，并确保 go 命令在 PATH 中。
使用 go mod init 初始化模块，依赖仅使用标准库与本地可用的 SQLite 驱动（如 modernc.org/sqlite），安装命令示例：go get modernc.org/sqlite。
准备固定本地样本文件：若干对象键、分片内容与摘要、到达时刻与乱序提交序列，放入工作区 samples 目录。
无需外部账号或网络服务，所有测试通过本地回环 HTTP 接口与 SQLite 文件完成。

业务要求：
1. 实现上传会话与分片模型：会话记录对象键、会话标识、分片序号下界、存活期毫秒与状态，分片记录会话标识、序号、字节大小、SHA-256 摘要与到达毫秒时刻；发起会话时若同键已有进行中的未过期会话，按声明策略返回业务码 E_SESSION_CONFLICT 并附现有会话标识，不得静默覆盖。
2. 实现分片提交幂等与乱序容忍：同一会话同一序号的重复提交只计一次，内容摘要一致视为幂等成功并累计重复次数，摘要不一致返回 E_PART_MISMATCH 并保留首次提交；乱序到达的分片不得影响最终合并顺序与对象摘要，合并结果必须与按序号升序提交时逐位一致。
3. 实现事务日志与元数据重建：每次写入、合并与取消先向 SQLite 追加意图记录（含会话标识、分片序号、摘要与日志序号）再提交数据事务；提供重建入口，仅依据已提交数据与未完成意图重建会话状态、分片清单与对象元数据，重建结果须与中断前最后一次完整提交状态逐项一致，恢复报告只包含已落盘事实。
4. 实现同键会话代际与并发裁决：同一对象键的多个上传会话按代际序号区分，生效会话之外的分片不得计入重建与合并；同一键两个并发发起请求只允许一个成功，另一个返回 E_SESSION_CONFLICT；会话取消须在同一事务内迁移其分片为已作废并释放其占用的合并名额。
5. 实现在全局并发分片校验上限与每轮时间预算约束下的合并前摘要复核：复核任务按会话单写者调度，超并发上限的分片进入有界等待队列，队列满返回 E_VERIFY_QUEUE_FULL，预算耗尽时按确定性规则降级并输出被跳过分片清单；任一分片摘要复核失败返回 E_PART_MISMATCH 并整体中止本次合并，不得部分写入对象元数据。
6. 实现合并的原子提交与摘要一致性校验：合并前校验分片序号从下界连续无缺口、各分片摘要与已存记录一致、对象总大小等于各分片大小之和；任一项不满足返回对应业务码（至少含 E_PART_MISSING、E_SIZE_MISMATCH），成功时在同一事务内写入对象元数据与会话完成状态，同键重复合并只允许一次成功、其余返回已有结果。
7. 实现单写者提交与多读者查询的并发一致：分片提交、合并与取消按会话单写者串行执行，多个只读查询（会话状态、分片清单、对象元数据、恢复报告）可并发且只能看到某一完整提交版本；查询不得看到会话已标记完成而其对象元数据尚未写入的中间状态，同一请求标识重复提交只执行一次、其余等待并复用结果，内容不一致返回 E_CONFLICTING_REQUEST。
8. 提供本地 HTTP API 与统一业务错误码 JSON 错误体：接口覆盖发起会话、提交分片、查询会话与分片清单、触发合并与重建、取消会话、查询恢复报告，失败响应含业务码与上下文，至少覆盖 E_SESSION_CONFLICT、E_PART_MISMATCH、E_PART_MISSING、E_SIZE_MISMATCH、E_VERIFY_QUEUE_FULL、E_CONFLICTING_REQUEST。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地固定样本验证乱序幂等提交、摘要复核与合并原子性，以及强制终止后仅凭持久化日志重建的一致状态与恢复报告。
