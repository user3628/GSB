当前是空白工作区，没有现存项目、代码或数据附件，需要从零实现一个面向本地列式计算引擎的聚合与窗口函数执行组件。组件接收分组聚合查询（分组键、聚合函数、分组参数）与窗口查询（分区键、排序键、窗口帧定义、排序偏移量），在本地列式数据表上以 NumPy 数组批量推进执行。真实引擎中聚合与窗口执行存在本质的算法取舍：分组聚合可以用排序后线性扫描，也可以用哈希表累积，窗口帧的滑动求和与滑动分位同样面临按帧重算与增量维护的选择；当数据规模、分组基数、窗口宽度差异悬殊时，单一算法会出现幂等退化或内存暴涨，必须按数据规模自动切换算法并保持数值结果一致。组件还需在多窗口并发、批次间状态演进与异常中断下保持结果可复现。

任务环境与准备：
安装 Python 3.11 与 NumPy 1.26，使用标准库 sqlite3 与 http.server，无需外部服务或网络
在空白工作区准备项目目录与 pytest 运行环境，固定随机种子，样本数据由内置生成器本地生成
确认本地临时目录可写用于批次落盘与 SQLite 数据库文件，全部测试可离线执行

业务要求：
1. 实现列式数据载入与聚合、窗口查询描述的校验：数据表以列名到 NumPy 数组的映射及元数据（行数、列类型、列基数、空值计数）描述，聚合查询含分组键列表、聚合函数列表、是否含空分组标记，窗口查询含分区键、排序键、窗口帧下界与上界偏移量、窗口内聚合函数。须校验列存在、类型可聚合、窗口帧偏移合法与非负，非法描述返回固定业务码 E_BAD_QUERY 且不进入执行。
2. 实现分组聚合的两种算法与规模自适应切换：提供排序扫描与哈希累积两条执行路径，分组基数低于行数的配置比例阈值时用哈希累积，超阈值时用排序扫描；两条路径对相同输入在分组键确定次序归一化后必须逐值相等，含空键分组、全空聚合列与无行输入等边界。切换阈值与所选路径须写入执行报告。
3. 实现窗口帧计算的按帧重算与增量维护两条路径：滑动求和使用增量维护（进入帧加、离开帧减），滑动分位使用按帧重算，窗口宽度超过配置的最大增量帧宽或分位计算时须自动选用对应路径；两条路径对相同输入逐值相等，含分区边界、排序键重复与空值排序位置等边界，并记录所选路径。
4. 实现排序键的稳定序与重复键归一：排序键重复时，分区内须按稳定次序（原始行序）定序，使窗口帧在重复键上的包含关系确定；分组键与排序键含空值时须按显式声明的空值排序方向处理，同一查询在任意算法路径下产出相同窗口结果，排序键与窗口帧偏移非法组合须返回 E_WINDOW_FRAME。
5. 实现数值精度控制与结果一致性校验：浮点聚合结果按配置的十进制有效位定点输出，滑动求和的增量路径须输出与按帧重算路径的偏差上界并以十进制定点字符串给出；当偏差超过配置容差时须在报告中标记并回退为按帧重算路径，且最终结果须与回退前一致，同时输出回退触发位置。
6. 实现批次推进与已提交结果游标：执行按配置的向量批量推进，每完成一批须在单个 SQLite 事务中写入批次序号、阶段标识、已产出的完整结果批次与中间聚合状态摘要，事务提交后才允许游标读取；中断或失败时未提交批次不得可见，重读同一游标位置须返回相同内容。
7. 实现并发会话隔离与规模变化的快照一致性：多个查询会话可并发推进，每个会话开始时固定数据版本与参数版本，中途版本变化须以 E_SNAPSHOT_STALE 终止并保留已提交批次；所有会话共享的内存额度与临时落盘目录须互不干扰，额度超限须有序中断并返回 E_BUDGET_EXHAUSTED，中断后其他会话结果不受影响。
8. 提供本地 HTTP 接口、确定性样本与完整示例：通过本地 HTTP 提供提交聚合查询、提交窗口查询、推进一批、查询批次清单与执行报告、创建并推进游标的接口，错误统一以固定业务码在 JSON 中返回；内置固定随机种子的样本生成器生成至少四组规模差异明显的数据（极小分组、极大分组基数、极宽窗口、全重复排序键），示例展示算法切换、精度回退与并发隔离。
