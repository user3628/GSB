在 Windows 空白工作区中，需要从零构建一个面向本地可观测性数据集的 SLI/SLO 错误预算计算组件，供 SRE 团队集成到告警与预算评审流程。组件接收按时间窗口聚合的请求事件（时间戳、服务名、SLI 类型、是否良好事件），计算滑动窗口 SLI、错误预算消耗，并基于多窗口（如 5 分钟短窗口与 1 小时长窗口）燃烧率触发分级告警。数据规模会从少量样本突增到较大批量，算法需在精确计算与近似采样之间取舍，同时必须保证多窗口之间预算消耗的一致性、窗口边界对齐以及迟到事件对已关闭窗口影响的正确处理。用户通过本地 HTTP API 提交样本、查询预算与告警，并附带完整示例脚本。

任务环境与准备：
安装 Python 3.11 或更高版本，确保 python 与 pip 可在 PowerShell 中直接调用。
安装依赖：pip install fastapi uvicorn numpy pytest httpx。
确认 SQLite 由 Python 标准库 sqlite3 提供，无需额外安装。
准备本地固定样本文件（如 events_small.jsonl 与 events_large.jsonl），事件时间戳覆盖至少两小时窗口，样本内容确定且可重复生成。
在 PowerShell 中通过 uvicorn 启动本地 HTTP 服务，所有数据写入工作区内的 data 目录。
测试强制终止恢复时，使用任务管理器或 Stop-Process 结束进程，并验证重启后读取持久化状态。

业务要求：
1. 实现事件摄入与窗口模型：接收包含时间戳、服务名、SLI 类型与是否良好事件的事件批次，按固定窗口长度（可配置为 1 分钟）与滑动步长将事件分配到带版本的时间桶中；每个桶记录良好事件数、总事件数与最后更新时间，时间戳乱序或超出可接受迟到范围时返回业务码 E_LATE_EVENT 且不改动桶计数。
2. 实现多窗口 SLI 与错误预算计算：至少支持 5 分钟、30 分钟、1 小时三种滑动窗口，对每窗口按良好事件率计算 SLI，并结合 SLO 目标（如 99.9%）计算错误预算消耗比例；当窗口内总事件数低于配置的最小样本量时，返回业务码 E_INSUFFICIENT_DATA 并在响应中给出当前样本量，不得以零样本计算 SLI。
3. 实现误差可控的采样取舍：当单窗口事件数超过配置的精确计算上限时，可对事件进行均匀时间分桶采样或蓄水池采样，但必须输出采样率、采样方法与估计的 SLI 置信区间；精确计算与采样计算的结果差异应在声明的置信区间内，且同一输入快照多次查询得到逐位一致的采样结果。
4. 实现多窗口燃烧率告警与跨窗口一致性：燃烧率由短窗口与长窗口的 SLI 共同判定（例如短窗口燃烧率超阈值且长窗口燃烧率同向超阈值才触发），告警状态包含 OK、WARNING、CRITICAL；当同一服务不同窗口的预算消耗汇总必须等于该服务总预算消耗，不得因窗口重叠而重复计入或遗漏。
5. 实现迟到事件与已关闭窗口处理：定义窗口关闭规则（窗口结束时间加迟到容忍期），进入关闭状态的窗口不得再被修改；迟到事件若落入已关闭窗口，按确定规则计入下一可用窗口或返回 E_LATE_EVENT 并记录拒绝原因，拒绝不得破坏已关闭窗口的预算快照。
6. 实现并发摄入与查询一致性：服务端以单写者串行执行事件摄入与窗口重算，允许多个查询并发读取已提交的窗口与告警状态；查询看到的是某一完整提交版本，不得看到部分事件已写入而预算未更新的中间状态；并发触发同一窗口重算时仅一个执行，其余等待复用结果。
7. 实现持久化与强制终止恢复：窗口、事件计数与告警状态持久化到 SQLite，写操作先落意图记录再提交；进程在窗口重算中途被强制终止后重启必须扫描未完成意图，将窗口恢复到最后一个完整版本或标记为待重算，并输出基于持久化事实的恢复报告；恢复报告不得承诺强制终止后仍生成完整退出报告。
8. 提供本地 HTTP API 与端到端示例脚本：API 覆盖事件摄入、按服务与窗口查询 SLI 与预算、燃烧率告警查询、恢复报告查询，统一错误响应为包含业务码的 JSON；示例脚本使用固定本地样本分别生成小规模（低于采样阈值）与大数据量（超过采样阈值）两个场景，输出各窗口 SLI、采样信息、预算消耗汇总、告警状态与一次强制终止后的恢复摘要，便于人工核验。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地固定样本验证多窗口 SLI、预算汇总一致、采样取舍及强制终止恢复，输出各窗口指标与恢复摘要。
