迁移方案落定之后，团队需要在本地工作区独立把多镜头运动推演的预测分片调度与误差审计组件写出来，当前目录没有任何既有实现。程序内置固定种子生成器在本地写出帧序列分片（低分辨率灰度帧，每段含匀速平移方块、缓慢变形色块与一次方向突变）与一份运动清单，逐序列声明初始位移与速度、加速度衰减系数、每步期望状态取值范围、预测步数与序列总帧数；另附一份带单调版本号的推演策略快照，声明全局并发分支上限、每分支步数配额、单轮时间预算、分支剪枝阈值与预测步数上界。真值帧由同一生成器可复现产出，作为误差比对的唯一来源。引擎按状态滚动推演、帧渲染、逐步误差审计、分支裁决汇总四阶段推进，在全局步数预算、单分支配额、峰值内存与每轮时间预算四重约束下调度推演分支，并把阶段进度、逐步误差与版本指纹写入 SQLite 供核对。

任务环境与准备：
安装 Go 1.22 或以上（含 go 命令行与标准库），使用 go mod init 初始化模块，不引入网络依赖。
通过 go get modernc.org/sqlite 或等效纯 Go SQLite 驱动提供本地数据库能力，确保无 CGO 依赖。
在工作区创建 samples 目录与输出目录，程序启动时由内置固定种子生成器写出帧序列分片、运动清单、推演策略快照与真值帧。
本地 HTTP 服务绑定回环地址的随机空闲端口，测试前先运行生成器产出一组确定性样本并记录其内容摘要。

业务要求：
1. 实现四阶段流水线：每条推演分支依次完成状态滚动推演、帧渲染、逐步误差审计、分支裁决汇总，阶段状态含阶段名、序列标识、分支号、已推进步数、输入内容指纹、策略版本与单调序号；非法阶段跳转、缺失前置阶段产物或重复进入已完成阶段须返回结构化业务码 E_PHASE_ORDER 并附序列标识与当前阶段，不得静默推进。
2. 实现分支调度器：以预测分支为调度单元，在全局步数预算、单分支步数配额、并行分支上限与每轮时间预算四重约束下决定接纳顺序与并发度；接纳前须依据运动清单的预测步数与剪枝阈值预估步数消耗与峰值工作集，超预算分支记录为未启动并给出原因与预算余量，预算回收后按原接纳顺序继续推进。
3. 实现确定性状态滚动推演与帧渲染内核：按清单初始位移、速度与衰减系数逐步更新状态，速度每步按衰减系数更新，依据状态对画布执行平移与形变变换并做双线性采样与 8 位量化输出预测帧；速度衰减系数为零或负、位移出现非有限值、期望状态取值范围越界或画布尺寸为零须在该步返回 E_MOTION_INVALID 与 E_NUMERIC，并保留序列标识、分支号与步号。
4. 实现逐步误差审计与分支对比：以真值帧为唯一来源，对每步预测帧计算逐像素平均绝对误差与逐步误差曲线，并横向对比各分支的误差轨迹与最终裁决；误差须由显式抽样位置与像素量化步长推导误差上界并输出有效位数，预测步数超出真值帧数时返回 E_TIME_RANGE 并附序列标识与超出帧数。
5. 实现剪枝裁决与容差判定：依据剪枝阈值在推演中途终止偏差过大的分支并回收其配额，剪枝后剩余分支的推演结果与配额使用须与从未派发被剪枝分支时逐字节一致，剪枝依据可追溯；单步误差超出可配置逐帧容差或分支最终误差超出端到端容差时返回 E_TOLERANCE_EXCEEDED 并附序列标识、分支号、步号与最大偏差。
6. 实现异常输入注入：注入入口须支持帧序列含 NaN、画布尺寸为零、速度衰减系数非正、预测步数超过上界、真值帧数与序列总帧数不符与空分片等情况，各注入在对应环节返回稳定的 E_MOTION_INVALID、E_NUMERIC、E_SHAPE_MISMATCH、E_TIME_RANGE 与 E_EMPTY_SHARD，同一注入不得在不同阶段产生不同码。
7. 实现 SQLite 事务化状态与恢复边界：阶段进度、逐步误差与版本指纹在同一事务内写入，同一分支同一步同一版本只允许一条有效记录；收到停止请求时完成当前不可拆分的推演步后退出，被强制终止后重启仅凭已提交事实重建进度，不承诺生成退出报告，恢复后的逐步误差与裁决结论须与一次连续执行逐字节一致。
8. 实现并发发布互斥、版本指纹与整体替换识别：当帧序列内容、运动清单、推演策略或剪枝阈值任一变化时，由各阶段内容摘要构成版本指纹并定位受影响的最早阶段与最早步号，使该步及其全部下游产物失效重建；多工作进程发布时使用 SQLite 条件更新与真实文件锁并比较分支内序号，仅允许序号连续推进，落后、重复或跨分支错位发布以及记录被整体替换（序号回退、指纹变化或摘要不匹配）返回 E_STALE_PUBLISH 并附当前生效序号，仅正常推进被接受。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地帧序列驱动四阶段推演与分支调度，核验逐步误差上界、剪枝一致性、异常码与强制终止后的恢复一致性。
