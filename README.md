当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的多模态协同推理数据编辑与操作应用，核心问题是可复现验证与异常注入。输入为固定随机种子生成器产出的本地确定性样本：一组文本片段 JSONL（含 text_id、文本、语言标签、来源通道）与一组图像描述片段 JSON（含 image_id、小尺寸 PNG 文件名、64 维视觉特征向量、对应 text_id、来源算子标签），文本与图像通过 text_id 关联，覆盖中英混排、一对多关联、缺失关联与少量重复样本。应用按四个阶段推进：文本编码（规范化后固定哈希嵌入）、跨模态投影对齐（视觉特征投影到文本空间并计算余弦相似度）、融合打分（相似度、来源算子置信度与语言一致性加权合成协同结论）、结果聚合（按样本汇总一致/弱一致/冲突及诊断明细）。应用需提供本地 HTTP 与命令行编辑入口，支持编辑文本与特征、执行分阶段构建、查询状态与版本指纹、请求优雅停止与恢复，并在参数注入下返回稳定业务错误码。运行不依赖真实模型、GPU、外部服务或网络。

任务环境与准备：
安装 Python 3.11 并在项目根创建虚拟环境，安装 fastapi、uvicorn、numpy、pillow、pytest 与 pyyaml 等依赖。
使用固定随机种子的本地生成器在 data/ 下产出文本片段 JSONL、图像描述 JSON 与对应小尺寸 PNG，无需网络与 GPU。
确认工作目录具备可写权限以创建工作区、锁文件与检查点目录；在 Windows 本地运行 uvicorn 与命令行入口，不使用任何容器环境。

业务要求：
1. 实现文本规范化与固定哈希编码阶段：对每条文本做 Unicode NFKC、空白折叠、全半角统一与小写化，以固定哈希函数生成 64 维单位嵌入并记录分词偏移；空文本、仅含标点或嵌入为零向量时须返回带 text_id 与字段名的 E_EMPTY_INPUT，不得静默产出零向量参与后续计算。同一输入与配置必须逐字节一致。
2. 实现跨模态投影对齐阶段：按配置投影矩阵把 64 维视觉特征映射到文本空间并做单位归一化，计算与对应文本嵌入的余弦相似度；投影矩阵维度与特征维度不符、对应 text_id 不存在或相似度出现 NaN/Inf 时返回带 image_id 与阶段的 E_PROJECTION_INVALID 或 E_MISSING_REF，且诊断输出保留原始维度与缺失引用。
3. 实现融合打分与协同结论聚合阶段：由相似度、来源算子置信度与语言一致性按可配置权重合成融合分，按阈值判定一致、弱一致、冲突三类结论并输出各分量对数贡献与权重和被跳过分量的重新归一化过程；全部分量不可用或权重和为零时返回 E_WEIGHT_ZERO 并保留诊断上下文，结论在同配置下逐字节一致。
4. 实现参数注入验证通道：提供注入入口支持非法投影维度、非法来源算子标签、超长文本（超过可配置字符上限）、相似度 NaN 与一对多关联缺失等情形，各注入须在对应阶段返回稳定业务码（E_PROJECTION_INVALID、E_INVALID_OPERATOR、E_TEXT_TOO_LONG、E_NUMERIC、E_MISSING_REF）并附样本标识与阶段名，不得使进程崩溃或返回不完整结果。
5. 实现阶段检查点持久化与优雅停止恢复：每阶段完成时以原子方式写入含阶段名、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分样本单元后退出，不承诺强制终止后生成退出报告；恢复时忽略损坏、不完整或序号重复记录，从最近一致检查点继续。
6. 实现版本变化检测与增量失效传播：当文本内容、视觉特征、投影矩阵、融合权重、置信度配置或结构版本任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；失效原因、指纹与重建结果须在查询接口中可观测，增量结果须与从零全量运行逐字节一致，不一致返回 E_INCREMENTAL_MISMATCH 并附差异定位。
7. 实现并发阶段发布保护与快照整体替换识别：多工作进程对同一工作区发布阶段产物时使用真实文件锁并比较检查点序号，仅允许序号连续推进，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_INVALID_STAGE；当检测到快照被整体替换（序号回退、指纹不符或摘要不匹配）时须区分回退、篡改与正常推进三种情形并分别裁决。
8. 提供本地 HTTP 与命令行交互应用及确定性演示：支持导入样本、编辑文本与特征、触发分阶段构建、查询各阶段状态与版本指纹、查看失效原因与协同结论、请求停止与执行恢复；演示数据至少 3 条文本片段与 3 条图像描述片段，含中英混排、一对多关联与至少 1 条缺失关联，完整运行生成固定摘要，并演示一次参数注入后的错误码与一次恢复后与全量运行的一致性比对。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
