当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的跨模态对齐检索组件及完整示例，供上层检索服务以库形式集成。输入为固定随机种子生成器产出的本地小尺寸 RGB PNG 分片（几何色块与渐变区域构成，含明暗差异视角）与一份 JSONL 图文对清单，每条含 item_id、image_file、caption（中英混排）、lang 与 source；系统不依赖任何真实视觉语言模型、GPU 或外部服务。组件需为每张图提取确定性视觉描述子（分块颜色均值、标准差与梯度方向直方图），为每条 caption 提取词袋与字符 n-gram 特征，经可配置投影矩阵映射到同一 64 维对齐空间后按可配置位宽做定点量化落盘，再据此建立双向检索索引并输出召回结果。核心难点在于定点量化引入的误差会沿投影、索引与相似度计算链路传播，召回排序对误差高度敏感，必须使量化配置变化可追溯、误差界可解释、增量更新后的召回结果与全量构建一致。交付物为可集成的领域组件、完整示例与可重复演示脚本。

任务环境与准备：
安装 Python 3.10 及以上，并安装 NumPy 与 Pillow（用于 PNG 读写与像素运算），按 lock 或 requirements 固定版本。
确认工作目录为空，可从零创建包结构、示例脚本与本地数据生成脚本；不依赖网络、GPU、真实模型或外部服务。
运行本地生成器产出小尺寸 PNG 分片与 JSONL 图文对清单，覆盖中英混排 caption、明暗差异视角与至少 8 位和 4 位两套量化配置所需的样本。
在本机准备可用的本地 HTTP 端口与临时工作区目录，用于演示并发文件锁、检查点写入与恢复流程。

业务要求：
1. 实现视觉描述子与文本特征提取阶段：图像按可配置网格切块，逐块计算颜色均值、标准差与梯度方向直方图并拼接为固定维度视觉特征；caption 经 Unicode NFKC、空白折叠与全半角统一后提取词袋与字符 n-gram 特征，并记录每个特征的来源偏移与权重；同一输入与配置必须产生逐字节一致的特征摘要，缺失图像文件或空 caption 须返回带 item_id 与字段名的 E_MISSING_INPUT 并保留在诊断输出中，不得静默跳过。
2. 实现跨模态投影与定点量化落盘：以可配置投影矩阵把视觉与文本特征映射到同一 64 维空间并做单位归一化，按可配置位宽（8 位或 4 位）与逐维或逐向量粒度做定点量化，每维记录缩放因子、零点与量化误差界；投影矩阵维度不匹配、含 NaN 或 Inf、位宽取非法值须返回 E_PROJECTION_INVALID 或 E_INVALID_BITWIDTH 并附 item_id 与维度信息，量化缩放因子为零时须显式报告而不得继续计算。
3. 实现误差传播追踪与有效位数诊断：对每个检索结果输出视觉路与文本路各自的对数贡献、量化引入的误差界与最终相似度的有效位数，并给出语料级误差界随分片规模变化的估计；误差界须由显式缩放因子、量化步长与本地高精度参考相似度共同给出，不得从缺失信息推断；当相似度出现 NaN、Inf 或误差界超出可配置上限时返回带 item_id 与阶段名的 E_NUMERIC 并保留诊断上下文。
4. 实现双向检索与相似度分解：支持文本检索图像与图像检索文本，排序按余弦相似度与倒排命中加权的可配置组合，输出 top-k 结果及每个结果的相似度分量、量化误差界与来源分片；k 超出索引规模、查询文本为空或查询投影维度不符时返回 E_INVALID_QUERY；同分结果须按 item_id 升序确定性排列，同一查询在相同配置下必须返回逐字节一致的 top-k 清单与分数明细。
5. 实现增量更新与全量一致性校验：当图像内容、caption、投影矩阵、量化位宽或排序权重任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游表征与索引失效并重建，未受影响上游表征继续复用；提供单分片更新入口，仅重建失效链路后与从零全量构建的特征摘要、量化向量与 top-k 清单做逐字节比对，不一致须返回 E_INCREMENTAL_MISMATCH 并附差异位置，失效原因须在查询接口中可观测。
6. 实现持久化阶段检查点与优雅停止恢复：每个分片按特征提取、投影量化、索引构建、召回校验四阶段完成时以原子方式写入含分片标识、阶段名、输入内容指纹、配置版本、量化参数指纹、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；进程收到停止请求时完成当前不可拆分分片单元后退出，不承诺强制终止后生成退出报告；恢复时必须忽略损坏或不完整记录，最终索引与召回摘要须与一次从零完整运行逐字节一致，且序号连续推进无跳跃。
7. 实现并发发布保护与快照整体替换识别：多个工作进程对同一工作区发布阶段产物时使用真实文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布须被拒绝并返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_INVALID_STAGE；当检测到检查点记录被整体替换（序号回退、输入指纹变化或产物摘要不匹配）时须识别版本变化并区分回退、篡改与正常推进三种情形，仅正常推进可被接受。
8. 提供本地 HTTP 与命令行交互应用及确定性演示：支持导入分片与清单、设置投影与量化配置、触发分阶段构建、执行双向检索并查看相似度分解与误差传播诊断、查询各阶段状态与版本指纹、请求停止、执行恢复、导出检索结果与诊断报告；演示数据至少 3 个图像分片与对应中英混排 caption，覆盖 8 位与 4 位两套量化配置，一次完整运行生成固定摘要，并演示一次量化位宽变更后的增量重建与全量摘要对比。
