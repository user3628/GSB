这次技术验证立项时工作区还是空的，团队要为本地回环环境的 VPN 隧道转发运维做一套分片重组与乱序缓冲引擎，验证隧道承载层的重组行为与带宽预算能否被稳定复现。与按会话绑定通道的转发思路不同，本引擎的核心对象是「隧道分片」：一条隧道上的大报文按声明分片大小切成带序号的分片，分片经本地 UDP 承载端乱序、重复、丢失地到达，接收侧按隧道维护乱序缓冲区，依据重排窗口、乱序容忍深度与每隧道带宽预算决定何时重组交付、何时触发快速重传请求、何时判定丢弃并上报缺口。运行中运维提交带版本号的重组策略快照与只含局部改动的增量片段，改动会使受影响隧道的缓冲水位、缺口视图与重组统计级联失效。难点在于乱序缓冲状态与带宽预算互相挤压：窗口过小会误判缺口，窗口过大则缓冲区与带宽被长尾分片长期占用，而进程可在任意时刻被强制终止，缓冲与缺口必须依据持久化事实恢复。所有分片样本由程序内置固定种子生成器产出，承载端为本地测试服务。

任务环境与准备：
安装 Go 1.22 或更高版本，并确认 go env 指向本地模块缓存；SQLite 使用纯 Go 驱动或本机已安装的 sqlite3 动态库，版本随驱动说明安装。
Windows 本地开放回环 UDP 端口供本地承载端测试服务监听，无需外部网络、真实账号或 VPN 设备。
运行时目录使用独立临时目录保存 SQLite 数据库文件、快照文件与演示产物，演示脚本以固定种子重新生成分片样本，保证重复运行结果一致。
执行前在命令行确认 go build 与 go test 可通过，演示脚本在 Windows 终端一次运行产出全部输出。

业务要求：
1. 实现隧道分片与重组策略快照模型：分片记录隧道标识、分片序号、分片总数字节、载荷字节数与校验摘要，策略快照含单调递增版本号、生成时间、重排窗口毫秒、乱序容忍深度、每隧道带宽预算字节每秒与整体校验摘要；加载时校验版本单调与摘要，失败返回 E_SNAPSHOT_INVALID 并保持旧快照完全可用，成功须整体替换并识别版本变化。
2. 实现分片校验与乱序缓冲区：按隧道标识独立维护乱序缓冲区，分片到达时校验序号范围与摘要，序号超出分片总数或摘要不符返回 E_FRAGMENT_INVALID 并指明字段；同一序号重复到达且摘要一致视为幂等重复并计入统计，摘要不一致返回 E_FRAGMENT_CONFLICT 并保留首次分片内容，缓冲区不得因重复或冲突分片改变重组结论。
3. 实现基于乱序容忍深度的重组交付裁决：当某隧道已连续收到自缺口起不超过乱序容忍深度的后继分片时暂不判定缺口，超过深度后按声明规则判定该序号缺失并把缺口视图固定下来；重排窗口到期前到达的迟到分片须能回填缺口并使缺口视图失效重算，禁止把已固定缺口在迟到分片到达后仍判定为丢失。
4. 实现每隧道带宽预算下的缓冲占用裁决：乱序缓冲中未重组载荷的总字节不得超过按每隧道带宽预算与重排窗口推导出的占用上限，逼近上限时按分片到达时刻与序号稳定次序计算可释放候选并输出释放依据，不得静默丢弃仍在容忍深度内的分片；预算不足时须返回 E_BUFFER_BUDGET_EXCEEDED 并附占用、上限与候选释放清单。
5. 实现缺口驱动的重传请求与预算联动：判定缺口后生成重传请求，但重传请求数量与频率受每隧道带宽预算与声明重传比例上限约束，超出时按缺口序号稳定次序给出确定性降级次序并返回 E_RETRANS_SHED 并附降级依据；重传请求须带隧道标识、缺口序号与请求序号，同一缺口重复请求须可被识别为重复而不重复占用预算。
6. 实现增量策略片段提交与级联失效：增量只含受影响的隧道或策略字段并携带基础版本，基础版本非当前已提交版本时返回 E_STALE_BASE 且不改变任何状态；受影响隧道的缓冲水位、缺口视图、释放候选与重组统计必须级联失效并在同一事务边界内原子重建，同一基础版本的两个并发增量只允许一个成功、另一个收到 E_STALE_BASE。
7. 实现单写者缓冲推进与多读者查询的并发一致及幂等：分片到达、重组交付、缺口固定与级联重建按隧道单写者串行执行，多个只读查询（缓冲水位、缺口视图、重组统计）可并发读取某一完整提交版本；同一请求标识重复提交只推进一次、其余等待并复用结果，内容不一致返回 E_CONFLICTING_REQUEST；查询不得看到缺口已判定而重传请求尚未落盘的中间状态。
8. 使用 SQLite 持久化策略版本、乱序缓冲条目、缺口视图、重传记录与意图日志，分片到达、重组交付、缺口固定与级联重建前先写意图记录再提交事务；进程在重组或级联重建中途被强制终止后重启须扫描未完成意图，把未提交分片回滚为未到达、未提交缺口回滚为可重算状态，恢复报告只包含已落盘事实并可据此续算。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地分片样本验证乱序缓冲重组、缺口回填、带宽预算裁决与强制终止后的缓冲恢复一致性。
