项目初始状态是空目录，需要为 Windows 主机安全基线构建一个进程隔离与能力限制的可复现验证组件。组件以本地确定性样本描述一组受测进程：每个进程声明启动命令、需要的能力令牌（文件读、文件写、子进程创建、注册表写）、限制目录与允许的子进程白名单。系统需要基于 Windows 作业对象（Job Object）与受限令牌在独立的临时工作目录中真实创建受限进程，验证越权操作被内核拒绝或组件主动拦截，并维护带版本号的能力策略快照以支持异常注入与强制终止后的恢复。组件需支持通过外部参数注入越权访问、能力泄漏、句柄继承逃逸、子进程越权与快照版本跳号五类异常，断言每个异常均产生稳定业务码且不污染已提交快照。所有样本、受限令牌与临时目录由组件内置生成器在本地产出，不依赖外部账号、网络或真实凭据。

任务环境与准备：
安装 Go 1.22 或更高版本（Windows amd64），配置 GOPATH 与模块代理为本地缓存模式，执行 go version 确认可用。
使用 CGO 启用的 GCC 工具链（如 mingw-w64）以支持对 Windows API 的 syscall 调用；执行 gcc --version 确认可用。
准备 SQLite 驱动依赖（如 go-sqlite3），版本固定并在 go.mod 中锁定；执行 go mod tidy 完成本地依赖缓存。
创建只放样本生成器与命令入口的空模块目录，所有确定性样本、受限令牌与临时工作目录由程序在运行时于系统临时目录下生成，不预置外部数据文件。

业务要求：
1. 实现能力策略模型与快照版本化存储：解析本地样本中的进程声明（启动命令、能力令牌集合、限制目录、子进程白名单），在 SQLite 中建立带递增版本号的策略快照表与进程记录表；每次策略加载或更新须在单个事务内提交新版本并整体保留旧快照，读取时校验版本链连续性，发现跳号返回 E_SNAPSHOT_VERSION 并回退到最近连续版本，快照内容比较须识别整体替换式版本变化而非仅比对版本号。
2. 实现基于 Windows 作业对象的进程隔离核心：对每个受测进程创建 Job Object 并设置活动进程数上限、关闭时终止作业与 UI 限制等基本限制，在独立临时工作目录中启动进程并将句柄关联到 Job；进程须使用受限令牌启动，确保其无法访问限制目录之外的文件路径；越权访问必须由内核或组件在真实边界上拒绝，不得以延迟或软判定代替真实隔离。
3. 实现能力令牌到实际权限的映射与越权拦截：把声明式能力令牌（文件读、文件写、子进程创建、注册表写）映射为对目标路径或对象的具体探测操作，在受限进程内执行探测并由父进程记录判定结果；当进程尝试白名单外的子进程创建或限制目录外的文件写入时返回稳定业务码 E_CAP_DENIED，并在输出中记录令牌、目标路径与原始错误码，区分内核拒绝与应用层拦截。
4. 实现句柄继承逃逸检测：在启动受测进程前显式关闭可继承句柄，测试受测进程是否仍能通过继承句柄访问限制目录之外的文件或命名管道；构造一个故意携带可继承句柄的父进程，断言子进程无法利用该句柄完成越权读写并返回 E_HANDLE_ESCAPE；检测须基于真实句柄表状态而不是模拟标志。
5. 实现异常注入验证链路：通过外部参数或配置文件构造越权文件写、白名单外子进程创建、可继承句柄逃逸、能力泄漏（进程获得未声明令牌）与快照版本跳号五类样本，分别断言对应业务码、受限进程实际被终止或操作被拒绝的终态、已提交快照未被污染；注入仅通过输入参数触发，不得修改源码制造失败。
6. 实现强制终止后的恢复一致性：在策略快照提交与进程启动之间或进程运行中被强制终止后重启，依赖 SQLite 已提交事务恢复策略版本与进程记录，已提交快照不回滚、未提交变更整体丢弃；重启后若发现版本链跳号须以 E_SNAPSHOT_VERSION 拒绝继续加载并保留最近连续快照供回放，强制终止后不承诺生成退出报告，恢复仅依赖持久化状态。
7. 实现并发验证会话的资源控制：多个受测进程可在独立会话中并发启动与探测，会话间作业对象与临时目录隔离；并发度、单会话进程数与单进程运行时长上限可配置，超并发上限的会话进入等待队列而非直接拒绝，单进程超时须通过 Job Object 终止其进程树并返回 E_PROCESS_TIMEOUT，所有等待与终止事件记录会话标识与原因。
8. 提供可集成的领域组件与完整示例：导出 Go 包接口供宿主安全服务接入（策略加载、进程验证、快照回放、报告导出），附带本地确定性样本生成入口与一键运行示例命令；导出的 JSON 报告包含策略版本链、每个受测进程的能力声明与实际判定、业务码、快照版本号与恢复结论，报告按进程标识与业务码稳定排序，重复运行且输入不变时报告字节级一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本验证受限进程真实隔离、越权拒绝、五类异常注入与强制终止恢复，报告字节级可重复。
