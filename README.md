当前为空白工作区，需从零构建一个本地可运行的 CTR 与 CVR 预估训练推理管线及可复现实验工作台，交付算法实现与可复现的实验环境。输入为固定随机种子生成器产出的本地 JSONL 样本分片：每条含 impression_id、user_features（若干数值与类别特征）、item_features、context 特征、CTR 标签（0/1）与可选的转化标签（0/1，仅当曝光为正时存在）、source 与 lang 字段；样本按分片组织并附一份分片清单声明每个分片的行数、正样本比例与缺失字段，作为显式观测。管线需完成特征哈希装配、双目标（CTR 与 CVR）逻辑回归训练、曝光到转化的漏斗一致性校验与推理打分四阶段，并以 ESMM 风格的联合思路约束 CTR 与 CVR 的关系。所有概率计算在对数域进行，样本、配置与随机种子均由本地生成器确定性产出，不依赖任何真实广告平台、线上服务或 GPU。

任务环境与准备：
确认工作区为空目录，安装 Python 3.10 及以上版本，并安装 numpy 与 pyyaml（离线可用本地轮子或已预装环境）。
准备本地确定性样本生成脚本的依赖仅为标准库与 numpy，运行前置检查脚本打印 Python 与依赖版本以确认可执行环境。
确认当前操作系统为 Windows，所有路径使用本地相对路径，不依赖任何外部服务、真实账号、GPU 或网络下载。
预留本地磁盘目录用于样本分片、检查点与实验输出，运行前以只读方式登记分片清单中的行数与正样本比例作为观测真值。

业务要求：
1. 实现特征哈希装配阶段：对类别特征做 Unicode NFKC、空白折叠与小写化后与数值分箱值一起以固定哈希函数映射到配置的特征维度，数值特征按分箱边界离散化并记录分箱命中；缺失字段须按显式缺失指示特征处理而非静默丢弃，同一输入与配置必须产生逐字节一致的特征指纹。
2. 实现双目标逻辑回归训练核心：以对数域批量梯度下降同时训练 CTR 与 CVR 两个目标，CVR 只在曝光为正的样本上计算损失，并按 ESMM 思路把 CVR 分数与 CTR 分数组合为转化率约束项参与总目标；逐轮记录两个目标的损失值、参数变化量与样本遍历顺序，参数以定点量化落盘并记录缩放因子。
3. 实现漏斗一致性校验：检查转化标签仅在 CTR 标签为正时出现、CVR 概率不大于对应 CTR 概率、样本级组合概率落在合法区间；违反时返回带 impression_id、校验项与违反值的 E_FUNNEL_VIOLATION 并保留在诊断输出，不得静默修正标签或截断概率。
4. 实现可配置的分片级训练与推理调度：以分片为单位，在全局最大训练轮次预算、单分片样本配额与并行工作进程上限三重约束下决定接纳顺序与并发度，接纳前依据分片清单行数预估消耗，超限分片记录为未处理并给出原因；累计消耗不得越界。
5. 实现并行执行与确定性归约：使用本地进程池并行处理已接纳分片，各分片结果按分片序号全局排序后归约，使并行运行的参数摘要、损失曲线与推理打分数值与单进程顺序执行逐字节一致；工作进程异常须以结构化错误对象记录并保留已完成分片结果，不得以线程超时描述为已终止失控计算。
6. 实现异常注入与稳定业务错误码一致性：提供参数注入入口，支持注入特征维度为零、分片清单行数与实际行数不符、CTR 标签非 0/1、CVR 标签为正而 CTR 标签为零、学习率或迭代轮数为负等情形；各异常须在对应阶段返回稳定业务码（E_INVALID_PARAM、E_MANIFEST_MISMATCH、E_LABEL_INVALID、E_FUNNEL_VIOLATION 等）并附分片标识与行位置。
7. 实现持久化检查点、配置版本指纹与增量失效传播：每阶段完成时以原子方式写入含阶段名、分片输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；当样本内容、特征维度、学习率、迭代轮数、置信阈值或组合约束权重变化时识别受影响的最早阶段并使其全部下游失效重建。
8. 提供可复现实验环境与本地 HTTP 及命令行工作台：支持导入分片与配置、触发分阶段训练推理、查询各阶段状态与版本指纹、查看损失曲线与漏斗校验明细、请求停止与执行恢复、导出模型参数与打分结果；两次相同配置运行须得到逐字节一致的目标指标摘要，演示中至少触发一次停止恢复与两次异常注入并展示结果一致性。
