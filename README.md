新立项的 GitOps 回滚收敛组件在空目录中起步，需要交付可集成的领域组件与完整示例：为本地 Kubernetes 风格集群判定对象漂移、组织带依赖约束的回滚收敛批次，并在本地回环 HTTP 端点上真实执行写回与回读核对。集群对象来自内置固定种子生成器产出的确定性 JSON 样本，每个对象声明标识、类别、命名空间、期望字段集合、实际字段集合、字段来源标记、依赖的其他对象与资源预算；回滚策略以带单调递增版本号的 JSON 快照提交，声明漂移判定容差、批次规模上限、单轮时间预算、最大并行写回批数与重试上限。真实场景中大量对象并发变更、依赖链较长且写回端点可能超时，必须对并行写回数量与每轮时间预算做严格裁决，并回答携带观察版本的读请求能否直接获得收敛结论。

任务环境与准备：
安装 Go 1.22 或更高版本（Ubuntu 可通过 apt 或官方二进制安装），配置 GOPATH 与模块代理；安装 SQLite 3 命令行工具用于检查持久化结果。
使用 go mod init 初始化模块，并引入 mattn/go-sqlite3 或 modernc.org/sqlite 作为 SQLite 驱动，版本在 go.mod 中固定。
编写固定种子生成器，在本地生成集群对象 JSON 样本、回滚策略快照、增量片段与观察版本查询样本，数据规模覆盖数十到数百对象与较长的依赖链。
启动本地回环 HTTP 测试端点，实现可配置的写回成功、返回错误、响应挂起与连接关闭行为，作为真实写回与回读核对的被测端点。
提供可重复执行的验证脚本，按顺序完成样本加载、漂移判定、批次组织、写回回读、增量提交、陈旧读拒绝与强制终止后恢复，并输出带业务码的 JSON 结果。

业务要求：
1. 实现集群对象与回滚策略快照的解析和归一化：对象声明标识、类别、命名空间、期望字段集合、实际字段集合、字段来源标记、依赖对象列表与资源预算；策略快照携带单调递增版本号、生成时间、漂移判定容差、批次规模上限、单轮时间预算毫秒、最大并行写回批数与重试上限，以及整体校验摘要。解析本地 JSON 样本时校验标识唯一、依赖引用存在、资源预算为非负整数，解析失败返回 E_SPEC_INVALID 并指明字段与对象标识，整批不入库。
2. 实现漂移判定核心：逐字段比较期望与实际字段集合，区分字段缺失、字段多余、取值偏移与来源冲突四类漂移，数值字段按策略声明的相对容差做定点比较而非裸浮点比较，同一对象命中多类漂移时按声明的稳定优先级给出主类别并保留全部命中明细；无漂移的对象不得进入回滚批次，漂移对象须输出类别、字段名与双方取值。
3. 实现依赖约束下的收敛与回滚批次组织：被依赖对象所在批次序号严格小于依赖者所在批次；依赖出现环时返回 E_DEPENDENCY_CYCLE 并附环上对象标识列表，环外对象仍须给出分层结果；批次规模受策略上限与对象资源预算约束，超限时拆分批次而非丢弃对象，并输出拆分依据与每批资源预算合计值。
4. 实现向本地回环测试端点的真实写回与回读核对：每次写回具备独立超时，超时后必须真实关闭底层 HTTP 连接并释放其占用的并行名额，返回 E_WRITE_TIMEOUT 并附批次标识与对象标识；写回成功后回读实际字段集合并重新判定漂移，仍存在漂移时返回 E_CONVERGE_FAILED 并按重试上限决定重试或标记失败，禁止用内存中的期望值冒充回读结果。
5. 实现带版本号的整份快照提交与增量片段提交及版本绑定：增量片段只含受影响对象并携带基础版本号，基础版本不是当前已提交版本时返回 E_STALE_BASE 且不改变任何已提交状态；同一基础版本的两个并发增量只允许一个成功，另一个必须收到 E_STALE_BASE；读请求携带观察版本，若对象收敛视图版本不高于观察版本则返回结论并标注所用版本，落后时必须返回 E_STALE_READ 并附视图版本与观察版本。
6. 实现单轮时间预算与并行写回批次的并发约束，并保证派生产物的级联失效：写回受每轮时间预算与最大并行批数共同约束，超并行上限的批次进入有界等待队列，队列满返回 E_WRITE_QUEUE_FULL；批次划分、漂移明细与收敛汇总须维护对对象字段与依赖边的引用关系，任一变化时全部受影响派生产物级联失效并在同一事务边界内原子重建，禁止出现批次已更新而漂移明细仍为旧值的中间可见状态。
7. 实现单写者提交与多读者查询的并发一致及幂等复用：快照提交、增量提交、批次组织与写回推进按单写者串行执行，多个只读查询可并发读取某一完整提交版本；同一批次标识重复触发只执行一次、其余等待并复用同一结果，内容不一致时返回 E_CONFLICTING_REQUEST，查询不得看到对象已标记收敛而回读核对记录尚未落定。
8. 实现基于 SQLite 的意图持久化与强制终止后恢复：快照提交、批次组织与写回前先写意图记录再提交事务；进程在批次组织或写回中途被强制终止后重启，须扫描未完成意图，把未提交写回回滚为待写回、把快照切换标记为已中止，恢复报告只包含已落盘事实并给出回滚后的批次与对象状态。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地固定种子样本验证漂移判定、依赖批次组织、真实写回回读与强制终止恢复，输出结果与错误码。
