当前是空白工作区，没有现存项目、代码或数据附件。需从零构建一个本地可运行的表格与图表结构化数据处理管线与结果验证工具，核心是在并行调度与资源预算约束下完成表格区域检测与图表结构还原。输入为固定随机种子生成器产出的本地确定性 PNG 分片与一份 JSON 任务清单，分片由色块网格构成模拟表格与图表（含表头、合并单元格区域、柱状图与折线图），清单逐分片声明图像宽高、表格与图表区域真值（归一化坐标）、单元格行列数、图表坐标轴范围与数据系列真值，以及分片规模档与总像素数上界；不依赖真实 OCR 模型、外部数据集或 GPU。管线按四个阶段推进：图像预处理与区域检测、表格结构还原、图表结构提取、结果验证汇总。

任务环境与准备：
安装 Python 3.10 及以上版本，并在项目虚拟环境中安装 numpy 与 Pillow，均使用本地 wheel 包，不依赖联网安装。
确认工作区为空目录，创建项目所需的 data、work 与 output 子目录，用于存放本地生成的分片与清单、检查点记录与导出结果。
运行本地样本生成器（需自行实现）以固定随机种子产出分片 PNG、任务清单与真值声明，生成后记录内容摘要供后续复现比对。
准备本地 HTTP 测试服务与命令行入口所需的端口与工作目录，确保不依赖真实账号、线上站点或付费资源。
确认操作系统为 Windows，进程池与文件锁行为在本地文件系统上可复现，测试前清理 work 目录中的历史检查点。

业务要求：
1. 实现图像预处理与区域检测阶段：对每个分片做灰度化与阈值化，基于连通域与行列投影分别检测表格候选区域与图表候选区域，输出归一化坐标、置信度与检测依据；同一输入与配置必须产生逐字节一致的候选区域清单，检测区域越界或宽高为零时须返回带分片标识与区域坐标的 E_INVALID_REGION 并保留诊断信息。
2. 实现表格结构还原阶段：在表格候选区域内依据像素行列投影的峰谷切分行线与列线，识别表头区域与合并单元格（跨行或跨列在像素投影上表现为缺线），输出单元格行列索引、像素范围与合并跨度；合并跨度越界、行列数方向与清单声明冲突或识别出零面积单元格时，须返回带分片标识与单元格位置的 E_TABLE_STRUCTURE 并给出冲突原因。
3. 实现图表结构提取阶段：对图表候选区域识别坐标轴范围与刻度，按像素到数据坐标的线性映射提取柱状与折线系列的数据点，输出系列名、数据点坐标与数值；坐标轴范围为零跨度、数据点落在轴范围之外或刻度间距非均匀时须返回带分片标识与坐标范围的 E_CHART_AXIS，且已提取的合法系列须继续保留在诊断输出中。
4. 实现预算约束下的分片并行调度：以分片为调度单元，在总像素处理预算、单工作进程像素配额与并行进程上限三重约束下决定接纳顺序与并发度；接纳前依据清单声明的宽高与分片规模档预估消耗，超预算分片记录为未处理并给出原因，保证任意时刻累计处理像素不超过总预算，不得以线程超时方式描述已终止失控计算。
5. 实现并行执行与确定性归约：使用本地进程池并行处理已接纳分片，各分片的表格结构、图表系列与验证结果按分片序号与分片内行列序全局排序后再归约，使并行运行的汇总输出与串行顺序执行逐字节一致；工作进程异常须以结构化错误对象记录并保留已成功的分片结果，不得静默丢弃。
6. 实现阶段检查点持久化与优雅停止恢复：每个分片各阶段完成时以原子方式写入含分片标识、阶段名、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分分片后退出，不承诺强制终止后生成退出报告，恢复时必须忽略损坏、不完整或序号重复的记录并从最近一致检查点继续。
7. 实现版本变化检测、增量失效传播与并发发布保护：当分片像素内容、区域检测参数、表格切分容差、图表映射参数或预算配置任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；多工作进程发布同一工作区产物时使用文件锁并比较分片序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT，请求非法阶段跳转或缺失前置阶段产物返回 E_INVALID_STAGE。
8. 提供结果验证工具与本地确定性演示：命令行与本地 HTTP 接口支持导入分片与清单、触发分阶段执行、查询各分片状态与版本指纹、查看预算消耗与未处理分片原因、请求停止、执行恢复、导出表格与图表结构化结果；验证工具须按清单真值计算表格区域交并比、单元格行列准确率与图表系列数值误差并输出汇总报告；演示数据至少 4 个分片，覆盖合并单元格表格、柱状图、折线图与中英混排文本，一次完整运行生成固定摘要，并在分片间触发停止后恢复，验证结果与完整运行逐字节一致。
