团队准备新建一个项目，面向 Windows 主机上目录遍历与路径规范化的安全边界问题，构建一个本地可交互的路径解析裁决工作台。业务输入由程序内置生成器在独立临时目录内确定性创建：一棵真实目录树，其中混合普通目录、文件、指向树内目标的符号链接、指向树外目标的符号链接、目录联接（junction 形式的重解析点）与相对目标链接，另有若干以 `..` 与混合分隔符书写的待解析路径清单及一条受限根路径。工作台需在真实文件系统上逐个组件解析路径，识别每一跳的重解析点类型与目标，裁决解析结果是否仍处于受限根之内，并对越界、链接环、深度超限与目标缺失等情况给出稳定业务码。所有测试均在 Windows 本机临时目录完成，不触碰系统目录，不依赖外部服务与真实账号。

任务环境与准备：
安装 Go 1.22 或更高版本（Windows amd64），确认 go version 可用。
使用纯 Go 的 SQLite 驱动（如 modernc.org/sqlite），通过 go get 拉取并固定版本，避免依赖 CGO 或外部数据库。
确认运行环境允许在临时目录创建符号链接与目录联接；若创建符号链接需要开发者模式或提升权限，程序应在生成阶段检测并给出明确前置提示，缺失时使用目录联接与相对链接替代组合以保持样本确定性。
不依赖任何网络服务、真实账号或外部数据；目录树、链接与路径清单均由程序内置生成器在临时工作目录内确定性产出。
运行方式前置为 go build 与 go test，所有子命令与演示入口须可直接在 Windows 命令行执行。

业务要求：
1. 实现受限根下的逐组件路径解析核心：以受限根为起点，按路径分量顺序在真实文件系统上解析每一跳，识别普通目录、文件、符号链接、目录联接与相对目标链接，并在规范化后判定最终目标是否仍位于受限根之内；越出受限根返回 E_PATH_ESCAPE 并记录首次越界的分量与当时已解析的绝对路径。
2. 实现链接跳转的循环与深度控制：对解析过程中经过的每一跳记录其重解析点标识与目标规范路径，当同一目标在解析链中重复出现时判定为链接环返回 E_LINK_CYCLE，当跳转次数超过可配置上限时返回 E_LINK_DEPTH；两类终止都必须给出完整的跳转链及其循环点或深度截断点。
3. 实现相对目标链接与大小写、分隔符归一：正确处理以相对路径书写的链接目标（相对其所在目录解析）以及 `..`、正反斜杠混用与 Windows 大小写不敏感的比较规则；规范化后的路径用于逃逸判定与去重，但报告中须同时保留原始书写形式与规范化结果以便审计。
4. 实现缺失目标与悬挂链接的稳定裁决：当链接目标不存在、目标在受限根之外但尚未创建、或中途分量不是目录时，分别返回 E_TARGET_MISSING、E_ESCAPE_DANGLING、E_NOT_DIRECTORY，已成功解析的分量结果保留在快照中；此类裁决不得因后续样本的存在与否而改变。
5. 实现带版本号的解析快照与整体替换识别：每完成一批路径清单的解析后在单个 SQLite 事务内提交递增版本号的快照，记录各路径的跳转链、裁决码与受限根标识；快照内容比较须识别整体替换式版本变化而非仅比对版本号，加载时校验版本链连续性，发现跳号返回 E_SNAPSHOT_VERSION 并回退到最近连续版本。
6. 实现并发路径解析与资源控制：多份路径清单可在独立会话中并发解析，会话间状态隔离；并发度与单会话路径数上限可配置，超并发上限的清单进入等待队列而非直接拒绝，单清单路径数超限时以 E_PATH_BUDGET 终止该会话但仍完整提交已完成路径的裁决；在途计数须可观测。
7. 实现异常注入验证链路：通过外部参数或配置文件构造逃逸链接、链接环、深度超限、悬挂链接与快照版本跳号五类输入，分别断言对应业务码、其余路径裁决结论不受污染、已提交快照未被推进；注入仅通过输入与参数进行，不得修改源码制造失败。
8. 导出确定性 JSON 报告：包含受限根、每条待解析路径的原始形式与规范化结果、跳转链逐跳明细、裁决业务码、失败分量位置与快照版本链；报告按路径清单标识与路径序号稳定排序，时间字段只使用固定采样标记，重复运行且输入不变时报告字节级一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地临时目录样本验证路径逃逸、链接环与悬挂链接裁决及快照恢复一致性。
