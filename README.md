为音色克隆与发音建模团队从零构建一个本地可运行的说话人嵌入训练与克隆推理工作台，核心问题是参考音频数据规模从数十秒到数十分钟变化时，在发音单元建模、嵌入聚合与训练预算之间做算法路径取舍，并保证交互式克隆结果与全量重算逐位一致、崩溃后可恢复。工作区为空，需自行初始化项目。输入是本地样本目录：一份说话人清单 JSONL，每条含 speaker id、参考音频文件相对路径（本地确定性合成的 16 位单声道 PCM WAV，采样率 16000 或 22050 Hz，由不同基频、共振峰与包络的合成音段拼接，含静音间隔）、语音段与文本的配对标注（音素序列与起止毫秒）；一份发音单元表 JSON，声明音素集合、各音素的共振峰原型向量与最小样本数要求；一份克隆配置 JSON，声明帧长与帧移毫秒、嵌入维度、规模阈值（小于该阈值走小样本直接聚合、达到或超过走大样本分块聚类训练）、训练轮数上限、收敛容差与全局训练预算单元。团队需要据此完成逐帧声学特征提取、发音单元对齐、说话人嵌入训练与音色克隆推理，输出每句话的合成频谱片段与逐音素发音得分，并可视化诊断各阶段状态。

任务环境与准备：
安装 Python 3.10 及以上版本，创建虚拟环境并安装 numpy、fastapi、uvicorn、httpx、pytest 与标准库 sqlite3 相关依赖。
准备本地确定性样本生成脚本，合成覆盖 16000 与 22050 Hz、不同基频与共振峰的参考 WAV、音素标注 JSONL、发音单元表与克隆配置，不使用真实账号或线上资源。
确认无 Docker 或其他容器依赖，所有服务与测试均在 Windows 本地进程内运行，SQLite 数据库与结果目录位于工作区可写路径。
启动 FastAPI 服务前预留本地端口并确保未被占用，演示入口使用固定样本与参数生成可重复结果。

业务要求：
1. 工程创建接口接收说话人清单、发音单元表、克隆配置与全局预算单元，校验 speaker id 唯一、参考 WAV 头与清单声明的采样率与声道一致、音素标注区间落在音频时长内且起止有序、每个音素均在发音单元表声明集合中、帧长与帧移为正毫秒且帧移不超过帧长、嵌入维度为正整数、规模阈值不低于发音单元表声明的最大最小样本数；任一非法返回 E_PARAM 或 E_PHON 业务码并指出文件与行号，且不写入任何阶段状态或结果文件。
2. 须实现确定性帧级声学特征提取与音素对齐：各说话人参考音频按清单下混为单声道，按帧长与帧移划帧并加显式窗函数，由短时能量、过零率与共振峰估计派生逐帧特征，全部以 float64 计算；音素标注按帧时间区间映射到帧序列并在边界帧按重叠比例归属，同一音频与配置下逐帧特征向量与逐帧音素归属须逐位可重复，不得依赖字典遍历顺序、系统时间或全局随机状态。
3. 须实现规模驱动的双路径嵌入训练并输出路径决策记录（含选择理由、实际使用帧数、分块数、训练轮数与收敛状态）：参考音频总帧数低于规模阈值时走直接均值聚合路径，达到或超过阈值时走分块聚类训练路径；两条路径在同一说话人上产出的嵌入维度一致，路径切换不得改变发音单元表与标注的解释方式，同一输入与配置下所选路径须完全可重复。
4. 大样本分块聚类训练须按分块尺寸遍历帧块，块内按帧下标升序、块间按块序号升序确定性累加，尾块（不整除部分）必须走同一累加路径而非退回整块拷贝；聚类迭代达到训练轮数上限或中心变化量低于收敛容差即停止，任意合法分块尺寸与轮数上限下的嵌入向量须与不分块直接聚合在声明容差内一致，超出容差返回 E_PRECISION 并定位说话人与帧区间。
5. 克隆推理的低延迟预览接口须返回指定句子的音素数、帧数、逐音素发音得分摘要与若干帧的合成频谱片段，且必须与用同一参数走全量训练与合成得到的结果完全一致，包括音素归属、发音得分、嵌入版本与频谱值；预览不得走抽样、截断帧或降低维度近似，检测到任何不一致须返回 E_VERIFY 并给出首个不一致的音素与帧号。
6. 服务须支持多说话人并发训练并共享创建时给定的全局训练预算单元：每个说话人每帧特征提取与每轮聚类按其帧数与配置显式换算消耗，任务开始前原子扣减、结束后归还，预算不足时按 speaker id 字典序排队并返回 E_BUDGET 与等待清单而非阻塞等待或超额执行；并发场景下扣减总数不得超过给定预算，排队与降级决策须写入路径决策记录，且不得改变任何说话人的嵌入结果。
7. 训练与推理进度须在 SQLite 中以说话人、阶段、帧块三级记录事务提交，单帧块的特征摘要、嵌入中间量与块进度标记须在同一事务中写入；嵌入结果文件先写临时文件再原子替换并登记内容哈希，某帧块失败时该块整体回滚且该说话人其余已提交帧块状态不变，不得留下半写文件或与快照版本不一致的记录。
8. 进程被强制终止后重启，须从 SQLite 已提交帧块进度继续，核对每个说话人的阶段标记、帧块标记、嵌入结果文件内容哈希与快照版本，重算未提交帧块且不重复消费已提交帧块、不重复累加已提交中间量；恢复后的逐说话人嵌入向量、逐音素发音得分、路径决策序列与无中断执行须完全一致；每次阶段完成须整体替换生成版本化快照（含配置指纹、嵌入版本与结果文件哈希），读取快照时若检测到数据库版本与磁盘哈希不一致、配置指纹变化或残留旧版本结果文件须返回 E_STALE 并定位到说话人与结果文件，并提供固定样本演示入口跑出多路径决策、预算排队、逐音素得分与恢复前后一致性结论的可重复结果。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地合成音频与固定配置验证双路径训练、逐音素得分、预览与全量一致、预算排队及中断恢复结果可重复。
