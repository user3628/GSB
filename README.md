交付从新建的代码库开始，需要为一家分布式办公企业的出口 VPN 运维团队从零构建一个 VPN 隧道转发的交互延迟统计与计算结果一致性裁决工作台。企业的多条 VPN 隧道承载大量并发转发流，运维需要在本机离线复现隧道转发决策：每条流按隧道策略表选择出口隧道，策略表包含隧道标识、目的网段、优先级、带宽上限与转发代价；决策结果用于计算负载分摊与延迟预算。同时，工作台必须对同一批转发请求给出交互侧与结算侧两份逐条一致的裁决结果，并给出基于单调时钟的交互延迟统计口径。系统需维护带递增版本号的策略快照与结算快照，支持快照整体替换识别、进程被强制终止后的恢复一致性，以及并发转发会话的资源控制。验收在 Windows 上使用本地确定性样本与 SQLite 完成。

任务环境与准备：
安装 Go 1.22 或以上版本（Windows amd64），确认 go env 中 CGO 设置与本地构建可用；SQLite 驱动使用纯 Go 实现（如 modernc.org/sqlite），通过 go get 安装，不依赖系统 C 库。
在 Windows 本地创建空工作目录作为代码库根路径，确保有可写临时目录用于 SQLite 数据库文件与确定性样本生成。
运行前通过程序内置生成器产出确定性样本：策略表 JSON、转发请求文本块、五类异常注入参数文件；所有样本与参数均为本地文件，不访问网络。
验证时使用命令行入口运行完整工作台、异常注入子命令与报告导出，重复运行同一输入以比对报告字节一致性。

业务要求：
1. 实现隧道策略表与转发请求的解析与规范化：策略表以 JSON 描述，每条策略包含隧道标识、目的网段 CIDR、优先级、带宽上限与转发代价；转发请求以带长度前缀的文本块描述，包含流标识、源地址、目的地址与请求包长。解析时校验 CIDR 合法性、隧道标识唯一性、优先级与代价为非负整数，非法输入返回 E_POLICY_INVALID，并记录原始偏移。
2. 实现单条转发流的隧道选择与负载分摊核心：按目的网段匹配候选隧道，依优先级从高到低、同优先级按带宽上限从大到小选择出口隧道并计算分摊权重（使用整数定点，scale=1e6，禁止浮点）；当多条隧道匹配且权重分配出现截断时，截断余量须逐次写入误差账本并可按流聚合出有界误差上界；无匹配隧道返回 E_NO_TUNNEL。
3. 实现交互侧与结算侧的逐条一致性裁决：交互侧在请求到达时即时给出隧道选择与分摊权重的初步结果，结算侧在窗口关闭后综合全部请求给出最终结果；两侧必须按流标识与请求序号逐条一致，当结算侧因乱序或后到请求修正初步结果时，须记录修正轨迹并返回可查询的修正码；任何一条不一致须以 E_RESULT_MISMATCH 定位到具体流与请求序号。
4. 实现基于单调时钟的交互延迟采样与统计：对交互侧每次裁决记录从接收请求到返回初步结果的耗时（单调时钟差值，不依赖墙钟），按隧道标识与结果码聚合样本数、平均、P95 与最大值；统计输出中的时间字段只使用固定采样标记，重复运行且输入不变时统计结果字节级一致；采样不得引入随机因素。
5. 实现带版本号的策略快照与结算快照并识别整体替换：每完成一轮策略加载或一个窗口结算后在单个 SQLite 事务内提交递增版本号快照，旧快照整体保留可回放；加载时校验版本链连续性，发现跳号返回 E_SNAPSHOT_VERSION 并回退到最近连续版本；快照内容比较须识别整体替换式版本变化而非仅比对版本号，整体替换时须记录替换前后的策略集合摘要。
6. 实现进程强制终止后的恢复一致性：在窗口结算提交或策略加载提交过程中进程被强制终止后重启，依赖 SQLite 已提交事务恢复策略版本、窗口进度与结算结果，已提交窗口与快照不回退、未提交事务整体丢弃且该窗口可重新结算；恢复后若发现版本链跳号须以 E_SNAPSHOT_VERSION 拒绝加载并回退到最近连续版本。
7. 实现并发转发会话与资源控制：多个转发请求窗口可在独立会话中裁决，会话间策略状态与误差账本隔离；并发度与单会话请求数上限可配置，超并发上限的会话进入等待队列而非直接拒绝，单会话请求数超限时以 E_REQUEST_BUDGET 终止该会话并保留已处理请求的初步结果；在途会话计数须可观测，并发冲突须记录会话标识与请求序号。
8. 实现异常注入验证链路与确定性报告：通过外部命令行参数或配置文件构造无匹配网段、定点乘法溢出、快照版本跳号、整体替换式版本变化与并发会话竞争五类样本，分别断言对应业务码、已提交快照未被污染、其余会话结论不受影响；注入仅通过输入与参数进行，不得修改源码；导出 JSON 报告包含各会话裁决摘要、交互与结算一致性比对、误差账本、延迟统计、快照版本链与业务码，报告按会话标识与请求序号稳定排序，重复运行且输入不变时字节级一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

使用本地确定性样本在 Windows 上运行，验证隧道选择、交互与结算逐条一致、延迟统计可重复及五类异常注入的业务码与快照状态。
