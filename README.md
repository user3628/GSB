长上下文推理团队在该项目启动时手上只有一个空工作目录和一份格式规范草案，需要据此交付一套位置编码频率表与配置的格式互操作组件及可复现实验环境，用于在 RoPE、NTK 缩放 RoPE、线性插值 RoPE 三种方案之间迁移并做版本兼容性裁决。输入由程序内置固定种子生成器确定性产出：一组分片文件（JSON，含方案名、头维度、基础频率、缩放系数、序列长度与外推倍率）与随附的高精度参考位置偏置矩阵（定点量化保存）；配置存在两种结构版本，版本 2 以结构化字段描述缩放方式与分块大小，版本 1 以整数字符串与百分比表述且缺少外推倍率字段。组件需完成配置解析与兼容升级、位置偏置矩阵分块计算、版本指纹识别与增量失效、以及性能预算下的并发执行调度，所有状态写入本地 SQLite 并支持强制终止后恢复。

任务环境与准备：
安装 Go 1.22 或以上版本（例如通过系统包管理器或官方安装包安装），确保 go 命令在 PATH 中可用。
使用 go mod init 初始化模块，仅引入标准库与 SQLite 驱动（如 modernc.org/sqlite），通过 go get 拉取并锁定版本。
在本地工作目录下运行内置固定种子生成器命令生成至少 3 个分片文件、两种结构版本的配置与高精度参考偏置矩阵，所有产物落在工作目录内，不访问网络。
准备一个空的 SQLite 数据库文件路径作为默认状态库，并确保进程对工作目录与数据库文件具有读写权限。
本地 HTTP 测试使用回环地址与随机可用端口，不依赖任何外部服务、真实账号或 GPU。

业务要求：
1. 实现统一内部位置编码配置模型与版本 2、版本 1 两种结构配置的双向编解码：内部模型以方案标识、头维度、基础频率、缩放系数、缩放方式、分块大小、外推倍率与结构版本描述一份配置；版本 1 中缩放系数为整数百分比、外推倍率为整数且缺少分块大小字段，导入时须按可配置规则做百分比换算、补齐缺省值并标注降级项与换算依据，转换后须能导出为版本 2 并通过回导校验；结构版本号与内容形态不符时返回带字段名与取值的 E_VERSION_MISMATCH。
2. 实现位置偏置矩阵分块计算核心：按基础频率与头维度计算 RoPE、NTK 缩放 RoPE、线性插值 RoPE 三种方案的位置相关偏置，并支持任意合法非整除头维度与批量序列长度；计算按行块与列块组织且不得一次性物化完整偏置矩阵，奇数头维度最后一维不旋转并显式记录；同一配置与分片必须产生逐字节一致的偏置矩阵摘要、逐块中间量摘要与旋转角度表。
3. 实现数值精度控制与误差界逐块审计：偏置相关量以定点量化存储并记录每方案每块的缩放因子，旋转角度与缩放系数的乘积和比值全程在缩放定点域或对数域计算；对每个行块按显式抽样位置与高精度参考偏置矩阵比对，给出最大绝对偏差、相对偏差与有效位数，误差界须由缩放因子、量化步长与累加顺序显式推导并随结果保留；偏差超容差时返回带分片标识、方案名与块行列区间的 E_NUMERIC，出现零基频、负缩放系数或非有限值时返回带方案与字段的 E_CONFIG_INVALID。
4. 实现版本指纹识别与块级增量失效传播：当某分片内容、基础频率、缩放系数、缩放方式、分块大小或外推倍率任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段与最小行块区间，使该区间及其全部下游偏置块与审计结论失效并重建，未受影响行块继续复用；当检测到配置记录被整体替换（版本号回退、指纹变化或摘要不匹配）时须区分正常推进、整体替换与回退，整体替换使全部派生状态失效重建，回退拒绝并返回 E_STALE_VERSION。
5. 实现 SQLite 事务化分块状态持久化与强制终止恢复：每完成一组列块的每个行块即以事务写入含分片标识、方案名、行块序号、已覆盖列范围、缩放因子、产物摘要、输入指纹与单调序号的记录，同一分片同一方案同一行块只允许一条有效记录；写入过程任意位置中断不得留下半写记录，进程被强制终止后重启仅凭已提交事实重建进度，不承诺生成退出报告，恢复后最终偏置矩阵摘要与审计报告须与一次连续运行逐字节一致。
6. 实现并发发布互斥与缓存预算裁决：多工作进程对同一 SQLite 库发布行块状态时使用事务条件更新与真实文件锁并比较行块序号，仅允许序号连续推进，落后、重复或跨方案错位发布返回 E_STALE_PUBLISH；在可配置峰值内存预算内规划偏置块、旋转角度表与中间缓冲占用，超预算时按行块或序列批次拆分执行并记录拆分决策与每步内存估算，或返回带预算明细的 E_MEMORY_BUDGET。
7. 实现增量重算与全量一致性校验：提供单分片替换与单配置字段变更入口，仅重建失效链路后与从零全量构建的偏置矩阵摘要、逐块中间量摘要与审计报告做逐字节比对，不一致须返回 E_INCREMENTAL_MISMATCH 并附首个差异行块与两路摘要取值；批量运行须与逐分片单独运行再汇总的结果一致。
8. 提供本地 HTTP 与命令行实验台及确定性演示：支持导入分片与两种版本配置、执行格式互转与旧版回导、触发分阶段偏置计算、查询各阶段状态与版本指纹、查看逐块误差与失效原因、请求优雅停止与执行恢复、导出审计报告；演示数据由内置生成器产出至少 3 个分片，覆盖三种方案、非整除头维度与版本 1 旧配置，两次相同配置运行须得到逐字节一致的报告摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证两代配置互转、分块偏置计算与误差审计，含中断恢复及增量一致性。
