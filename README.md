客服质检系统的语音情感分析子模块刚完成立项评审，开发目录里除了这份需求说明还没有任何实现与样本。输入由程序内置固定种子生成器在本地产出：16 kHz、单声道、16 位 PCM WAV 分片，每片是一段客服对话轮次录音，含平静、激动、犹豫三类情感段与静音间隔；另附 JSON 轮次清单逐片声明轮次标识、参考情感段起止毫秒、参考情感类别、说话人编号与样本总数上界，并提供一份带单调版本号的判定策略快照，声明帧长帧移毫秒、能量与基频特征权重、情感判定阈值、校准样本比例、每轮处理预算与恢复轮次。组件按帧级特征提取、轮次级情感打分、阈值校准与情感证据归因、增量演进与恢复四阶段推进。真实场景里同一会话的轮次会增量追加，某轮录音被修正、阈值或特征权重被调整时，只有受影响的最早阶段及其下游需要重建，且进程可能被强制终止，重启后只能依据 SQLite 中已提交的事实恢复识别状态。

任务环境与准备：
安装 Go 1.22 或以上版本，并确保 go 命令与 SQLite 驱动（如 modernc.org/sqlite）可离线获取。
在 Linux（WSL Ubuntu）下创建空工作目录作为项目根目录，确认当前用户对目录有读写权限。
程序内置固定种子生成器负责产出 WAV 分片、轮次清单与策略快照，不依赖外部音频素材或网络。
运行前确认本地回环 HTTP 端口未被占用，SQLite 数据库文件路径可写。

业务要求：
1. 实现帧级特征提取阶段：按策略声明的帧长与帧移（毫秒）对 16 位 PCM 做汉宁窗分帧，帧长帧移须显式换算为整数采样点并在诊断中记录换算值，逐帧计算对数能量、过零率与自相关基频，输出带帧索引、采样点范围与特征摘要的帧级特征表；同一输入与策略必须产生逐字节一致的特征表，空分片或全静音分片须显式标记并返回带轮次标识的业务码。
2. 实现轮次级情感打分核心：以策略声明的特征权重把帧级特征聚合为轮次级三类情感分数，聚合须在对数域或缩放定点域累加并记录参与帧数与被跳过帧原因；同一轮次在不同帧块切分方式下聚合结果须逐字节一致，基频出现 NaN 或能量全为零时返回带轮次标识与帧索引的 E_NUMERIC 并保留诊断上下文。
3. 实现阈值校准与情感证据归因：依据策略声明的校准样本比例与固定种子从参考情感段中确定性抽样，按校准样本分数估计三类判定阈值并输出阈值、命中率与被校准样本范围；每个判定结果须附带由参与帧的对数贡献与阈值余量构成的证据链，证据链重新导入后须能重建同一判定与同一证据链，中间帧缺失须返回 E_EVIDENCE_BROKEN。
4. 实现增量演进与依赖失效传播：会话内轮次追加时仅处理新轮次；某轮录音被修正、帧参数、特征权重、判定阈值或校准比例变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段与最小轮次集合，使该集合及其全部下游产物失效重建，未受影响轮次的特征表与分数继续复用；重建结果须与从零全量运行逐字节一致，不一致返回 E_INCREMENTAL_MISMATCH 并附首个差异轮次。
5. 实现 SQLite 事务化阶段检查点与强制终止恢复边界：每轮次每阶段完成时在单个事务内写入含阶段名、轮次标识、输入内容指纹、策略版本、产物摘要与单调序号的记录，同一轮次同一阶段只允许一条有效记录；收到停止请求时完成当前不可拆分单元后退出，被强制终止后重启仅凭已提交事实重建进度，恢复后的帧特征、情感分数、阈值与证据链须与一次连续执行逐字节一致。
6. 实现策略快照整体替换识别与并发发布互斥：当判定策略快照或轮次清单被整体替换时，通过内容摘要与版本序号区分正常追加、整体替换、版本回退与分叉四种情形，整体替换须使全部派生状态失效重建，回退须拒绝并返回 E_STALE_VERSION；多工作进程对同一库发布阶段产物时使用 SQLite 条件更新与真实文件锁并比较轮次内序号，仅允许序号连续推进，落后、重复或跨轮次错位发布返回 E_STALE_CHECKPOINT。
7. 实现每轮处理预算约束下的恢复轮次调度：以轮次为调度单元，在每轮处理预算与恢复轮次上限共同约束下决定本轮接纳的轮次顺序，接纳前依据清单声明样本总数与帧参数预估帧消耗，超预算轮次记录为未处理并给出预算余量与原因，不得静默丢弃；裁剪后本轮结果须与按裁剪后输入从零运行的结果逐字节一致。
8. 提供本地 HTTP 与命令行交互接口及确定性演示：支持导入 WAV 分片与轮次清单、提交策略快照、触发分阶段执行、查询各阶段状态与版本指纹、查看逐轮情感分数与证据链、执行单轮录音修正、请求优雅停止、执行恢复与导出识别报告；演示数据由内置生成器产出至少 3 个会话、含三类情感段与一次强制终止恢复场景。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
