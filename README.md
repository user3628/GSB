当前是空白工作区，需从零构建一个本地可运行的机器翻译实验系统，交付算法实现与可复现的实验环境。业务目标是在没有真实平行语料与预训练模型的前提下，用本地确定性样本研究“数据规模变化时翻译建模算法应如何取舍”。输入由固定随机种子的本地生成器产出：三档平行语料分片（小档约 200 句对、中档约 2000 句对、大档约 12000 句对），每条句对含 pair_id、源语言句子（中文或英文）、目标语言句子、语言对标签、来源域标签与噪声标记（如多余空格、全半角混排、长度比例为零的异常对），另附分档清单声明每档句对数、平均句长、词表规模与总 token 上界。系统需完成分词与子词切分、词对齐统计、翻译模型训练与解码、以及基于数据规模的算法取舍决策：小档偏向低参数高泛化的近似对齐与短语表裁剪，大档可启用更精细的对齐与更大词表，取舍须给出可复算的理由与误差。所有输出须可复现，摘要逐字节一致。

任务环境与准备：
安装 Python 3.11 与 NumPy（pip install numpy），无需 GPU 与网络数据。
从空工作区创建项目目录，运行本地固定种子生成器产出三档平行语料分片、分档清单与参考译文。
准备本地文件锁与原子写入所需的标准库能力，确认工作区可读写并预留检查点目录。
准备集成测试脚本入口，支持演示停止恢复、错误注入与摘要比对。

业务要求：
1. 实现双语规范化与子词切分阶段：对源句与目标句做 Unicode NFKC、空白折叠、全半角统一与小写化，按中文单字与拉丁连续串切分 token，再以本地语料统计的字节对编码合并规则生成子词；切分结果须带 token 起止字符偏移、语言标记与合并来源，空句或仅含标点的句对须返回带 pair_id 的 E_EMPTY_SENTENCE 并保留在诊断输出中。
2. 实现词对齐统计与对数域翻译概率估计：从各档语料统计共现计数，以可配置平滑强度与丢弃阈值估计词对齐概率，全程在对数域累加；当平滑强度为零、语料不足以估计某语言对的转移或出现非正计数时须返回带语言对与词项位置的 E_NUMERIC，且不得静默返回空对齐表。
3. 实现基于数据规模的算法取舍决策：依据每档句对数、平均句长、词表规模与可配置训练预算，在对齐粒度（词级精确对齐、子词近似对齐）、短语表规模与解码搜索宽度三处选择组合，记录候选打分明细、选择理由与被淘汰方案原因；小档须避免启用仅对大档合理的短语表规模与搜索宽度，取舍结论须可由输入规模与预算独立复算。
4. 实现确定性翻译训练与解码核心：按选定方案以固定顺序迭代训练短语概率并对目标句做对数域集束搜索解码，输出候选译文、解码得分与搜索轨迹摘要；同一输入与取舍结论必须产生逐字节一致的候选译文与得分，若集束中出现 NaN、归一化得分为零或搜索宽度为零须返回 E_DECODE_FAILED 并附 pair_id 与步索引。
5. 实现翻译质量指标与规模相关误差带：以本地参考译文为唯一真值来源计算逐句 BLEU 近似与词级精确率，按档汇总并给出与句对数相关的置信区间估计；指标计算须说明所依赖的有效句对数与被跳过句对，越界或无法计算时须显式计数而非静默丢弃。
6. 实现阶段检查点持久化与优雅停止恢复：每档按切分、对齐、取舍、训练解码、评测五阶段完成时以原子方式写入含阶段名、档位标识、输入内容指纹、取舍结论指纹、产物摘要与单调序号的记录，写入过程任意位置中断不得留下半写记录；进程收到停止请求时完成当前不可拆分句对单元后退出，不承诺强制终止后生成退出报告；恢复后候选译文与评测摘要须与一次从零完整运行逐字节一致且序号连续推进。
7. 实现版本变化检测与增量失效传播：当某档语料内容、平滑强度、BPE 合并规则、取舍预算或解码宽度任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；失效原因与受影响范围须在查询接口中可观测，禁止用旧档位结果冒充新结果。
8. 实现并发发布保护、稳定业务错误码与本地确定性演示：多工作进程对同一工作区发布阶段产物时使用真实文件锁并比较档位内序号，仅允许序号连续推进，落后、重复或跨档位错位发布须返回 E_STALE_CHECKPOINT，缺失前置阶段产物或非法阶段跳转返回 E_INVALID_STAGE；演示须覆盖三档语料、中英双向语言对与至少 3 类异常样本，一次完整运行生成固定摘要，并演示档间触发停止后恢复与错误注入时的错误码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地三档语料验证分阶段取舍、训练解码与摘要复现，并验证停止恢复与错误码一致。
