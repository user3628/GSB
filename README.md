当前是空白工作区，需从零构建一个本地可运行的合同条款要素抽取组件，交付可集成的领域组件与完整示例。输入为若干本地 UTF-8 JSONL 合同分片，每条含 contract_id、clause_text、条款序号、来源模板标识与可选的条款结构化标注；文本为中英混排的合同条款句，含金额、日期、期限、违约金比例等要素。系统需完成条款规范化、要素抽取与冲突裁决三级处理：要素抽取以本地种子标注估计的正则-词典混合规则打分，冲突裁决在同一 contract_id 内出现同一要素的多个取值时按优先级与生效日期裁决。系统不依赖真实模型、GPU 或外部服务。组件须支持异常注入与可复现验证，并保证相同输入与配置产生逐字节一致结果。

任务环境与准备：
安装 Python 3.10 及以上版本，创建并激活本地虚拟环境。
安装 NumPy 依赖，仅使用本地 wheel 包，不联网下载模型或数据。
在空工作区创建项目目录与本地确定性样本：至少 30 条 JSONL 合同条款，覆盖四类要素、中英混排与含冲突取值的合同，并附种子标注与要素词典。
准备结构版本 1 的种子标注样例（字符偏移、千分位金额、缺省条款序号）用于导入互通演示。
准备本地 HTTP 服务运行端口与命令行入口，确保无外部服务依赖。
准备异常注入参数文件与停止恢复演示脚本，所有样本与配置均落盘且可重建。

业务要求：
1. 实现条款规范化与切分阶段：对 clause_text 做 Unicode NFKC、空白折叠、全半角统一与条款序号剥离，按中文句读与换行切分为带字符偏移的条款单元，输出 clause_id 与 contract_id 的稳定映射；空条款或仅含序号时返回 E_CLAUSE_EMPTY 并附 contract_id 与偏移区间，同输入规范化结果逐字节一致。
2. 实现要素抽取打分器：以本地种子标注估计各要素类型（金额、日期、期限、违约金比例）的正则命中与词典命中权重，输出每条款的候选要素、起止偏移、归一化值与置信度；金额与比例须按定点量化归一，出现 NaN 或量化溢出时返回带 contract_id 与要素名的 E_NUMERIC，禁止静默丢弃候选。
3. 实现同合同内要素冲突裁决：当同一 contract_id 下同一要素出现多个不同取值时，依据可配置的条款优先级与生效日期裁决唯一取值，生效日期相同且优先级并列时须有确定性仲裁规则；被淘汰取值及其依据须保留在诊断输出中，禁止只返回胜出值。
4. 实现标注结构版本互操作：支持导入结构版本 1 的种子标注，其中要素以字符偏移描述、金额为带千分位字符串、缺失条款序号字段；导入时按可配置规则做偏移换算、金额定点解析与序号缺省推导，转换后结果须可通过导出回写并再次导入得到逐字节一致的结构。
5. 实现异常注入与业务错误码一致性：提供参数注入入口，支持注入非法条款序号、超长条款（超过可配置字符上限）、种子标注要素类型不在要素表内与生效日期格式非法等情况；各异常在对应阶段返回稳定业务码（E_INVALID_CLAUSE_NO、E_TEXT_TOO_LONG、E_UNKNOWN_ELEMENT、E_INVALID_DATE）并附 contract_id 与阶段名，注入不得修改源码或改变配置存储内容。
6. 实现版本指纹与结果失效：当条款文本、种子标注、要素权重、裁决优先级或归一化精度任一变化时，计算各阶段内容摘要构成的版本指纹，使受影响的最早阶段及其全部下游抽取与裁决结果失效并重建；未受影响上游结果继续复用，失效原因与指纹须在查询接口中可观测，禁止复用旧版本裁决结果。
7. 实现可复现实验环境与指标汇总：对本地评测集批量执行抽取与裁决，统计要素精确率与召回率、冲突裁决正确率与版本兼容转换成功率，并按配置指纹生成实验摘要；两次相同配置运行须得到逐字节一致的摘要，指标计算须依赖显式标注真值与诊断输出中的淘汰记录。
8. 提供交互接口与确定性演示：命令行与本地 HTTP 接口支持单合同解析、查看要素候选与冲突裁决依据、执行批量实验、查询版本状态、请求停止与执行恢复；批量执行按阶段以原子方式写入含单调序号的检查点，收到停止请求时完成当前不可拆分条款单元后退出，恢复后结果须与一次从零完整运行逐字节一致；演示数据含至少 30 条合同条款、覆盖四类要素与中英混排，至少演示一次版本 1 标注导入与一次异常注入。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
