视觉字符识别小组的开发机上只有一个尚未初始化的空目录，首个版本要从零写出可被上层车牌识别服务集成的字符区域定位与结构模板匹配组件及完整示例。输入全部由程序内置固定种子生成器在本地产出：一组小尺寸灰度 PNG 车牌分片，分片由底纹、固定位置的字符色块与随机噪声叠加而成，字符尺寸与间距在生成器内按固定参数确定；另附一份 JSON 任务清单，逐分片声明图像宽高、字符区域真值（归一化坐标与字符类别）、字符间距参考区间、分片语言标签与来源通道，并给出一份以定点量化保存的高精度参考匹配分数作为唯一误差比对来源。组件按图像规范化与二值化、字符区域定位、结构模板匹配、误差传播审计四个阶段推进，每个阶段都要把中间产物以带内容指纹与单调序号的记录落盘，使任意阶段中断后都能凭已落盘事实恢复，且恢复后的定位结果、匹配分数与审计结论必须与一次连续运行逐字节一致。定位与匹配链路中的灰度归一化、区域得分累加与模板相似度都在定点域进行，缩放因子与量化步长会沿链路放大误差，因此每个字符区域的匹配分数都必须附带可复核的误差上界与有效位数，并能与本地高精度参考逐项比对。真实样本里会混入全白分片、字符区域越界、间距为负与字符类别缺失等异常，组件需要在对应阶段给出稳定业务码而不是静默产出错误结果。

任务环境与准备：
在 Linux（WSL Ubuntu）上准备 Go 1.22 或更高版本，并确认 go 命令可用。
准备 SQLite 3 命令行工具用于结果核查，Go 侧通过内置驱动或本地文件方式访问同一数据库。
在空白工作目录初始化 Go 模块，示例与样本由程序内置固定种子生成器在本地产出，不依赖网络、GPU 或外部数据集。
运行前确认工作目录可写，并保留一个空数据库路径用于阶段检查点落盘。

业务要求：
1. 实现图像规范化与二值化阶段：解码 PNG 后校验实际宽高与清单声明一致，不一致返回带分片标识、声明值与实际值的 E_DIM_MISMATCH；灰度化后按可配置阈值做二值化并对全白、全黑分片单独标记，归一化后的像素摘要须与清单中的图像内容指纹一致，同一输入与配置必须产生逐字节一致的二值图摘要与标记清单。
2. 实现字符区域定位核心：依据二值图的连通域与水平投影切分出候选字符区域，输出归一化坐标、置信度与来源策略；候选区域越界、宽高为零或切分数量与字符间距参考区间明显冲突时须在对应区域给出诊断并返回带分片标识的 E_REGION_INVALID，不得把无效区域带入下一阶段。
3. 实现结构模板匹配阶段：依据清单声明的字符类别集合与真值坐标构造本地确定性模板库，对每个候选区域在定点域累加像素相似度并输出匹配分数、最优模板类别与匹配距离；模板库为空、区域尺寸与模板不匹配或匹配分数出现 NaN 时返回带分片标识与区域序号的 E_TEMPLATE_MISMATCH。
4. 实现误差传播审计：每个字符区域的匹配分数须附带由缩放因子、量化步长与累加顺序显式推导的误差上界与有效位数，推导依据随结果保留；再与高精度参考匹配分数按固定抽样位置比对，偏差超过可配置容差须报告分片标识、区域序号与最大绝对偏差，并返回 E_NUMERIC_MISMATCH。
5. 实现基于内容指纹与单调序号的阶段检查点：每个分片每阶段完成时在单个 SQLite 事务内写入含阶段名、分片内容指纹、配置版本、产物摘要与单调序号的记录，同一分片同一阶段只允许一条有效记录；写入任意位置中断不得留下半写记录，恢复时忽略损坏、不完整或序号重复的记录。
6. 实现版本变化检测与阶段级失效传播：当分片像素内容、二值化阈值、定位参数、模板库、量化位宽或容差任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段与最小分片集合，使该集合及其全部下游产物失效并重建；未受影响上游产物继续复用，增量结果须与从零全量运行逐字节一致，否则返回 E_INCREMENTAL_MISMATCH 并附首个差异位置。
7. 实现优雅停止与强制终止后的恢复边界：收到停止请求时完成当前不可拆分区域单元后落库并退出，不承诺强制终止后生成退出报告；被强制终止后重启仅凭已提交事务事实重建进度，恢复后的定位结果、匹配分数与审计报告必须与一次连续运行逐字节一致，检查点序号连续推进且无跳跃。
8. 实现并发发布保护与稳定业务错误码：多个工作进程对同一 SQLite 库发布阶段产物时使用事务条件更新与真实文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT；请求缺失前置阶段产物或非法阶段跳转返回带当前已提交阶段的 E_STAGE_ORDER，并提供本地 HTTP 接口触发分阶段执行与查询状态。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证定位与匹配结果、误差上界与参考比对，以及中断恢复和并发拒绝的正确性。
