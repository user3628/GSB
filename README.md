为语音合成（TTS）团队从零构建一个本地可运行的声学特征到波形的合成诊断工作台，核心问题是数值精度与误差传播。输入是本地样本目录：一份合成请求清单 JSONL，每条含 utt id、采样率（16000 或 22050 Hz）、帧移毫秒、逐帧声学特征（基频、谱包络低维系数、能量）与目标时长帧数；一份合成配置 JSON，声明声码器合成路径（逐帧重叠相加或分块相位累积）、重叠窗长与窗型、累加精度策略（float32 或 float64）、基频轨迹平滑系数与浮点容差；一份参考波形摘要目录，存放若干 utt 若干位置的期望采样值摘要用于诊断。团队需要据此完成确定性波形合成、逐帧误差溯源与不稳定样本定位，并可视化诊断整个管线。工作区为空，需从零创建 FastAPI 服务与可交互的诊断工作台。

任务环境与准备：
安装 Python 3.11 及以上，并在项目虚拟环境中安装 numpy、fastapi、uvicorn、pytest（版本自选，安装命令使用 pip）。
在本地创建样本目录：合成请求清单 JSONL、合成配置 JSON 与参考波形摘要目录，全部使用脚本确定性生成的合成声学特征，不依赖真实账号、线上服务或外部数据集。
确认 Windows 本地可运行 uvicorn 与 pytest，所有音频以文件形式落盘，不引入 Docker、容器或其他容器环境。

业务要求：
1. 服务创建接口接收样本目录、合成配置与浮点容差，校验 utt id 唯一、采样率仅取 16000 或 22050、帧移为正毫秒且不超过窗长、谱包络维度一致且各系数为有限实数、基频位于合法语音区间、容差为正小数；任一非法返回 E_PARAM 业务码并指出出错文件与行号，且不创建任何结果文件或临时目录。
2. 须实现确定性波形合成器：由谱包络与基频派生每帧正弦分量，按重叠窗逐帧叠加并做窗函数归一化，采样值按输出的采样率与帧移换算得到逐帧样本区间；合成须全部以 float64 在声明累加顺序下计算，同一输入与配置在任何执行顺序与机器时钟下产出的波形须逐字节一致，不得依赖全局随机状态。
3. 须显式支持 float32 与 float64 两条累加精度路径：同一次合成由策略参数选定主路径，另一条路径须作为对照同步合成并记录逐帧均方差异、最大绝对差与首个差异采样下标；两条路径结果须均可查询，差值统计须能定位到具体 utt 与帧号。
4. 误差传播须逐帧可观测：每帧的合成误差估计由谱包络系数相对误差、基频平滑残差与重叠窗归一化误差按权重平方和合成，并给出各来源贡献分量与参与累加的帧范围；超容差帧须在诊断报告中定位到 utt、帧号与首个越界采样位置，不得被静默计入合格结果。
5. 须实现与参考波形摘要的逐点核对：读取参考摘要目录中登记的采样位置，比较合成波形与期望摘要值，偏差超过容差须返回 E_TRACE 并给出 utt、采样下标与偏差值；参考摘要缺失或位置越出合成波形长度时返回 E_REF 并定位到 utt 与缺失位置，不得因单点失败丢弃其余 utt 的核对结果。
6. 合成进度与结果须在 SQLite 中以 utt、阶段、帧三段记录事务提交，单帧样本区间、该帧误差分量与帧进度标记须在同一事务中写入；某帧合成失败时该帧整体回滚且不得留下半写波形文件，同一 utt 其余已提交帧状态不变，重复执行同一帧不得在其上重复叠加。
7. 每次合成完成须以整体替换方式生成版本化快照，含配置指纹（合成路径、窗长窗型、累加策略与容差的内容哈希）、各 utt 逐帧摘要与波形文件内容哈希；读取快照时若检测到数据库版本与磁盘波形哈希不一致、配置指纹变化或残留旧版本波形文件，须返回 E_STALE 并定位到 utt 与版本号。
8. 进程被强制终止后重启，须从 SQLite 已提交帧进度继续，核对每个 utt 的阶段标记、波形文件内容哈希与快照版本，重算未提交帧且不重复消费已提交帧；恢复后的逐帧波形、误差分量、两路径差值摘要与快照版本序列须与无中断执行完全一致，并须提供确定性演示入口跑出上述可重复结果。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用固定本地样本验证波形逐字节可重复、两精度路径差值可定位、超容差与参考摘要偏差定位，以及强制终止后恢复一致。
