某小团队接到一项新需求，要为服务网格的灰度分流建立一套可复核的权重账本工作台，当前工作区是空的。与按请求抽取样本做回放不同，这里以「分流账本」为核心对象：网关每次裁决记录一条账本条目，含毫秒时间戳、路由键、客户端标识、实际命中版本、候选版本集合、各候选的千分比路由权重与本次请求权重。运维通过本地 HTTP 接口提交带单调版本号的路由权重快照与只含局部改动的权重迁移片段；迁移可把某路由键从一个版本迁到另一个版本，迁移期间须保留旧版本承接历史请求的能力。工作台据此为每个路由键维护归属版本账本、迁移过渡期状态与多版本权重守恒视图，并在本地回环对端执行归属探测，识别守恒失衡与迁移竞态。

任务环境与准备：
安装 Go 1.22 或以上版本，执行 go version 确认可用；不要求容器环境。
安装 SQLite 命令行工具用于查看持久化状态，Go 侧使用纯 Go SQLite 驱动，无需 CGO。
在项目内提供固定种子样本生成器，产出账本条目、路由权重快照、迁移片段与异常注入参数；样本写入临时目录，测试结束可清理。
提供本地回环探测测试服务，支持正常归属响应、连接拒绝、响应超时与返回体归属标识错误等行为，监听随机空闲端口。
运行 go mod tidy 拉取依赖，并通过 go test ./... 与本地 HTTP 演示脚本复现核心流程。

业务要求：
1. 实现账本条目与路由权重快照的解析和归一化：条目记录毫秒时间戳、路由键、客户端标识、命中版本、候选版本集合、各候选千分比权重与请求权重；快照声明单调递增版本号、生成时间、按路由键的候选版本权重与整体校验摘要。解析时校验同一路由键候选权重之和为 1000、命中版本属于候选集合、请求权重为正整数、时间戳非负，非法输入返回带业务码的 JSON 错误体且整批不入库。
2. 实现归属版本账本与权重守恒视图：为每个路由键维护各版本累计承接的请求权重与账本条目数，并按候选权重计算期望占比与实际占比，守恒判定要求实际占比与期望占比之差在声明容差内，否则返回 E_WEIGHT_IMBALANCE 并附路由键、版本与双方占比及偏差绝对值；比例类结果保留固定小数位并附舍入方式与累计舍入误差。
3. 实现路由权重迁移与过渡期状态：迁移片段只含受影响的迁移步骤并携带基础版本，声明源版本、目标版本、迁移比例千分比与过渡期毫秒；基础版本不是当前已提交版本时返回 E_STALE_BASE 且不改变任何已提交状态；过渡期内源与目标按迁移比例共同承接请求，过渡期满后源版本权重归零但历史账本仍须按原版本可查，禁止在过渡期内把源版本的承接记录重写为目标版本。
4. 实现迁移竞态识别与陈旧读裁决：同一路由键的两个迁移片段若过渡期重叠且比例之和不等于 1000，返回 E_MIGRATION_RACE 并附双方迁移标识与重叠区间；读请求携带观察版本，账本归属视图版本落后于观察版本时必须返回 E_STALE_READ 并附视图版本与观察版本，不得返回可能跨迁移步骤的混合归属结果。
5. 实现真实归属探测与超时可中断：对每个路由键向本地回环探测端点发起真实 HTTP 请求以核验当前归属版本，每次探测具备独立超时，超时后必须真实关闭底层连接并释放其占用的并发名额，返回 E_PROBE_TIMEOUT；探测结论须区分端点拒绝的 E_PROBE_REFUSED 与响应体归属标识与账本不一致的 E_PROBE_MISMATCH，并附端点与探测批次。
6. 实现账本与归属视图的级联失效与原子重建：为每个路由键维护其账本条目、累计承接权重、守恒视图与探测结论对路由权重快照版本的引用关系；权重或迁移比例变化时，受影响路由键的全部派生结果必须级联失效并在同一事务边界内原子重建，禁止出现账本已计入新权重而守恒视图仍按旧权重计算的中间可见状态，重建失败须整体回滚。
7. 实现单写者提交与多读者查询的并发一致及幂等：权重快照提交、迁移片段提交、归属重建与探测轮次按版本单写者串行执行，多个只读查询可并发读取某一完整提交版本；同一提交标识重复提交只执行一次、其余等待并复用结果，内容不一致返回 E_CONFLICTING_LEDGER；所有写操作先向 SQLite 写入意图记录再提交事务，进程在重建或探测中途被强制终止后重启须扫描未完成意图，把未提交迁移回滚为待生效并把未提交账本条目丢弃，恢复报告只含已落盘事实。
8. 实现可复现异常注入接口与统一错误码：请求参数可对探测端点注入连接拒绝、响应超时、返回体归属标识错误与迟到响应四类情形，对账本侧注入候选权重之和不为 1000、迁移比例越界与版本跳号三类情形，每类返回互不相同的业务码；错误体为含业务码与上下文的 JSON，至少覆盖 E_LEDGER_INVALID、E_WEIGHT_IMBALANCE、E_STALE_BASE、E_MIGRATION_RACE、E_STALE_READ、E_PROBE_TIMEOUT 与 E_CONFLICTING_LEDGER；异常注入只改请求参数，不得修改源码或持久化样本制造失败。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用固定本地样本验证权重守恒、迁移过渡与陈旧读裁决的逐位可复现，并确认探测超时释放与中断后账本恢复只依赖持久化事实。
