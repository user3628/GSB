工作目录中没有既有实现，需要在本机为内部代理网关团队构建一个请求签名时效窗口校验与随机数去重引擎，交付可交互的专业应用与可重复演示。引擎不作为配额限流器：它只裁决请求是否新鲜、签名是否有效、随机数是否在时效窗口内被重复使用，并以带版本号的窗口配置快照驱动这些判定。请求批次由固定种子生成器产出，包含毫秒时间戳、路由键、客户端标识、随机数、签名摘要与请求权重；代理侧对端由本地回环测试服务提供，可对签名校验与去重查询注入超时、拒绝与迟到确认行为。核心冲突在于：判定必须对同一批次逐条可复核且不受时钟偏移与窗口回滚影响，而并发批次与异常注入又要求判定可中断、可恢复且失败原因可区分。异常只能通过外部参数和真实连接行为触发，不得修改源码制造验收失败。

任务环境与准备：
安装 Go 1.21 或更高版本并确认 go version 可用；需要第三方包时在联网环境执行 go mod tidy，运行期不依赖外部网络。
SQLite 使用 Go 纯实现驱动（如 modernc.org/sqlite）以避免 CGO，无需外部数据库服务；工作目录保持为空或仅含项目自身文件。
准备本地回环测试端口作为代理对端，用于注入超时、连接拒绝与迟到确认，端口由运行时参数指定，不依赖真实网关或线上站点。
签名密钥与请求批次均由程序内置固定种子生成器产出，无外部账号、证书或附件依赖，演示脚本随项目生成。

业务要求：
1. 实现请求批次与窗口配置快照解析：请求记录含毫秒时间戳、路由键、客户端标识、随机数、签名摘要与请求权重，窗口配置声明时间戳偏移容忍上下界、随机数去重窗口长度、签名规范化字段集合与整体校验摘要；解析时校验随机数长度与字符集、权重为正整数并做溢出检查，非法记录返回 E_REQUEST_INVALID 且整批不入库。
2. 实现签名校验与时间戳偏移裁决：以固定本地密钥对规范化字段做确定性摘要比对，摘要不一致返回 E_SIGNATURE_MISMATCH；请求时间戳与服务端参考时刻的偏移早于容忍下界返回 E_TIMESTAMP_EARLY、晚于容忍上界返回 E_TIMESTAMP_LATE，且两类须附偏移毫秒数与所触边界，偏移在容忍区间内才可进入去重判定。
3. 实现随机数去重表的窗口回收语义：同一客户端在去重窗口内的随机数只允许首次成功，重复提交返回 E_NONCE_REPLAYED 并附首次占用时刻与剩余窗口毫秒；随机数记录须显式声明窗口边界包含关系与亚毫秒截断规则，窗口到期后才可回收，回收须以已持久化的首次占用时刻为依据，不得仅凭调用时的当前时刻。
4. 实现窗口配置版本绑定与整体替换：配置快照携带单调递增版本号、生成时间与校验摘要，提交时版本号不大于当前版本返回 E_STALE_SNAPSHOT；加载新快照须整体替换旧配置并识别版本变化，校验失败时旧配置必须完全可用；同一请求的签名校验、偏移裁决与去重结论须读取同一配置版本，禁止混用新旧版本的容忍区间与窗口长度。
5. 实现低延迟快速裁决与完整裁决策略：快速模式按声明的预检上限只校验部分签名与随机数并输出采样率、预检方法与结论置信说明，完整模式校验全部字段；两种模式对同一批次与同一配置版本的结论差异须逐条可核对，快速模式不得把未预检字段判为已通过，也不得放宽去重窗口。
6. 实现单写者裁决、多读者查询与并发一致：签名校验与去重裁决按批次单写者串行执行，多个只读查询可并发读取某一完整提交版本；同一请求标识重复提交只裁决一次、其余等待并复用结果，内容不一致返回 E_CONFLICTING_REQUEST；查询不得看到签名已通过而去重表仍按旧配置版本判定重放的中间可见状态。
7. 使用 SQLite 持久化配置版本、去重表占用、裁决结论与意图日志并支持强制终止恢复：签名校验状态、去重表占用与裁决结论写入前先写意图记录再提交事务；进程被强制终止后重启须扫描未完成意图，把去重表与裁决回滚到最后一个完整版本或把批次标记为已中止，恢复报告只基于已落盘事实。
8. 提供本地 HTTP 接口、异常注入参数与可重复演示脚本：接口覆盖配置提交、批次提交、按配置版本查询裁决结论与去重表占用、恢复报告查询；外部参数可注入代理对端超时、连接拒绝、迟到确认、配置版本跳号与批次中途中断五类情形，每类返回互不相同的业务码且失败响应为含业务码与上下文的 JSON，脚本使用固定样本完成一次完整裁决与一次强制终止后恢复。
