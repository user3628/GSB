在 Windows 空白工作区中，需要从零构建一个面向本地 Serverless 运行时的冷启动与并发控制验证应用，供函数平台工程师在离线环境中评估冷启动延迟与并发额度在异常条件下的行为。函数规格由本地确定性 JSON 样本提供：函数标识、运行时类型、初始化耗时微秒、每实例内存字节、单实例并发上限、函数并发上限与预留额度；调用轨迹由固定种子生成的确定性样本提供：到达毫秒时间戳、函数标识、期望执行时长微秒、优先级与重试标记。应用需模拟实例池的创建、复用、回收，维护冷启动与热启动判定，在函数并发上限与实例预留额度约束下准入调用，并通过本地 HTTP 测试端点按声明耗时真实执行。核心难点在于可复现验证与异常注入：冷启动耗时受初始化并发与预热策略影响，实例创建在资源紧张时须真实超时并释放，异常注入后复查结论必须与注入参数逐项对应，进程被强制终止后实例池与并发占用必须依据持久化事实恢复一致。

任务环境与准备：
确认 Windows 上已安装 Python 3.11 或更高版本，并可在命令行运行 python 与 pip。
创建空白工作目录，在其中初始化项目虚拟环境并安装 FastAPI、uvicorn、NumPy 与 pytest，版本以安装时解析到的稳定版本为准。
准备固定随机种子的函数规格样本与调用轨迹样本文件，全部置于项目内 samples 目录，不访问网络或外部服务。
准备本地 HTTP 测试端点脚本，可分别返回成功响应、真实不响应与主动拒绝连接，用于创建超时与执行超时验证。
确认 SQLite 由 Python 标准库提供，无需额外安装；所有数据与日志写入工作目录下本地文件。

业务要求：
1. 实现函数规格与调用轨迹的解析和归一化：解析初始化耗时微秒、内存字节、单实例并发上限与函数并发上限，校验内存与耗时为非负整数、并发上限为正整数并做溢出检查，解析失败或引用未声明函数的调用记录返回业务码 E_SPEC_INVALID 且整批不入库。
2. 实现实例池与冷启动模型：每个实例记录实例标识、绑定函数、状态、已占并发槽位与最近活跃时刻，状态至少包含 CREATING、READY、BUSY、DRAINING、TERMINATED 并规定合法迁移路径，非法迁移返回 E_INVALID_TRANSITION 且不修改已持久化状态；调用到达时无可用实例则触发创建并计为冷启动，复用 READY 实例计为热启动，二者必须在结果中可区分。
3. 实现并发准入裁决：调用按函数并发上限与实例预留额度准入，超出上限时按优先级进入有界等待队列，队列满返回 E_CONCURRENCY_LIMIT；预留额度须与按需额度分离计量，预留额度只允许声明过的函数使用，越权使用返回 E_QUOTA_DENIED 并附当前额度占用。
4. 实现真实可中断的创建与执行超时：实例创建与调用执行都必须通过本地 HTTP 测试端点的真实连接体现，单次操作用独立超时，超时后必须真实关闭连接并释放其占用的并发槽位与预留额度，返回 E_START_TIMEOUT 或 E_EXEC_TIMEOUT，不得以等待冒充超时，也不得把线程超时描述为已终止失控代码。
5. 实现可复现异常注入接口：请求参数可注入实例创建超时、执行中断、重复调用标识、并发额度瞬时耗尽与轨迹乱序五类情形，每类返回互不相同的业务码并记录注入参数；注入后复查的冷启动次数、超时次数与额度占用必须与注入参数逐项对应，同一输入重复回放须得到逐次一致的判定结果。
6. 实现实例回收与并发槽位释放的跨模块一致：实例进入 DRAINING 后不再接受新调用，已在途调用完成后才可 TERMINATED，回收须在同一事务边界内释放实例槽位、归还预留额度并更新函数可用实例计数，禁止出现实例已 TERMINATED 而并发占用未释放、或额度已归还而实例仍可接单的中间可见状态。
7. 使用 SQLite 持久化函数规格版本、实例、调用裁决、额度占用与意图日志，准入、创建、执行与回收均先写意图记录再提交事务；进程被强制终止后重启须扫描未完成意图，把未提交实例回滚为 TERMINATED 或重建为 CREATING、归还未提交额度占用，并输出仅基于已持久化事实的恢复报告，不得承诺强制终止后仍生成完整退出报告。
8. 实现单写者调度与多读者查询的并发一致：实例创建与并发准入按函数单写者串行执行，多个只读查询可并发读取某一完整提交版本；同一调用标识重复提交只执行一次、其余等待并复用结果，内容不一致返回 E_CONFLICTING_CALL，查询不得看到调用已准入而实例槽位未占用的中间状态。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
本地样本验证冷启动与热启动判定、并发额度裁决、五类异常注入结果及强制终止后恢复报告一致性。
