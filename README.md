当前为空工作区，需从零构建一个本地可运行的语音识别分片转写编辑工作台。系统输入为本地确定性音频分片（由固定种子的生成器产出的 WAV 文件，16 kHz、单声道、16 位 PCM）以及一份任务清单，清单描述每个分片对应的参考转写文本、语言标签与分片顺序。系统不依赖任何真实 ASR 模型与外部服务，而是通过一个本地可替换的转写适配层产出带词级起止时间与置信度的候选结果，再由编辑工作台完成格式互操作与版本兼容的核心工作：支持在 SRT、WebVTT、JSON 三种字幕/转写格式之间双向导入导出，维护统一的时间轴模型和多版本编辑历史，在多版本之间做差异合并与往返转换一致性校验。工作台以本地 HTTP 接口与命令行两种方式操作，所有时间以毫秒整数表示，编辑历史按单调递增版本号持久化，进程被强制终止后可从最近一致快照恢复。

任务环境与准备：
安装 Python 3.11 或更高版本，并安装 numpy、fastapi、uvicorn、pytest；将版本写入 requirements.txt，使用虚拟环境隔离。
准备本地演示数据生成脚本：以固定随机种子生成至少 3 个 WAV 分片、任务清单 JSON、一份旧结构版本 JSON 转写以及一份可整体替换的快照样本，全部提交到工作区且不依赖网络。
确认工作目录可写以进行文件锁与原子快照写入，Windows 下使用 msvcrt 文件锁实现互斥，运行前清理无关残留工作区。
准备命令行与 HTTP 启动脚本及 pytest 用例入口，所有用例仅使用本地样本与本地服务，不访问任何外部站点或账号。

业务要求：
1. 实现统一时间轴模型与三种格式编解码：以毫秒整数维护词级起止时间、文本、置信度与语言标签，实现 SRT、WebVTT、JSON 的双向导入导出；导出 SRT 时时间格式为 HH:MM:SS,mmm，WebVTT 为 HH:MM:SS.mmm，往返转换后时间轴与文本必须逐字段一致，SRT 与 JSON 往返须保留语言标签与置信度，WebVTT 往返须在 cue 负载中携带同等信息或对不可承载字段给出显式丢失报告。
2. 实现多版本编辑历史与差异合并：每次编辑生成新的单调版本号，记录增删改的词级条目与来源版本；合并两个版本时若同一时间区间出现冲突修改，须按可配置策略（后者胜出或标记冲突）处理，且合并结果须保留可追溯到来源版本的条目标识，不得静默丢改。
3. 实现往返转换一致性与版本兼容校验：对每个分片执行 JSON→SRT→JSON、JSON→WebVTT→JSON 的往返链，校验时间轴顺序、空闲间隙与重叠区间保持不变；当导入的 JSON 来自旧结构版本（缺少字段或使用旧时间单位）时，须按显式迁移规则升级并标记迁移来源，无法迁移则返回 E_INCOMPAT_FORMAT。
4. 实现持久化快照与中断恢复：以单调版本号为单位原子写入快照，包含版本号、输入分片指纹、格式配置指纹与全量时间轴摘要；进程收到停止请求时完成当前不可拆分编辑单元后退出，恢复时从最近一致快照继续，已发布版本不重复计算，且任一时刻磁盘上不得出现半写快照；对无法处理的终止信号不承诺生成退出报告，恢复仅依赖已落盘快照。
5. 实现快照整体替换时的版本识别：当检测到快照文件被整体替换（版本号回退、指纹变化或摘要不匹配）时，须识别版本变化并区分回退、篡改与正常推进三种情形，仅正常推进可被接受，其余返回 E_STALE_SNAPSHOT 并保留原状态不被覆盖，识别依据须来自快照内的版本与指纹字段而非文件时间戳。
6. 实现并发编辑的发布保护：多个工作进程对同一工作区发布新版本时使用文件锁并比较版本号，仅允许版本号连续推进；落后或重复发布须被拒绝并返回 E_STALE_VERSION，冲突期间已完成但未提交的编辑须可重放，不得造成版本号跳号或时间轴损坏。
7. 实现时间轴异常检测与业务错误码：导入或编辑时校验词级区间不得为负、不得结束早于开始、不得超出分片总时长；检测到重叠词、零长度词与超出容差的间隙时须返回带分片标识与条目位置的 E_TIMELINE_ERROR，且不得部分写入新版本。
8. 提供编辑工作台应用与本地确定性演示：本地 HTTP 接口与命令行支持导入分片、查询版本历史与差异、执行合并、请求停止与恢复、导出三种格式；演示数据含至少 3 个分片、中英混排文本与一次旧结构 JSON 迁移，并注入损坏快照与非法时间区间验证 E_STALE_SNAPSHOT 与 E_TIMELINE_ERROR；转写适配层提供统一接口，内置桩按参考文本与固定伪置信度确定性生成词级时间轴，更换实现不得改变时间轴模型与版本历史语义，一次完整运行生成涵盖各版本条目数、格式校验结果与错误码计数的固定摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地音频分片验证三格式往返一致、版本合并与快照恢复正确，并确认注入损坏快照与非法时间区间时返回指定业务错误码。
