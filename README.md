为关系与事件抽取（REE）数据工程团队从零构建一个本地可运行的关系与事件抽取结果管理与诊断工作台，核心问题是抽取结果在多个序列化格式版本之间的互操作与版本兼容判定。输入是本地样本目录：一份文档清单 JSONL，每条含 doc id、原始 UTF-8 文本与句子边界（以 Unicode 字符下标给出）；一份抽取结果文件，含文档中的实体提及（实体 id、类型、起止字符下标）、关系三元组（头实体 id、尾实体 id、关系类型、置信度）与事件记录（事件 id、触发词起止下标、事件类型、论元列表，论元含角色名与实体 id），结果文件带格式版本号与产物指纹；另有一份模式表 JSON，声明合法的实体类型、关系类型、事件类型与论元角色集合，并带模式版本号与按版本记录的类型演进历史。工作区为空，需从零创建项目：一个可交互的 FastAPI 服务，提供工程创建、格式互转与迁移、一致性校验、诊断报告与版本化快照查询接口。难点在于：字符下标计数口径、关系与事件引用的实体完整性、模式版本演进后的兼容判定与不可映射字段的显式拒绝，以及中断后的恢复一致性必须同时成立。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 fastapi、uvicorn、numpy、pytest 与 httpx（用于接口测试）。
在空白工作区初始化项目目录，准备本地确定性样本：文档清单 JSONL、带格式版本号的抽取结果文件、带版本演进历史的模式表 JSON，以及覆盖绝对偏移与紧凑格式、旧版本迁移与不可映射字段的用例。
确认可用本地端口启动 FastAPI 服务，演示入口与测试均只依赖本地样本，不访问外部站点或账号。

业务要求：
1. 工程创建与导入接口接收文档清单、抽取结果文件、模式表与字符计数口径配置，校验 doc id 唯一、句子边界有序且不越出原文长度、实体与关系事件字段完整、结果文件格式版本号与模式版本号可解析；任一非法返回 E_PARAM 或 E_DOC 业务码并指出出错文件与行号，不得写出任何结果文件或临时目录。
2. 须实现两种结果序列化格式的确定性互转：一种为按下标存储的绝对偏移格式，另一种为按句子内相对偏移加游程的紧凑格式，互转过程中所有字符下标须按统一口径（默认按 Unicode 字符计数而非 UTF-8 字节）计算；往返转换后实体、关系与事件的起止下标和引用关系必须完全一致，出现偏差须返回 E_OFFSET 并定位到 doc id 与实体 id。
3. 须实现模式版本兼容判定与迁移：模式表声明带版本号的类型集合演进历史，导入旧版本结果时逐字段比较实体类型、关系类型、事件类型与论元角色，只有可无损映射的差异（类型改名且基数属性不变、角色集合为原有子集）才允许迁移，不可映射字段须返回 E_COMPAT 并列出不兼容字段名、旧版本号与新版本号，禁止以丢弃字段或改写为默认值的方式通过迁移。
4. 须实现引用完整性与一致性校验：关系三元组的头实体与尾实体必须存在于同文档实体集合且区间不重叠越界，事件论元引用的实体必须存在，事件触发词区间必须落在某一句子边界内；校验按文档与实体 id 升序进行，任一违例返回 E_REF 并定位 doc id、事件 id 与字段名，校验失败不得留下部分迁移或部分格式化结果。
5. 须提供诊断工作台接口，输出逐文档的实体数、关系数、事件数、论元覆盖率、按类型统计的计数与置信度分位，并单独列出迁移中被改名类型、被收敛角色与被拒绝字段的清单；诊断统计须只来自已提交结果，任一文档分片缺失或被重复计数时须给出可定位到 doc id 与分片的诊断信息，而不是给出看似正常的数值。
6. 迁移与诊断进度须在 SQLite 中以文档粒度事务提交，单文档的迁移结果、一致性校验摘要与结果文件内容哈希在同一事务中写入；结果分片文件先写临时文件再原子替换并登记内容哈希，进程被强制终止后重启须核对已提交文档的内容哈希与分片文件，重算未提交文档且不重复处理已提交文档。
7. 每次迁移或完整诊断须以整体替换方式生成版本化快照，含配置指纹（格式版本号、模式版本号与字符计数口径）、逐文档结果摘要与分片哈希；读取快照时若检测到数据库版本与磁盘分片哈希不一致、格式或模式版本变化、残留旧版本结果文件，须返回 E_STALE 并定位到 doc id 与分片，禁止汇入旧数据。
8. 须提供确定性本地演示入口：固定一组覆盖绝对偏移与紧凑格式、旧模式版本迁移、不可映射字段拒绝与中断恢复的样本，跑出逐文档迁移前后格式、可映射与不可映射字段清单、实体关系事件计数、恢复前后一致性结论与快照版本序列的可重复结果，并给出可用等价参数复现的请求示例。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本验证跨格式互转往返一致、模式兼容判定、引用校验与中断恢复，诊断统计可重复。
