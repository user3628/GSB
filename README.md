当前是空白工作区，需从零构建一个本地可运行的说话人分离与识别增量编辑工作台，交付领域数据编辑与操作应用。输入为固定随机种子生成器产出的本地 WAV 分片（16 kHz、单声道、16 位 PCM），每个分片包含 2 至 3 个说话人的混合语音段、静音段与重叠说话段，另附一份 JSON 清单声明每个分片的参考说话人分段标注（以毫秒计的起止、说话人编号、可信度标记）与分片顺序，作为真值与观测来源；系统须在导入时以样本总数与标注时长上界校验清单一致性。系统不依赖任何真实分离模型、预训练声纹模型、GPU 或外部服务：分离以基于频谱幅值掩码的确定性迭代估计实现，声纹嵌入以梅尔频带能量统计拼接固定哈希投影实现，识别按最近质心完成。工作台需围绕交互延迟与计算结果一致性这一核心难点，提供分段编辑、说话人改名与合并、增量重算、版本化快照与诊断查询能力。

任务环境与准备：
安装 Python 3.10 或以上，并在虚拟环境中安装 NumPy、SciPy 的标准发行版本；Windows 下用 python -m venv 创建虚拟环境后 pip 安装。
准备本地确定性 WAV 分片生成器与 JSON 清单生成脚本：固定随机种子、16 kHz、单声道、16 位 PCM，生成含 2 至 3 个说话人、静音段与重叠说话段的样本及毫秒级参考标注与可信度标记。
保留一个空白工作区目录作为工作区根路径，用于存放分片、清单、快照记录与导出结果；确认目录可写且路径中不含需要转义的保留字符。
在任务执行前确认 Python 标准库的 http.server 与 threading 可用，无需外部服务或网络访问。

业务要求：
1. 实现频谱分离与声纹嵌入核心：对 16 位 PCM 分帧加汉宁窗后做短时傅里叶变换，按初始说话人数做确定性的迭代幅值掩码估计并重建各路分离波形；再以梅尔频带能量统计拼接固定哈希投影生成声纹嵌入；同一输入与配置必须产生逐采样点一致的分离波形与逐字节一致的嵌入，序列化采用定点量化以消除平台浮点打印差异。
2. 实现说话人识别与重叠段判定：按嵌入与说话人质心的余弦相似度做最近质心归类，质心由清单参考分段与本地种子共同确定；对分离后能量同时超过阈值的帧判定为重叠说话段并输出其起止毫秒与参与说话人；相似度差距低于可配置边界的段须标记为低置信并保留在诊断输出中，不得静默归入任一说话人。
3. 实现统一时间轴编辑模型与操作：以毫秒整数维护说话人分段（起止、说话人编号、置信度、重叠标记），支持切分、合并相邻同说话人段、改名与说话人合并、以及跨分片统一说话人身份；每次编辑生成单调版本号并记录操作来源与影响区间，编辑后时间轴不得出现负区间、结束早于开始或超分片总时长的段。
4. 实现交互查询的延迟预算与缓存一致性：单次查询（查询分段、相似度明细或重叠段）须在可配置延迟预算内返回，超出预算时返回带查询标识与已耗时字段的 E_LATENCY_BUDGET 结构化错误而非阻塞等待；缓存键须包含分片内容指纹、配置版本与编辑版本号，编辑提交后旧版本缓存结果不得被返回。
5. 实现增量重算与全量一致性校验：会话中修改分段标注、说话人数、掩码迭代次数或识别阈值时，依据各阶段版本指纹识别受影响的最早阶段，仅重算该阶段及其下游，未受影响上游结果复用；增量结果须与从零全量构建的分段清单、重叠段与识别统计逐字节一致，不一致时返回 E_INCREMENTAL_MISMATCH 并附差异摘要。
6. 实现版本化快照、优雅停止与整体替换识别：每阶段完成后以原子方式写入含阶段名、分片指纹、配置版本、编辑版本号与产物摘要的快照记录，任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分单元后退出，不承诺强制终止后生成退出报告，恢复后结果须与完整运行一致；检测到快照被整体替换（版本号回退、指纹变化或摘要不匹配）时须区分回退、篡改与正常推进，仅正常推进可被接受，其余返回 E_STALE_SNAPSHOT。
7. 实现并发编辑发布保护与业务错误码一致性：多个工作进程对同一工作区发布编辑版本时使用文件锁并比较版本号，仅允许版本号连续推进，落后、重复或跨分片错位发布返回 E_STALE_VERSION；请求缺失前置阶段产物或非法阶段跳转返回 E_INVALID_STAGE；并发期间已完成但未提交的编辑须可回退且不得影响已发布版本的可读性。
8. 提供编辑工作台应用与本地确定性演示：命令行与本地 HTTP 接口支持导入分片与清单、执行分离与识别、编辑分段与说话人、查询各阶段状态与版本指纹、请求停止、执行恢复、导出分段与重叠段结果；演示数据至少 3 个分片、覆盖 2 至 3 个说话人与重叠说话段，一次完整运行生成固定摘要，并用注入的非法阈值与越界版本号验证错误码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
