当前为空工作区，需从零构建一个本地可运行的语义与实例分割增量更新引擎及可复现实验环境。输入为固定随机种子生成器产出的本地小尺寸 RGB PNG 分片（含语义色块区域与实例区域）以及一份 JSON 配置，配置描述每个分片的语义类别颜色映射、实例分离的连通性阈值、后处理最小区域面积、融合权重与随机种子，不依赖任何真实数据集、预训练模型或 GPU。引擎对每个分片依次执行四个阶段：像素级语义分类（按配置颜色映射与邻域平滑权重打分）、实例分离（连通域标记与面积过滤）、边界后处理（形态学细化与类别冲突消解）、量化输出（写出语义掩码与实例掩码 PNG 并生成统计摘要）。工作台需支持单分片配置或图像内容变更后的增量重建，并保证增量结果与全量构建逐字节一致。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy 与 Pillow 依赖（pip 安装，无需 GPU）。
从新工作区创建项目目录，编写固定随机种子的小尺寸 RGB PNG 分片生成器与 JSON 配置样本，确保可离线重复生成。
准备本地 HTTP 服务仅监听本机回环地址，不依赖任何外部站点或真实数据集。
在工作区内提供运行脚本与命令行入口，保证所有演示与校验可在 Windows 本地完成。

业务要求：
1. 实现语义分类与实例分离两个前端阶段：逐像素按配置颜色映射打分并加入可配置邻域平滑权重，得到语义标签图；再按连通性阈值与最小区域面积阈值做实例标记与面积过滤，输出每实例的类别、像素数与外接框；同一输入与配置必须产生逐字节一致的标签图与实例清单。
2. 实现边界后处理与量化输出阶段：对语义标签图执行可配置迭代次数的细化与类别冲突消解，冲突按邻域多数与配置优先级裁决，平票时须有确定性裁决规则；最终量化写出语义掩码与实例掩码 PNG，并生成含每类像素占比、实例数与边界像素数的摘要，禁止静默丢弃类别。
3. 实现持久化阶段检查点：每个分片按分类、分离、后处理、量化四阶段完成时以原子方式写入含分片标识、阶段名、输入内容指纹、配置版本、产物摘要与单调序号的记录；写入任意位置中断不得留下半写记录，恢复时须忽略损坏或不完整记录并从最近一致检查点继续。
4. 实现优雅停止与恢复一致性：进程收到停止请求时完成当前不可拆分分片单元后退出，不承诺强制终止后生成退出报告；恢复后最终掩码与统计摘要必须与一次从零完整运行的输出逐字节一致，且检查点序号连续推进、无跳跃与重复。
5. 实现版本变化检测与增量失效传播：当分片图像内容、类别颜色映射、连通性阈值、最小面积、后处理迭代或融合权重任一变化时，通过版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建；未受影响上游产物继续复用，失效原因与各阶段指纹须在查询接口中可观测。
6. 实现增量与全量一致性校验：提供单分片更新入口，仅重建失效链路，并支持与从零全量构建的语义掩码、实例掩码与摘要做逐字节摘要比对；若检测到不一致须返回 E_INCREMENTAL_MISMATCH 并附差异文件清单，不得以增量结果覆盖校验基准。
7. 实现并发阶段发布保护与业务错误码：多工作进程对同一工作区发布阶段产物时使用文件锁并比较检查点序号，仅允许序号连续推进，落后或重复发布返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_INVALID_STAGE，非法配置（越界阈值、缺失颜色映射）返回 E_INVALID_CONFIG。
8. 提供可复现实验环境与本地演示：命令行与本地 HTTP 接口支持导入分片、查看各阶段状态与版本指纹、请求停止、执行恢复、查询增量失效原因、导出掩码与摘要；演示数据至少含 4 个分片、多类别与至少 2 个实例区域，完整运行生成固定摘要，并演示一次阶段间停止恢复与一次单分片配置变更的增量重建。
