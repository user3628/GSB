从无到有搭建时，需要为一家内部服务通信安全团队构建一个中间人检测与证书固定校验的数据处理管线与结果验证工具。管线接收本地确定性样本：每个样本是一次 TLS 连接的观测记录，包含服务端证书链（PEM）、客户端声明的证书固定策略（SPKI 哈希集合或受信根集合）、连接时的 SNI 与协议版本、以及该连接在观测窗口内的状态演进事件序列（握手开始、证书接收、固定校验、握手完成、异常终止）。固定策略可能随版本更新而整体替换，且连接过程中可能出现策略热更新。管线需对每条连接重放状态演进，逐事件判定固定校验结果，在策略版本切换时保证已进行中的连接与更新后连接处理一致，在并发多连接调度与资源预算下完成，并输出可回放、可逐条验证的一致性报告。样本中的证书链与密钥均由本地生成器产出，全部校验在内存中完成，不发起任何真实网络握手。

任务环境与准备：
安装 Go 1.22 或以上版本并设置 GOTOOLCHAIN=local；go mod init 初始化模块后引入 modernc.org/sqlite（纯 Go 驱动，无需 CGO）或 mattn/go-sqlite3（需 CGO 与 Windows 下的 GCC 工具链）。
确认 Windows 临时目录可写；示例与测试在独立临时工作目录内生成确定性证书链（标准库 crypto/x509 自建根与中间 CA）与观测样本，不访问外部网络与真实证书颁发机构。
SQLite 数据文件写入项目目录下的 data 子目录，运行前无需预置任何外部资源或账号。

业务要求：
1. 实现观测记录与固定策略的本地解析核心：从确定性样本中读取证书链 PEM、固定策略（SPKI 哈希集合或受信根集合）、SNI、协议版本与状态演进事件序列；解析时校验策略标识唯一性、哈希算法受支持性、事件序号连续性与证书链结构完好，对策略缺失、哈希算法未知、事件序号跳变分别返回 E_POLICY_MISSING、E_HASH_ALGO_UNSUPPORTED、E_EVENT_SEQ_GAP。
2. 实现证书固定校验与中间人判定核心：对每条连接按事件序列重放，在固定校验事件处按当前生效策略用标准库计算叶证书与中间证书的 SPKI 哈希并比对，策略为受信根集合时执行路径构建与验证；策略不匹配且无法构建受信路径时判定为疑似中间人并返回 E_MITM_SUSPECTED，同时记录命中策略项与叶证书指纹；SNI 与证书 SAN 不匹配、协议版本超出策略允许范围须分别给出独立业务码。
3. 实现策略版本热更新与连接一致性：策略以带递增版本号的快照存储，更新在单个 SQLite 事务内提交并整体替换生效策略集合；已进入握手阶段的连接在更新后仍沿用其开始时绑定的策略版本完成校验，新连接使用最新版本，绑定关系须在事件轨迹中逐事件可追溯，快照内容比较须识别整体替换式版本变化而不只看版本号。
4. 实现带版本号的连接状态快照与中断恢复：每条连接处理过程中按事件提交检查点，记录已处理事件序号、固定校验中间结论与策略版本绑定；运行被中断后重启从最近已提交检查点继续，未提交事件整体重做，检查点版本链跳号时返回 E_SNAPSHOT_VERSION 并回退到最近连续版本，恢复后已提交结论不回退，恢复过程不得依赖退出报告生成。
5. 实现并发连接调度与资源预算裁决：并发度、全局内存预算与单连接事件数上限均为参数，调度器按连接事件数加权排队，超并发上限的连接进入等待队列而非直接拒绝；单连接事件数超限以 E_EVENT_BUDGET 终止并保留已处理事件结论，全局预算不足时按事件数从少到多降级处理并标记 E_GLOBAL_BUDGET，两种判定在并发度变化时须保持业务码序列稳定。
6. 实现异常链路注入验证：通过外部命令行参数或配置文件构造固定哈希不匹配、策略热更新竞争、证书链断裂、事件序号跳变与快照版本跳号五类样本，分别断言对应业务码、受影响连接终态未被污染、已提交策略快照版本未被推进；注入不得修改源码，异常输入须可重复构造且与正常样本在同一批次内隔离处理。
7. 实现确定性一致性报告与可回放验证：导出 JSON 报告包含每条连接的策略版本绑定、事件轨迹、固定校验结论与业务码、快照版本链；报告按连接标识与事件序号稳定排序，交互侧重放结论与结算侧最终结论逐条一致，重复运行且输入与参数不变时报告字节级一致，时间字段只使用固定采样标记。
8. 提供可集成的 Go 包接口与完整示例：导出观测加载、策略应用、固定校验、快照回放与报告导出接口供宿主服务接入，附带本地确定性样本生成入口与一键运行示例命令；示例在 Windows 无外部网络依赖下运行，生成覆盖正常、疑似中间人、策略热更新、证书链断裂与事件跳变五类样本，输出可逐条复核的报告摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地确定性样本验证固定校验、策略版本绑定、并发调度与中断恢复，并复核报告字节级一致。
