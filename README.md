当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的 GEMM 与 BMM 矩阵乘算子库及完整示例，供上层训练推理代码以库形式集成。输入为固定随机种子生成器产出的本地 .npy 矩阵样本集：小规模（64×64×64）、中规模（512×256×384）、大规模（1024×1024×1024），以及若干批量矩阵乘样本，覆盖批量维度大于 1、非方阵、带转置 A/B 标志与含 NaN/Inf 的异常样本，均附形状清单。算子需实现分块矩阵乘核心（寄存器块 MR×NR、缓存块 MC×KC 与 KC×NC 两层，沿 K 方向累加），并要把每个输出块的计算当作一个不可拆分的状态单元：块完成后以原子方式写入含块坐标、输入形状指纹、分块方案指纹、累加策略与产物摘要的检查点，进程收到停止请求时完成当前块后退出，恢复后最终输出矩阵必须与一次从零完整运行逐字节一致。当输入矩阵内容、分块方案或累加策略变化时，须识别受影响的最早块区间并使其下游块状态失效重建。交付物为可集成的算子库、命令行示例与本地确定性演示。

任务环境与准备：
安装 Python 3.10 及以上版本，并准备 numpy 依赖（用于本地 .npy 矩阵读写与高精度参考实现），无需 GPU 与外部服务。
在空工作区创建项目目录与样本目录，编写固定随机种子的本地生成器产出小、中、大三档 GEMM 样本与批量 BMM 样本，覆盖非方阵、转置标志与含 NaN/Inf 的异常样本，并生成形状清单。
准备本地确定性演示脚本与命令行入口，约定工作区目录结构、检查点文件位置与文件锁实现方式，确保全部验证可在 Windows 本机离线执行。

业务要求：
1. 实现 GEMM 与 BMM 的统一分块内核：以寄存器块（MR×NR）与缓存块（MC×KC、KC×NC）三层分块组织 K 方向累加，支持 A/B 转置标志、任意合法非方阵形状与批量维度；BMM 在批维度最外层展开并保持每批块的独立状态标识，同一输入与分块方案必须产生逐字节一致的输出矩阵与块摘要，越界尾块须按形状清单显式裁剪并记录尾块标记。
2. 实现基于数据规模的分块参数选择：依据 M/N/K、批量大小与可配置 L1/L2 缓存预算估计工作集，从候选分块方案中按预测访存量与并行维度打分选出方案，并记录选择理由与打分明细；小规模输入须避免选出明显超出缓存预算的方案，方案指纹须作为后续块检查点与失效判定的显式输入，同一输入与预算必须选出同一方案。
3. 实现块级持久化检查点：每个输出块完成累加后以原子方式写入含分片标识、块坐标、输入形状指纹、分块方案指纹、累加策略、产物摘要与单调块序号的记录，写入过程任意位置中断不得留下半写记录；恢复时必须忽略损坏、不完整或序号重复的记录，从最近一致检查点继续，且已发布块不得重复计算。
4. 实现优雅停止与恢复一致性：进程收到停止请求时完成当前不可拆分的输出块后退出，不承诺强制终止后生成退出报告；恢复后最终输出矩阵、逐块摘要与汇总报告必须与一次从零完整运行逐字节一致，块序号连续推进、无跳跃与重复，且被中断块的部分累加中间值不得被误当作已完成状态复用。
5. 实现版本变化检测与块级失效传播：当输入矩阵内容、转置标志、分块方案、累加策略或缓存预算任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早块区间，使该区间块及其全部下游块状态失效并重建，未受影响块状态继续复用；失效原因与受影响块区间须在查询接口中可观测，禁止用旧块状态拼出与全量构建不一致的结果。
6. 实现并发块发布保护与稳定业务错误码：多个工作进程对同一工作区发布块产物时使用文件锁并比较块序号，仅允许序号连续推进，落后、重复或跨分块方案错位发布须被拒绝并返回 E_STALE_CHECKPOINT；请求缺失前置块产物、非法形状或形状清单与实际不符的块时返回 E_INVALID_SHAPE，错误对象须附分片标识、块坐标与原因。
7. 实现数值精度自校验与异常链路：对累加结果抽样若干块与按二次幂分解求和的本地高精度参考实现比对，超出可配置容差的块须报告块行列区间、最大绝对偏差与相对偏差并返回 E_NUMERIC_MISMATCH；当输入含 NaN 或 Inf 时须按 IEEE 语义传播而非静默替换，且须在诊断中标记受影响块。
8. 提供可集成的算子库接口、命令行示例与本地确定性演示：以库函数与命令行提供 GEMM/BMM 调用、分块方案查询、逐块误差报告、检查点状态与版本指纹查询、请求停止与执行恢复；示例须用本地确定性样本覆盖三档规模、非方阵、转置与含 NaN 的异常样本，一次完整运行生成固定摘要，并演示在块间触发停止后恢复且结果与完整运行一致。
