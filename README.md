奖励建模方向的新一轮迭代从空白目录起步，尚无任何代码可用，需要先把历史偏好标注整理成可训练的偏好对特征包。程序内置固定种子生成器在本地产出 JSONL 标注分片，每条含 pair_id、prompt、chosen、rejected、source、lang 与标注一致度分值，覆盖中英混排、同一 prompt 下多个偏好对、单侧回复为空与分值越界等情形；另有一份 YAML 特征配置声明词项权重、长度惩罚系数、特征投影矩阵维度与各 source 的采样预算。组件要把偏好对加工成带归因说明的奖励特征包：先做文本规范化与词项抽取，再分解偏好强度因子，构造定点量化特征向量并给出误差界，最后在预算约束下裁决保留哪些偏好对，并支持标注编辑后的增量重建。

任务环境与准备：
在 Linux（WSL Ubuntu）工作区初始化 Go 模块，使用 Go 1.22 及以上版本，确认 go 命令可用。
安装 SQLite 开发库（如 libsqlite3-dev）并准备纯 Go 或 cgo 绑定依赖，所有依赖可离线安装。
准备 YAML 解析与 JSONL 解析所需的 Go 第三方库，版本固定并写入 go.mod。
运行前确认工作区可写，SQLite 数据库文件与样本目录均位于本地工作区。

业务要求：
1. 实现文本规范化与词项特征抽取阶段：对 prompt、chosen、rejected 做 Unicode NFKC、空白折叠、全半角统一与小写化，按中文单字与拉丁连续串切分并记录字符偏移，输出每条偏好对的词项序列与来源 lang/source；空文本、仅含标点或单侧回复为空时须在对应环节返回带 pair_id 的 E_EMPTY_TEXT，不得静默跳过。
2. 实现偏好对的因子分解打分：把偏好强度分解为长度惩罚、词项重叠方向、标注一致度三个可解释因子，各因子在对数域计算并输出数值、对数贡献与最终强度的有效位数；任一因子不可计算时回退到配置下限并记录回退原因，因子出现 NaN 或 Inf 时返回带 pair_id 与因子名的 E_NUMERIC 并保留诊断上下文。
3. 实现奖励特征向量构造与量化误差界：按配置投影矩阵把词项特征映射到固定维度并做单位归一化，再以可配置位宽做定点量化，逐维记录缩放因子与量化误差界；投影矩阵维度与特征维度不符、矩阵含 NaN 或量化缩放因子为零时返回带 pair_id 与维度位置的 E_PROJECTION；误差界须由显式缩放因子与量化步长推导并随结果保留。
4. 实现预算约束下的偏好对保留裁决：在全局 token 预算与单 source 配额共同约束下，按偏好强度与语言覆盖要求决定保留哪些偏好对，采用确定性的配额分配与并列仲裁规则，输出保留清单、被淘汰对及其淘汰原因与预算余量；累计消耗超出预算时须按确定性优先级降级并记录降级决策，不得静默丢弃。
5. 实现阶段检查点与优雅停止恢复：每个阶段以 SQLite 事务写入含阶段名、输入内容指纹、配置版本、产物摘要与单调序号的记录，同一阶段同一输入只允许一条有效记录；收到停止请求时完成当前不可拆分的偏好对单元后退出，恢复后的因子打分、特征摘要与保留清单须与一次连续运行逐字节一致，强制终止后恢复仅依赖已提交记录。
6. 实现配置与标注变化的指纹识别与失效传播：当某条标注被编辑、某 source 分片被整体替换、词项权重、长度惩罚、投影矩阵或预算配置变化时，由各阶段内容摘要构成版本指纹并区分正常追加、标注级编辑、整体替换与回退，使受影响的最早阶段与最小偏好对集合失效重建，未受影响产物继续复用，回退须拒绝并返回 E_STALE_VERSION。
7. 实现增量重建与全量一致性校验：提供单标注编辑与单 source 分片替换入口，仅重建失效链路后与从零全量构建的因子打分、特征摘要、保留清单与归因报告做逐字节比对，不一致须返回 E_INCREMENTAL_MISMATCH 并附首个差异 pair_id 与差异字段。
8. 实现并发发布保护、整体替换识别与稳定业务错误码：多工作进程发布阶段产物时使用 SQLite 条件更新与真实文件锁并比较阶段内序号，仅允许序号连续推进，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT；检测到记录被整体替换时区分回退、篡改与正常推进，仅正常推进被接受；提供参数注入入口验证各业务码一致性。
