训练推理一体化的样本回填场景进入编码阶段，团队要在 Windows 空白工作区交付一个引擎：训练侧样本分片分批到达并带文本与标签，推理侧请求引用某模型版本对文本打分，同一样本后来被更正标签或补充特征时必须让受影响区域的参数与推理打分一起按依赖失效重建而非整体重训。难点在于样本回填与推理打分共享同一固定哈希特征空间与定点量化链路，量化误差会沿特化路径放大，而回填又要求重建结果与从零全量训练逐字节一致。样本与事件均由程序内置固定种子生成器产出，不依赖真实模型、GPU 或外部服务。

任务环境与准备：
在 Windows 空白工作区初始化 Go 模块，安装 Go 1.22 或以上版本并确认 go 命令可用。
引入 SQLite 驱动（如 modernc.org/sqlite，纯 Go 实现），版本以 go.mod 锁定，无需 CGO 与容器环境。
确认本地可创建临时目录与 SQLite 数据库文件，样本与事件由程序内置固定种子生成器产出，无需外部数据集或网络。
运行方式为 go run 或 go build 后的可执行程序，验证命令与期望摘要随交付说明给出。

业务要求：
1. 实现样本到达与固定哈希特征化：对样本文本做 Unicode NFKC、空白折叠与小写化，按中文单字加相邻二字与拉丁连续串切分后以固定哈希映射到配置维度，缺失值写入显式缺失桶，输出带样本标识的稀疏特征向量与冲突计数；同一输入与配置必须逐字节一致。
2. 实现训练侧增量参数维护：以定点整数累加梯度、按可配置学习率与迭代轮数更新参数，每样本更新生成的参数版本与样本批次绑定，并记录每维缩放因子与参数变化量；训练必须可中断续跑，续跑后的参数与一次连续训练逐字节一致。
3. 实现推理侧定点打分与量化误差传播追踪：对推理请求按当前有效参数版本在定点域累加打分，输出分数、所用版本摘要与每维误差界；误差界须由显式缩放因子与本地高精度参考结果给出，出现 NaN 或 Inf 时返回带请求标识与维度的 E_NUMERIC。
4. 实现回填触发的依赖失效与局部重建：当某样本标签更正或特征补充时，通过内容摘要构成的版本指纹定位受影响的最小特化单元，仅重建该单元及其下游参数与推理缓存，未受影响单元参数继续复用；局部重建结果须与从零全量训练逐字节一致，不一致返回 E_INCREMENTAL_MISMATCH 并附首个差异位置。
5. 实现 SQLite 事务化状态与强制终止恢复：以事务写入批次、参数版本、特化单元归属与推理缓存，同一单元同一版本只允许一条有效记录；进程被强制终止后仅凭已提交事实重建进度，不承诺生成退出报告，恢复后的状态与连续执行逐字节一致。
6. 实现并发回填与发布互斥：多工作进程对同一库发布参数或缓存时使用 SQLite 条件更新与文件锁，仅允许版本号连续推进，落后、重复或跨单元错位发布返回 E_STALE_CHECKPOINT，并发下不得出现同一单元两条有效参数。
7. 实现整体替换识别与异常注入链路：当样本集或配置被整体替换时，通过内容摘要与版本序号区分正常推进、整体替换与回退，替换使全部派生状态失效重建，回退拒绝并返回 E_STALE_CHECKPOINT；提供参数注入入口覆盖非法特征维度、标签非零一、学习率非正与哈希维度为零等情况，各由对应环节返回稳定业务码。
8. 提供库接口与确定性演示：以库函数加命令行提供样本导入、回填、推理打分、版本状态查询与重建报告导出，演示数据由固定种子生成器产出至少 3 个批次、跨批次更正与一次强制终止恢复，完整运行产生固定摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
