当前是空白 Windows 工作区，需要从零构建一个面向单机混合精度训练的检查点管理与精度策略组件，交付算法实现与可复现实验环境。训练以若干轮次推进，每轮包含按参数分片组织的权重、主参数（FP32 副本）、优化器动量与损失缩放系数；检查点包含各分片的主参数、动量、学习率调度位置与数据加载器游标，各分片带内容摘要与精度标记（FP16/FP32）。运维人员以带版本号的精度策略快照提交分片精度分配（哪些分片用半精度副本、哪些保持全精度、损失缩放的初始值与增长因子），并提交只含受影响分片的增量片段。核心难点是增量更新与依赖失效：某分片精度标记或损失缩放参数变化时，引用它的主参数派生摘要、参数一致性校验结果、恢复基线与显存占用估算必须级联失效并原子重建；同时进程可能被强制终止，重启后必须依据 SQLite 持久化事实把检查点与派生结构恢复到一致状态。所有数据来自本地确定性种子生成的样本张量，不依赖 GPU 或外部数据集，用户通过本地 HTTP API 操作。

任务环境与准备：
确认 Windows 上已安装 Python 3.11 及以上，并能执行 python --version。
在全新工作区创建虚拟环境并安装 NumPy、Flask 与标准库自带 sqlite3 对应的依赖包，记录安装命令。
准备固定随机种子的样本张量与本地确定性分片文件生成脚本入口，不依赖 GPU、外部数据集或网络服务。
确认本地 HTTP 端口可被占用，运行前关闭冲突服务，所有测试使用本地回环地址。

业务要求：
1. 实现检查点与分片模型：每轮检查点包含轮次序号、参数分片集合（每片含 FP16 内容摘要、FP32 主参数摘要、动量摘要与精度标记）、损失缩放系数、调度位置与数据游标；分片摘要须由固定种子生成的样本张量真实计算，摘要不一致时返回业务码 E_CHECKSUM_MISMATCH 且不提交检查点，未写满的分片不得进入正式清单。
2. 实现带单调版本号的精度策略快照与增量片段提交：增量只含受影响的参数分片与损失缩放字段并携带基础版本，基础版本不是当前版本时返回 E_STALE_BASE 且不改变任何已提交状态；提交时版本号不大于当前版本返回 E_STALE_SNAPSHOT；整份快照替换时须识别版本变化并整体替换旧策略，不得混合新旧分片的精度标记。
3. 实现依赖失效与级联重建：为每个分片维护其对主参数派生摘要、参数一致性校验结果、恢复基线与显存占用估算的引用关系；当某分片精度标记、主参数摘要、动量摘要或损失缩放参数变化时，该分片全部派生结构及依赖它的聚合产物必须级联失效并在同一事务边界内原子重建，禁止出现部分派生结构已更新而另一部分仍为旧值的中间可见状态。
4. 实现混合精度数值契约：由 FP16 副本与损失缩放系数还原参数量时使用显式定点或声明舍入方式，输出每片还原偏差与累计舍入误差，并与 FP32 主参数的逐元素比较给出最大绝对与相对偏差；损失缩放系数变化时须重算受影响分片的还原结果，同一策略版本与同一检查点重复计算必须逐位一致。
5. 实现强制终止后的恢复：检查点提交与级联重建前先写入 SQLite 意图记录再提交事务；进程在重建中途被强制终止后重启须扫描未完成意图，把检查点与派生结构回滚到最后一个完整检查点版本或将对应提交标记为已中止，恢复报告只包含已持久化事实，不得承诺强制终止后仍能生成完整退出报告。
6. 实现单写者提交与多读者查询的并发一致：检查点提交、增量提交与级联重建按提交串行执行，多个只读查询可并发读取某一完整提交版本；同一提交标识重复提交只执行一次、其余等待复用结果，内容不一致返回 E_CONFLICTING_COMMIT；查询不得看到检查点已提交而某分片主参数派生摘要仍为旧值的状态。
7. 实现快照整体加载与版本识别：策略快照文件携带格式版本、快照序号与生成时间，加载时校验版本兼容性与序号单调，加载过程在策略索引与 SQLite 表之间原子切换，切换成功后旧快照资源才可释放；任何校验失败须保持旧策略与旧派生结构不变并返回业务码。
8. 提供本地 HTTP API 与可复现实验脚本：API 覆盖策略快照提交、检查点提交、增量片段提交、按版本查询分片派生摘要与还原偏差、查询恢复报告；统一失败响应为含业务码的 JSON，至少覆盖 E_CHECKSUM_MISMATCH、E_STALE_BASE、E_STALE_SNAPSHOT、E_CONFLICTING_COMMIT、E_INVALID_PRECISION。脚本用固定种子完成一次全量提交、一次只改单片精度的增量提交、一次强制终止后恢复，输出派生结构变化与偏差摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用固定种子样本验证策略增量提交、级联重建、精度还原偏差与强制终止恢复结果一致。
