为跨语言学术检索团队从零构建一个本地可运行的论文级相关性排序与结果验证管线，核心问题是把跨语言语义匹配与分级相关性判定组织成可持久化、可断点续算的处理流程。输入是本地样本目录：一份检索请求清单 JSONL，每条含 req id、源语言查询文本、目标语言查询文本与跨语言查询嵌入向量（固定维度 float64）；一份论文库清单 JSONL，每条含 paper id、语言标识、标题与摘要嵌入向量、以及若干章节片段（片段 id、片段嵌入向量、片段质量权与置信度）；一份人工分级标注 JSONL，每条含 req id、paper id 与相关性等级（0 到 3 的整数）；一份排序配置 JSON，声明语言对、相似度下限、分级边界、每请求算力单元上限与浮点容差。工作区为空，需从零创建项目：一个 FastAPI 服务，提供作业创建、按请求分批执行、请求进度查询、快照导出与恢复接口。处理须按 request_loaded、evidence_fused、graded、committed 四个阶段推进，乱序推进被拒绝；每次阶段完成以整体替换生成版本化快照。进程被强制终止后重启只能从 SQLite 已提交的请求粒度进度继续，已提交请求不得重复消费，恢复后的逐请求等级序列与快照版本序列须与无中断执行完全一致。

任务环境与准备：
安装 Python 3.11 及以上版本并用本地 venv 隔离环境，执行 pip install fastapi uvicorn numpy pytest 安装依赖，不引入容器或外部服务。
编写生成脚本确定性产出检索请求清单、论文库清单、分级标注与排序配置四份 JSONL/JSON 文件，固定嵌入维度、等级覆盖 0 到 3，并包含若干脏数据行用于驱动 E_PARAM 与 E_LABEL 路径。
确认 Windows 下可用 curl 或等价 HTTP 客户端访问本地端口；用于验证强制终止的进程须能被显式 kill，SQLite 文件与结果目录置于可控的本地工作目录下。

业务要求：
1. 作业创建接口接收样本目录、检索请求清单、论文库清单、分级标注、排序配置与浮点容差，校验 req id 与 paper id 唯一、嵌入维度与配置一致、相关性等级为 0 到 3 的整数、容差为正小数；任一非法返回 E_PARAM 并指出出错文件与行号，且不创建任何结果文件或临时目录。
2. 证据融合须在请求内先按片段置信度降序、同分按片段 id 字典序稳定处理，把章节片段与摘要嵌入按片段质量权做加权归约并用 log-sum-exp 在 float64 下计算与跨语言查询嵌入的归一化余弦；同一输入与配置下逐请求的融合向量与余弦值须逐位可重复，不得依赖字典遍历顺序、并行分片划分或执行顺序。
3. 分级判定须把归一化余弦与片段覆盖率按配置权重合成为论文得分，再依严格递增的分级边界映射为 0 到 3 的预测等级；分级边界非严格递增、越出闭区间或权重为负时返回 E_BOUND 并指出配置键；某请求的论文全部低于相似度下限时记录空结果并继续其他请求，不得因单请求零候选整体失败。
4. 打分结果须与人工分级标注逐对核对：标注引用的 req id 或 paper id 不存在时返回 E_LABEL 并定位标注行号，预测等级与标注等级逐条比对后按请求与等级累计对角计数与混淆计数，指标只允许来自已提交请求，未提交请求不得被静默计入，任何计入项须能回溯到请求与论文对。
5. 请求必须按算力单元上限分批执行：每请求消耗单元由其片段数与论文数按配置显式换算，批开始前原子扣减全局单元预算，预算不足时按 req id 字典序将请求排入等待序列并在结果中给出等待与降级记录，并发场景下扣减总量不得超过给定上限。
6. 作业状态须以作业、阶段、请求三级记录在 SQLite 中提交，单请求的融合摘要、逐论文得分与阶段进度须在同一事务中写入；某请求失败时该请求整体回滚且其余已提交请求状态不变，不得留下部分得分或与快照版本不一致的记录。
7. 每次阶段完成须以整体替换方式生成版本化快照，含作业版本号、各请求阶段结果摘要与结果文件内容哈希；读取快照时若检测到数据库版本与磁盘结果文件哈希不一致、版本号变化或残留旧版本结果文件，须返回 E_STALE 并定位到请求与版本，禁止返回旧数据。
8. 进程被强制终止后重启须从 SQLite 已提交请求进度继续，核对每个请求的阶段标记、结果文件内容哈希与快照版本，重算未提交请求且不重复消费已提交请求；须提供确定性演示入口与诊断报告，用固定样本跑出逐请求等级序列、混淆计数、已提交与重算请求数、等待请求数、快照版本序列及恢复前后一致性结论的可重复结果，并给出可用 curl 复现的请求示例。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证跨语言证据融合、分批算力预算、快照版本与强制终止后的恢复一致性。
