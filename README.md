当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的实例分割预测结果校验与并行调度工作台，交付领域可视化与诊断工作台。输入为固定随机种子生成器产出的本地 JSON 分片：每片含一批图像样本，每个样本含 image_id、宽高、按类别分组的真值实例多边形（顶点为归一化坐标）与预测实例列表（每个预测含类别名、置信度、归一化多边形与来源算子标签）；真值由本地生成器可复现产出，作为校验的唯一真值来源。系统不依赖任何真实分割模型、预训练权重、GPU 或外部数据集。工作台按四个阶段推进：多边形解码与面积计算（把归一化顶点换算为像素域并计算多边形面积与包络框）、预测-真值实例匹配（按类别与 IoU 做唯一匹配，区分命中、重复预测、漏检与背景误报）、匹配质量聚合（按类别与来源算子统计命中率、重复率与平均 IoU），以及预算约束下的分片并行调度与汇总；全部校验结论只依赖本地分片内容与配置。

任务环境与准备：
安装 Python 3.10 及以上版本与 NumPy（使用标准数组运算，无需其他第三方库）。
在空工作区创建项目目录与运行脚本；准备固定随机种子的本地生成器，产出至少 4 个 JSON 分片，含多类别真值多边形与不同密度的预测实例，不引入外部数据集或网络下载。
准备本地 HTTP 接口所需的 Python 标准库 http.server 或同类无外部依赖的实现，确认监听端口仅用于本地回环访问。
确认文件锁、进程池与临时文件原子重命名所需的标准库能力在当前 Windows 环境可用后，再执行演示与验证步骤。

业务要求：
1. 实现多边形解码与面积计算阶段：把归一化顶点按样本宽高等比换算为像素坐标，用鞋带公式计算多边形面积与包络框，并检测顶点数不足、坐标越界与自交形态；顶点数少于 3 或面积为零的预测须标为无效并记录原因，同一输入必须产生逐字节一致的面积与包络框结果，越界坐标按可配置方式钳制或拒绝并记录。
2. 实现按类别唯一匹配核心：对每个样本在同类别真值与预测之间按 IoU 从高到低贪心匹配，IoU 使用像素域多边形交集面积与并集面积之比，默认阈值 0.5 可配置；每个真值最多匹配一个预测、每个预测最多匹配一个真值，未匹配预测按置信度区分重复预测与背景误报，并输出样本级匹配明细。
3. 实现匹配质量聚合与统计口径一致：按类别、来源算子标签与分片汇总命中数、漏检数、重复预测数、背景误报数、平均 IoU 与各项比率，分母为零时须显式记为不适用并计数；聚合结果必须与样本级匹配明细按样本标识排序后累加一致，同分实例须有确定性仲裁规则保证重复运行结果稳定。
4. 实现预算约束下的分片并行调度：以分片为调度单元，在全局最大匹配评估次数预算、单工作进程评估配额与并行进程上限三重约束下决定接纳顺序与并发度；接纳前依据样本数与预测数预估消耗，超预算分片记录为未处理并给出原因，任何时刻累计评估次数不得超过总预算，不得以线程或进程超时描述为已终止失控计算。
5. 实现并行执行与确定性归约：使用本地进程池并行处理已接纳分片，各分片的匹配明细与聚合结果按分片序号、样本标识与类别名全局排序后再归约，使并行运行的汇总输出与单进程顺序执行逐字节一致；工作进程异常须以结构化错误对象记录并保留已完成分片结果，不得因单分片失败丢弃其他分片结论。
6. 实现阶段检查点持久化与优雅停止恢复：每个分片按解码、匹配、聚合三阶段完成时以原子方式写入含分片标识、阶段名、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分样本单元后退出，不承诺强制终止后生成退出报告，恢复后最终明细与汇总须与从零完整运行逐字节一致。
7. 实现版本变化检测与增量失效传播：当分片内容、类别名集合、IoU 阈值、匹配策略或预算配置任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；失效原因与指纹须在查询接口中可观测，禁止以旧结论冒用。
8. 提供增量-全量一致性校验、并发发布保护与本地演示：提供单分片更新入口仅重建失效链路，并与从零全量构建的匹配明细与聚合摘要做逐字节比对，不一致返回 E_INCREMENTAL_MISMATCH 并附首个差异位置；多工作进程发布同一工作区时使用真实文件锁并比较分片序号，仅允许连续推进，落后或重复发布返回 E_STALE_CHECKPOINT，缺失前置阶段返回 E_INVALID_STAGE；命令行与本地 HTTP 接口支持导入分片、触发分阶段执行、查询状态与版本指纹、查看预算消耗与未处理原因、请求停止与恢复、导出结果，演示数据至少 4 个分片、含多类别与至少 3 种预测密度，并用注入的越界预算与非法阈值验证错误码。
