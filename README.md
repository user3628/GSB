当前是空白工作区，需要从零实现一个面向本地微服务流量治理场景的「限流熔断降级网关仲裁引擎」。网关接收上游客户端桩并行发起的请求，按路由规则决定是否放行：每条路由声明令牌桶限流参数、熔断器窗口与阈值、降级策略（回退响应或抛错）以及上游依赖组。真实治理网关的核心难点在于三类保护机制共享同一份资源预算：在途请求数上限、单轮探测预算与并发探测上限互相挤占，限流放行会改变熔断窗口内的请求样本，熔断打开又会触发降级从而减少对上游的消耗，因此放行、熔断探测与降级回退之间必须做出显式仲裁，而不是各自独立决策。网关还需在真实并发下保证令牌扣减、熔断状态迁移与预算占用的原子性，并把每次仲裁决策与状态迁移持久化到 SQLite，使进程重启后能从已提交的熔断窗口计数、预算账目与降级队列继续，而对未提交的在途探测按明确策略回退。

任务环境与准备：
安装 Python 3.10 及以上版本，创建虚拟环境并安装 fastapi、uvicorn、httpx、pytest、pytest-asyncio，全部从本地离线包或已缓存轮子安装。
确认 SQLite 由 Python 标准库 sqlite3 提供并在 Windows 本地文件系统上可读写，数据目录使用工作区内可写路径。
准备本地客户端桩与上游依赖桩所需的 HTTP 端口段，确保无外网访问；所有时钟基于 time.monotonic 与服务端时间戳，测试前校对本机单调时钟可用。
在工作区根目录预留数据目录、临时目录与日志目录，测试运行前清空以复现初始状态；pytest 使用固定随机种子与固定并发编排参数。

业务要求：
1. 实现路由与保护策略配置模型及校验：每条路由声明令牌桶每窗口令牌数、窗口长度、突发容量、熔断窗口长度与失败率阈值、半开探测并发上限、降级策略与上游依赖组。校验须拒绝非正令牌数、突发容量小于等于零、熔断阈值落在 (0,1] 之外以及同一路由键重复定义，非法配置返回固定业务码 E_BAD_ROUTE 且不得进入仲裁流程。
2. 实现令牌桶窗口的精确扣减与并发互斥：同一路由的令牌扣减须在路由一致性边界内串行化，扣减前以服务端单调时钟判定窗口翻页并重置令牌，突发容量允许超出稳态速率但不得超过配置上限。并发请求不得因竞争产生超额扣减，也不得因翻页竞争丢失已扣减记录，扣减结果须与单线程顺序执行同一请求序列的结果一致。
3. 实现熔断器状态机与窗口样本统计：熔断器合法状态为 closed、open、half_open，由窗口内失败率越过阈值、冷却时间到期与半开探测结果驱动迁移，非法迁移须拒绝并返回 E_INVALID_CIRCUIT。窗口内失败率计算须按窗口翻页滚动，被限流拒绝的请求不得计入失败样本，否则会污染熔断判定。
4. 实现放行、熔断探测与降级的统一仲裁：请求须同时通过路由令牌扣减、在途请求上限与熔断状态判定才可放行；熔断打开期间须按降级策略返回回退结果并标记降级原因；half_open 状态只允许不超过探测并发上限的请求作为探测放行，其余按降级处理。仲裁输出须给出首个触发的约束名与当前值，使三类机制冲突时结果可解释。
5. 实现有限预算下探测请求的排队与推迟：half_open 探测名额与在途请求上限构成共享预算，名额耗尽时候选探测请求进入该路由的探测队列，排队须有真实超时并返回 E_PROBE_BUDGET_EXHAUSTED 而非静默丢弃。排队期间若熔断器被其他探测结果重新打开，队列内请求须按降级策略处理，且不得继续占用探测名额。
6. 实现真实并发调度与状态隔离：通过本地 HTTP 接口接收并行请求，在配置的最大在途请求数约束下调度，超出上限须有序推迟而非立即失败；同一路由的令牌与熔断状态串行化，不同路由之间可并行推进。并发锁等待须有真实超时并返回 E_CONTENTION_TIMEOUT，超时不得导致令牌或预算账目出现负值。
7. 实现 SQLite 持久化与重启恢复：路由窗口令牌数、熔断窗口计数与状态、在途请求记录、探测队列与仲裁事件须在每次决策提交点以单事务写入，事务提交后才对查询可见。重启后须恢复熔断状态与预算账目，把中断时处于放行中的请求回退为未计数，未确认的探测名额须释放而不重复计入失败样本。
8. 提供本地客户端桩、诊断报告与可重复测试：实现可配置到达速率、失败注入、重试行为与到达乱序的本地客户端桩驱动并发压测，输出每路由的令牌扣减、熔断迁移、降级与探测排队明细及诊断摘要。pytest 用例须在 Windows 离线覆盖令牌超额竞争、熔断窗口翻页、半开探测预算冲突、锁等待超时、重启恢复与降级策略分支。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地并发客户端桩验证限流、熔断、降级共享预算下的仲裁正确性、重启后状态恢复一致性及诊断报告输出。
