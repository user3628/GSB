当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的图像重建三维几何数据处理管线与结果验证工具。输入为固定随机种子生成器产出的本地确定性样本：一组小尺寸多视角图像分片（灰度 PNG，16×16 到 32×32，含同一几何体的平移、缩放与明暗变化视角）与一份 JSON 重建清单，逐分片声明相机位姿（旋转矩阵与平移向量）、内参、可见点真值坐标、点云采样密度与重建算法偏好；真值点云由本地生成器按清单可复现产出，作为结果验证的唯一真值来源。管线按四个阶段推进：图像特征提取（角点与梯度方向直方图描述子）、多视角三角化（按清单位姿与内参做点对应与视线交会）、几何一致性裁剪（剔除重投影误差超阈值的点并按采样密度降采样）、结果封装（输出点云与验证摘要）。系统不依赖真实数据集、预训练模型、GPU 或外部站点，需在交互查询上满足延迟预算并在重建结果上保持跨阶段一致性。

任务环境与准备：
安装 Python 3.11 或更高版本，并以 pip 安装 numpy 与 fastapi，建议用本地虚拟环境隔离依赖。
确认工作区为空目录，运行前不放置任何既有代码或数据文件；生成器脚本与样本均在本任务内创建。
准备本地确定性样本生成脚本：以固定随机种子产出至少 3 个 16×16 至 32×32 灰度 PNG 分片、对应位姿与内参清单及真值可见点坐标，写入工作区 samples 目录。
确保工作区目录可写，用于存放检查点记录、缓存与导出的点云与验证摘要文件。
本地 HTTP 服务使用 127.0.0.1 绑定与可配置端口，不依赖任何线上站点、真实账号或付费资源。

业务要求：
1. 实现图像特征提取阶段：对每个灰度分片做固定规则规范化与梯度方向直方图描述子计算，输出带分片标识、像素坐标与描述子向量的特征清单；同一输入与配置必须产生逐字节一致的特征清单，空白图像或梯度全零的图像须返回带分片标识的 E_EMPTY_FEATURE，不得静默产出空清单。
2. 实现多视角三角化核心：依据清单声明的旋转矩阵、平移向量与内参，把跨分片匹配的特征点对转换为视线，以最小二乘交会求解三维坐标并记录每点的重投影误差与参与视角数；位姿矩阵非正交、内参含零焦距或某点仅有一个视角时须返回 E_INVALID_POSE 并附视角标识，不得输出未验证坐标。
3. 实现几何一致性裁剪与降采样：按可配置重投影误差阈值剔除不一致点，再按清单声明的采样密度做确定性体素降采样，输出裁剪与降采样前后的点数、被剔除点及原因；当剔除后剩余点数低于可配置下限或降采样后出现重复体素键时须返回 E_GEOMETRY_DEGENERATE 并保留诊断。
4. 实现交互查询的延迟预算与缓存一致性：单次查询（点云摘要、剔除原因或误差统计）须在可配置延迟预算内返回，超出预算时返回带查询标识与已耗时字段的 E_LATENCY_BUDGET 结构化错误而非阻塞等待；缓存键须包含样本指纹、位姿配置版本与阶段产物摘要，阶段指纹变化后旧缓存不得被命中，命中结果须与冷计算逐字节一致。
5. 实现持久化阶段检查点与优雅停止恢复：每阶段完成时以原子方式写入含阶段名、分片标识、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分分片单元后退出，恢复时必须忽略损坏、不完整或序号重复的记录并从最近一致检查点继续。
6. 实现版本变化检测与增量重建一致性：当某分片像素、相机位姿、内参、误差阈值或采样密度任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；增量重建完成后点云、误差统计与验证摘要须与从零全量重建逐字节一致，不一致须返回 E_INCREMENTAL_MISMATCH 并附差异点数量。
7. 实现并发发布保护与异常链路业务错误码：多工作进程对同一工作区发布阶段产物时使用文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布须被拒绝并返回 E_STALE_CHECKPOINT；请求非法阶段跳转或缺失前置阶段产物时返回 E_INVALID_STAGE，每个错误须携带阶段名与分片标识。
8. 提供结果验证工具与本地确定性演示：命令行与本地 HTTP 接口支持导入分片与清单、触发分阶段重建、查询各阶段状态与版本指纹、查看失效原因、请求停止、执行恢复、导出点云与验证摘要；演示数据至少 3 个图像分片与 6 个以上真值可见点，一次完整运行生成固定摘要，并用注入的非法位姿与非正焦距验证错误码同时演示一次阶段间停止后的恢复一致性。
