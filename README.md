当前是空白工作区，没有现存项目、代码或数据。需要从零实现一个面向本地 HTTP/2 端点的多路复用并发流调度与异常注入验证管线，用于在离线环境下复现真实 HTTP/2 连接中多路复用、流控窗口与连接级并发约束协同的核心机制。管线包含一个本地确定性 HTTP/2 服务桩（绑定回环地址与随机端口，用 asyncio 实现帧收发与窗口账目对账）、一个客户端流调度器以及一个结果验证工具。客户端在一个连接上并发发起多条请求流，每条流携带流标识、请求头、请求体分块序列与优先级声明；服务端按自身声明的流控窗口与最大并发流设置决定接收、挂起或拒绝，并以 DATA 帧与 RST_STREAM 反馈状态，客户端与服务端的窗口账目必须可对账一致。管线须维护流状态机、连接级与流级窗口账目、流优先级调度次序，把每次帧收发与调度决策持久化到 SQLite，并在进程重启后依据持久化状态恢复未完成流与窗口账目。真实难点在于：客户端窗口扣减必须与服务端实际接收量对账一致；超时重传不得使同一流重复计入已完成集合；客户端因预算耗尽被迫推迟发送时窗口账目不得被错误扣减；异常注入必须在指定帧位置复现失败且失败后连接与本地状态可判定。

任务环境与准备：
安装 Python 3.11 及以上版本，创建虚拟环境并安装 aiohttp 与 pytest 的指定版本，全程离线可复现。
在 Windows 上确认回环地址可用并能绑定随机端口，任务执行时以本地服务桩启动，不依赖真实站点或外部账号。
准备 SQLite 数据库文件目录与本地样本目录，样本与随机种子固定，无需 GPU 与外部数据集。
运行前清空临时目录与数据库文件以确保起点一致，所有测试通过 pytest 在本机执行。

业务要求：
1. 实现 HTTP/2 帧编解码与流标识管理：须支持 HEADERS、DATA、RST_STREAM、WINDOW_UPDATE、SETTINGS、PING 六类帧的编码与解码，帧头包含长度、类型、标志位与流标识，客户端分配的流标识须为奇数递增且同一连接内不得重复；解码须拒绝长度与帧头声明不符、帧类型未知与流标识为偶数的帧，并返回互不重叠的业务码。
2. 实现连接级与流级流控窗口账目及与服务端对账：初始窗口由 SETTINGS 声明，每发送 DATA 帧须同时扣减连接窗口与流窗口，窗口不足以容纳整块数据时须拆分或推迟发送；收到 WINDOW_UPDATE 须按增量恢复对应窗口并拒绝使窗口超过上限的更新；任何时刻窗口不得为负，且客户端扣减总量须与服务端累计接收 DATA 字节数对账一致，不一致须以固定业务码报告。
3. 实现多路复用的并发流调度与优先级次序：同一连接上的并发流不得超过声明的最大并发流数，超限的请求须进入等待队列且不得被分配流标识；就绪流按优先级权重与流标识序的确定次序调度并轮转，高权重流不得完全饿死低权重流；调度决策须记录到事件序列。
4. 实现流状态机与非法迁移拒绝：流状态取值须为 idle、open、half_closed_local、half_closed_remote、closed，迁移由发送 HEADERS、发送带结束标志的 DATA、收到 RST_STREAM 与收到 END_STREAM 驱动；非法迁移须拒绝并返回 E_INVALID_STREAM_STATE，关闭后的流不得再发送数据。
5. 实现异常注入与可复现验证：注入配置来自请求参数或配置文件，按注入点名称（encode_frame、window_debit、schedule、send_data、receive_window_update）与触发计数精确定位，仅在指定注入点第 N 次被调用时抛出指定异常，其余调用正常执行；关闭注入后以相同输入重跑，须得到与从未失败时逐字段一致的调度结果与窗口账目。
6. 实现超时重传、预算耗尽推迟与去重语义：单流发送可声明基于真实单调时钟的预算，预算耗尽须以 E_STREAM_BUDGET_EXHAUSTED 推迟该流而非终止连接，且推迟期间不得继续扣减窗口；重传到达时若该流已被标记完成则不得重复计入结果集合，也不得改变窗口账目；重传次数超过上限须以固定业务码转入失败集合并保留失败原因。
7. 实现 SQLite 持久化与重启恢复一致性：流状态、连接与流窗口账目、等待队列次序、注入计数水位与事件序列须在提交点以单事务写入，事务提交后才对查询可见；进程重启后须把中断时处于发送中的流回退为可再调度状态并恢复窗口账目，恢复后继续推进的最终结果须与不中断参照运行一致。
8. 提供本地 HTTP 查询接口、验证工具与可重复测试：通过本地 HTTP 查询连接级与流级窗口账目、流状态快照、调度事件序列与失败集合；验证工具须对同一批请求在未注入与各注入点失败后重跑的执行结果比对并给出是否等价的结论。pytest 用例须在 Windows 离线覆盖窗口扣减、并发流上限等待、优先级轮转、非法状态迁移、异常注入计数与重启恢复。
