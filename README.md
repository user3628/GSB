当前为空工作区，需从零构建一个本地可运行的卷积与插值算子工作台，交付领域数据编辑与操作应用，核心难点是算子计算状态的演进与中断恢复一致性。输入为固定随机种子生成的本地 .npy 张量分片（形状 NHWC，含小尺寸与中尺寸、奇数通道、边界填充可见样本）以及一份 JSON 算子清单，清单描述每个分片要执行的算子链：一维与二维卷积（可配置卷积核、步长、填充、膨胀）、最近邻/双线性/双三次插值（可配置缩放因子与对齐模式）、以及它们的串联顺序；另附一份每步期望输出形状与数值区间的声明，作为可核对真值的观测来源。算子需以 NumPy 实现分块卷积核心与插值坐标映射，不使用 GPU、真实模型或外部服务。系统须把算子链拆成阶段逐段执行，每阶段完成后持久化检查点；进程被优雅停止后要能从最近一致检查点恢复，且恢复结果与一次完整运行逐字节一致；当分片张量、卷积参数或插值参数变化时须识别受影响阶段并使其及下游失效重建。

任务环境与准备：
安装 Python 3.11 并在虚拟环境中安装 numpy 与 pytest；Windows 本地运行，不使用容器。
创建空工作区目录，准备本地确定性样本生成脚本，用固定随机种子生成至少 3 个 NHWC 形状的 .npy 张量分片与配套 JSON 算子清单及形状和数值区间声明。
确认本地 HTTP 服务端口可用，文件锁使用标准库实现；准备本地测试脚本用于触发阶段间优雅停止与恢复流程。

业务要求：
1. 实现二维与一维卷积核：支持 NHWC 布局、可配置卷积核尺寸、步长、填充模式（same/valid）与膨胀率，按输出分块与输出通道分块组织计算，索引越界处按零填充处理；输出形状与数值须与清单声明的期望形状及数值区间核对，不符时返回带分片标识与块位置的业务错误码 E_SHAPE_MISMATCH。
2. 实现插值核：支持最近邻、双线性与双三次三种模式的任意缩放因子（含上采样与下采样）及 half_pixel/align_corners 两种坐标对齐模式，坐标映射全程在浮点域计算并按输出位置裁剪边界；同一输入与参数必须产生逐字节一致的输出，坐标越界须被裁剪而非静默回绕。
3. 实现算子链串联与阶段划分：按清单顺序把卷积与插值串成算子链，每个算子为一个阶段，阶段间传递张量与形状元数据；当清单出现非法算子名、参数缺失或前序阶段形状与当前算子不兼容时返回 E_INVALID_STAGE 并指出算子位置，不得执行部分链路。
4. 实现持久化阶段检查点：每个阶段完成时以原子方式写入含算子序号、算子参数指纹、输入张量指纹、配置版本、产物摘要与单调序号的记录，写入过程任意位置中断不得留下半写记录；恢复时必须忽略损坏、不完整或序号重复的记录，从最近一致检查点继续执行剩余算子。
5. 实现优雅停止与恢复一致性：进程收到停止请求时完成当前不可拆分阶段后退出，不承诺强制终止后生成退出报告；恢复后最终输出张量、各阶段形状轨迹与摘要必须与一次从零完整运行的对应产物逐字节一致，且检查点序号连续推进、无跳跃与重复发布。
6. 实现版本变化检测与失效传播：当分片张量内容、卷积参数、插值参数或对齐模式任一变化时，通过版本指纹识别受影响的最早算子阶段，使该阶段及其全部下游阶段产物失效并重建；未受影响上游产物继续复用，失效原因与指纹须可查询，禁止用旧版本产物冒充新结果。
7. 实现并发安全发布保护：多个工作进程对同一工作区发布阶段产物时使用文件锁并比较算子序号，仅允许序号连续推进，落后或重复发布须被拒绝并返回稳定业务码 E_STALE_CHECKPOINT；请求缺失前置阶段产物的下游计算须返回 E_INVALID_STAGE。
8. 提供本地确定性演示数据与交互应用：至少 3 个张量分片，覆盖小与中尺寸、奇数通道、上采样与下采样以及带填充边界样本，一次完整运行生成固定摘要；演示中人为在阶段间触发停止后恢复，并用注入的非法卷积参数与越界缩放因子验证错误码；命令行与本地 HTTP 接口支持导入分片、查看阶段状态与版本指纹、请求停止、执行恢复、导出算子链结果与形状轨迹。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证卷积与插值结果、中断恢复与全量运行逐字节一致，并核对失效重建与业务错误码。
