当前是空白工作区，需从零构建一个本地可运行的核密度漂移检测与分布比对工作台，交付可交互的专业应用与可重复演示。输入为固定随机种子生成的本地 NPZ 样本集：一份参考分布样本与一份待检分布样本，各含特征矩阵与样本来源标签，分为小规模（约 1500 行、8 列）与大规模（约 15000 行、24 列）两档，含连续列、重尾列与少量缺失值；另附 JSON 声明文件记录每档行数、列数、缺失列下标与期望的输出统计口径。工作台以确定性方式实现逐列核密度估计与分布比对：按配置的核函数（高斯或 Epanechnikov）、带宽选择规则（Silverman、Scott 或可指定数值）与分块大小对密度做分块累加评估，计算逐列最大均值差异（MMD）、KL 近似散度与逐列漂移判定，并给出分块累加的误差传播上界与批大小无关的归约一致性结果。

任务环境与准备：
安装 Python 3.11 与 NumPy 1.26（pip install numpy==1.26.4），仅使用标准库与 NumPy，不依赖网络与外部服务。
运行本地固定种子生成器脚本，产出参考与待检两档 NPZ 样本及 JSON 声明文件，生成结果须可重复重建。
确保工作区可写，用于存放阶段检查点记录、增量缓存与导出的密度曲线及判定报告；本地 HTTP 接口绑定 127.0.0.1 的可用端口。

业务要求：
1. 实现核密度估计核心：对每列按可配置核函数与带宽规则（Silverman、Scott 或指定数值）在查询网格上做密度评估，评估按可配置分块大小累加，带宽须由样本标准差与样本量显式估计；对含缺失值的列须按可配置填充后重新估计并在诊断中标明，同一输入与配置必须产生逐字节一致的密度曲线与核参数。
2. 实现分块累加的数值稳定性控制：分块密度累加须采用可配置的补偿求和或成对求和，并以本地高精度参考曲线比对给出误差上界；当带宽为零、样本量不足以估计标准差或核参数中出现 NaN、Inf 时须返回带列名与阶段位置的 E_NUMERIC，不得静默返回空曲线。
3. 实现分布比对指标：以参考与待检两档样本的核密度曲线计算逐列 MMD（基于核矩阵的分块累加估计）与 KL 近似散度，两个指标均须说明各自所依赖的样本量与核参数，并按声明文件的口径输出逐列汇总；当两样本列数或列名不一致时返回 E_COLUMN_MISMATCH 并附差异清单。
4. 实现漂移判定与阈值裁决：按可配置阈值与至少两列的自助重采样显著性水平判定每列是否漂移，重采样由固定种子派生且不依赖外部随机源；判定结果须记录得分、阈值、显著性依据与参与重采样的样本索引范围，同输入同配置结果逐字节一致，阈值或显著性水平变化须改变判定并留下配置版本指纹。
5. 实现分批评估与跨批归约一致性：支持把待检样本按任意批大小与任意批顺序分批送入评估，逐批核密度贡献须经显式规格化累加器归约，使不同批大小与批顺序下的最终密度曲线、MMD、KL 与漂移判定逐字节一致；空批或批内特征维度与参考不一致时须返回带批号与位置的 E_INVALID_BATCH，已归约结果不得被污染。
6. 实现持久化阶段检查点与优雅停止恢复：每个阶段（带宽估计、分块密度、指标计算、漂移判定）完成时以原子方式写入含阶段名、输入内容指纹、配置版本、累加器摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分分块单元后退出，不承诺强制终止后生成退出报告；恢复后密度曲线、指标与判定结果须与一次从零完整运行逐字节一致，检查点序号连续推进。
7. 实现版本变化检测、增量失效与并发发布保护：当参考或待检样本内容、核函数、带宽规则、分块大小、阈值或显著性水平任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其下游失效并重建，未受影响上游继续复用且失效原因在查询接口可观测；多工作进程发布阶段产物时使用文件锁并比较阶段内序号，仅允许序号连续推进，落后或重复发布返回 E_STALE_CHECKPOINT，缺失前置阶段产物返回 E_INVALID_STAGE。
8. 提供诊断工作台应用与本地确定性演示：命令行与本地 HTTP 接口支持导入两档样本、设置核与判定配置、触发分阶段评估、查询各阶段状态与版本指纹、查看逐列误差上界与漂移依据、请求停止、执行恢复、导出密度曲线与判定报告；演示数据覆盖两个规模档与含缺失列，完整运行生成固定摘要，并演示一次配置变更后的增量重算与一次中断恢复。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
