一名独立开发者接手了本地搜索场景的完整需求，要在空工作区交付一个稀疏倒排索构建与压缩查询实验台，核心问题是数值精度与误差传播：BM25 权重在对数域计算、定点量化存储、压缩解码与累加的过程中，误差会沿倒排链路放大，每次查询都必须给出一份可复核的误差上界，并能与本地高精度参考结果比对。输入为固定种子生成器产出的 JSONL 文档分片（含 doc_id、标题、正文、lang、source，覆盖中英混排、重复文档、空正文与超长文档）与一份 YAML 索引配置，声明分词粒度、停用词表、跳表步长、倒排分块大小、差值编码与变长字节编码参数、BM25 参数、定点量化位宽、查询缓存容量与查询延迟预算。工作区为空，全部数据与参考值由本地生成器可复现产出，不依赖真实站点、外部服务或下载数据集。

任务环境与准备：
安装 Go 1.22 或以上版本并确认 go version 可用；SQLite 通过纯 Go 驱动（如 modernc.org/sqlite）在项目内引入，无需额外系统安装。
创建全新空工作区并在其中初始化 Go 模块；准备本地种子数据生成器所需的配置文件，运行生成器产出 JSONL 文档分片、YAML 索引配置与高精度 BM25 参考结果，所有数据在本地固定种子下可复现。
确保运行环境可监听本地回环端口以提供 HTTP 接口，并为工作区目录分配可写权限以存放 SQLite 数据库与检查点文件。

业务要求：
1. 实现分词与词项编号阶段：对标题与正文分别做 Unicode NFKC、空白折叠、全半角统一与小写化，中文按单字与相邻二字组合切分、拉丁字母数字按连续串切分，去除停用词后为每个词项分配稳定单调递增的整数编号，输出带文档标识与字符偏移的 token 序列；同一输入与配置必须产生逐字节一致的词项表，空正文文档须保留空词项集而非跳过。
2. 实现文档频次与权重统计：统计每个词项的文档频次、每篇文档长度与平均文档长度，按可配置 BM25 参数在自然对数域计算文档-词项权重，并以配置位宽做定点量化存储且记录每个词项的缩放因子与量化误差界；对数域出现非有限值、缩放因子为零或量化后权重全为零时须返回带词项与文档标识的稳定业务码 E_NUMERIC，不得静默钳制。
3. 实现倒排列表构建与压缩解码：每个词项的倒排列表按 doc_id 升序组织，采用差值编码后以变长字节编码写入分块，为每个倒排列表按跳表步长稀疏构建跳表并记录跳表项对应 doc_id；解压任意分块得到的 doc_id 序列与量化权重必须与未压缩形式逐项一致，若出现解码不一致须返回 E_DECODE_MISMATCH 并定位首个差异分块。
4. 实现压缩查询执行与分数还原：支持多词项的与、或查询语义，利用跳表在多个列表间跳跃求交，按需解压命中分块并累加量化权重后还原为浮点分数，输出按分数降序、同分按 doc_id 升序的命中清单及每项分数分量；空查询、词项全集未命中或解码后权重全为零时须返回带查询标识的诊断结论而非空结果。
5. 实现误差传播诊断与有效位数估计：对每个查询结果输出各词项权重的对数贡献、量化与压缩解码引入的误差界以及最终分数的有效位数，并给出语料级误差界随文档数与词项数变化的估计；误差界必须由显式缩放因子、量化步长与本地高精度参考实现逐项给出，不得从缺失信息推断，同输入同配置的诊断摘要须逐字节一致。
6. 实现查询延迟预算与缓存一致性：单次查询须在配置延迟预算内返回，超出预算时返回带查询标识与已耗时字段的 E_LATENCY_BUDGET 结构化错误而非阻塞等待或静默截断；缓存键须包含查询词项集合、查询语义、配置版本与索引版本指纹，缓存命中结果须与重新计算结果逐字节一致，配置变化后旧缓存不得被命中。
7. 实现阶段检查点持久化与增量失效传播：每阶段完成时以事务写入含阶段名、输入分片内容摘要、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；当文档内容、停用词表、跳表步长、分块大小、编码参数、BM25 参数或量化位宽任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游倒排、跳表与诊断产物失效并重建，未受影响上游继续复用，且增量结果须与从零全量构建逐字节比对。
8. 实现 SQLite 事务化存储、并发发布保护与本地确定性演示：同一阶段同一文档只允许一条有效记录，多工作进程发布时使用事务条件更新与真实文件锁并比较序号，仅允许序号连续推进，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_PREREQ_MISSING；提供命令行与本地 HTTP 接口支持导入分片、触发分阶段执行、查询状态与版本指纹、查看误差报告与缓存命中、请求优雅停止与执行恢复，并给出至少含中英混排、重复文档与空正文的确定性演示数据及固定运行摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
