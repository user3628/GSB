当前是空白工作区，需要在 Windows 本地从零构建一个面向单机训练场景的检查点存储层组件，供上层训练编排器集成，核心业务问题是分片级去重与引用计数回收。训练以若干轮次推进，每轮产生参数分片与优化器动量分片；连续两轮之间往往只有少数分片发生变化，其余分片内容完全相同。组件不能按检查点整目录存放分片，而要以内容摘要为唯一标识把分片存入共享的分片池，检查点只需记录自己引用了哪些分片标识以及每片的内容摘要。删除或裁剪某个检查点时，只递减其引用的分片引用计数，引用计数归零的分片才允许真正从池中移除，且必须保证任一时刻仍有检查点引用的分片不会被误删。难点在于去重与回收之间的状态耦合：同一分片可能被多个检查点同时写入或同时释放，引用计数的读取、占用与递减必须与检查点元数据提交处于同一事务边界；进程可能在任何时刻被强制终止，重启后必须依据持久化的引用记录与意图日志重建引用计数并判定孤儿分片，不能假设强制终止后仍能生成完整退出报告。用户通过本地 HTTP API 提交轮次写入、查询引用计数与分片池状态、触发裁剪与孤儿回收、查询恢复报告。所有分片内容由固定随机种子在本地生成，不依赖 GPU 或外部存储。

任务环境与准备：
安装 Python 3.11 或更高版本，并确保 pip 可用。
安装 FastAPI、uvicorn、numpy 与 pytest，版本以本地已安装或可离线安装为准。
在空白工作区创建项目目录，确保当前用户对工作目录有读写权限，用于存放分片池物理文件与 SQLite 数据库。
确认本地回环端口可绑定，用于启动 HTTP 服务与演示脚本。
所有分片样本由脚本按固定随机种子在本地生成，无需 GPU 或外部存储。

业务要求：
1. 实现分片池与检查点引用模型：每个分片以 SHA-256 内容摘要为唯一标识存入池中并记录字节大小与引用计数，检查点元数据只记录轮次序号、其引用的分片标识列表与调度器位置，不得复制分片内容；同一内容的分片重复写入必须命中已有条目并只递增引用计数，不得产生第二份物理分片。
2. 实现轮次写入的增量语义：提交新一轮时由调用方给出与上一轮相比发生变化的参数分片与动量分片集合，未变化的分片直接沿用上一轮引用；写入须在同一事务边界内完成分片入库、引用计数递增与检查点元数据提交，任一步失败则整轮不生效，禁止出现分片已入库而检查点未引用或检查点已引用而分片计数未增的中间状态。
3. 定义检查点与分片条目状态机：检查点至少包含 PENDING、COMMITTED、RELEASED、INVALID 四种状态，分片条目至少包含 LIVE、ORPHAN、RECLAIMED 三种状态，并各自规定合法迁移路径；非法迁移返回 E_INVALID_TRANSITION 且不得修改已持久化状态；被任一 COMMITTED 检查点引用的分片不得迁移为 ORPHAN。
4. 实现引用计数递减与物理回收：裁剪或释放检查点时递减其引用的全部分片计数，计数归零的分片先迁移为 ORPHAN 并记录迁移时刻，再由回收流程真实移除其物理文件并把状态置为 RECLAIMED；回收必须在同一事务内校验该分片当前引用计数确为零且无 COMMITTED 检查点引用，否则返回 E_RECLAIM_BLOCKED 并保留分片。
5. 实现强制终止后的引用计数重建：写入、释放与回收前先写意图记录，进程被强制终止后重启须扫描全部已提交检查点重新汇总每个分片的期望引用计数，与持久化计数不一致的分片须标记为需修正并在恢复报告中给出差异明细；未完成写入产生的分片不得被计入任何检查点引用，须依据意图记录判定为孤儿候选而非直接删除。
6. 实现孤儿判定与回收安全边界：对未被任何 COMMITTED 检查点引用且意图日志中不存在进行中写入的分片，须在完成恢复报告后才允许回收；回收顺序须按分片大小降序与摘要字典序稳定排序，输出本次回收的分片数、字节数与阻挡回收的分片清单及原因，保证同一持久化状态重复触发回收得到一致的回收计划。
7. 实现单写者写入与多读者查询的并发一致及幂等：写入、释放与回收按单写者串行执行，多个只读查询可并发读取引用计数与分片池状态；同一轮次重复提交写入只执行一次、其余等待并复用结果，若重复提交的分片集合与首次不一致则返回 E_CONFLICTING_REQUEST；查询只能看到某一完整提交版本，不得出现检查点已 COMMITTED 而某分片计数尚未递增的中间可见状态。
8. 提供本地 HTTP API 与可重复演示脚本：API 覆盖轮次提交、查询检查点与分片引用计数、触发裁剪与孤儿回收、查询恢复报告，统一错误响应为含业务码的 JSON，至少覆盖 E_CHECKSUM_MISMATCH、E_INVALID_TRANSITION、E_RECLAIM_BLOCKED、E_CONFLICTING_REQUEST；脚本用固定种子生成连续若干轮仅部分变化的分片，完成一次去重写入、一次裁剪递减、一次强制终止后重建计数与一轮孤儿回收并输出各步引用计数变化。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
