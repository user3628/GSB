为多标签图像分类离线评估团队从零构建一个本地可运行的评估管线，核心问题是评估结果的可复现验证与入参驱动的可控异常注入。输入是本地样本目录：一份图像清单 JSONL，每条含 image id、宽高与真实标签集合（每个标签含类别名与置信度真值）；一份类别词表 JSON，含每个类别的名称、固定维度嵌入向量与所属标签组；一份模型预测文件 JSONL，每条含 image id、预测标签名、置信度分数与嵌入向量。管线需完成逐图多标签预测与真实标签的确定性匹配、按标签组汇总命中与假正例计数，并支持通过创建作业时传入的注入配置在声明阶段制造指定故障，验证错误定位与部分结果恢复。工作区为空，需从零创建项目：一个 FastAPI 服务，提供评估作业创建、分阶段执行、进度与统计查询、版本化快照获取接口，并提供确定性演示入口。

任务环境与准备：
安装 Python 3.11 及以上版本，创建虚拟环境并安装 FastAPI、uvicorn、NumPy 与 pytest，版本以本地可安装的最新稳定版为准。
准备本地样本目录：编写脚本确定性生成图像清单 JSONL、类别词表 JSON 与预测文件 JSONL，覆盖多标签重叠、零预测图像、置信度越界注入点与标签缺失注入点。
确认 SQLite 由 Python 标准库提供，无需额外安装，运行前清空结果目录与数据库文件以从零初始状态开始。
准备异常注入参数样例与等价复现命令，用于验证注入故障时业务码、定位信息与部分结果恢复清单。

业务要求：
1. 评估作业创建接口接收样本目录、类别词表、预测文件、匹配阈值、服务端口与异常注入配置，校验文件存在、image id 唯一、嵌入维度与词表一致、阈值位于开区间、端口可用、注入配置只引用合法阶段与合法注入类型；任一非法返回 E_PARAM 业务码并指出出错文件与行号，不创建任何结果文件、临时目录或作业状态。
2. 须实现确定性多标签匹配：同一图像内预测按置信度降序、同分按标签名字典序处理，每个预测只匹配一个尚未被占用的真实标签，匹配以标签名完全一致且置信度不低于阈值为前提，未匹配上的预测计为假正例；匹配顺序与 worker 分配、字典遍历顺序无关，同一输入下逐图匹配结果须逐位可重复。
3. 须实现按标签组汇总：通过类别词表把每个标签映射到所属标签组，分别累计命中数、假正例数与漏检数，标签名不在词表中或缺失标签组时返回 E_CLASS 并定位 image id 与标签名；某图像无任何预测或全部预测低于阈值时记录空结果并继续其他图像，不得因单图零预测整体失败。
4. 须实现入参驱动的可复现异常注入：在声明阶段按注入类型制造输入损坏、预测置信度越界、标签未在词表中三类故障之一，每类注入须给出确定失败点并返回带定位信息的 E_INPUT、E_CONF 或 E_CLASS 业务码；未注入故障时任何合法输入不得产生这些业务码，注入故障不得修改源数据文件。
5. 须实现部分结果恢复语义：注入故障导致某分片失败时，该分片在 SQLite 中的提交必须整体回滚，其余已提交分片结果保持可用并可查询统计；服务须输出已提交与未提交分片清单，恢复后重跑只处理未提交分片，最终统计须与不注入故障的全量执行完全一致。
6. 评估进度与统计须在 SQLite 中以图像粒度事务提交，逐图结果以原子替换写入不可分割的分片文件并登记内容哈希，分片提交与统计汇总在同一事务中完成；每次完整评估或恢复完成后须生成整体替换的版本化快照，含作业版本号、各图像匹配摘要与分片哈希。
7. 读取快照或导出统计时须检测版本一致性：若磁盘分片哈希与数据库记录不一致、快照版本落后于已提交分片或残留旧版本分片，须返回 E_STALE 并定位到具体分片与图像，禁止把旧数据静默汇入统计；作业未完成时读取快照返回 E_PENDING。
8. 进程被强制终止后重启须从 SQLite 已提交进度继续，核对每个分片的哈希与提交标记，重算未提交分片且不重复消费已提交分片；须提供确定性本地演示入口，固定样本、阈值与注入序列跑出逐图匹配计数、按标签组指标、被注入故障类型与定位、恢复前后一致性结论的可重复结果，并给出可用等价参数复现的请求示例。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证多标签匹配统计、注入故障定位、分片恢复与版本快照一致性，并给出可重复运行结果。
