当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的跨语言多源事实陈述核验与证据链冲突消解组件，交付可集成的领域组件与完整示例。业务场景为多语种知识库的事实陈述合并：同一实体在中文与英文语料中会给出互相冲突的数值陈述（人口数、面积、成立年份、任期起止月份），系统需把每条陈述归一到统一表述后做冲突消解，产出唯一可信陈述并保留完整证据链。输入为若干本地 UTF-8 JSONL 语料分片，每条含 claim_id、entity_id、lang、raw_value、unit、表述句式、来源渠道标识与可选可信度标注；数值由固定随机种子本地生成器产出，单位体系包含万、亿、平方公里、平方英里、年月混合区间，并含跨语言同义单位与少量单位缺失、负值、区间倒置样本。系统按四阶段推进：表述规范化与数值解析、单位与日历归一、同实体冲突消解、证据链汇总导出；全程使用定点量化与十进制精确运算，禁止依赖浮点近似判断取值相等。

任务环境与准备：
安装 Python 3.10 及以上，创建虚拟环境并安装 numpy 与 pytest（版本号在 requirements 中固定）。
在空工作区建立 src、samples、configs、tests 目录，语料分片与旧版证据清单由固定随机种子的本地生成器脚本产出，不下载外部数据。
确认运行环境不依赖网络、GPU 或容器，所有命令可在 Windows 终端直接执行。

业务要求：
1. 实现表述规范化与数值解析阶段：对 raw_value 与表述句式做 Unicode NFKC、空白折叠、全半角统一，识别中文数字量词与英文缩写数字，输出带字符偏移的数值片段、单位片段与解析来源标记；无法解析、数值片段为空或出现歧义分隔符（如千分位与小数点冲突）时返回带 claim_id 与偏移的 E_PARSE_AMBIGUOUS，同输入同配置须逐字节一致。
2. 实现单位换算与年月日历归一：把万、亿、平方公里、平方英里、年月区间等换算到统一基准单位，数值以定点十进制表示并记录换算因子与精度位数，年月区间按统一月序号展开并保留原始开闭语义；单位缺失、未知单位或区间开闭冲突时以可配置兜底策略标记为待复核而非静默丢弃，换算因子与位数须可在诊断中逐个复算。
3. 实现同实体冲突消解核心：在同一 entity_id 下按要素类别对归一声明分组，取值不相等即判为冲突，依据来源渠道先验、语言权重与陈述新鲜度在对数域合成可信度，输出唯一可信陈述与被降级声明；可信度并列时须有确定性仲裁规则，且判定取值相等须使用十进制精确比较而非浮点容差。
4. 实现证据链构造与可追溯导出：为每条被采纳或被降级声明保留从原始片段偏移、解析来源、换算因子到裁决理由的完整证据链，导出为版本化证据清单；重新导入该清单后须能重建同一裁决结论与同一证据链，证据链缺失中间环节时返回 E_EVIDENCE_BROKEN 并指出断点声明。
5. 实现证据清单结构版本迁移：支持导入版本 1 旧证据清单，其中数值为带千分位字符串、单位以自由文本描述、缺少换算因子字段且年月区间为单值；导入时按可配置规则做数值定点化、单位字典映射与换算因子补全，指标明降级项，导出回版本 1 须与原清单等价，不可映射单位须返回 E_INVALID_FORMAT。
6. 实现版本指纹与增量失效传播：当语料分片内容、单位字典、语言权重、可信度先验、精确比较精度或仲裁规则任一变化时，由各阶段内容摘要构成版本指纹，识别受影响的最早阶段并使其及全部下游归一声明、裁决结论与证据链失效重建；未受影响上游产物继续复用，失效原因与指纹在查询接口可观测。
7. 实现批量复算与一致性校验：对本地评测集批量执行归一与消解，统计冲突识别率、裁决正确率与证据链重建成功率，并按配置指纹生成复算摘要；两次相同配置运行须得到逐字节一致摘要，且批量结果须与逐实体单独运行再汇总逐字节一致，禁止归约顺序影响取值判定。
8. 提供可集成组件接口与完整示例：以库函数与命令行提供单实体核验、声明降级原因与证据链查询、批量复算、版本状态查询、请求停止与执行恢复；各阶段按原子方式写入含单调序号的检查点，收到停止请求时完成当前不可拆分实体单元后退出，恢复后最终裁决与证据链须与一次完整运行逐字节一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证单位日历归一、精确冲突消解与证据链可重建，并核对停止恢复后结果与完整运行一致。
