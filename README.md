当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的关键点与姿态估计数据处理管线与结果验证工具，核心难点是增量更新与依赖失效。输入为固定随机种子生成器产出的本地确定性样本：一组小尺寸 RGB PNG 人体简笔画分片（由圆点关节与线段骨架渲染而成，含平移、缩放与轻度旋转的多个视角）与一份 JSON 样本清单，逐分片声明图像宽高、真值关键点坐标（归一化）、骨架连接对、关键点可见性标记、分片来源标签与期望输出姿态置信区间；图像与真值由本地生成器按清单可复现产出，作为结果验证的唯一真值来源。管线不依赖任何真实姿态模型、预训练权重、GPU 或外部服务，按四个阶段推进：图像预处理与关键点热图生成、关键点峰值解码与亚像素修正、骨架装配与几何一致性校验、姿态结果量化与验证汇总。关键业务要求在于：样本清单、生成参数或骨架定义任一变化时必须精确识别受影响的最早阶段并使其全部下游产物失效重建；中断与恢复后最终姿态摘要必须与一次完整运行逐字节一致。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy 与 Pillow，版本以满足本地 PNG 读写与数组运算为准。
确认工作目录为空，准备一个本地确定性样本生成脚本入口，按固定随机种子产出 PNG 分片、样本清单与真值关键点文件。
确认运行环境可写本地文件系统并支持文件锁与原子替换，Windows 下使用标准库的文件锁与临时文件重命名机制。
不安装任何深度学习框架、预训练权重或外部服务客户端，全部计算在本地 CPU 上完成。

业务要求：
1. 实现图像预处理与关键点热图生成阶段：对每张分片做灰度化与归一化后，以可配置高斯核半径围绕真值可见关键点生成逐关键点热图，并对分片做可配置对比度扰动；不可见关键点须生成全零热图并显式标记，热图尺寸与图像尺寸不一致或高斯半径为负须返回带分片标识与阶段名的 E_INVALID_PARAM。
2. 实现关键点峰值解码与亚像素修正阶段：在每张热图上求取局部极值候选，按可配置候选上限输出带分片标识、关键点名称、像素坐标与热图响应值的候选列表，并对峰值邻域做加权质心修正得到亚像素坐标；同一热图被多个候选命中时按响应值降序与关键点名称做确定性排序，响应为零或候选为空须保留空候选记录而非静默丢弃。
3. 实现骨架装配与几何一致性校验阶段：依据清单声明的骨架连接对把关键点候选装配为姿态实例，按对称关节长度比例与关节角度约束剔除违反几何一致性的实例并记录违规连接对与偏差量；当某实例有效关键点数低于可配置下限、骨架连接对含未知关键点名或装配后出现多实例冲突时，须返回带分片标识与违规详情的 E_POSE_INVALID，且不得部分写入结果。
4. 实现姿态结果量化与验证汇总阶段：按清单声明的关键点坐标约定输出姿态实例、逐关键点误差与均方根误差，并与清单中的期望姿态置信区间比对，越界实例须标记并给出越界关键点清单；汇总须按分片来源标签与关键点名称分组统计命中率与误差分布，指标计算只能依赖清单真值与显式候选结果，不得从缺失信息推断，同输入同配置须生成逐字节一致的验证摘要。
5. 实现版本指纹与增量失效传播：当某分片图像内容、真值关键点、可见性标记、骨架定义、高斯核半径或几何约束参数任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；失效原因、受影响分片清单与最新指纹须在查询接口中可观测，禁止复用已失效的旧产物参与汇总。
6. 实现阶段检查点持久化与优雅停止恢复：每个分片按预处理、峰值解码、骨架装配、验证汇总四阶段完成时以原子方式写入包含分片标识、阶段名、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入过程任意位置中断不得留下半写记录；进程收到停止请求时完成当前不可拆分分片单元后退出，不承诺强制终止后生成退出报告，恢复时须忽略损坏、不完整或序号重复的记录并从最近一致位置继续，最终姿态结果与验证摘要必须与一次从零完整运行的对应产物逐字节一致且检查点序号连续推进。
7. 实现并发阶段发布保护与稳定业务错误码：多个工作进程对同一工作区发布阶段产物时使用真实文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布须被拒绝并返回 E_STALE_CHECKPOINT；请求非法阶段跳转或缺失前置阶段产物时返回 E_INVALID_STAGE 并附当前已达阶段，发布被拒时已完成但未提交的阶段产物须可被后续读取而对汇总结果不可见。
8. 提供本地 HTTP 与命令行交互应用及确定性演示：支持导入分片与清单、触发分阶段构建、查询各阶段状态与版本指纹、查看失效原因与逐关键点误差、请求停止、执行恢复、导出姿态结果与验证报告；演示数据至少 4 个分片，含中英混排来源标签、多实例与至少 1 个不可见关键点，一次完整运行生成固定摘要，并演示在阶段间触发停止后恢复以及用注入的非法骨架连接与越界高斯核参数验证错误码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证分阶段姿态估计、版本变化后的增量失效重建、停止恢复与全量结果逐字节一致，以及错误码返回。
