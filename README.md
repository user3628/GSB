当前为空工作区，需从零构建一个本地可运行的流式语音端点检测（VAD）组件与完整示例，交付可被其他音频服务以库形式集成的领域组件及可重复演示。输入为固定随机种子生成器产出的本地 WAV 分片（16 kHz、单声道、16 位 PCM），包含清晰语音段、静音段、低信噪比段、语句内气息停顿与突发冲击噪声等情形；另附一份 JSON 清单记录每个分片的参考端点标注（以毫秒计的语音段起止）、分片顺序与声明的样本总数。组件需实现分帧加窗、能量与频谱平坦度双特征打分、双阈值滞回状态机、最短语音段与最短静音段平滑、端点时间戳输出五个环节，并支持逐帧流式喂入与整文件批处理两种调用方式，二者对同一输入必须产出一致端点。声明真值以清单中的参考端点为准，能量观测与同步标记均来自本地确定性样本，不从缺失信息推断。

任务环境与准备：
安装 Python 3.11 与 numpy、scipy 的稳定版本，并确认 pip 可用。
在空工作区创建项目目录，运行本地固定种子样本生成器产出 3 个以上 16 kHz 单声道 16 位 PCM WAV 分片及其 JSON 清单，样本生成不依赖网络或外部数据集。
准备本地命令行与文件系统权限用于写检查点与文件锁，确认运行环境可执行多进程场景。
预先准备异常注入所需样例（全零分片、削顶峰分片、长度不符清单），由生成器落盘，避免测试时改动源码。

业务要求：
1. 实现分帧与双特征打分：按可配置帧长（默认 20 ms）与帧移（默认 10 ms）对 16 位 PCM 做汉宁窗分帧，逐帧计算对数能量与频谱平坦度，并用可配置权重合成归一化得分；帧边界超出样本末尾时须以短帧处理并标记，样本总数与清单声明不一致须返回 E_INPUT_LENGTH 并附分片标识与实际长度。
2. 实现双阈值滞回状态机与平滑：以高阈值进入语音、低阈值退出语音，叠加可配置的最短语音段长度与最短静音段长度做后处理；状态机须输出每帧状态与触发原因，高阈值低于低阈值、最小段长为负等非法配置须在启动时返回 E_INVALID_CONFIG，不得进入半初始化状态。
3. 实现流式与批处理一致性：提供逐帧流式喂入接口与整文件批处理接口，对同一分片二者输出的端点数、起止毫秒与顺序必须逐字段一致；流式调用在单次喂养任意长度帧块时结果不变，端点只能在确认最短静音段之后发布，未确认的候选端点须以暂定状态可查询。
4. 实现端点检测指标与可复现实验摘要：依据清单参考端点按可配置时间容差计算命中率、误报数与漏报数，统计端点对齐的平均偏差与最大偏差；以批处理指标与流式指标双通道汇总，相同输入与配置两次运行的摘要须逐字节一致，容差变化须改变指标并留下配置版本指纹。
5. 实现异常注入与业务错误码一致性：提供参数注入入口，支持注入静音全零分片、幅值削顶分片、清单声明长度与实际不符、非法置信阈值与特征维度不匹配等异常；各异常须在对应环节返回稳定业务码（E_INPUT_LENGTH、E_INVALID_CONFIG、E_SILENT_INPUT、E_FEATURE_MISMATCH），并附分片标识与帧或样本位置，不得静默输出空端点。
6. 实现处理会话检查点与优雅停止恢复：每个分片处理完成时以原子方式写入含分片标识、输入内容指纹、配置指纹、端点摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分分片后退出，恢复后最终端点结果与一次从零完整运行逐字节一致，强制终止后的恢复仅依赖已持久化记录。
7. 实现版本变化检测与并发发布保护：当分片样本内容、帧参数、特征权重或阈值配置任一变化时，通过版本指纹识别受影响分片并使其结果失效重建，未受影响分片继续复用；多工作进程发布同一工作区结果时使用文件锁并比较序号，仅允许连续推进，落后或重复发布返回 E_STALE_CHECKPOINT，缺失前置分片时返回 E_INVALID_STAGE。
8. 提供可集成组件接口与完整本地演示：以库函数与命令行提供单分片端点检测、流式会话、批量评测、状态与版本查询、请求停止与恢复；演示数据至少 3 个分片，覆盖清晰语音、低信噪比、语句内停顿与冲击噪声，完整运行生成固定摘要，并演示一次停止后恢复及一次异常注入的错误码返回。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性分片验证流式与批处理端点一致、恢复后结果不变，并验证注入异常返回对应业务错误码。
