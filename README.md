当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的跨语言法律条款引证链冲突消解组件及完整示例，供上层合同审查服务以库形式集成。业务场景为多语种合同库的条款引证合并：同一主合同在中英文版本中会以不同句式引用同一条款（如“第 3.2 条”“Section 3.2”“第三条第二款”），并给出互相冲突的引用要素（适用期限、违约金比例、生效月份），系统需把每条引证归一到统一条款定位后做冲突消解，产出唯一可信引证并保留完整证据链。输入为若干本地 UTF-8 JSONL 引证分片，每条含 citation_id、contract_id、lang、raw_text、引证片段与来源渠道；由固定随机种子生成器产出，覆盖中英混排、跨分片重复引证、同条款多版本引证与少量异常样本，并附一份本地种子标注分片作为消解真值来源，不依赖任何真实语料、模型或外部服务。

任务环境与准备：
安装 Python 3.11 及 pip，创建本地虚拟环境。
安装依赖：numpy、fastapi、uvicorn、pytest（按 requirements.txt 固定版本，均可离线获取）。
无需 GPU、外部服务或真实账号；引证分片与种子标注由固定随机种子的本地生成器脚本产出。
运行前确认工作区可读写并预留检查点与证据清单目录，Windows 下路径使用反斜杠或原始字符串。
启动本地 HTTP 服务使用 uvicorn 绑定 127.0.0.1 的本地端口，不监听外部网络。

业务要求：
1. 实现引证文本规范化与条款定位解析阶段：对 raw_text 做 Unicode NFKC、空白折叠、全半角统一，识别中文“第X条”“第X款”与英文“Section X.Y”“Article X”等句式，把条款号与款项号归一到统一整数定位并保留原始字符偏移与句式来源；无法解析出条款定位、引证片段与原文不匹配或定位出现负数时，须返回带 citation_id 与偏移的 E_CITATION_UNPARSED 并保留在诊断输出。
2. 实现同合同引证要素归一与冲突分组阶段：在同一 contract_id 下按条款定位把引证分组，把适用期限以月为单位的区间、违约金比例以定点百分比、生效月份归一化后比较，取值不相等即判为冲突；引证时间区间结束早于开始、违约金比例超出配置可表示范围或生效月份非法时返回带 citation_id 与要素名的 E_ELEMENT_INVALID，不得静默丢弃该引证。
3. 实现冲突消解核心：依据来源渠道先验、语言权重与引证新鲜度在对数域合成可信度，为每组冲突选出唯一可信引证并输出被降级引证及其降级理由；可信度并列时须有确定性仲裁规则，且消解结果须满足同组只剩一条可信引证；某组全部引证被判定不可信时须标为待人工复核并给出依据，不得随机挑选。
4. 实现证据链构造与可追溯导出：为每条被采纳或被降级的引证保留从原文偏移、条款定位解析来源、归一化换算因子到裁决理由的完整证据链，导出为版本化证据清单；重新导入该清单后须能重建同一消解结论与同一证据链，证据链缺失中间环节或与结论不一致时返回 E_EVIDENCE_BROKEN 并指出断裂环节。
5. 实现证据清单结构版本迁移：支持导入结构版本 1 的旧证据清单，其中条款定位为自由文本、比例以带千分位字符串表述、缺少换算因子字段；导入时须按可配置规则做定位解析、比例定点化与换算因子补全，转换后应可导出为版本 2 并通过往返校验，换算依据须在证据链中显式记录；版本号与内容形态不一致时返回 E_VERSION_SHAPE_MISMATCH。
6. 实现阶段检查点与优雅停止恢复：每阶段完成时以原子方式写入含阶段名、输入分片内容摘要、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分的引证单元后退出，恢复后最终消解结论、被降级引证与证据链必须与一次完整运行逐字节一致且序号连续推进。
7. 实现版本指纹、增量失效传播与并发发布保护：当引证分片内容、单位换算字典、语言权重、可信度先验或精确比较精度任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游归一定位、消解结论与证据链失效并重建，未受影响上游产物继续复用；多工作进程发布阶段产物时使用真实文件锁并比较序号，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT，缺失前置阶段返回 E_INVALID_STAGE。
8. 实现批量复算与一致性校验及完整示例：对本地评测集批量执行归一与消解，统计冲突识别率、消解正确率与证据链重建成功率，并以配置指纹生成复算摘要；两次相同配置运行须得到逐字节一致摘要，且批量结果须与逐合同单独运行再汇总逐字节一致，不一致返回 E_INCREMENTAL_MISMATCH 并附首个差异合同；以库函数与命令行提供单合同消解、降级原因与证据链查询、批量复算、请求停止与执行恢复，演示数据至少含 3 个合成分片、中英混排引证、跨分片重复引证与至少一处故意冲突。
