当前是空白工作区，没有现存项目、代码或数据附件，需要从零实现一个面向本地列式计算引擎的 Join 与 Shuffle 执行器工作台，用于在离线环境下复现真实计算引擎中多表等值 Join 经 Shuffle 重分区后推进、并发作业竞争、失败与进程重启后续算的核心机制。执行器接收若干本地列式数据块（每列以 NumPy 数组存储，列类型为整数或定长字符串编码）与一条 Join 计划（至少三张表的等值连接、每表参与连接的键列、分区函数与分区数、输出列与排序键），按配置的分区数与向量批量推进：先对每张表做分区映射生成 Shuffle 分区文件，再逐分区构建分区内哈希连接，最后输出按键序归一化的结果。真实计算引擎中 Shuffle 不是一次性完成：分区文件的写、读、合并与回收分阶段推进，每个阶段都可能因写入失败、被取消、资源预算耗尽或进程崩溃而中断；同时多个作业共享同一批数据块版本与本地临时目录，并发推进时既要保证各自的结果确定，又要在重启后只重算未提交的批次。工作台须维护作业、阶段、分区与批次的版本化状态，通过 SQLite 持久化，并通过本地 HTTP 接口暴露推进、查询、取消与重试能力。

任务环境与准备：
安装 Windows 可用的 Python 3.11 及以上版本，并确保 python 与 pytest 命令位于 PATH。
在虚拟环境中安装 numpy 与 pytest（例如 python -m venv .venv 后 pip install numpy pytest），无需联网服务或外部账号。
确认本地回环地址可绑定端口以便运行 HTTP 接口与测试客户端，确认可创建并写入本地临时目录用于 Shuffle 分区文件。
准备固定随机种子的列式样本生成脚本作为输入数据来源，不依赖任何既有项目文件、外部数据集或附件。

业务要求：
1. 实现列式数据块与 Join 计划的载入与校验：每张表以列名到 NumPy 数组的映射及元数据（行数、列类型、列基数、空值计数）描述，计划声明参与等值连接的表及每表的键列、分区函数与分区数、输出列与排序键；须校验键列存在、类型可比较、分区数为正整数、输出列可解析，非法输入须返回业务码 E_BAD_PLAN 且不得进入执行。
2. 实现 Shuffle 分区映射的分区文件生成与批次推进：每张表的每一行须按分区函数映射到确定分区，分区文件带自描述头（魔数、格式版本、表名、分区序号、行数与 CRC32），按向量批量逐批写出并以原子重命名完成；每批完成须记录批次序号与该批输出的行摘要，同一输入数据块版本与同一分区函数下重复执行须产出逐字节一致的分区文件。
3. 实现分区内哈希连接与输出归一化：对每个分区按到达表的顺序构建哈希表并探测，连接结果须按输出列与排序键的确定次序归一化，使任意分区数与分批大小下输出逐值相等；空值键须按显式声明的语义处理且不得误匹配；分区内连接完成时须产出该分区的输出行数与内容摘要并持久化。
4. 实现作业、阶段与批次的状态机与持久化：作业状态取值须为 pending、running、succeeded、failed、canceled，阶段状态取值须为 shuffle、join、output，非法迁移须拒绝并返回 E_INVALID_TRANSITION；每批完成须在单个 SQLite 事务中写入批次进度、阶段状态与输出摘要，事务提交后才允许查询与续算。
5. 实现失败、取消与进程重启后的断点续算：任一阶段失败或作业被取消时不得留下部分写入的分区文件与半提交批次；进程重启后须把中断时处于 running 的作业标记为可恢复并从最后一个已提交批次继续推进，已完成阶段须复用已持久化的分区文件与摘要而不全量重算，续算最终结果须与从未中断时逐值一致。
6. 实现并发作业的数据版本快照与临时目录隔离：多个作业可并发推进，每个作业在开始时固定所读数据块版本与分区函数版本，中途版本变化须以 E_SNAPSHOT_STALE 终止该作业并保留已提交批次；并发作业须使用各自隔离的临时分区目录，互不覆盖对方的 shuffle 文件，共享内存额度与磁盘配额超限时须有序中断并返回 E_QUOTA_EXCEEDED。
7. 实现并发 Shuffle 写入的互斥与资源控制：多个作业同时写同一分区目标位置时须串行化到该分区文件的一致性边界内并以原子重命名保证只有一个生效；并发抢占须基于真实单调时钟设置超时并以 E_CONTENTION_TIMEOUT 返回，不得用睡眠或线程超时冒充已经终止失控写入。
8. 实现本地 HTTP 接口、诊断报告与可重复测试：提供提交作业、推进一批、查询作业与批次状态、取消作业、查询分区文件清单与续算诊断报告的接口，错误统一以固定业务码在 JSON 中返回；诊断报告须列出每阶段已提交批次、复用的分区文件与触发续算的位置。pytest 用例须在 Windows 离线覆盖非法计划拒绝、分批一致性、失败与重启续算、并发隔离与配额中断，并在固定随机种子下可重复。
