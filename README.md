当前为空工作区，需从零构建一个本地可运行的查询理解与意图解析引擎，用于搜索与推荐场景的算法实现与可复现实验。输入为若干本地 JSONL 查询样本，每条包含 query_id、raw_query、locale、channel 与可选的历史点击类目序列；系统需完成规范化、分词、意图分类（导航/信息/交易/本地服务四类）与实体槽位抽取，并输出结构化的查询理解结果。意图分类基于本地已标注小样本估计的朴素贝叶斯与特征权重混合打分，实体槽位基于本地词典与规则匹配。系统不依赖任何真实搜索引擎、线上模型或外部账号，所有训练与评测数据来自本地确定性生成器。核心挑战在于查询理解的异常链路必须可复现验证：需要定义输入注入点（非法 locale、空查询、超长查询、词典版本不一致、槽位重叠等），让异常在各阶段以稳定业务错误码暴露，并支持在实验环境中复现同一异常与同一分数。

任务环境与准备：
安装 Python 3.11 及 NumPy、pytest，使用标准库提供 HTTPServer 与 JSONL 读写能力，无需容器或外部服务。
准备本地确定性数据生成脚本，按固定随机种子产出 30 条以上查询样本、已标注训练小样本与槽位词典 JSON，全部随工作区提供。
确认工作区为空白目录，运行入口为命令行与本地 HTTP 接口，实验摘要与演示脚本可在离线环境下重复执行。

业务要求：
1. 实现查询规范化与分词阶段：对 raw_query 做 Unicode NFKC、空白折叠、全半角统一与小写化，按连续拉丁字母数字与单个中文字符切分，并输出带字符偏移的 token 序列；空查询或仅含标点的查询须返回 E_EMPTY_QUERY，并携带 query_id 与阶段名，不得进入后续阶段。
2. 实现意图分类打分器：从本地已标注样本估计各意图类别的先验与 token 条件对数概率，结合可配置的类别特征权重得到四类意图的分数，并以 softmax 归一化输出置信度；同一输入在固定配置下必须产生逐字节一致的结果，且须记录每个候选类别的分量得分以便复现。
3. 实现实体槽位抽取与重叠消解：基于本地词典做最长匹配抽取类目、品牌与地域三类槽位，记录每个槽位的起止偏移与来源词典版本；当多个槽位区间重叠时按可配置优先级消解，被抑制的候选须保留在诊断输出中，词典缺失时返回 E_DICT_MISSING。
4. 实现多级回退链：当主分类置信度低于阈值时依次回退到基于历史点击类目的先验分类、基于 channel 的默认意图，直至最终兜底；每级回退须记录触发原因与被跳过级别，最终结果须标注所用回退级别，且回退链在相同输入下必须可完全复现。
5. 实现异常注入与错误码一致性：提供参数注入入口，支持注入非法 locale、超长查询（超过可配置字符上限）、槽位词典版本不一致与置信度 NaN 等异常；各异常须在对应阶段以稳定业务码（E_INVALID_LOCALE、E_QUERY_TOO_LONG、E_DICT_VERSION、E_NUMERIC）暴露，不得静默降级或部分写出结果。
6. 实现版本指纹与结果失效：当标注样本、意图特征权重、阈值配置或槽位词典任一变化时，计算各阶段的版本指纹，使依赖该阶段的下游理解结果失效并重建；未受影响阶段结果继续复用，失效原因与指纹须在查询接口中可观测，禁止继续返回旧版本缓存结果。
7. 实现可复现实验环境与指标汇总：对本地评测集批量执行解析，统计意图准确率、槽位精确率与召回率、回退触发率，并按注入的随机种子与配置指纹生成实验摘要；两次相同配置运行须得到逐字节一致的摘要，不同种子须产生可区分摘要。
8. 提供交互接口与确定性演示：命令行与本地 HTTP 接口支持单条查询解析、查看分量得分与回退轨迹、执行批量实验、查询版本状态；演示数据含至少 30 条查询、覆盖四类意图与中英混排，并至少演示一次异常注入复现与一次失效重建。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本验证意图解析、槽位抽取、回退链与异常码一致性，并两次运行比对实验摘要逐字节一致。
