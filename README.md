某训练推理框架的稀疏算子组在本机空白目录中启动稀疏矩阵乘（SpMM）算子优化项目，需要交付可集成的 Go 算子库与可重复演示的交互式诊断应用。输入为程序内置固定种子生成器产出的本地 CSR 稀疏矩阵样本（以 .json 描述 indptr、indices、data）与配套稠密右乘矩阵样本，覆盖约 1%、10%、40% 三档稀疏率，方阵、高瘦、矮胖三种形状，以及空行、全零行块、重复列索引、显式零值等结构性退化情形；每份样本附形状与稀疏率声明，作为分块决策与精度估计的显式观测。算子需以行块与列块组织稀疏专用计算，同时支持交互侧快速查询与结算侧全量裁决两条路径，两条路径在同一快照版本下必须给出逐条一致的结果；算子状态、分块方案与误差报告需持久化到本地 SQLite，支持中断恢复与并发发布保护。

任务环境与准备：
在 Windows 本地安装 Go 1.22 或以上版本，并确认 go 命令在 PATH 中可用。
使用纯 Go 实现的 SQLite 驱动（如现代 sqlite 包），通过 Go 模块拉取并锁定版本，不使用 CGO 与容器环境。
从空白工作区创建 Go 模块，初始化目录结构与 main 包；所需第三方依赖均通过 go.mod 固定版本。
算子库提供内置固定种子样本生成器，生成三档稀疏率、三种形状及结构性退化样本，所有样本在本地落盘并可重建。
运行前置条件为本地文件系统可写目录与可用端口；不依赖 GPU、外部服务、真实账号或线上站点。

业务要求：
1. 实现 CSR×稠密矩阵的稀疏专用分块内核：按行块与列块组织计算且仅遍历非零元，支持方阵、高瘦、矮胖形状，对重复列索引按其出现次序累加、对显式零值按配置跳过或保留并分别计数；每行输出累加顺序须显式可配置（按列索引升序或按分块顺序），同一输入与配置必须产生逐字节一致的分块结果与诊断轨迹。
2. 实现基于稀疏结构与交互延迟预算的自动分块参数选择：依据非零元数、平均每行非零数、空行比例、稠密矩阵列宽与可配置缓存预算，从候选行块与列块方案中按预测访存量、负载均衡度与预计单块查询时延打分选优，并记录打分明细、选择理由与被淘汰方案；小规模输入不得选出明显过大、导致空块占比过高的方案。
3. 实现交互侧查询与结算侧全量裁决的双路径结果一致性：交互侧按查询所请求的行区间在延迟预算内返回部分结果，超出预算时返回带查询标识与已耗时字段的 E_LATENCY_BUDGET 结构化错误而非阻塞等待；结算侧对全量行块执行完整累加，两路径在同一快照版本下对同一行区间的结果、误差上界与逐块摘要必须逐条一致，不一致时返回 E_PATH_MISMATCH 并附首个差异行块。
4. 实现数值精度与误差传播控制：累加支持顺序求和与补偿求和两种策略，全程在相应精度域内执行，并对每个输出块给出与本地高精度参考结果比较的误差上界估计；估计须依赖显式的本地参考值与随机抽样位置，不得从缺失信息推断；当抽样块超出可配置容差时报告行列区间、最大绝对偏差与相对偏差，并返回业务码 E_NUMERIC_MISMATCH。
5. 实现峰值内存约束下的执行调度：在可配置峰值内存上限内规划输出缓冲、行块工作区与稠密矩阵切片的占用，超预算时须按列块或行块拆分执行并记录拆分决策与每步内存估算，或返回带预算明细的 E_MEMORY_BUDGET，不得依赖运行时内存溢出或崩溃来体现超出预算。
6. 实现分块方案与算子状态的版本化 SQLite 持久化：把自动选择或用户指定的分块方案连同矩阵形状指纹、稀疏结构指纹、求和策略与缓存预算原子写入版本化存储，每版本含单调序号与摘要；每完成一个不可拆分的行块单元即以事务写入含方案版本、行块坐标、输入指纹与产物摘要的记录，同一方案版本同一行块只允许一条有效记录，写入任意位置中断不得留下半写记录。
7. 实现优雅停止与强制终止恢复的差异处理：收到停止请求时完成当前行块单元后落库并退出；被强制终止后重启仅凭已提交的持久化事实恢复进度，不承诺生成退出报告；恢复后交互侧与结算侧结果、误差报告与逐块摘要必须与一次连续完整执行逐字节一致，且方案版本序号与行块序号连续推进、无跳跃与重复。
8. 实现并发发布保护、整体替换识别与稳定业务错误码：多工作进程对同一数据库发布分块方案或行块结果时使用 SQLite 事务条件更新与真实文件锁并比较方案版本序号，仅允许序号连续推进，落后、重复或跨方案错位发布返回 E_STALE_PUBLISH；检测到方案记录被整体替换（序号回退、指纹变化或摘要不匹配）时须区分回退、替换与正常推进，回退与替换使受影响的下游缓存与误差报告失效重建。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

用本地三档稀疏率与三类形状样本验证双路径结果逐条一致、误差报告可复核，并演示中断恢复与并发发布被拒。
