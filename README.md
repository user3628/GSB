当前是空白工作区，需从零构建一个本地可运行的梯度提升二分类概率校准工作台，交付领域可视化与诊断工作台。输入为固定随机种子生成的本地 NPZ 样本集，包含特征矩阵、二分类标签与一份 JSON 声明文件；样本分为小规模（约 800 行、12 列）与中规模（约 8000 行、32 列）两档，含连续列、含缺失值列与相关冗余列，无类别列，以避免编码环节。声明文件记录每档行数、列数、缺失列下标与标签正例比例，作为预处理与统计的显式观测。工作台以确定性方式实现梯度提升决策树二分类：按配置以固定直方图分箱构建回归树、逐轮拟合残差得到原始分数，再通过 Platt 缩放与等距回归两种校准器把原始分数映射为概率，并按校准后概率计算对数损失、Brier 分数与分箱校准偏差。核心难点是概率校准与分批计算的结果一致性：累计预测与原始分数累加必须在不同批大小、不同分批顺序下给出完全一致的校准结果，任何配置或样本变化都必须使受影响的校准阶段失效并重建。

任务环境与准备：
安装 Python 3.11 与依赖：numpy、flask、pytest，使用本地 wheel 源或已有离线包。
确认工作区为空目录，创建项目根目录与 data、state、out 子目录。
运行本地固定种子生成脚本产出两档 NPZ 样本与声明 JSON，生成后校验文件摘要并落盘。
准备本地 HTTP 测试用的空闲端口配置与命令行入口约定，不启动任何外部服务。
确认所有读写路径位于项目目录内，检查 Windows 下原子写入所用临时文件的同卷替换行为。

业务要求：
1. 实现直方图分箱与梯度提升核心：按可配置分箱数对连续特征做确定性分箱，逐轮以二阶梯度统计构建回归树并按可配置学习率累积原始分数，支持可配置轮数、最大深度与最小叶样本数；同一输入与超参数必须复现完全一致的原始分数与分箱边界，分箱数为零或学习率越界须在训练前返回 E_INVALID_PARAM。
2. 实现两种概率校准器：Platt 缩放以对数域牛顿迭代拟合 sigmoid 参数，等距回归以保序回归加线性插值得到单调映射，两者均须记录迭代轮数与最终参数；校准输入为训练集外折的原始分数与标签，校准器在同一输入下必须逐字节一致复现，校准样本全为单一类别时返回 E_CALIBRATION_INFEASIBLE 并附样本数。
3. 实现分批预测与跨批一致性归约：支持把待预测样本切分为任意批大小并按批顺序传入，逐批原始分数与校准概率须以显式规格化累加器归约，使不同批大小与不同批顺序下的最终概率向量、对数损失与 Brier 分数逐字节一致；累加器须记录已归约批数与样本数，批大小为零或批样本重复计入须返回 E_BATCH_STATE 并保留已归约状态。
4. 实现数值精度与校准诊断：以定点量化记录原始分数与概率的有效位数，给出与本地高精度参考实现比较的对数损失误差上界估计；按可配置分箱计算预测概率与真实频率的校准偏差并输出可靠性表，出现 NaN、Inf 或概率越界时返回 E_NUMERIC 并附样本位置与阶段，禁止静默截断。
5. 实现持久化阶段检查点与优雅停止恢复：每个阶段（分箱、提升、校准、诊断）完成时以原子方式写入含阶段名、输入内容指纹、配置版本、累加器摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分的提升轮次后退出，不承诺强制终止后生成退出报告，恢复后最终原始分数、校准参数与诊断表须与一次从零完整运行逐字节一致。
6. 实现版本变化检测与失效传播：当样本内容、分箱数、提升轮数、树超参数、校准器类型或校准折划分任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；失效原因与各阶段指纹须在查询接口中可观测，禁止用旧校准参数作用于新原始分数。
7. 实现增量与全量一致性校验及并发发布保护：提供单配置变更入口，仅重建失效链路后与从零全量构建的原始分数摘要、校准参数与诊断表做逐字节比对，不一致须返回 E_INCREMENTAL_MISMATCH 并给出差异阶段；多工作进程对同一工作区发布阶段产物时使用文件锁并比较序号，仅允许序号连续推进，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT，请求非法阶段跳转或缺失前置阶段产物返回 E_INVALID_STAGE。
8. 提供诊断工作台应用与本地确定性演示：命令行与本地 HTTP 接口支持导入样本、设置提升与校准配置、触发分阶段训练、查看各阶段状态与版本指纹、查看可靠性表与失效原因、请求停止、执行恢复、导出概率与诊断报告；演示数据覆盖两个规模档，一次完整运行生成固定摘要，并演示一次校准器切换后的增量重建、一次停止后恢复及一次不同批大小的概率一致性比对。
