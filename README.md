这条新业务线要落地的首个组件是一套 RoPE 位置编码分块算子库，供上层训练推理代码以库形式集成，当前工作目录尚未初始化、没有任何既有实现。输入由程序内置固定种子生成器确定性产出：Q/K 张量分片（JSON 描述形状 [批量, 头数, 序列长度, 头维度] 与定点量化数值），覆盖短序列、长序列、奇数头维度、批量大于 1 与含极值样本；另附形状声明清单与一份带单调版本号的算子配置快照，声明基础频率、缩放方式（不缩放、线性插值、NTK 分段）、缩放系数、旋转角度分块大小、因果掩码开关、全局并发分块上限、单工作进程分块配额、每轮时间预算与峰值内存上限，并提供以定点量化保存的高精度参考旋转后张量作为唯一真值来源。组件需在不物化完整旋转角度矩阵的前提下按行块与列块流式完成分块旋转与查询键打分，并在并行调度与资源预算约束下推进；真实环境中多个行块任务会同时到达，预算与内存会相互挤占，而版本变化又要求只重建受影响块区间。

任务环境与准备：
准备 Linux（WSL Ubuntu）环境，安装 Go 1.22 或以上版本与 SQLite 3 命令行工具（apt install sqlite3），无需 GPU 或外部服务。
在空白工作目录初始化 Go module，引入本地 SQLite 驱动（如 modernc.org/sqlite），测试数据由组件内置固定种子生成器产出，不下载任何外部数据集。
确认本机文件锁、SQLite 事务与进程池行为可正常执行，运行前清理工作目录中的历史数据库与检查点文件。

业务要求：
1. 实现 RoPE 分块旋转核心：按配置的旋转角度分块大小沿头维度成对旋转，奇数头维度时最后一维不旋转并显式记录，支持线性插值与 NTK 分段两类频率缩放；同一输入与配置必须产生逐字节一致的旋转后张量与逐块角度摘要。
2. 实现旋转后查询键打分与在线 Softmax 归一化：按因果掩码开关计算点积，先行内减去最大值再在对数域累加指数和与加权输出，输出注意力权重摘要与每行归一化因子；当出现 NaN、Inf 或归一化因子为零时返回带分片标识、行块坐标与业务码 E_NUMERIC 的结构化错误。
3. 实现全局并发分块上限、单工作进程分块配额与每轮时间预算三重约束下的并行调度：以行块为调度单元，接纳前依据形状声明与已覆盖键范围预估分块消耗，超预算行块记录为未处理并给出原因与预算余量，不得静默丢弃。
4. 实现峰值内存上限约束下的执行规划：在可配置峰值内存内规划旋转后张量、行块工作区与角度表缓冲占用，超预算时按行块或批次拆分执行并记录拆分决策与每步内存估算，或返回带预算明细的 E_MEMORY_BUDGET。
5. 实现分块中间状态的版本化 SQLite 事务持久化：每完成一组列块的每个行块即以事务写入含分片标识、行块序号、已覆盖键范围、运行最大值、指数和、部分输出摘要、输入指纹与单调序号的记录，同一分片同一行块只允许一条有效记录，写入中断不得留下半提交记录。
6. 实现版本指纹识别与块级失效传播：当分片内容、基础频率、缩放方式、缩放系数、分块大小或因果掩码开关任一变化时，由各阶段内容摘要构成版本指纹并识别受影响的最早行块与列块区间，使该区间状态失效重建，未受影响行块状态继续复用；检测到记录整体替换时须区分正常推进、整体替换与回退。
7. 实现优雅停止、强制终止恢复与并发状态发布保护：收到停止请求时完成当前不可拆分分块后退出；强制终止后仅凭已提交事实恢复进度，不承诺生成退出报告；多工作进程发布行块状态时使用事务条件更新与真实文件锁并比较行块序号，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT。
8. 提供可集成库接口、本地 HTTP 与命令行交互应用及确定性演示：支持导入分片与配置、触发分阶段计算、查询各阶段状态与版本指纹、查看逐块角度与打分摘要、预算消耗与失效原因、请求停止与执行恢复；演示数据至少 4 个分片，覆盖短序列、长序列、奇数头维度与因果掩码。
