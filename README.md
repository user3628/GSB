当前是空白工作区，需从零构建一个本地可运行的图像分类与多标签预测校验工作台，面向 CV 图像分类与多标签场景的可复现验证与异常注入。输入为固定随机种子生成器产出的本地小尺寸 RGB PNG 样本与一份 JSON 清单，清单逐样本声明 image_id、宽高、真值多标签集合（每标签含名称与置信度下界）以及一张本地打分表（每标签的模型输出分数，由确定性伪推理产生，不依赖真实模型、GPU 或外部服务）；生成器须同时产出至少含双标签、单标签、空标签、标签超出类别表、分数含 NaN 及图像尺寸声明与实际不符等异常样本。系统按四阶段推进：图像解码与预处理（尺寸校验、归一化、分块统计）、逐标签打分校验（阈值化、多标签独立性判定）、多标签指标汇总（逐标签精确率召回率与平均精度、标签共现一致性）、以及校验报告与失败样本定位。工作台须支持异常注入、结果失效与增量重算、阶段检查点与中断恢复、并发发布保护，并以命令行与本地 HTTP 接口提供可交互演示；所有样本、配置与真值均来自本地落盘文件，观测与真值来源须显式可查。

任务环境与准备：
确认使用 Python 3.10 及以上，具备标准库与文件锁能力。
安装 numpy 与 Pillow（用于像素统计与 PNG 读写），无需 GPU 与外部服务。
在工作区创建 samples、configs、checkpoints 与 reports 目录，并由本地固定随机种子生成器产出样例图像与清单文件。
准备本地 HTTP 服务运行端口与命令行入口，确保全部输入输出落在工作区目录内。

业务要求：
1. 实现图像解码与预处理阶段：读取 PNG 样本并校验实际宽高与清单声明一致，不一致须返回带 image_id、声明值与实际值的 E_DIM_MISMATCH 并保留在诊断输出；对像素做固定规则归一化并计算分块颜色与梯度统计作为样本画像，同一输入必须产生逐字节一致的画像摘要。
2. 实现逐标签打分校验与多标签独立性判定：按清单打分表对各标签分数与真值下界比较并输出命中、漏报、误报三类判定，同时检验多标签同时成立的样本是否存在标签互斥冲突，冲突须以带 image_id 与标签对的 E_LABEL_CONFLICT 报告；空标签样本须作为合法输入处理而非报错。
3. 实现多标签指标汇总：计算逐标签精确率、召回率与平均精度，以及宏平均与微平均结果，并统计标签共现矩阵的一致性；指标计算须依赖清单真值与显式判定结果，不得从缺失信息推断，同输入同配置的指标摘要须逐字节一致。
4. 实现异常注入与业务错误码一致性：提供参数注入入口，支持注入声明尺寸与实际不符、标签超出类别表、分数为 NaN 或 Inf、清单缺失 image_id 与打分表长度不符等情况；各异常须在对应阶段返回稳定业务码（E_DIM_MISMATCH、E_UNKNOWN_LABEL、E_NUMERIC、E_MISSING_FIELD、E_SCORE_LENGTH），且注入不得影响未涉及样本的判定结果。
5. 实现持久化阶段检查点与优雅停止恢复：每样本每阶段完成时以原子方式写入含阶段名、image_id、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分样本单元后退出，恢复后最终判定与指标摘要须与一次从零完整运行逐字节一致。
6. 实现版本变化检测与增量失效传播：当样本像素内容、真值标签、打分表、阈值配置或分块参数任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建；未受影响上游结果继续复用，失效原因与指纹须在查询接口中可观测，禁止复用旧版本判定。
7. 实现并发发布保护与快照整体替换识别：多工作进程对同一工作区发布阶段产物时使用文件锁并比较阶段内序号，仅允许序号连续推进，落后、重复或跨样本错位发布返回 E_STALE_CHECKPOINT；当检测到检查点目录被整体替换（序号回退或摘要不匹配）时须识别版本变化并拒绝接受，而非静默覆盖。
8. 提供可交互工作台应用与本地确定性演示：命令行与本地 HTTP 接口支持导入样本、触发分阶段校验、查询各阶段状态与版本指纹、查看失败样本与冲突明细、请求停止、执行恢复、导出校验报告；演示数据至少 4 个样本，覆盖双标签、单标签、空标签与含异常注入的样本，完整运行生成固定摘要并演示一次停止恢复与一次异常注入。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证分阶段校验、指标汇总、异常错误码与停止恢复后结果一致，并附运行摘要。
