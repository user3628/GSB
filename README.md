当前是空白工作区，需从零构建一个本地可运行的视频目标跟踪领域可视化与诊断工作台。输入为固定随机种子生成器产出的本地确定性视频序列分片：每段序列含若干低分辨率灰度帧（.npy，像素 0-255），帧中有一个矩形目标按本地生成器声明的运动模型（匀速平移、缓慢缩放、一次方向突变）演进，另附一份 JSON 跟踪清单，逐序列声明初始目标框（归一化坐标）、每帧参考目标框真值、帧率、搜索窗口扩展比例、外观模型更新阈值与轨迹置信度下限，真值框为结果验证的唯一来源；清单还声明每序列可见帧数与样本总数上界，供一致性校验。工作台按四个阶段推进：帧级外观建模、候选采样与响应打分、轨迹状态演进与遮挡恢复、可视化诊断汇总。系统不依赖任何真实跟踪模型、预训练权重、GPU 或外部服务，全部机制在本地确定性与毫秒级整数时间轴上实现。核心难点是轨迹状态在逐帧演进中的一致性与中断后的恢复一致性：跟踪状态既是逐帧演进的结果又是可恢复的持久化对象，两者必须彼此自洽。

任务环境与准备：
安装 Python 3.11 及以上，创建本地虚拟环境并在其中安装 numpy 与 pyyaml（版本以可离线安装的本地包为准）。
确认工作区为空目录，具备可写权限与本地文件锁能力（Windows 文件系统支持独占打开），无需 Docker 或任何容器环境。
运行本地确定性生成器脚本产出至少 3 个视频序列分片、跟踪清单与遮挡序列，并核对清单声明的帧数与样本总数；生成器须固定随机种子且可重复执行。
准备本地 HTTP 服务端口与命令行入口的配置文件，确认无外部网络依赖；演示数据、真值框与参考摘要全部落在工作区本地目录。
确认路径分隔符与文件名在 Windows 下合法，避免保留字符，并预先建立检查点与快照目录供原子写入使用。

业务要求：
1. 实现帧级外观建模阶段：对每帧按初始目标框与参考真值框裁剪区域，计算灰度直方图与梯度方向直方图并按固定规则归一化为确定的外观模型，输出带序列标识、帧号、框坐标与模型摘要的逐帧模型记录；同一输入与配置必须产生逐字节一致的模型记录，空框、框越出画面或像素全零时须返回带序列标识与帧号的 E_INVALID_REGION 并保留诊断输出。
2. 实现候选采样与响应打分阶段：在可配置搜索窗口扩展比例内以固定步长网格采样候选框，按外观模型相似度与中心先验在对数域合成为响应分，并保留前若干候选及其分数分量；当搜索窗口完全落在画面外、候选数为零或响应分出现 NaN/Inf 时须返回 E_NUMERIC 并附序列标识、帧号与采样网格信息，不得静默退回上一帧结果。
3. 实现轨迹状态演进与遮挡恢复：按帧序推进目标位置与尺度，以可配置外观模型更新阈值决定是否更新模板，检测到连续若干帧响应分低于轨迹置信度下限时判定为遮挡并进入恢复流程，恢复时须在与中断前状态一致的搜索范围检索并以显式记录说明恢复依据与所用历史帧；同一输入与配置下目标框序列、遮挡区间与更新事件必须逐字节一致。
4. 实现轨迹状态持久化检查点：每序列每完成一个不可拆分的逐帧状态演进单元即原子写入含序列标识、帧号、输入帧内容指纹、跟踪配置指纹、轨迹状态摘要与单调序号的记录，写入任意位置中断不得留下半写记录；恢复时必须忽略损坏、不完整或序号重复的记录，从最近一致检查点继续，且已发布帧的状态不重复计算。
5. 实现优雅停止与恢复一致性：进程收到停止请求时完成当前不可拆分的逐帧单元后退出，不承诺强制终止后生成退出报告；恢复后最终目标框序列、遮挡区间、模板更新事件与逐帧误差曲线必须与一次从零完整运行输出逐字节一致，且检查点序号连续推进、无跳跃与回退。
6. 实现版本变化检测与增量失效传播：当某序列帧内容、初始目标框、参考真值框、搜索窗口比例、更新阈值或置信度下限任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早帧与阶段，使该帧及其全部下游状态失效并重建，未受影响上游帧状态继续复用；失效原因、受影响帧区间与指纹须在诊断查询中可观测，禁止复用失效状态。
7. 实现并发状态发布保护与稳定业务错误码：多工作进程对同一工作区发布逐帧状态时使用真实文件锁并比较序列内帧序号，仅允许序号连续推进，落后、重复或跨序列错位发布须被拒绝并返回 E_STALE_CHECKPOINT；请求缺失前置帧状态的跳帧诊断或非法阶段跳转返回 E_INVALID_STAGE，轨迹状态整体替换（序号回退或摘要不匹配）须被识别并拒绝。
8. 提供本地 HTTP 与命令行可视化诊断工作台及确定性演示：支持导入序列与跟踪清单、触发分阶段执行、查询各阶段状态与版本指纹、查看逐帧目标框与遮挡区间、逐帧误差与失效原因、请求停止与执行恢复；演示数据至少 3 个序列，覆盖匀速平移、缩放与方向突变并含一次遮挡，完整运行生成固定摘要，并演示在逐帧演进间触发停止后恢复以验证结果一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
