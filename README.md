当前是空白工作区，需要在 Windows 本地从零构建一个面向本地训练实验追踪的组件与可复现实验环境。训练实验由若干运行（run）组成，每个运行记录标识、实验名、参数集合、指标序列（步号、数值）、制品摘要与工具链版本；实验追踪存储需与外部追踪工具互换数据，因此运行的持久化必须支持两种可互换格式：紧凑二进制格式（含魔数、格式版本字节、每条记录长度前缀、CRC32 校验、可选字段存在位图与大端小端标记）与分片 JSON 行格式（每行含运行标识、实验名、参数、指标序列、工具链版本与相对保留期）。两种格式在数值精度、可选字段、时间戳量纲与版本语义上并不对齐：二进制以毫秒整数记录指标步号时刻，JSON 行以微秒整数并允许缺省参数，工具链版本形如 2.1.0-rc3 的段式字符串。组件还需按实验名与工具链版本维护指标摘要缓存与参数依赖索引，作为带版本的派生结构支撑查询。难点在于格式互操作与版本兼容的判断必须与派生缓存的增量更新、快照整体替换、并发提交与强制终止后的恢复保持一致，任何字段映射或降级补齐的错误都会在缓存中被放大。用户通过本地 HTTP 接口提交运行、导入导出、查询指标摘要并检索导入冲突报告，所有数据来自本地确定性样本，不依赖真实追踪服务或外部账号。

任务环境与准备：
确认 Windows 本地已安装 Python 3.11 及以上版本，并能创建虚拟环境；NumPy 通过 pip 安装，版本以本地 wheel 可用为准，不要求联网以外的额外仓库。
无需容器、数据库服务或外部追踪平台；SQLite 使用 Python 标准库 sqlite3，所有样本为任务内生成的确定性 JSON 与二进制文件。
准备固定随机种子与固定本地样本目录，样本涵盖参数可选缺省、指标序列混合精度、工具链版本高低与 CRC 可篡改点。
准备本地回环 HTTP 端口用于组件接口与演示脚本，确保端口空闲；演示脚本仅访问本机回环地址。

业务要求：
1. 实现两种持久化格式的编解码：紧凑二进制格式必须含魔数、格式版本字节、大端小端标记、每条记录长度前缀、CRC32 校验与可选字段存在位图；分片 JSON 行格式每行含运行标识、实验名、参数、指标序列与相对保留期。两种格式对同一运行集合导出再导入后，参数、指标序列与工具链版本必须逐字段还原，CRC 校验或长度前缀不符时返回业务码 E_RECORD_CORRUPT 并指出记录序号。
2. 实现格式协商与版本兼容裁决：导入前检测输入格式与格式版本，依照显式声明的兼容矩阵给出接受、降级接受与拒绝三种结论；旧版本缺参数或指标精度较低时走降级接受，补齐为声明默认值并记录降级明细，高版本含未知必填字段时返回 E_FORMAT_UNSUPPORTED 且整批不入库；协商预检接口须在不改变任何已提交状态的前提下给出结论。
3. 实现时间与版本语义归一化：二进制毫秒时间戳与 JSON 行微秒时间戳须归一化为同一内部表示，按调用方声明的截断规则处理亚毫秒部分并输出每条记录的舍入位与累计舍入误差；JSON 相对保留期须依据记录自带基准时间换算为绝对过期时刻；工具链版本按段式字符串规则比较，低于、等于、高于预期三态必须可判定且比较结果不依赖输入顺序。
4. 实现导入冲突解决与批次原子生效：导入运行与现有运行标识相同时，按工具链版本优先级、指标序列摘要一致性与最后写入时间打破平局的确定规则解决，结局分为覆盖、跳过与拒绝三类并写入导入报告；整批导入必须原子生效，任一条记录被拒绝则整批回滚且已提交状态不变，导入报告不得与已提交状态矛盾。
5. 实现指标摘要缓存与参数依赖索引的增量更新：按实验名与工具链版本维护指标分位与计数摘要，按参数键维护引用了该参数的运行索引；新增运行只更新受影响实验与参数的派生条目而非全量重建，当某参数或工具链版本变化导致摘要口径改变时，受影响实验摘要与参数索引必须级联失效并在同一事务边界内原子重建，禁止出现摘要已更新而参数索引仍指向旧运行的中间可见状态。
6. 实现快照整体替换与版本识别：运行集合快照文件携带格式版本、快照序号与生成时间，加载时校验版本兼容性与序号单调，加载过程在运行表、指标摘要与参数索引之间原子切换，切换成功后旧快照资源与派生统计才可释放；任何校验失败或中途异常必须保持旧快照完整可用并返回 E_SNAPSHOT_INVALID，不得出现新旧快照数据混合。
7. 实现单写者提交与多读者查询的并发一致及强制终止恢复：运行提交、导入与快照切换按提交串行执行，多个只读查询可并发读取已提交版本，同一请求标识重复提交只执行一次、其余等待并复用结果；写操作先向 SQLite 写入意图记录再提交事务，进程被强制终止后重启须扫描未完成意图把运行与派生缓存回滚到最后一个完整版本或将批次标记为已中止，恢复报告只基于已持久化事实。
8. 实现统一业务错误码 JSON 错误体与可复现演示脚本：失败响应须含业务码与上下文，至少覆盖 E_RECORD_CORRUPT、E_FORMAT_UNSUPPORTED、E_CONFLICTING_RUN、E_SNAPSHOT_INVALID、E_STALE_BASE 与 E_VERSION_RETIRED；脚本使用固定本地样本完成一次二进制导出与 JSON 行导出、一次跨格式导入、一次人为篡改 CRC 的导入失败、一次指标摘要级联重建与一次强制终止后恢复，输出导入报告、摘要重建范围与恢复结论供人工核对。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
