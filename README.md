嵌入式视觉团队目前的工作区没有任何既有实现，需要直接落地一个轻量图像分类器的分层量化标定与误差传播审计工作台。输入由程序内置固定种子生成器在本地产出：一组以 JSON 描述的多层线性分类器权重与逐层偏置、一组小尺寸灰度图像分片（PNG）及对应真值标签、一份量化策略声明（每层位宽 8 位或 4 位、对称或非对称模式、逐层或逐通道粒度、校准样本比例与随机种子），以及一份高精度参考推理输出作为误差比对真值。工作台按校准样本选取、逐层定点标定、量化推理、误差传播审计四阶段推进，需要把逐层量化误差归因到各层并给出可复核的误差上界，同时维护带单调版本号的标定快照，支持进程被强制终止后的恢复与外部参数注入验证。

任务环境与准备：
安装 Go 1.22 或更高版本，确认 go version 可用，并设置 GOPATH 与模块代理以便拉取内置依赖。
安装 SQLite 3 命令行工具用于检查数据库文件，Go 侧使用纯 Go 驱动以免依赖 CGO。
在工作区运行 go mod init 初始化模块，并准备由程序内置固定种子生成器产出的权重、图像分片、量化策略与高精度参考输出样本。
确认本地端口可用以启动 HTTP 接口，运行前无需任何外部账号、GPU 或在线数据集。

业务要求：
1. 实现校准样本选取与特征规范化阶段：依据量化策略声明的校准比例与种子用确定性分层抽样从图像分片中选出校准集，对图像做固定规则灰度归一化与展平，并校验分片实际宽高与声明一致；同一输入与策略必须产生逐字节一致的校准集清单与特征摘要，校准比例为零或超出可用分片数时返回带比例的 E_CALIB_SAMPLE。
2. 实现逐层定点标定核心：对每层权重与逐层校准激活按声明的位宽、对称或非对称模式与逐层或逐通道粒度计算缩放因子与零点，取值范围须覆盖校准极值并做边界钳制，逐层记录缩放因子、零点、钳制次数与量化误差步长；缩放因子为零、全零通道或声明位宽不在支持集合内时返回带层名与通道号的 E_QUANT_PARAM，不得静默产出全零权重。
3. 实现量化推理与真值比对：在量化域完成逐层线性前向并记录每层累加位宽与溢出钳制次数，输出预测标签与逐类分数；与高精度参考推理输出按显式抽样位置比对，计算逐层输出偏差与端到端相对误差，超出可配置容差的层须报告层名、抽样位置与最大偏差并返回 E_NUMERIC_MISMATCH。
4. 实现误差传播归因与误差上界审计：以本地高精度参考为唯一真值，按一阶敏感度与逐层扰动重放两种方式把端到端偏差分摊到各层并按贡献排序，误差上界须由显式缩放因子与量化步长逐层推导，同时输出每层有效位数；两种归因排序不一致的层须标记为待复核并保留两种依据，权重全零或参考输出缺失时返回带层名的 E_AUDIT_INPUT。
5. 实现分层标定快照的 SQLite 事务持久化：每层标定完成时以事务写入含版本号、层名、输入内容指纹、量化策略指纹、产物摘要与单调序号的记录，同一层同一版本只允许一条有效记录；读取任何版本时不得看到半提交记录，进程被强制终止后仅凭已提交事实重建进度，恢复后的标定结果与逐层误差报告须与一次连续执行逐字节一致。
6. 实现版本整体替换识别与失效传播：当权重内容、校准集、量化策略或抽样位置任一变化时，通过各阶段内容摘要构成的版本指纹区分正常推进、整体替换与回退，整体替换使全部逐层标定与审计结论失效重建，回退则拒绝并返回 E_STALE_VERSION；未受影响上游标定结果继续复用，且失效范围须在诊断中逐层列明。
7. 实现并发标定发布保护与数值异常链路：多个工作进程对同一数据库发布标定快照时使用 SQLite 条件更新与真实文件锁并比较版本号，仅允许版本号连续推进，落后、重复或跨层错位发布返回 E_STALE_VERSION；提供参数注入入口支持非法位宽、全零通道、含 NaN 权重与校准比例越界，各异常须在对应阶段返回稳定业务码并保留诊断上下文。
8. 提供本地 HTTP 与命令行交互接口及确定性演示：支持导入权重与图像分片、设置量化策略、触发分阶段标定、查询各层状态与版本指纹、查看逐层误差归因与误差上界、请求优雅停止、执行恢复、导出审计报告；演示数据至少覆盖 4 层、8 位与 4 位两档、对称与非对称两种模式及至少一个含离群值的通道。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
