当前是空白工作区，需要在 Windows 本地从零构建一个面向服务网格旁路流量镜像的采样与回放偏差裁决组件，交付可集成的领域组件与完整示例。组件读取本地确定性流量镜像样本（毫秒时间戳、连接标识、源服务、目的服务、方法、路径模板、状态码、响应字节数、耗时微秒），按带版本号的镜像策略快照（采样率、按目的服务的分层采样权重、路径模板包含与排除规则、单连接去重窗口、回放放大倍数）从镜像流中抽取应回放样本，再按回放倍数与并发约束构造回放批次，并把回放结果与线上原始统计对比，输出采样偏差、回放放大偏差与偏差来源分解。为支撑持续调参，样本以带版本的增量批次追加，策略以带版本号的增量片段提交并需基础版本校验；某策略规则变化时，依赖它的采样集合、回放批次与偏差分解必须级联失效并原子重建。查询只能看到某一完整提交版本，进程可能在任何时刻被强制终止，重启后必须依据持久化事实恢复。所有数据来自本地确定性样本与本地测试端点，用户通过本地 HTTP API 操作。

任务环境与准备：
Windows 本地安装 Python 3.11 及以上，使用 pip 安装 fastapi、uvicorn、numpy、pytest，版本在 requirements 中固定。
准备固定本地确定性样本：流量镜像记录 JSON 行文件、镜像策略基线快照与增量片段 JSON 文件，均置于工作区的 data 目录下。
提供本地回放测试端点（可返回成功、指定错误状态码与故意挂起三类行为），仅绑定本地回环地址，不需要任何外部服务或容器。
确认工作区可创建 SQLite 数据库文件与临时目录，并预先固定随机种子与样本规模以便结果可复现。
提供本地 HTTP 服务启动入口与演示脚本的运行说明，所有接口仅绑定回环地址。

业务要求：
1. 实现流量镜像样本解析与批次入库：每条记录含毫秒时间戳、连接标识、源服务、目的服务、方法、路径、状态码、响应字节数与耗时微秒，解析失败返回业务码 E_RECORD_INVALID 且整批不入库；合法记录以批次标识与行内序号唯一标识，同批次同序号重复提交必须幂等，内容不一致返回 E_CONFLICTING_RECORD 并保留首次提交。
2. 实现带版本号的增量提交与基础版本校验：样本增量片段只含新增记录，策略增量片段只含受影响规则并携带基础版本；若基础版本不是当前版本返回 E_STALE_BASE 且不改变任何已提交状态；整份快照替换时须识别版本变化并整体替换，不得把新旧版本的样本与策略混合使用。
3. 实现确定性分层采样：按目的服务的分层采样权重与全局采样率抽取应回放集合，同一连接在单连接去重窗口内只允许被抽中一次，路径模板的包含与排除规则优先于采样率；采样随机性必须由策略声明的固定种子与记录序号共同决定，使同一记录集合在任意提交切分方式下得到逐条一致的抽中结论。
4. 实现回放批次构造与放大倍数约束：按回放放大倍数与每批并发上限把抽中样本组织为回放批次，批次须满足同一连接不跨批乱序、批内样本数不超过上限、批内估计字节量与耗时不超过声明预算；无法满足时按确定规则拆分或降倍并输出降倍原因与影响样本数。
5. 实现回放执行与偏差裁决：向本地回放测试端点按批次重放请求，采集回放成功率、状态码分布与耗时分位，与线上原始统计对比得出采样偏差与放大偏差；单次回放具备独立超时，超时后须真实关闭底层连接并计入回放失败，不得以等待冒充超时；回放失败与采样偏差须在结论中分开归因。
6. 实现策略变更的级联失效与原子重建：为每条策略规则维护其对采样集合、回放批次与偏差分解产物的引用关系；当采样率、分层权重、路径规则或去重窗口变化时，受影响产物必须级联失效并在同一事务边界内原子重建，禁止出现采样集合已更新而偏差分解仍为旧值的中间可见状态。
7. 实现单写者提交与多读者查询的并发一致，并使用 SQLite 意图持久化：样本提交、策略提交与级联重建按提交串行执行，多个只读查询可并发读取已提交版本；查询只能看到某一完整提交版本；写操作先写意图记录再提交事务，进程在级联重建或回放中途被强制终止后重启须扫描未完成意图，把产物回滚到最后一个完整版本或将批次标记为已中止，恢复报告只基于已持久化事实。
8. 实现统一业务错误码与 JSON 错误体，至少覆盖 E_RECORD_INVALID、E_STALE_BASE、E_CONFLICTING_RECORD、E_SNAPSHOT_INVALID、E_REPLAY_TIMEOUT、E_BATCH_BUDGET_EXCEEDED，并提供本地 HTTP API 与端到端演示脚本：脚本用固定本地样本完成一次全量样本导入、一次只改单服务分层权重的增量提交观察级联重建、一次回放批次执行与偏差结论查询、一次回放超时归因与一次强制终止后恢复，输出各版本产物摘要与恢复报告。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
