为推理框架团队从零构建一个可集成的低精度量化算子组件，交付可集成的领域组件与完整示例。工作区为空，需自行初始化项目。输入是本地确定性生成的量化样本目录：一份层描述 JSON，声明每个层的名称、形状、输入缩放因子与零点、权重量化数据文件相对路径及 dtype（int8 或 int4 打包为字节数组，每个字节按先低后高半字节存放两个 int4 值）、权重量化方案（per-tensor 或 per-channel）与权重缩放因子数组；一份算子作业清单 JSONL，每条含作业 id、所引用的层名、分块尺寸、累加精度策略与目标输出 dtype（int8 或 int32）。团队需要按数据规模在直接反量化乘、分块整数累加与批量分块累加之间选择算法路径，输出反量化浮点结果、整数累加结果、量化回写结果与逐块路径决策，并诊断低精度路径带来的误差。

任务环境与准备：
安装 Python 3.10 及以上版本，并确保 pip 可用。
安装依赖：numpy、fastapi、uvicorn、httpx、pytest，均为纯本地运行。
准备本地确定性样本生成脚本，产出 int8 与 int4 打包权重、缩放因子与作业清单，覆盖尾块不对齐与批量形状不一致情形，不依赖外网与真实模型。
确保工作目录可写以创建 SQLite 数据库、结果分片与临时文件，并在演示前清空旧输出目录。

业务要求：
1. 组件须提供统一算子入口，接收层描述文件、作业清单、分块尺寸与累加精度策略，校验层名唯一、权重与输入形状可乘、dtype 仅为 int8 或 int4、int4 字节数组长度与每行半字节数一致、缩放因子非零且为有限实数、分块尺寸为正整数、累加策略为目标枚举值；非法输入返回 E_PARAM 或 E_SHAPE 业务码并指出出错文件、层名或行号，且不得创建任何结果文件或临时目录。
2. 须实现 int4 与 int8 权重的确定性解包与反量化：int4 每字节按先低半字节后高半字节顺序还原为有符号整数值，再按 per-tensor 或 per-channel 缩放因子与零点还原为 float64；同一权重文件与方案下解包与反量化结果须逐位可重复，解包越界、半字节数不足或缩放因子长度与输出通道数不符时返回 E_DQ 并定位到层名与通道下标，禁止只输出部分通道结果。
3. 须实现至少三条算法路径：小规模直接反量化乘、一般规模分块整数累加、批量分块整数累加，路径选择由层形状、分块尺寸与微小规模阈值共同决定并输出路径决策记录（含选择理由、分块尺寸、尾块数量、累加 dtype 与批量分桶数）；同一输入与配置下路径决策序列与结果须逐位可重复，不得依赖字典遍历顺序或文件内部键序。
4. 分块整数累加须自行按分块尺寸遍历边界块，尾块（不整除部分）必须走同一累加路径而非退回整块拷贝；任意合法分块尺寸下的结果须与不分块直接计算在声明容差内一致，超出容差返回 E_PRECISION 并定位到块序号与层名；整数累加中途须避免以低精度承载累加和，溢出须显式检测并返回 E_OVERFLOW 而不是静默回绕。
5. 累加精度策略须显式支持 float32 累加与 float64 累加两种模式：输入为 int8 或 int4 且选择 int32 整数累加时须先提升再累加、最后按目标输出 dtype 声明舍入与钳位，并输出逐块提升次数、舍入次数、钳位样本数与两种模式结果的最大绝对差；两模式差值统计须能定位到具体块序号与输出元素下标，超出容差元素须在诊断报告中单列。
6. 须实现规模自适应的批量分桶：批量分块整数累加须按可乘形状与缩放方案分桶后逐桶选择路径，桶内按层名下标的字典序稳定执行，不同桶之间不得共享可变累加缓冲区；批量内某层不可乘或解包失败时返回对应业务码并定位层名，其余已成功层的路径决策与结果须保留可查，禁止因单层失败丢弃其余层结果或伪造占位输出。
7. 进度须在 SQLite 中以作业、层、块三级记录事务提交，单块的整数累加中间量摘要、路径决策与块进度须在同一事务中写入，失败时该块整体回滚且不得留下部分写入；每次完成须以整体替换方式生成版本化快照，含配置指纹、路径决策摘要、逐结果矩阵内容哈希与误差观测摘要，读取快照时若检测到内容哈希与数据库记录不一致、配置指纹变化或残留旧版本结果文件须返回 E_STALE 并定位版本与层名。
8. 进程被强制终止后重启须从 SQLite 已提交块进度继续，核对每个作业的块处理标记、块结果内容哈希与快照版本，重算未提交块且不重复累加已提交块；须提供确定性本地演示入口与集成示例，用本地生成的覆盖 int8 与 int4、per-tensor 与 per-channel、尾块不对齐、批量形状不一致与中断恢复的样本，跑出各作业所选路径、分块尺寸、两模式差值、溢出与钳位计数、恢复前后一致性结论与快照版本序列的可重复结果，并给出可用 curl 复现的请求示例。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地 int8 与 int4 样本验证解包、路径决策、分块累加、快照与恢复一致性，并给出可重复演示结果。
