当前是空白工作区，没有现存项目、代码或数据附件。需从零构建一个本地可运行的对话式检索与生成式答案工作台，核心业务是在对话轮次与知识库规模同步变化时，对检索证据做对齐、冲突消解与答案生成，并让每次答案都带可追溯的证据链与可复现的诊断结论。输入由固定随机种子的本地生成器产出：一组对话会话分片（JSONL，含 session_id、turn_index、用户问题、上下文指代标记、语言标签），一组知识库文档分片（JSONL，含 doc_id、段落文本、段落版本号、来源通道与语言标签），以及一份工作台配置（YAML，描述检索深度、证据条数上限、证据对齐容差、答案模板、规模分档阈值与全局证据评估预算）。系统不得依赖任何真实检索服务、生成模型、外部 API、GPU 或线上站点；检索评分、证据对齐与答案组装全部以本地确定性算法实现。工作台需按会话分片执行四个阶段：查询改写与指代消解、证据检索与打分、证据对齐与冲突消解、答案组装与诊断汇总；其中任一阶段的版本变化都必须可被识别并使下游诊断失效重建。

任务环境与准备：
安装 Python 3.11 与 NumPy，使用标准库 http.server 提供本地接口，无需 GPU 或外部网络。
在工作区创建本地确定性生成器，按固定随机种子产出会话分片、知识库分片、配置与演示数据，生成结果需落盘并可重复。
准备跨进程文件锁与原子写盘的实现依赖，确保 Windows 下路径与换行处理一致。
运行目录与数据目录分离，确保中断恢复测试不依赖临时内存状态。

业务要求：
1. 实现查询改写与指代消解阶段：依据当前轮用户问题与会话前序轮次维护对话焦点（实体与上一轮答案引用的 doc_id），把省略主语与“它/该条”等指代替换为焦点文本，输出改写后查询、替换片段及其字符偏移；前序轮次缺失或焦点为空时须回退到原问题并记录回退原因，同一会话与配置必须产生逐字节一致的改写结果。
2. 实现证据检索与打分阶段：对改写查询在知识库文档分片上按词项重叠、段落版本新鲜度与来源通道先验在对数域合成检索分，输出按分数降序、同分按 doc_id 升序的候选段落及分数分量明细；空查询、零候选或分数出现 NaN/Inf 时须返回带 session_id、轮次与阶段名的稳定业务码 E_RETRIEVAL_EMPTY 或 E_NUMERIC，不得静默返回空结果。
3. 实现证据对齐与冲突消解阶段：把候选段落按证据对齐容差聚类为同一事实簇，簇内段落对同一事实给出不同数值或日期时判为冲突，依据段落版本号、来源通道先验与语言一致性在对数域合成可信度选出唯一采纳段落并输出被降级段落与裁决理由；可信度并列须有确定性仲裁规则，全簇均被降级时须保留冲突证据而非丢弃。
4. 实现答案组装与证据链导出阶段：按答案模板把采纳段落组织为带引用编号的答案，引用编号与证据链条目一一对应，证据链须记录段落原文偏移、版本号、来源通道与裁决理由；重新导入证据链后须能重建同一答案与同一引用映射，模板缺失必填槽位或引用编号不连续时返回 E_ANSWER_INVALID 并保留诊断上下文。
5. 实现基于数据规模与评估预算的检索取舍：依据会话轮数、知识库段落数、候选数与全局证据评估预算，在精确全量检索、分层截断检索与焦点优先检索三种策略中为当前档位选择一种，并记录选择理由、候选打分明细与被淘汰策略原因；须保证任一策略启用后证据评估次数不超过全局预算，小规模档不得选用仅面向大规模档设计的截断深度。
6. 实现阶段检查点持久化与优雅停止恢复：每个会话每阶段完成时以原子方式写入含阶段名、会话标识、轮次、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分的会话轮次单元后退出，恢复后最终答案、证据链与诊断汇总必须与一次从零完整运行的对应产物逐字节一致，检查点序号连续推进无跳跃与重复。
7. 实现版本变化检测与增量失效传播：当会话问题内容、知识库段落内容或版本号、检索深度、对齐容差、答案模板或规模分档阈值任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物（含答案与诊断）失效并重建，未受影响上游产物继续复用；失效原因与指纹须在查询接口中可观测，并支持与从零全量构建结果做逐字节摘要比对，不一致返回 E_INCREMENTAL_MISMATCH。
8. 提供并发发布保护、稳定业务错误码与本地确定性演示：多个工作进程对同一工作区发布阶段产物时使用真实文件锁并比较会话内轮次序号，仅允许序号连续推进，落后、重复或跨会话错位发布返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_INVALID_STAGE；命令行与本地 HTTP 接口支持导入分片与配置、触发分阶段执行、查询各阶段状态与版本指纹、查看证据链与取舍理由、请求停止、执行恢复、导出答案；演示数据至少 4 个会话分片与 3 个知识库分片，覆盖中英混排、指代消解、事实冲突与必然超预算的会话，一次完整运行生成固定摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
