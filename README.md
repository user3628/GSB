推理框架的算子组在一台 Linux 开发机上准备验证一套 Softmax 与 LayerNorm 分块算子库，当前目录除这份需求说明外没有任何实现，首个版本需要连同可复现实验环境一起交付。输入由程序内置固定种子生成器在本地确定性产出：若干 .json 张量分片，描述形状 [行数, 列数]、逐行缩放因子与数值，覆盖行方向 Softmax 与列方向 LayerNorm 两类归约、非整除分块、极端值（如 1e4 与 -1e4 混合）、全零行与含 NaN/Inf 的异常样本；另附形状清单声明每片行数与列数作为分块决策的显式观测，并给出以定点量化保存的高精度参考输出作为唯一真值来源。算子库需按行块与列块组织计算，在分块归约过程中以 SQLite 事务持久化每块的运行最大值、指数和或均值方差、部分输出与单调序号，使进程被强制终止后仅凭已提交事实即可恢复至与连续运行逐字节一致的最终结果，同时支持输入与配置变化后的块级失效传播与并发发布保护。

任务环境与准备：
在 Linux（WSL Ubuntu）上创建空工作目录并初始化 Go 模块，Go 版本不低于 1.22，使用标准库与 SQLite 驱动。
确认本地已具备可写临时目录与 SQLite 库文件位置，所有样本、参考输出与数据库均由程序内置固定种子生成器在本地确定性产出，不依赖网络、GPU 或外部数据集。
运行前先由生成器写出各分片 .json、形状清单与定点参考输出，再启动算子库与本地 HTTP 服务进行分阶段计算与恢复验证。

业务要求：
1. 实现 Softmax 按行分块与 LayerNorm 按列分块的统一归约内核：归约时先减去块内运行最大值再在对数域累加指数和、加权和或均值方差，支持任意合法非整除行列数与批量分片；同一输入与配置必须产生逐字节一致的输出与中间量摘要，出现 NaN/Inf 的块须返回带分片标识、块行列区间与异常值的 E_NUMERIC 业务码并保留诊断上下文，不得静默替换数值。
2. 实现分块中间状态的 SQLite 事务持久化：每完成一个不可拆分的行块或列块，以单个事务写入含分片标识、阶段名、块坐标、已覆盖列范围、运行最大值、指数和或均值方差、部分输出摘要、输入内容指纹与单调序号的记录；同一分片同一块坐标同一版本只允许一条有效记录，写入任意位置中断不得留下半写状态。
3. 实现优雅停止与强制终止后的恢复边界：收到停止请求时完成当前不可拆分块后落库并退出，不承诺强制终止后生成退出报告；被强制终止后重启仅凭已提交事务事实重建进度，恢复后的最终输出、逐块中间量摘要与验证报告必须与一次从零连续运行逐字节一致，且块序号连续推进、无跳跃与重复。
4. 实现基于输入形状与配置内容摘要的版本指纹与块级增量失效传播：当分片张量内容、归约类型、行块或列块大小、求和策略或量化位宽任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段与最小块区间，使该区间及其全部下游块状态失效并重建，未受影响块状态继续复用；增量结果须与从零全量运行逐字节一致，不一致返回 E_INCREMENTAL_MISMATCH 并附首个差异块坐标。
5. 实现误差界推导与参考输出逐块审计：对每个输出块按显式抽样位置与定点参考输出比对，给出最大绝对偏差、相对偏差与有效位数，误差界须由缩放因子、量化步长与分块累加顺序逐项推导，推导依据随结果保留；偏差超出可配置容差时返回带分片标识、块坐标与最大偏差的 E_TOLERANCE_EXCEEDED。
6. 实现并发块发布保护与快照整体替换识别：多个工作进程对同一数据库发布块状态时使用 SQLite 条件更新与真实文件锁并比较块序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_PUBLISH；检测到记录被整体替换（序号回退、内容指纹变化或摘要不匹配）时区分正常推进、整体替换与回退，整体替换使相关块状态失效重建，回退拒绝并返回 E_STALE_PUBLISH。
7. 实现峰值内存约束下的执行调度：在可配置峰值内存上限内规划行块工作区、列块切片、输出缓冲与中间累加器的占用，超预算时按行块或列块拆分执行并记录拆分决策与每步内存估算，或返回带预算明细的 E_MEMORY_BUDGET；不得以延迟或线程超时替代真实的内存拆分决策。
8. 提供可集成的算子库接口、本地 HTTP 与命令行验证工具及确定性演示：支持导入分片与配置、触发分阶段计算、查询各阶段状态与版本指纹、查看逐块误差与失效原因、请求优雅停止与执行恢复；演示数据至少覆盖 Softmax 与 LayerNorm 各两类分片，含非整除分块、极端值、全零行与一次强制终止恢复场景，并输出可由配置指纹复算的固定摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地分片验证分块归约输出与逐块误差审计，并确认强制终止后凭持久化状态恢复的结果与连续运行逐字节一致。
