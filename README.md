为 LLM 偏好对齐团队从零构建一个本地可运行的偏好对数据与奖励模型评分工作台，核心问题是偏好数据与奖励模型评分配置在多个格式版本之间的互操作与版本兼容判定。输入是本地样本目录：一份偏好对数据分片 JSONL，每条含 pair id、prompt、chosen 与 rejected 两条回复（含文本、token 计数与人工偏好强度评分）、来源标注与数据格式版本号；格式存在两种变体：A 版把 chosen 与 rejected 包装为两个对象数组，B 版把两条回复展开为扁平字段并以 0/1 标签表示偏好方向。另有一份奖励模型评分配置 JSON，声明若干评分因子（长度因子、人工评分因子、格式因子）的权重、缩放系数与配置版本号。团队需要据此完成偏好对规范化、奖励打分与数据过滤，导出可直接用于奖励模型训练的数据集，并诊断版本迁移过程中的兼容问题。工作区为空，需从零创建项目，交付算法实现与可复现的实验环境。

任务环境与准备：
确认 Windows 本地已安装 Python 3.11 及以上版本，并用 python -m venv 创建虚拟环境后激活。
在虚拟环境中安装 fastapi、uvicorn、numpy、pytest、httpx，版本以满足本文所用接口为准，不依赖任何在线模型或账号。
在项目内用脚本生成确定性本地样本：A 版与 B 版偏好对 JSONL 分片、若干版本的奖励模型评分配置 JSON 与浮点容差配置，全部写入工作区 samples 目录并固定内容哈希。
准备用于中断恢复验证的进程强制终止方式，在 Windows 上使用 taskkill /F 终止服务进程，恢复后重新读取 SQLite 与结果文件进行核对。
预留本地可写目录存放 SQLite 数据库、结果分片与快照文件，运行前确认目录为空以验证从零生成的完整流程。

业务要求：
1. 工作台入口接收样本目录、评分配置与浮点容差，校验 pair id 唯一、每条偏好对包含 chosen 与 rejected 且文本非空、人工偏好强度位于 [0,1]、token 计数为正整数、格式版本号可解析、评分因子权重非负；任一非法返回 E_PARAM 业务码并指出出错文件与行号，且不创建任何结果文件或临时目录。
2. 须实现 A 版对象数组与 B 版扁平字段两种偏好数据格式到统一内部表示的确定性互转，偏好方向在两种格式间须保持等价：A 版以 chosen 对象隐含方向，B 版以标签 0 表示 chosen、1 表示 rejected；往返转换后逐条 pair 的 prompt、两条回复文本、token 计数与偏好方向必须完全一致，任一方向歧义或标签缺失返回 E_FORMAT 并定位 pair id。
3. 须实现按评分配置的确定性奖励打分：每条回复的得分由人工偏好强度因子、长度因子与格式因子按权重加权合成，全部在 float64 下按因子声明顺序累加，缩放系数用于把合成值映射到声明区间；各因子的原始值、权重与累加顺序须可查询，同一输入与配置下逐回复得分逐位可重复，不得依赖字典遍历顺序。
4. 评分配置须支持版本兼容判定与迁移：按版本号逐字段比较当前配置与旧版配置，只有因子权重之和保持为 1 的归一化可重算、缩放系数单调性不变、因子集合仅为原有子集的差异才允许迁移；不可映射的新增因子或缺失因子须返回 E_COMPAT 并列出不兼容字段名与新旧版本号，迁移后的权重须重新归一化并记录归一化前后具体数值。
5. 过滤规则须按当前格式版本与评分配置版本共同判定：只有同时满足所选回复得分高于被拒回复、人工偏好强度不低于阈值且格式迁移无被拒绝字段的 pair 才进入训练集；被过滤 pair 须记录触发原因与阈值差，某版本下全部 pair 被过滤时须返回空训练集并给出计数而不是报错，非法阈值返回 E_SCORE。
6. 每次打分与过滤完成须以整体替换方式生成版本化快照，含配置指纹（数据格式版本、评分配置版本与容差的内容哈希）、逐 pair 得分与过滤摘要、训练集内容哈希；读取快照时若检测到数据库版本与磁盘文件哈希不一致、配置指纹变化或残留旧版本文件，须返回 E_STALE 并定位到版本与 pair id，禁止把旧数据静默汇入统计。
7. 打分与过滤进度须在 SQLite 中以 pair 粒度事务提交，单条 pair 的规范化结果、逐因子得分与过滤结论须在同一事务中写入，结果分片文件先写临时文件再原子替换并登记内容哈希；进程被强制终止后重启须核对已提交 pair 的结果哈希与提交标记，重算未提交 pair 且不重复计分，恢复后的训练集与快照版本序列须与无中断执行完全一致。
8. 须提供确定性本地演示入口：固定一组覆盖 A 版与 B 版格式、可迁移与不可迁移评分配置版本、可过滤与全部被过滤情形的样本，跑出逐 pair 偏好方向与得分、兼容判定结论与不兼容字段清单、被过滤原因计数、训练集大小与快照版本序列的可重复结果，并给出可用等价参数复现的命令示例。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地固定样本验证双格式互转、评分与版本迁移判定、过滤及中断恢复一致性，并附可重复运行结果。
