当前为空工作区，需从零构建一个本地可运行的图文跨模态检索索引工作台，交付领域可视化与诊断工作台。输入为固定随机种子生成器产出的本地小尺寸 RGB PNG 分片（几何图形与渐变色块构成）与一份 JSONL 图文对清单，每条含 pair_id、image_file、caption（中英混排）、lang 与 source；系统不依赖任何真实视觉语言模型、GPU 或外部服务。工作台需为每个分片提取确定的视觉描述子（分块颜色矩与边缘方向直方图），为每条 caption 提取词袋与字符 n-gram 特征，经可配置投影矩阵映射到同一 64 维检索空间并做归一化，再构建跨模态倒排索引与向量索引，支持文本检索图像与图像检索文本两类查询并返回 top-k 与分数明细。索引构建分为特征提取、投影对齐、索引构建、召回校验四个阶段，并按分片持久化阶段产物。

任务环境与准备：
安装 Python 3.11，创建本地虚拟环境，不需要容器或任何外部服务。
安装 NumPy、Pillow 与 FastAPI，并确认可在本机启动本地 HTTP 服务端口。
用固定随机种子的本地生成器产出至少 4 个 RGB PNG 分片与对应图文对 JSONL 清单，样本与清单随项目落盘。
在项目工作区下准备独立的数据目录与状态目录，确认当前用户对两目录有读写权限。
准备命令行运行入口，确认无需网络即可完成索引构建、双向检索与异常注入演示。

业务要求：
1. 实现视觉描述子与文本特征提取：图像按可配置网格切块，逐块计算颜色均值、标准差与边缘方向直方图并拼接为固定维度视觉特征；caption 经 Unicode NFKC、空白折叠与小写化后，以词袋与字符 n-gram 加权合成固定维度文本特征；同一输入与配置必须产生逐字节一致的特征，特征维度须在提取前声明并与清单声明的维度一致，不一致返回 E_DIM_MISMATCH。
2. 实现跨模态投影对齐与归一化：以可配置投影矩阵把视觉与文本特征映射到同一 64 维检索空间，并做单位归一化；矩阵维度与特征维度不匹配、矩阵含 NaN 或 Inf 时返回 E_PROJECTION_INVALID 并附阶段名与矩阵位置；归一化后须校验向量模长为 1 的偏差在 1e-9 内，否则返回 E_NUMERIC。
3. 实现跨模态倒排索引与向量索引构建：为文本特征建立词袋与 n-gram 倒排表、为视觉特征建立分块哈希倒排表，并为两类向量建立以分片号与向量号寻址的稠密索引；索引构建须记录每个 posting 的权重与来源分片，同一输入与配置下倒排表顺序与向量索引摘要须逐字节一致；分片缺失对应图像文件时在索引构建阶段返回 E_MISSING_FRAGMENT，不得跳过该分片。
4. 实现双向检索与分数明细：支持文本检索图像与图像检索文本，按余弦相似度与倒排命中加权的可配置组合排序，输出 top-k 结果及每个结果的相似度分量、倒排命中项与来源分片；k 超出索引规模、查询文本为空或图像特征维度非法时返回 E_QUERY_INVALID；同一查询在相同索引版本下重复执行须返回逐字节一致的结果与排序。
5. 实现索引版本指纹与增量失效传播：当图像内容、caption、投影矩阵、网格参数、n-gram 参数或排序权重任一变化时，通过内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游索引与召回结果失效并重建，未受影响上游产物继续复用；失效原因、各阶段指纹与重建范围须在诊断查询接口中可观测，禁止用旧索引回答查询。
6. 实现阶段检查点与优雅停止恢复：每个分片按特征提取、投影对齐、索引构建、召回校验四阶段完成时以原子方式写入含分片标识、阶段名、输入指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分阶段后退出，不承诺强制终止后生成退出报告，恢复后最终索引摘要与召回校验结果须与一次从零完整运行逐字节一致。
7. 实现异常注入与可复现验证通道：提供参数注入入口，支持注入维度不一致的清单、含 NaN 的投影矩阵、缺失图像文件、空查询与 k 越界等情况；各注入须在对应阶段返回稳定业务码（E_DIM_MISMATCH、E_PROJECTION_INVALID、E_MISSING_FRAGMENT、E_QUERY_INVALID）并写入带注入编号的异常记录，重复执行同一注入须得到逐字节一致的异常记录，且注入不得污染已发布的合法索引版本。
8. 实现并发发布保护与诊断工作台：多工作进程对同一工作区发布阶段产物时使用文件锁并比较检查点序号，仅允许序号连续推进，落后或重复发布返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_INVALID_STAGE；命令行与本地 HTTP 接口须支持导入图文对、触发分阶段构建、执行双向检索、查询各阶段状态与版本指纹、请求停止与恢复，诊断页面展示索引规模、各阶段指纹、注入记录与重建范围。
