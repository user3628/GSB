当前是空白工作区，需要从零构建一个面向本地确定性事件流的聚合与窗口函数计算引擎，交付数据处理管线与结果验证工具。引擎读取本地样本事件（毫秒时间戳、分组键、度量值），按滚动窗口、滑动窗口与会话窗口计算分组聚合（计数、求和、最值、分位），并维护窗口状态在多轮增量输入下的演进。为支撑长时间运行，引擎需周期性写入状态快照，进程可能在任意时刻被强制终止，重启后必须依据持久化快照与意图日志恢复窗口状态，使继续摄入后续事件后的聚合结果与从未中断时逐项一致。核心难点是状态演进与恢复一致性：窗口边界对齐、迟到事件、快照版本替换、并发摄入与查询可见性之间存在冲突，需要用真实机制处理而不是靠延迟规避。用户通过本地 HTTP 接口提交事件批次、触发快照、查询窗口结果与恢复报告，所有数据均来自本地固定样本。

任务环境与准备：
确认 Windows 本地已安装 Python 3.11 及以上版本，并能使用虚拟环境。
创建项目虚拟环境并安装 FastAPI、Uvicorn、NumPy 与 pytest，版本以本地可获取的稳定版为准。
准备固定本地样本事件文件与快照样本，包含边界时间戳、迟到事件、空分组与大规模混合量级度量值，全部为确定性数据。
确认 SQLite 可用，样本与运行时数据均写入工作区本地目录，不依赖外部账号或网络服务。
提供启动本地 HTTP 服务与运行验证脚本的说明，所有验证在本地回环地址完成。

业务要求：
1. 实现事件摄入与三类窗口划分：滚动窗口按固定宽度对齐到纪元边界，滑动窗口按固定宽度与步长生成相互重叠的窗口，会话窗口按分组键的空闲间隔切分；每条事件必须被分配到其时间戳所属的全部窗口，窗口边界包含关系须明确定义并对边界时间戳样本给出一致归属，非法时间戳或缺失分组键返回业务码 E_EVENT_INVALID 且整批不摄入。
2. 实现分组聚合与分位计算：对每个窗口的每个分组计算计数、求和、最小值、最大值与分位值，求和采用补偿求和以降低大规模混合量级样本的累计误差，分位使用确定性最近秩法并注明样本规模；度量值为空或分组无样本时返回确定的空聚合而非异常，求和结果在 JSON 中保留固定小数位并附舍入说明。
3. 定义窗口状态机，至少包含 OPEN、CLOSED、EMITTED 三种状态并规定合法迁移路径：窗口内新事件到达只允许在 OPEN 状态下合并进聚合，窗口关闭后到达的事件必须按声明策略进入迟到队列或返回 E_LATE_EVENT，已 EMITTED 的窗口不得再被修改；非法迁移返回 E_INVALID_TRANSITION 且不修改已持久化状态。
4. 实现状态快照与整体版本替换：快照包含窗口聚合状态、迟到队列、会话窗口切分状态与单调递增的快照版本；加载快照时必须识别版本变化并整体替换旧状态，不得把新旧快照的窗口状态混合使用，版本不单调或校验摘要失败返回 E_SNAPSHOT_INVALID 且保持原状态可用。
5. 实现强制终止后的断点恢复：每个事件批次提交前写入意图记录，快照写入先落临时产物再原子提交；进程在批次合并或快照提交中途被强制终止后重启，必须扫描未完成意图回滚到最后一个完整快照或标记批次已中止，恢复报告只基于已持久化事实，不承诺强制终止后仍生成完整退出报告；恢复后续摄入的事件产生的结果须与未中断路径逐项一致。
6. 实现并发摄入与查询可见性：事件摄入按分组键或全局单写者串行执行，多个窗口查询可并发读取已提交快照；同一批次标识重复提交只生效一次、其余等待并复用结果，内容不一致时返回 E_CONFLICTING_BATCH；查询只能看到某一完整提交版本，不得观察到事件已合并而窗口聚合未更新的中间状态，迟到事件与已关闭窗口的交互须有确定结论。
7. 实现窗口结果输出与资源边界：按请求指定的时间范围与分组过滤输出窗口结果，结果按窗口起点、分组键稳定排序并支持分页拼接不重不漏；当活跃窗口数或迟到队列长度超过配置上限时，按确定规则淘汰已 EMITTED 的最旧窗口并输出淘汰清单，超出硬上限的摄入返回 E_CAPACITY_EXCEEDED 而非静默丢弃。
8. 提供统一业务错误码、本地 HTTP 接口与结果验证工具：接口覆盖批次摄入、快照触发与加载、按范围查询窗口结果、迟到队列查询与恢复报告查询，失败响应为含业务码的 JSON，至少覆盖 E_EVENT_INVALID、E_INVALID_TRANSITION、E_LATE_EVENT、E_SNAPSHOT_INVALID、E_CONFLICTING_BATCH、E_CAPACITY_EXCEEDED；验证工具使用固定本地样本执行一次未中断全量摄入与一次含强制终止后续摄入的两条路径，比对两者窗口聚合结果是否逐项一致并输出差异清单。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用固定本地样本验证窗口聚合结果、强制终止后断点恢复一致性与各类异常码响应，输出恢复前后差异清单。
