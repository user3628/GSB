当前为空工作区，需从零构建一个本地可运行的多模态协同推理数据管线与结果验证工具。输入为本地确定性样本：一组文本片段（JSONL，含 id、文本、语言标签）与一组图像描述片段（JSON，含 id、视觉特征向量、对应文本 id、来源算子标签），由固定随机种子的本地生成器产出，不依赖真实模型、GPU 或外部服务。管线对每个样本集合执行四个协同阶段：文本编码（本地哈希嵌入）、视觉特征对齐（特征向量与文本嵌入的跨模态投影与相似度计算）、融合打分（跨模态一致性与来源算子置信度加权）、结果聚合（按样本汇总协同推理结论与置信度）。整个过程要求状态演进可追溯、阶段产物可持久化、中断后可恢复，并在上游输入或融合配置变化时精确识别失效范围。交付形式为数据处理管线与结果验证工具，含交互式查询接口。

任务环境与准备：
安装 Python 3.11 并在空工作区创建虚拟环境，安装 numpy 与 fastapi、uvicorn（固定版本写入依赖清单），不需要 GPU 与外部服务。
使用固定随机种子的本地生成脚本产出文本 JSONL 与图像描述 JSON 样本，落到工作区 samples 目录，并记录生成参数以便复现。
确认 Windows 本地文件锁、原子替换与线程池可用，准备工作区目录用于检查点、版本存储与演示输出。
准备验证工具运行入口与演示脚本说明，确保停止与恢复演示可在本机重复执行。

业务要求：
1. 实现文本编码与视觉对齐两个前端阶段：文本按 Unicode NFKC、空白折叠与小写化后以固定哈希函数生成 64 维单位嵌入；图像特征经可配置投影矩阵映射到同一空间并计算与对应文本嵌入的余弦相似度；同一输入与配置必须产生逐字节一致的嵌入与相似度，且记录每段的输入版本指纹。
2. 实现融合打分与结果聚合阶段：融合分数由跨模态相似度、来源算子置信度与可配置权重合成，聚合阶段按样本汇总协同结论（一致/弱一致/冲突）、总置信度与参与阶段摘要；权重变化须改变结果并留下可观测的配置版本信息，禁止在聚合中静默丢弃冲突样本。
3. 实现持久化阶段检查点：每个阶段完成时以原子方式写入包含阶段名、输入指纹、配置版本、产物摘要与单调序号的记录，写入过程任意位置中断不得产生半写记录；恢复时必须忽略损坏或不完整记录，从最近一致检查点继续，已发布阶段产物不得重复计算。
4. 实现优雅停止与中断恢复一致性：进程收到停止请求时完成当前不可拆分样本单元后退出，不承诺强制终止后生成退出报告；恢复后最终聚合结果必须与一次从零完整运行的输出逐字节一致，且检查点序号连续推进、无跳跃或回退。
5. 实现版本变化检测与失效传播：当文本片段、视觉特征、投影矩阵、融合权重或置信度配置任一变化时，通过版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建；未受影响上游产物继续复用，失效原因与指纹须在查询接口中可观测，禁止用旧版本结果冒充新结果。
6. 实现并发阶段发布保护：多个工作进程对同一工作区发布阶段产物时使用文件锁并比较检查点序号，仅允许序号连续推进；落后或重复发布返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_INVALID_STAGE，均不得覆盖已发布产物。
7. 实现异常输入与错误链路的稳定业务错误码：文本缺失、视觉特征维度与投影不匹配、相似度出现 NaN 或 Inf、样本引用不存在的文本 id 等情况，须在对应阶段返回带样本标识与阶段的业务错误码（E_MISSING_INPUT、E_SHAPE_MISMATCH、E_NUMERIC、E_INVALID_STAGE），非法阶段跳转亦须被拒绝。
8. 提供交互接口与本地确定性演示：命令行与本地 HTTP 接口支持导入样本、查询各阶段状态与版本指纹、请求停止、执行恢复、查看聚合结论；演示数据至少含 3 个文本片段与 3 个图像描述片段、覆盖中英混排与一个冲突样本，演示人为触发停止后恢复并与完整运行结果比对，附验证工具输出。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本执行完整管线，验证阶段状态、停止恢复一致性与错误码，并附验证工具输出。
