团队准备用一次独立原型替换老旧的量化工具链，工作区此刻是空目录，因此先从零写出一套可独立演示的分层定点量化工件。输入全部由程序内置固定种子生成器在本地确定性产出：一组以 JSON 描述的多层线性图像分类器权重与逐层偏置、一组小尺寸 PNG 灰度图像分片及其真值标签、一份量化策略声明（每层位宽 8 位或 4 位、对称或非对称模式、逐层或逐通道粒度、校准样本比例与随机种子），以及一份以定点量化保存的高精度参考推理输出作为唯一误差比对来源。工作台按校准样本选取、逐层定点标定、量化推理、误差归因四阶段推进，每次标定与审计都绑定输入指纹与策略版本，中断恢复后的结论须与一次连续运行逐字节一致。

任务环境与准备：
在 Linux（WSL Ubuntu）机器上准备空工作目录，确认可创建本地文件与 SQLite 数据库文件。
安装 Go 1.21 或以上版本（例如通过发行版包管理器或官方压缩包），并确保 go 命令在 PATH 中；不依赖任何第三方在线服务。
首次构建前执行 go mod init 并拉取本地可用依赖；SQLite 采用纯 Go 驱动以减少外部依赖，版本以 go.mod 锁定为准。
运行程序内置的固定种子生成器产出权重 JSON、灰度 PNG 分片、量化策略声明与高精度参考推理输出，所有样本只落在工作目录内。

业务要求：
1. 实现校准样本选取与图像规范化阶段：依据量化策略声明的校准比例与随机种子，用确定性分层抽样从图像分片中选出校准集，对图像做固定规则灰度归一化与展平，并校验每个分片实际宽高与清单声明一致；同一输入与策略必须产生逐字节一致的校准集清单与规范化向量，声明不符须返回带 image_id、声明值与实际值的 E_DIM_MISMATCH 并保留在诊断输出中。
2. 实现逐层定点标定核心：对每层权重与校准激活按声明的位宽、对称或非对称模式与逐层或逐通道粒度计算缩放因子与零点，取值范围须覆盖校准极值并做边界钳制，逐层记录缩放因子、零点、钳制次数与量化步长；缩放因子为零、全零通道或输入含 NaN 时须返回带层名与通道号的 E_INVALID_SCALE，不得以零缩放因子继续计算并产出静默结果。
3. 实现量化推理与参考比对：在整数累加域完成逐层线性前向并记录每层累加位宽与溢出钳制次数，输出预测标签与逐类分数，再与高精度参考推理输出按显式抽样位置比对，计算逐层输出偏差与端到端相对误差；容差参数须可配置，越界时返回 E_TOLERANCE_EXCEEDED 并附层名、最大偏差与参与抽样的位置清单，未越界时同样保留偏差明细供审计。
4. 实现误差归因与误差上界推导：以本地高精度参考为唯一真值，按一阶敏感度与逐层扰动重放两种方式把端到端偏差分摊到各层并按贡献排序，误差上界须由显式缩放因子与量化步长逐层推导并输出每层有效位数；两种归因排序不一致的层须标记待复核并同时保留两种依据，推导过程不得引用缺失信息。
5. 实现分层标定快照的 SQLite 事务持久化与优雅停止恢复：每层标定完成时在单个事务内写入含版本号、层名、输入内容指纹、量化策略指纹、产物摘要与单调序号的记录，同一层同一版本只允许一条有效记录；收到停止请求时完成当前不可拆分层级后退并提交，强制终止后重启仅凭已提交事实恢复进度，恢复后的逐层缩放因子、审计结论与归因排序须与一次连续运行逐字节一致。
6. 实现版本整体替换识别与失效传播：当权重内容、校准集、量化策略或抽样位置任一变化时，通过各阶段内容摘要构成的版本指纹区分正常推进、整体替换与回退，整体替换须使全部逐层标定与审计结论失效重建，回退须拒绝并返回 E_STALE_VERSION 并附当前生效版本与最小可接受版本；未受影响的输入阶段产物继续复用。
7. 实现并发发布互斥与数值异常链路：多工作进程对同一数据库发布标定快照时使用事务条件更新与真实文件锁并比较版本号，仅允许版本号连续推进，落后、重复或跨层错位发布返回 E_STALE_VERSION；提供参数注入入口覆盖位宽非法、逐通道缩放因子为零、激活为 NaN 与抽样位置越界等情况，各注入在对应阶段返回稳定业务码并保留诊断上下文。
8. 提供本地 HTTP 与命令行交互接口及确定性演示：支持导入权重与图像分片、设置量化策略、触发分阶段标定、查询各层状态与版本指纹、查看逐层误差归因与误差上界、请求优雅停止与执行恢复、导出审计报告；演示数据至少覆盖 8 位与 4 位、对称与非对称、逐层与逐通道组合，并含一个刻意越界样本与一个尺寸声明不符样本，完整运行可重复得到同一报告摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
