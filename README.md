需要在一个空白工作区中从零实现一个面向本地单机数据库内核场景的 MVCC 可见性快照互操作与版本兼容诊断工作台。数据库以行版本链维护多版本记录，每个版本携带事务标识、提交序号、删除标记与可见性区间；事务在开始时获取快照（活跃事务集合与快照序号），并按隔离级别判定行版本可见性。不同格式版本的快照以自描述结构持久化：v1 快照只记录最小活跃事务号与快照序号，v2 快照在此基础上增加活跃事务集合、快照获取逻辑刻度与来源节点标识。工作台须支持在同一数据目录中混合打开 v1 与 v2 快照，按格式版本分派判定器，对 v1 快照按声明的兼容默认值补全缺失字段，并支持显式迁移把 v1 快照升级为 v2。真实数据库的难点在于：快照格式的缺失字段会改变可见性判定结果，迁移前后对同一行版本链必须给出可解释且可验证等价的可见性结论，同时快照迁移与并发事务提交、进程重启之间必须保持状态一致。

任务环境与准备：
安装 Python 3.11 或以上，创建虚拟环境并使用 pip 安装 fastapi、uvicorn、numpy、pytest。
确认工作区为空白目录，所有样本数据、SQLite 数据库文件与临时文件均由程序或测试在本地生成，不依赖网络与真实数据库实例。
确保运行环境为 Windows，路径分隔符与原子替换均使用标准库实现，测试使用固定随机种子并离线运行。

业务要求：
1. 实现行版本链与快照的自描述持久化格式：行版本记录含行键、版本序号、创建事务、删除事务、提交序号与内容摘要；v1 快照含魔数、格式版本、快照序号与最小活跃事务号，v2 快照在此基础上增加活跃事务集合、快照获取逻辑刻度与来源节点标识；两种格式均须带条目数与 CRC32 校验和，打开时须拒绝魔数不符、版本不支持、校验和不匹配的快照并返回 E_SNAPSHOT_FORMAT，不得进入可见性判定。
2. 实现多版本格式互操作与兼容补全：数据目录可混合存在 v1 与 v2 快照，按段头版本分派判定器；以 v2 视图读取 v1 快照时，活跃事务集合须补全为声明的兼容默认值，快照逻辑刻度取该快照序号对应的刻度上界，来源节点标识标记为 legacy，且补全依据须写入诊断输出；以 v1 视图读取 v2 快照时只暴露 v1 字段，但不得因字段裁剪改变可见性结论。
3. 实现事务可见性判定与隔离级别语义：对每一行版本链，依据快照的活跃事务集合、快照序号与版本提交序号判定可见性，READ COMMITTED 下每次读取最新已提交版本，REPEATABLE READ 下须锁定快照序号内可见的版本；被删除版本须按删除事务是否在快照中可见决定是否隐藏；判定结果须包含可见版本序号、判定依据与所用快照格式版本，使调用方能解释每个可见性结论。
4. 实现显式快照格式迁移与等价性验证：提供把指定 v1 快照迁移为 v2 的接口，迁移须先写临时新快照并校验 CRC 与条目数后再原子替换，替换前旧 v1 快照保持可读；迁移必须保证对行版本链的可见性结论与迁移前逐行一致，并输出迁移前后可见性判定对比报告，列出所有结论一致的行数与存在差异的行键及差异原因。
5. 实现迁移中断后的恢复与回滚：迁移中断后重启时须依据持久化的迁移标记识别未完成迁移，把目标快照回滚到迁移前状态并清理临时文件；迁移标记须记录迁移前后的快照版本号与内容摘要，若回滚时发现旧快照摘要已变化须判定为损坏并返回 E_MIGRATION_CORRUPT；已完成迁移的快照不得被重复回滚。
6. 实现快照整体替换的版本识别与并发事务一致性：快照元数据整体替换须携带递增的快照版本号并先写临时文件校验摘要后原子替换，替换前旧快照保持可读；启动时若发现版本号未变化但内容摘要变化须判定为损坏并返回 E_SNAPSHOT_CORRUPT。并发事务提交与快照迁移同时发生时，迁移须在快照一致性边界内串行化，已开始的事务不得观察到迁移中间状态，锁等待须有真实超时并返回 E_CONTENTION_TIMEOUT。
7. 实现本地 HTTP 诊断接口与进程重启恢复：提供打开快照、执行可见性判定、触发快照迁移、查询迁移对比报告、查询快照格式与版本清单的接口，错误统一以固定业务码在 JSON 中返回；快照清单、迁移标记与可见性判定事件须在提交点以单事务写入 SQLite，重启后须恢复快照格式状态与迁移进度，中断时处于迁移中的快照按回滚规则处理，恢复后的可见性判定结果与重启前逐行一致。
8. 提供本地确定性样本与可重复测试：样本须包含至少一个 v1 快照、一个 v2 快照、一个损坏快照与覆盖插入、更新、删除的行版本链，pytest 用例须在 Windows 离线覆盖格式互操作读、兼容补全、迁移前后可见性等价、迁移中断回滚、快照损坏拒绝与并发迁移互斥，全部使用固定随机种子并在无外部依赖环境下可重复运行。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
本地样本验证 v1/v2 快照互操作、可见性判定、迁移等价与中断回滚及异常处理。
