当前是空白工作区，没有现存项目、代码或数据附件。需从零构建一个本地可运行的 TopK 与采样分块算子库和结果验证工具，核心场景是：在固定随机种子生成的 logits 矩阵上，按行做 TopK 筛选、对数域归一化与可复现采样，并在全局评估次数预算、单工作进程元素配额与峰值内存上限三重约束下并行推进；同时提供参数注入通道验证异常链路的业务码一致性。输入为本地 .npy logits 分片（形状 [行数, 词表大小]，覆盖小词表、大词表、并列最大分数、全负无穷行、含 NaN/Inf 的异常分片）与一份算子清单，逐分片声明 K 值档位、采样温度、是否启用核采样截断、期望输出形状与分值区间。不依赖 GPU、外部库或线上服务，所有样本与参考结果由本地确定性生成。

任务环境与准备：
安装 Python 3.10 及以上与 NumPy，确认可在 Windows 本地创建多进程池并按文件锁共享工作区目录。
使用固定随机种子脚本生成本地 .npy logits 分片与算子清单，覆盖小词表、大词表、并列最大分数、全负无穷行与含 NaN/Inf 的异常分片。
准备本地工作区目录用于检查点、锁文件与导出摘要，确认无外部网络与 GPU 依赖。

业务要求：
1. 实现逐行 TopK 分块筛选内核：按行块与词表列块组织扫描，维护每行当前前 K 名候选集合并记录候选来源列块与比较次序；K 大于词表大小、K 为零或负须返回带分片标识与 K 值的 E_INVALID_K，并列分数须有确定性名次裁决规则，同一输入与配置必须产生逐字节一致的候选清单与名次。
2. 实现对数域归一化与可复现采样核心：对每行 TopK 候选先减去最大分数再在对数域计算概率，按温度缩放；温度为零或非正返回 E_INVALID_TEMP；采样随机源须由配置种子与行号派生，同一种子在任意并行度下产生相同采样 token 序列与每步对数概率。
3. 实现核采样截断：按降序累积概率超过配置阈值时确定候选边界，多个等值概率跨越阈值时必须有一致的取舍规则，被截断候选须保留在诊断输出中；截断后概率和为零返回 E_NUMERIC，并附行号与截断位置，不得静默返回首候选。
4. 实现预算约束下的分片并行调度：以分片为调度单元，在全局元素评估预算、单工作进程元素配额与峰值内存上限三重约束下决定接纳顺序与并发度；接纳前依据形状清单预估消耗，超预算分片记录为未处理并给出原因，累计消耗不得超过预算且不得依赖内存溢出兜底。
5. 实现并行执行与确定性归约：使用本地进程池并行处理已接纳分片，各分片候选清单、采样序列与统计按分片序号与行号全局排序后归约，使并行汇总与单进程顺序执行逐字节一致；工作进程异常须以结构化错误对象记录并保留已完成分片结果，不得以线程超时描述为已终止失控计算。
6. 实现阶段检查点持久化与优雅停止恢复：每分片按筛选、归一化、采样、校验四阶段完成时原子写入含分片标识、阶段名、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分行块后退出，恢复后产物须与从零完整运行逐字节一致。
7. 实现版本变化检测与增量失效传播及并发发布保护：当分片 logits、K 值、温度、核采样阈值、种子或预算配置任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其下游产物失效并重建，未受影响上游产物复用；多工作进程发布时用文件锁比较分片内序号，落后或重复发布返回 E_STALE_CHECKPOINT，跨阶段错位返回 E_INVALID_STAGE。
8. 提供参数注入验证通道与确定性演示脚本：支持注入非法 K、NaN/Inf logits、全负无穷行、全并列最大分数与预算越界等情形，各注入在对应阶段返回稳定业务码（E_INVALID_K、E_NUMERIC、E_BUDGET_EXCEEDED、E_MEMORY_BUDGET）；演示数据至少 4 个分片，一次完整运行生成固定摘要，并演示停止后恢复与一次完整运行结果逐字节一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地分片验证 TopK 与采样结果、预算约束和停止恢复后产物与完整运行逐字节一致，并核对注入异常的业务码。
