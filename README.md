一条新的语音转换服务线在首个技术验证节点上立项，工作区尚未初始化，需要交付可被上层语音助手集成的流式推理组件与结果验证工具。输入由程序内置固定种子生成器在本地确定性产出：16 kHz、单声道、16 位 PCM WAV 分片，每片模拟源说话人短语音段，另附 JSON 转换清单逐片声明源与目标说话人编号、基频偏移系数、频谱包络弯折系数、帧移、转换块长与期望输出样本数上界，并给出参考基频均值区间作为真值来源。组件按帧分析与声学参数提取、并行转换组派发、波形重建、结果验证四阶段推进，运行中运维通过本地 HTTP 接口提交带单调版本号的转换策略快照与只含局部改动的增量片段。难点在于并行转换组的并发上限、单组帧配额与每轮时间预算共同约束派发，而预算回收、并行归约与断点恢复又必须让并行结果与串行顺序执行逐字节一致。

任务环境与准备：
安装 Go 1.22 或以上版本，并确认 go version 可用。
安装 SQLite 命令行工具，并用 go get 引入纯 Go 的 SQLite 驱动，确保无需 CGO 即可编译运行。
确认工作目录为空并初始化 Go module，测试与示例运行均在本地完成，不访问网络服务。
准备内置固定种子生成器与样例 WAV 分片、转换清单的生成命令，首次运行即可在本地产出确定性样本。

业务要求：
1. 实现帧分析与声学参数提取阶段：按清单声明的帧移对 16 位 PCM 做汉宁窗分帧，帧移以毫秒声明但须显式换算为整数采样点并记录换算值，逐帧以自相关法估计基频并计算梅尔频带对数能量，输出带帧索引与参数摘要的帧级参数表；同一输入与配置必须产生逐字节一致的参数表，采样率与清单冲突或帧移为零时返回带分片标识的业务错误码。
2. 实现声学参数映射与波形重建核心：按目标说话人编号与基频偏移系数调整逐帧基频，按频谱包络弯折系数在梅尔域重排频带能量后经三角滤波器组与逆变换合成波形，量化为 16 位 PCM 并记录幅值钳制次数；输出样本总数须与清单期望上界一致，基频偏移系数为零或包络系数越界时返回带分片标识与帧索引的 E_PARAM_INVALID。
3. 实现基于转换块长的并行转换组派发：以帧块为调度单元，在全局并发转换组上限、单组帧配额与每轮时间预算三重约束下决定接纳顺序与并发度，接纳前依据清单声明样本总数与帧参数预估帧消耗，超预算帧块记录为未处理并给出预算余量，不得静默丢弃。
4. 实现预算回收与并行归约的确定性：某组提前完成后其剩余帧配额可按确定性规则移交给等待组并记录移交明细，被回收与未被回收两种情形的最终重建波形、逐帧基频序列与汇总摘要必须与串行顺序执行逐字节一致，不得因并发调度改变结果或归约次序。
5. 实现流式逐块转换与整段转换的一致性校验：支持按帧块逐块送入并逐块输出 PCM，流式拼接后的样本总数、逐帧基频序列与梅尔能量摘要必须与整段一次性转换逐字节一致；出现不一致时返回带分片标识、首个差异帧索引与两路取值的 E_STREAM_MISMATCH。
6. 实现 SQLite 事务化阶段检查点与优雅停止及强制终止后的恢复：每分片每阶段完成时以事务写入含阶段名、输入内容指纹、策略版本、产物摘要与单调序号的记录，同一分片同一阶段只允许一条有效记录；收到停止请求时完成当前不可拆分帧块后落库退出，被强制终止后重启仅凭已提交事实重建进度，不承诺生成退出报告，恢复后的最终波形与逐帧摘要须与连续运行逐字节一致。
7. 实现策略快照增量片段应用与失效传播：增量片段须校验基础版本与当前生效版本一致，不一致返回 E_STALE_BASE 并附当前版本；当帧移、块长、基频偏移、包络弯折或并发预算变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段与最早帧块，仅重建该区间并复用其余帧块；检测到快照被整体替换时区分正常推进、整体替换与回退，整体替换令全部帧块与波形失效重建。
8. 实现并发发布保护与基频真值对齐诊断：多工作进程对同一数据库发布帧块产物时使用 SQLite 条件更新与真实文件锁并比较帧块序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT；同时以清单参考基频均值区间为唯一真值统计落入区间帧比例与越界帧索引，偏差超容差返回 E_TOLERANCE_EXCEEDED 并附最大偏差。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证并行与串行逐字节一致、预算裁决、增量重建、中断恢复与业务错误码。
