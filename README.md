当前是空白 Windows 工作区，需要从零构建一个面向本地 Kubernetes 调度语义的调度预算与亲和性裁决仿真引擎，供平台管理员离线评估一批待调度 Pod 在若干节点上的放置结果，并诊断判定过程中的资源预算消耗与亲和性约束传播。节点与 Pod 规格由本地确定性 JSON 样本提供：节点声明可分配 CPU（毫核整数）与内存（字节整数）、标签、污点、所属故障域与健康状态；Pod 声明资源请求与限额、节点选择器、硬性与软性节点亲和性、Pod 间亲和与反亲和、污点容忍与优先级。引擎需在全局调度并发预算、每轮时间预算与单节点放置上限的多重约束下推进调度轮次，维护节点资源余量、Pod 放置状态与亲和性约束满足情况，并支持在批次中途被强制终止后依据 SQLite 持久化事实恢复。所有数据来自本地样本，通过本地 HTTP API 交互。

任务环境与准备：
在 Windows 工作区安装 Python 3.11 及以上版本，创建虚拟环境并安装 FastAPI、uvicorn、pytest 与标准库 sqlite3 配套依赖。
准备本地确定性 JSON 样本目录，包含节点清单、待调度 Pod 清单与两份规格边界样本，样本内所有量纲为 500m、2、512Mi、1Gi 等字符串。
确认本地回环端口可用以启动 HTTP 服务，样本与 SQLite 数据库文件均放在工作区内，不访问外部网络或集群。
准备一份调度预算参数样例，覆盖并发上限、每轮时间预算与单节点单轮放置上限，用于重复演示。

业务要求：
1. 实现节点与 Pod 规格的解析与归一化：CPU 以毫核整数、内存以字节整数为内部表示，解析样本中形如 500m、2、512Mi、1Gi 的量纲字符串并做溢出与负数检查；解析失败、单位非法或 Pod 引用未声明的节点标签键时返回业务码 E_SPEC_INVALID 且整批不进入调度，失败项须列出具体字段路径。
2. 实现硬性约束过滤：requiredDuringScheduling 节点亲和性支持 In、NotIn、Exists、DoesNotExist、Gt、Lt 操作符与匹配表达式组合，节点选择器与污点容忍（NoSchedule、NoExecute 效果）共同参与过滤；每个被否决的 Pod 须记录被哪一节点否决、触发的约束类型与约束原文，禁止对不合格节点静默跳过。
3. 实现资源余量累计计算：按已放置 Pod 的请求逐个从节点可分配资源扣减，使用整数精确累计并在每步校验余量非负；当某 Pod 请求超过剩余量时记录兜底原因与剩余量快照，同一节点多次放置必须逐次更新余量，不得先汇总后统一扣减导致中间态不可见。
4. 实现软性亲和性加权打分与定点数值契约：preferredDuringScheduling 权重为整数，与 Pod 间亲和与反亲和、资源平衡度、污点降权共同合成总分；各区段分值使用定点整数或显式舍入方式，比较候选节点使用带容差的定点比较并按节点名稳定排序打破平局，同一输入重复打分必须逐位一致。
5. 实现 Pod 间亲和与反亲和判定：基于已放置 Pod 的标签与拓扑键（如 kubernetes.io/hostname、topology.kubernetes.io/zone）判定硬性反亲和是否被违反、硬性亲和是否可满足；拓扑键必须在节点标签中已声明，未声明时返回 E_TOPOLOGY_KEY_MISSING 而非按默认值猜测。
6. 实现多重预算并行调度：调度轮次受全局并发调度上限、每轮时间预算与单节点单轮放置上限共同约束，预算内按 Pod 优先级与到达顺序取任务，超出并发上限者进入有界等待队列，队列满返回 E_SCHED_QUEUE_FULL；预算耗尽时按确定性规则输出被跳过 Pod 清单及跳过原因，必须牺牲部分覆盖而非违反并发上限。
7. 使用 SQLite 持久化调度批次、意图记录与放置结论，所有写操作先落意图记录再提交事务：进程在批次中途被强制终止后重启须扫描未完成意图，把批次恢复为未完成状态并按已持久化事实重新计算或标记为已中止；恢复报告只包含已落盘事实，若未生成退出报告不得声称其存在。
8. 实现统一业务错误码 JSON 错误体与本地 HTTP API：接口覆盖样本批次提交、调度轮次触发、按批次查询放置结论与各 Pod 否决明细、按节点查询资源余量与约束明细、恢复报告查询，失败响应为含业务码与上下文的 JSON，至少覆盖 E_SPEC_INVALID、E_TOPOLOGY_KEY_MISSING、E_SCHED_QUEUE_FULL、E_INVALID_TRANSITION、E_BATCH_NOT_FOUND。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证调度放置、亲和性否决明细与强制终止后的恢复一致性。
