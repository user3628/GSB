在 Windows 空白工作区中，需要从零构建一个面向本地回环环境的 TLS 握手与证书链诊断工作台，供网络运维与安全工程师离线评估证书链验证过程中的数值精度与误差传播问题。工作台以本地确定性样本提供多组证书链（根、中间、叶证书的 DER 编码、有效期、签名算法、公钥参数）与客户端握手参数（支持的协议版本、密码套件、SNI、会话票据长度、系统时钟偏移毫秒），并模拟从 ClientHello 到 Finished 的握手阶段推进，在每个阶段计算证书链验证结果、路径构建、有效期余量、签名强度评分与握手预算消耗。核心难点在于数值精度与误差传播：证书有效期以毫秒级时间戳比较，时钟偏移、亚秒级截断与验证时刻的取整规则会改变证书是否在有效期内；公钥强度评分由模长位数、曲线参数与签名算法加权合成，经过多级乘除与累计求和后浮点误差会翻转强弱判定；握手预算由分阶段耗时估计累加，浮点运算顺序与舍入方式导致同一链在不同计算路径下诊断结论不一致。所有证书与握手样本均为本地确定性生成，不依赖外部 CA、真实站点或网络访问。

任务环境与准备：
在 Windows 空白工作区安装 Python 3.11 或以上版本，使用 pip 安装 Flask 与 cryptography 的指定版本，所有依赖来自本地 wheel 或已配置的包源。
使用 cryptography 在本地生成确定性根证书、中间证书与叶证书及对应私钥，导出 DER 文件与结构化 JSON 元数据，固定序列号、有效期与签名算法，不访问外部 CA。
准备握手参数 JSON 样本，包含协议版本、密码套件、SNI、会话票据长度、系统时钟偏移毫秒与阶段预算上限，所有数值在本地固定。
初始化 SQLite 数据库文件与意图日志表结构，确保进程重启后可从同一文件恢复状态。
编写本地演示脚本入口，使脚本能在无网络条件下重复运行并输出结构化诊断结果。

业务要求：
1. 实现证书链样本加载与 DER 解析，提取每张证书的序列号、颁发者与主体、有效期起止毫秒时间戳、签名算法、公钥算法与公钥参数（RSA 模长位数或 EC 曲线标识），解析失败或证书链缺少根证书时返回业务码 E_CHAIN_INVALID 并保持已加载样本不变。
2. 实现证书链路径构建与有效期余量计算，按颁发者与主体关系从叶证书向上构建到根证书，禁止出现环；有效期余量以毫秒整数计算并输出剩余或超期毫秒数，比较验证时刻时须显式声明系统时钟偏移的注入方式与亚秒截断规则，余量为零的边界情形须给出确定判定。
3. 实现签名强度评分与定点数值契约，评分由 RSA 模长位数或 EC 曲线安全等级、签名算法权重与有效期余量因子加权合成，各分项使用定点表示并输出每步舍入方式与累计舍入误差；同一证书链重复评分必须逐位一致，比较两条链强弱时使用带相对容差的定点比较并按稳定字典序打破平局。
4. 实现累计预算的数值稳定性，握手各阶段耗时估计与证书链验证开销累计时使用 Kahan 或等价补偿求和，并与朴素求和在混合大数小数的固定样本上对比给出可量化误差上界；同一链同一参数多次计算的总预算与分项占比必须逐位一致，结论不得因运算顺序变化而翻转。
5. 实现握手阶段状态机，至少包含 CLIENT_HELLO、SERVER_HELLO、CERTIFICATE、CERT_VERIFY、FINISHED 五个阶段并规定合法迁移路径，非法迁移返回 E_INVALID_TRANSITION 且不修改已持久化状态；某阶段校验失败时须记录该阶段的具体失败原因与业务码，并允许按配置选择终止或继续以完成诊断。
6. 实现握手预算超限裁决与降级策略，依据总预算上限与各阶段分项预算判定握手是否在预算内完成，超限时输出触发超限的阶段与实测值并返回 E_BUDGET_EXCEEDED；降级路径只允许跳过非关键诊断项，不得跳过证书链签名验证与有效期校验，降级明细须可逐项核对。
7. 使用 SQLite 持久化握手会话、阶段状态、诊断结论与意图日志，写操作先落意图记录再提交事务；进程在握手推进中途被强制终止后重启须扫描未完成意图，把会话标记为已中止或回滚到最后一个完整阶段边界，恢复报告只基于已持久化事实，不得承诺强制终止后仍生成完整退出报告。
8. 实现单写者握手推进与多读者诊断查询的并发一致，握手推进按会话单写者串行执行，多个诊断查询可并发读取已提交阶段快照；同一会话标识重复推进只执行一次、其余等待并复用结果，内容不一致返回 E_CONFLICTING_SESSION；查询只能看到某一完整提交版本，并提供本地 HTTP API 与可重复演示脚本完成正常握手、预算超限、强制终止恢复及数值误差说明查询。
