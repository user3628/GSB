某客服机器人平台的多轮对话理解子项目进入首次实现阶段，工作区为空，需要在 Windows 本地从零交付一个多轮对话意图槽位迁移与跨版本语义角色对齐工作台。业务输入全部由程序内置固定种子生成器在本地确定性产出：若干 JSONL 会话分片，每条含 session_id、turn_index、用户话语、机器人回复、语言标签与可选槽位标注；槽位标注存在两代语义角色体系，新版以“角色名+取值范围”描述，旧版以“整数角色码+自由文本取值”描述，两代之间只有一份有版本号的角色映射表，且同一角色在映射表中可能对应多个旧角色码。工作台需要把每轮对话的意图识别结果与槽位填充结果统一到新版角色体系，逐轮生成意图槽位状态轨迹，并对映射歧义、取值越界与版本升级导致的角色漂移给出可追溯的裁决。系统不依赖任何真实模型、GPU、外部服务或线上站点。

任务环境与准备：
安装 Go 1.22 或以上版本并在 Windows 上执行 go version 确认可用。
使用标准库 database/sql 与纯 Go 的 SQLite 驱动（如 modernc.org/sqlite），通过 go get 拉取并写入 go.mod。
准备本地工作目录，不依赖任何外部服务、真实数据集、GPU 或附件；会话分片、种子槽位标注与角色映射表由程序内置固定种子生成器在首次运行时产出。
确认可在 Windows 上执行 go build 与 go test；运行演示前先执行一次生成器命令产出确定性样本。

业务要求：
1. 实现统一意图槽位状态模型与两代语义角色体系的双向编解码：内部模型按会话与轮次维护意图标签、已确认槽位（新版角色名到规范化取值）、待澄清槽位与取值来源；实现内部模型与新版“角色名+取值范围”结构、旧版“整数角色码+自由文本取值”结构的双向编解码，编解码须保留轮次归属与取值边界，同一会话经内部模型往返后意图与槽位集合不得增减。
2. 实现旧版角色码兼容解析与显式升级：依据带版本号的角色映射表把整数角色码换算为新版角色名，并按旧版取值范围声明把自由文本取值归一化为新版取值类型（整数、枚举、日期区间）；一个旧角色码对应多个新角色名时须按映射表优先级与取值范围相容性裁决唯一角色，无法裁决的须保留全部候选并标注为歧义；映射表版本与旧版声明不符、角色码不在映射表内或取值无法归一化时须返回带 session_id、轮次与字段名的业务错误码，不得静默采用首个映射。
3. 实现逐轮意图与槽位状态演进核心：按 turn_index 顺序解析话语与回复，按可配置规则触发意图转移并更新已确认槽位与待澄清槽位，记录每轮状态变更集、触发规则与所用角色映射版本；意图转移出现环、槽位被不同取值重复确认或待澄清槽位未被任何轮次回应时，须保留诊断依据而非覆盖历史状态；同一输入与配置必须产生逐字节一致的状态轨迹。
4. 实现角色漂移与取值越界的对齐校验：对每轮槽位与新版角色取值范围比对，输出越界槽位、被映射表升级改变角色的槽位与歧义未决槽位三类清单，并以字符偏移指出其在原始话语中的出处；当映射表整体替换导致已确认槽位角色漂移时须给出漂移前后角色与判定依据；三类清单须可按会话、轮次与角色名确定性复算。
5. 实现阶段检查点与优雅停止恢复：工作台按解析、映射升级、状态演进、对齐校验四阶段推进，每轮完成后以原子方式写入含阶段名、session_id、轮次号、输入内容摘要、角色映射版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分的轮次单元后退出，不承诺强制终止后生成退出报告，强制终止后的恢复仅依赖已提交的持久化记录；恢复后最终状态轨迹与对齐校验清单须与一次从零完整运行逐字节一致。
6. 实现版本变化检测与增量失效传播：当某轮话语或槽位标注、角色映射表、意图转移规则、取值归一化精度或校验阈值任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早轮次与阶段，使该轮及其全部下游状态与校验清单失效并重建，未受影响轮次继续复用；失效原因须可按会话与轮次定位并保留重建前后的指纹对照。
7. 实现并发发布保护与稳定业务错误码：多个工作进程对同一工作区发布轮次状态时使用 SQLite 事务条件更新与真实文件锁，比较会话内轮次序号，仅允许序号连续推进，落后、重复或跨会话错位发布须返回 E_STALE_CHECKPOINT 并保留原有有效记录；检测到记录被整体替换（序号回退、指纹变化或摘要不匹配）时须区分回退、篡改与正常推进，仅正常推进被接受；请求非法阶段跳转、缺失前置阶段产物或映射表版本冲突时须返回带会话标识与阶段名的业务错误码。
8. 提供本地 HTTP 与命令行交互接口及确定性演示：支持导入会话分片与种子槽位标注、触发分阶段执行、编辑角色映射表、查询各会话逐轮状态与版本指纹、查看角色漂移与歧义裁决明细、请求停止、执行恢复、导出统一意图槽位状态；演示数据至少 4 个会话，覆盖中英混排、旧版整数角色码歧义映射、映射表升级导致角色漂移与待澄清槽位未回应的情形，一次完整运行须产生确定的状态轨迹与对齐校验摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
