当前是空白工作区，没有现存项目、代码或数据附件。需从零构建一个本地可运行的生成图像质量评估组件与可复现实验环境，面向多模态 AIGC 生成结果的自动质量评估与异常输入验证。系统不依赖任何真实生成模型、GPU、外部服务或下载数据集。输入为固定随机种子生成器产出的本地小尺寸 RGB PNG 图像分片（由几何色块、渐变、纹理与噪声组合而成），每张图像配一条元数据声明：image_id、提示词（中英混排）、声明宽高、参考图像文件名（可为空）、期望质量区间与来源算子标签。评估流程分四个阶段推进：图像解码与标准化、分维度质量指标计算（清晰度、色彩一致性、结构保真、文本-图像提示词一致性）、加权融合与质量分级裁决。评估结果需可复算、可增量重建，并支持参数注入以验证异常链路。

任务环境与准备：
安装 Python 3.10 及以上，确认可导入 NumPy、Pillow 与 pytest（版本以本机已装为准，安装说明置于项目 README）。
准备本地工作目录用于存放生成的 PNG 分片、元数据 JSON、检查点记录与摘要输出，无需任何网络下载或外部服务。
由固定随机种子生成器产出至少 4 张 RGB PNG 样本及对应元数据与一张参考图，生成脚本随项目提供以便重建。
确认本地可监听回环地址的 HTTP 端口用于诊断接口，若端口被占用可在配置中改写。

业务要求：
1. 实现图像解码与标准化阶段：读取 PNG 并校验实际宽高与元数据声明一致，不一致须返回带 image_id、声明值与实际值的 E_DIM_MISMATCH 并保留在诊断输出；将像素转换为浮点并做固定规则归一化，输出每张图像的尺寸、通道数、像素均值与方差摘要；同一输入与配置必须产生逐字节一致的标准化摘要，空图像或全黑图像须显式标记而非静默通过。
2. 实现分维度质量指标：清晰度以拉普拉斯响应的归一化方差度量，色彩一致性在无参考图像时以像素色偏与饱和度分布度量、有参考图像时以参考图的色彩直方图距离度量，结构保真仅在存在参考图时以局部梯度方向一致性度量；每个指标须输出分数、有效像素数与被跳过原因，缺失参考图时结构保真须记为不可用并说明依据而非填零。
3. 实现文本-图像提示词一致性指标：对提示词做 Unicode NFKC、空白折叠与全半角统一后，按中文单字与拉丁连续串切分，以固定哈希函数将词项映射到颜色与纹理基元词汇表并从图像中提取对应统计量，合成 0 到 1 的一致性分数；词表缺失词项时须回退到显式未知基元并记录回退数量，同一输入与配置须逐字节一致。
4. 实现加权融合与质量分级裁决：各维度分数按可配置权重在对数域或归一化域合成为最终质量分，按可配置阈值分为优、良、差三级，并输出各维度对数贡献、权重和被跳过维度的重新归一化过程；全部可用维度分数为零或权重和为零时须返回 E_NUMERIC 并附 image_id 与维度名，同一维度分数并列时须有确定性裁决。
5. 实现质量分与元数据期望区间的比对与异常注入：将最终质量分与元数据声明的期望质量区间比对并输出越界样本清单与偏差量；提供参数注入入口，支持注入声明尺寸不符、标签外不存在参考图文件、像素含 NaN 与权重为负四类异常，各异常须在对应阶段返回稳定业务码（E_DIM_MISMATCH、E_MISSING_REFERENCE、E_NUMERIC、E_INVALID_CONFIG）并保留诊断上下文。
6. 实现阶段检查点持久化与优雅停止恢复：每张图像每阶段完成时以原子方式写入含阶段名、image_id、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分样本单元后退出，不承诺强制终止后生成退出报告；恢复后最终质量分、分级与诊断摘要须与一次从零完整运行逐字节一致，且序号连续推进。
7. 实现版本指纹与增量失效传播及并发发布保护：当图像内容、参考图、权重、阈值、提示词或哈希词表任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游继续复用；多个工作进程发布阶段产物时使用真实文件锁并比较样本内序号，落后、重复或跨样本错位发布返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_INVALID_STAGE。
8. 提供本地确定性演示与可复现实验环境：生成至少 4 张图像分片与元数据，覆盖中英混排提示词、含参考图与不含参考图、至少一张期望区间故意越界样本及至少一张尺寸声明不符样本；提供命令行与本地 HTTP 接口支持导入分片、触发分阶段评估、查询各阶段状态与版本指纹、查看逐维分数与失效原因、请求停止与恢复；一次完整运行生成固定摘要，在阶段间触发停止后恢复并执行一次异常注入，输出摘要与诊断报告。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本完整跑通四阶段评估并复现固定摘要，停止恢复与全量结果逐字节一致，异常注入均返回约定业务码。
