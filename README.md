当前为空白工作区，需从零构建一个本地可运行的长上下文位置编码外推偏置诊断工作台，交付领域数据编辑与操作应用。长上下文 LLM 中 RoPE、NTK 缩放 RoPE、线性插值 RoPE 与 ALiBi 斜率偏置在训练长度之外外推时，位置相关偏置随相对距离呈现不同衰减形态，外推异常常表现为远距离偏置异常抬高或单调性破坏。工作台不改动注意力权重，而是围绕本地确定性分片计算各方案的位置相关偏置矩阵、外推分档统计与单调性诊断，供研究人员编辑编码配置并复现比对。输入为固定随机种子生成器产出的本地张量分片（Q/K 形状 [批量, 头数, 序列长度, 头维度]）与参考诊断指标文件，配置为一份 YAML，描述各方案基础频率、缩放系数、外推倍率档位、目标诊断指标与容差。系统不依赖真实模型、GPU 或外部服务，观测、同步标记与真值全部来自本地分片与参考指标文件。

任务环境与准备：
安装 Python 3.11 及 NumPy、PyYAML 的固定版本，在本地虚拟环境中执行，不依赖任何线上服务或账号。
在空工作区创建项目目录结构，所有 Q/K 张量与参考诊断指标由固定随机种子生成器在本地生成并写盘。
预置一份版本 2 YAML 配置样例与一份结构版本 1 旧清单样例，供兼容解析与回导验证使用。
启动本地 HTTP 服务前确认回环端口可用，命令行与接口调用全部以本地回环地址进行。

业务要求：
1. 实现位置编码偏置矩阵计算核心：按配置的基础频率与头维度计算 RoPE、NTK 缩放 RoPE、线性插值 RoPE 四种方案的位置相关偏置，并计算 ALiBi 方案的斜率偏置矩阵，输出每种方案的偏置矩阵摘要（逐档均值、方差与峰值）与维度元数据；同一输入与配置必须产生逐字节一致的偏置结果，非整除头维度须按配置的补齐规则处理并登记。
2. 实现外推分档与敏感度统计：按配置的外推倍率档位把偏置矩阵切分到各档区间，逐档统计偏置均值、相邻位置间距的差分绝对值均值与单调性违反次数，并标记出现单调性破坏的档位与方案；档位为空时须保留空档记录而非跳过，档位边界须与配置声明逐字段一致，分档结果在重复运行时逐字节一致。
3. 实现定点量化数值域上的偏置计算与误差传播控制：偏置相关量以定点量化保存并记录每方案缩放因子，基频与缩放系数的乘积与比值计算全程在缩放后的定点域或对数域进行；当出现零基频、负缩放系数、量化缩放因子为零或结果出现 NaN/Inf 时，须在对应阶段返回带方案名与档位标识的 E_NUMERIC，并保留诊断上下文。
4. 实现诊断指标汇总与容差比对：按方案汇总各档敏感度统计、偏置峰值、外推倍率相关变化率，并与本地参考诊断指标文件按可配置容差比对；超差方案须标记为未通过并给出越界指标名、参考值与估计值，指标计算须依赖显式分片样本与参考值，不得从缺失信息推断。
5. 实现结构版本 1 旧清单兼容解析：旧清单中缩放系数为整数百分比、缺少 ALiBi 斜率字段且外推倍率为整数；导入时须按可配置规则做百分比换算、补齐缺省斜率与外推倍率字段并生成稳定方案标识，换算规则须可回导，导出重新导入后得到的偏置摘要与分档统计与直接转换结果逐字节一致。
6. 实现阶段检查点与优雅停止恢复：按配置解析、偏置计算、分档统计、容差比对四阶段推进，每阶段完成时以原子方式写入含阶段名、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分档位单元后退出，恢复后最终诊断报告与从零完整运行逐字节一致且序号连续。
7. 实现版本变化检测、依赖失效与并发发布保护：当分片张量内容、基础频率、缩放系数、外推倍率档位或诊断容差变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游诊断产物失效并重建，未受影响上游结果继续复用；多进程发布阶段产物时使用文件锁并比较序号，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT，缺失前置阶段产物返回 E_INVALID_STAGE。
8. 实现异常注入与交互接口：提供参数注入入口与命令行、本地 HTTP 接口，支持注入越界序列长度、非法缩放系数、档位数为零与含 NaN 的分片等情况，各注入须在对应阶段返回稳定业务码（E_SEQ_TOO_LONG、E_INVALID_PARAM、E_INVALID_CONFIG、E_NUMERIC）；接口支持编辑编码配置、查看各方案分档诊断与失效原因、请求停止与执行恢复，演示数据至少 3 个分片、覆盖四种方案与三档外推倍率。
