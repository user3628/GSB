当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的车内多音区语音活动仲裁与指令归属引擎，交付领域数据编辑与操作应用。输入为固定随机种子生成器产出的本地 WAV 分片（16 kHz、单声道、16 位 PCM），每个分片模拟一段车内录音，包含主驾、副驾、后排左右共 4 个音区的麦克风信号依次拼接存储，另附一份 JSON 会话清单声明每个分片的音区排布（每音区的样本起止偏移与声道标签）、各音区参考语音活动区间（以毫秒计）、参考指令词表命中结果与音区优先级，作为真值与观测来源；系统须在导入时以样本总数、音区偏移之和与标注时长上界校验清单一致性。系统不依赖任何真实 VAD、波束成形、声学模型、预训练权重、GPU 或外部服务：音区活动检测采用确定性短时能量与频谱平坦度双特征滞回判定，指令归属采用跨音区到达时延差与参考词表命中强度的确定性打分仲裁。用户会在界面中反复查询某毫秒时刻的活跃音区集合、时延差明细与指令归属判定，并编辑音区优先级与命中词表，然后要求增量重算；每次查询必须有明确延迟预算，且无论查询顺序、缓存命中与否、是否先做编辑，最终判定结果都须逐字节一致。

任务环境与准备：
安装 Python 3.11 及 NumPy、FastAPI、uvicorn、pytest，均为纯本地依赖，不访问网络资源
确认工作目录为空白文件夹，无遗留数据；采样率 16 kHz、单声道、16 位 PCM 的多音区拼接 WAV 由本地固定种子生成器创建
准备 JSON 会话清单模板与至少 3 个分片的音区参考活动区间与词表命中结果，确保样本总数与音区偏移可用于导入校验
本地 HTTP 服务绑定回环地址与独立端口，文件锁目录位于工作区内可写路径

业务要求：
1. 实现分帧与音区活动检测核心：对每个分片按清单音区偏移切出各路信号，按可配置帧长与帧移做汉宁窗分帧，逐帧计算对数能量与频谱平坦度并合成得分，以高阈值进入、低阈值退出的滞回状态机判定各音区活跃帧，叠加最短语音段与最短静音段后处理；帧边界越界须显式补零并记录补零帧数，同一输入与配置产生逐字节一致的逐帧活跃标记。
2. 实现跨音区到达时延与指令归属仲裁：以各音区活跃区间的起止毫秒计算两两到达时延差，按可配置声速与音区几何先验转换为距离差得分，再与参考词表命中强度合成归属分，为每条疑似指令判定唯一责任音区；当最高两名归属分差距低于可配置间距时标记为待复核而非强行归属，并记录参与仲裁的音区与分量得分。
3. 实现统一毫秒时间轴与音区编辑模型：以毫秒整数维护各音区的活动区间、重叠活动标记、语音来源音区与指令归属记录，支持切分、合并相邻同类区间、调整音区优先级、编辑命中词表条目；每次编辑生成单调编辑版本号并记录操作类型、影响区间与前后值，非法区间须返回带分片标识、音区与区间位置的业务错误。
4. 实现交互查询的延迟预算与缓存一致性：单次查询（时刻活跃音区集合、时延差明细或指令归属依据）须在可配置延迟预算内返回，超出预算时返回带查询标识与已耗时字段的 E_LATENCY_BUDGET 结构化错误而非阻塞等待；缓存键须包含分片内容指纹、编辑版本号与阶段配置指纹，命中与未命中的结果须逐字段一致。
5. 实现增量重算与全量一致性校验：当音区优先级、命中词表、帧参数、滞回阈值或归属间隔阈值修改时，依据各阶段内容摘要构成的版本指纹识别受影响的最早阶段，仅重算该阶段及其下游，未受影响上游结果继续复用；增量结果须与从零全量构建的活跃区间、时延差明细与归属判定逐字节一致，不一致须返回 E_INCREMENTAL_MISMATCH 并附首个差异位置。
6. 实现版本化快照、优雅停止与整体替换识别：每阶段完成后以原子方式写入含阶段名、分片内容指纹、配置版本与编辑版本号、产物摘要与单调序号的快照记录，任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分单元后退出，恢复后结果须与完整运行一致；检测到快照整体替换（序号回退、指纹变化或摘要不匹配）须区分回退与篡改并仅接受正常推进。
7. 实现并发编辑发布保护与业务错误码一致性：多个工作进程对同一工作区发布编辑版本时使用真实文件锁并比较版本号，仅允许版本号连续推进，落后、重复或跨分片错位发布返回 E_STALE_VERSION；请求缺失前置阶段产物或非法阶段跳转时返回 E_INVALID_STAGE，冲突期间已完成但未提交的编辑须可显式丢弃或重试。
8. 提供编辑工作台应用与本地确定性演示：命令行与本地 HTTP 接口支持导入分片与清单、执行音区检测与归属仲裁、编辑音区优先级与命中词表、查询各阶段状态与版本指纹、请求停止、执行恢复、导出活动区间与归属结果；演示数据至少 3 个分片，覆盖 4 音区、静音段、双音区重叠活动与一次优先级编辑，完整运行生成固定摘要，并演示一次延迟预算超限与一次编辑后增量重算。
