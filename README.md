当前是空白工作区，需从零构建一个本地可运行的多尺度特征金字塔算子链组件，交付可集成的领域组件与完整示例，供上层检测头以库形式集成。输入为固定随机种子生成的本地 .npy 特征分片集：三个不同分辨率层级的特征图（形状 NCHW，含小尺寸与中尺寸、奇数通道数、含极端激活值的样本）以及一份 JSON 融合清单，逐融合任务声明层间上采样倍率、横向连接卷积核尺寸与步长、通道注意力权重向量、层间融合的加权求和系数与输出通道数，并声明每层期望输出形状与允许数值区间；另附一份高精度参考融合输出分片作为比对真值来源。系统不依赖 GPU、深度学习框架或外部数据集。核心业务问题是：在多层特征自上而下融合与通道注意力加权串联时，如何诊断各层权重扰动对端到端输出的敏感性并保证同一权重下结果可复现。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy（建议 1.24 及以上）与 pytest 用于本地确定性测试。
使用固定随机种子生成融合清单所需的多层级 .npy 特征分片，覆盖小尺寸与中尺寸、奇数通道与含极端激活值样本，并生成对应高精度参考融合输出。
准备一份 JSON 融合清单，为每个任务声明上采样倍率、横向连接卷积参数、注意力权重向量、融合系数、量化位宽、期望输出形状与允许数值区间。
准备本地测试脚本，用于触发分阶段融合、权重扰动注入、整体替换识别、停止与恢复，并比对输出摘要。

业务要求：
1. 实现横向连接卷积与上采样重排内核：对每个层级按清单声明的卷积核尺寸、步长与输出通道做 NCHW 布局卷积，再按上采样倍率以双线性或最近邻完成重排并与下层特征对齐；奇数通道与奇数尺寸下须显式处理尾元素，输出形状与清单声明不一致时返回 E_SHAPE_MISMATCH 并附层名与期望实际形状。
2. 实现通道注意力加权与层间融合：对每层按清单声明的注意力权重向量做逐通道加权，权重和不为 1 时须按可配置规则归一化并记录原始和，再按融合系数做加权求和得到该尺度输出；当注意力向量长度与通道数不符、权重出现 NaN/Inf 或融合系数全为零时返回带层名与索引的 E_INVALID_PARAM 并保留诊断。
3. 实现权重扰动敏感性诊断：对每层注意力权重与融合系数按可配置扰动幅度做单层扰动重放，记录该层扰动引起的端到端输出相对偏差，并结合一阶敏感度估计给出逐层敏感性排序；两种方式排序不一致的层须标记为待复核，各层扰动偏差之和与全层同时扰动的端到端偏差之差不超过可配置容差。
4. 实现逐层输出的定点量化与误差界估计：每层输出与最终融合输出按清单位宽做对称定点量化并记录缩放因子，量化误差界须由显式缩放因子与本地高精度参考结果按层逐项给出，并输出每层有效位数；缩放因子为零或量化后全部饱和时须在对应层返回 E_NUMERIC 并附层名与饱和元素计数。
5. 实现阶段检查点与快照整体替换识别：每个融合任务每层处理完成时以原子方式写入含任务标识、层名、输入分片内容指纹、注意力权重指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；检测到记录被整体替换（序号回退、指纹变化或摘要不匹配）时须区分回退、篡改与正常推进并返回 E_STALE_CHECKPOINT。
6. 实现优雅停止与恢复一致性：进程收到停止请求时完成当前不可拆分的层级融合单元后退出，不承诺强制终止后生成退出报告；恢复后最终各尺度输出张量、逐层误差报告与敏感性排序必须与一次从零完整运行逐字节一致，且检查点序号连续推进、无跳跃与重复，强制终止后的恢复仅依赖已写入的记录。
7. 实现版本指纹与增量失效传播：当特征分片内容、注意力权重向量、融合系数、扰动幅度或量化位宽任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早层级与阶段，使该层及其全部下游产物（含敏感性排序）失效并重建；未受影响层级结果继续复用，失效原因与指纹可查询，增量结果须与从零全量运行逐字节一致并给出 E_INCREMENTAL_MISMATCH 差异定位。
8. 实现并发发布保护与本地演示接口：多工作进程对同一工作区发布层级产物时使用真实文件锁并比较任务内序号，仅允许序号连续推进，落后、重复或跨任务错位发布返回 E_STALE_CHECKPOINT，缺失前置层级产物时返回 E_INVALID_STAGE；命令行与本地 HTTP 接口支持导入分片与清单、触发分阶段融合、查询状态与敏感性排序、请求停止与执行恢复。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
