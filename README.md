当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的音频指纹检索特征压缩与量化误差审计组件，供上游音乐检索服务以库形式集成。输入为固定随机种子生成器产出的本地 WAV 分片（16 kHz、单声道、16 位 PCM），每片为短音乐片段，含稳定音调段、噪声段与节奏变化段；另附一份 JSON 指纹配置清单，逐分片声明分片标识、谱峰检测的局部邻域大小、指纹对时间差与频率差范围、量化位宽、每帧最大谱峰数与期望检索误配率上限，并附固定种子生成的参考指纹对清单作为检索真值来源。组件需把音频转换为谱峰、指纹对与压缩后的指纹向量，并沿谱峰检测、指纹对生成、量化压缩链路审计数值误差。

任务环境与准备：
Windows 本地环境，安装 Python 3.10 及以上版本，创建独立虚拟环境。
安装 NumPy，使用 pip 安装 wheel 包，不引入 GPU、音频解码库或外部服务依赖，WAV 读取自行按 16 位 PCM 解析。
准备本地确定性 WAV 与配置生成脚本，固定随机种子并落盘到工作区 samples 目录，覆盖稳定音调段、噪声段与静音分片。
创建用于检查点、文件锁与版本指纹的工作区目录，确认当前用户具备读写权限。

业务要求：
1. 实现分帧与谱峰检测阶段：对 16 位 PCM 按可配置帧长与帧移做汉宁窗分帧并计算幅度谱，在每帧时间-频率平面的局部邻域内以极大值检测取谱峰，按每帧最大谱峰数截断并记录每峰的帧索引、频率格与幅度；同一输入与配置必须产生逐字节一致的谱峰清单，静音分片或全零分片须返回带分片标识的 E_NO_PEAK 而非静默输出空表。
2. 实现指纹对生成核心：对每个谱峰在其后时间差范围内搜索幅度最高的若干锚点峰，按配置的时间差与频率差上下界筛除越界对，把每对编码为锚点峰与目标峰的频率格与时间差组合；锚点峰为某分片最后一个谱峰循环扫描时须显式声明循环策略并保持确定性，生成的对数须与配置上限一致且可按分片固定顺序复算。
3. 实现指纹向量量化压缩与误差边界：按配置位宽对频率格与时间差做定点量化并记录每字段缩放因子，再以确定性哈希把量化对映射到有限桶宽以压缩向量；量化步长引入的频率偏移须给出显式上界，桶宽小于量化值域时须统计碰撞次数与最强碰撞桶，冲突超阈值须返回 E_BUCKET_COLLISION 并附分片标识与碰撞桶号。
4. 实现检索精度与误差传播审计：以参考指纹对清单为唯一真值来源，统计压缩后指纹向量的命中率、误配率与平均时间差偏移，并逐字段输出量化引入的上界、实际最大偏差与有效位数；误差上界须由缩放因子与量化步长显式推导，语料级误配率须随分片规模给出估计，当实测误配率超过声明上限时须标记该分片为未通过并给出越界指标名与估计值。
5. 实现分片级加权与可疑分片标注：按谱峰数、指纹对数与桶碰撞率对每个分片计算审计可信度，权重归一化与命中统计须在对数域或定点域进行以控制浮点误差；可信度低于可配置下限的分片标为可疑并在汇总中单列，汇总须区分未通过分片与可疑分片两类，且同一输入的摘要逐字节一致。
6. 实现阶段检查点持久化与优雅停止恢复：每分片按谱峰检测、指纹对生成、量化压缩、误差审计四阶段完成时以原子方式写入含分片标识、阶段名、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入过程任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分单元后退出，恢复后最终指纹向量与审计报告须与一次从零完整运行逐字节一致，检查点序号连续推进。
7. 实现版本变化检测与增量失效传播：当分片样本内容、局部邻域大小、时间差或频率差范围、量化位宽、每帧最大谱峰数或桶宽任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；失效原因与命中阶段须在查询接口中可观测，禁止用旧版本产物参与新版本审计。
8. 实现并发发布保护与稳定业务错误码：多工作进程对同一工作区发布阶段产物时使用真实文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT，请求非法阶段跳转或缺失前置阶段产物返回 E_INVALID_STAGE；同时提供库函数与命令行支持导入分片与配置、查询各阶段状态与版本指纹、查看审计报告、请求停止与执行恢复，并用至少 3 个分片（含静音分片与超低桶宽配置）的确定性演示验证错误码与恢复一致性。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
