为 OCR 文字检测识别团队从零构建一个本地可运行的检测识别管线与结果验证工具，核心问题是交互预览的低延迟与预览结果同全量重算结果的一致性。输入是本地样本目录：一份图像清单 JSONL，每条含 image id、宽高、灰度像素文件相对路径（本地确定性合成的文本行条带图像，像素为 8 位单通道，含若干由矩形笔画拼出的文字行区域与空白间隔）；一份候选文本框文件 JSONL，每条含 box id、所属 image id、四元坐标（左上与右下像素坐标）、类别无关置信度与文本嵌入向量；一份识别词表 JSON，含每个字符的文本嵌入向量（固定维度 float64）与最小识别置信度。工作区为空，需从零创建项目：一个 FastAPI 服务，提供检测结果创建、按图像交互预览候选框与识别文本、全量识别提交、逐图像进度与统计查询、版本化快照导出接口。核心难点在于：用户会以较低延迟反复调整交并比阈值、置信度下限与识别字符集，预览必须与全量重算逐项一致，且进程被强制终止后恢复结果须与无中断执行完全相同。

任务环境与准备：
安装 Python 3.11 与 pip，创建虚拟环境并安装 fastapi、uvicorn、numpy、pytest（版本以本地 wheel 可装为准），无需联网服务或容器。
在空工作区创建项目目录结构，准备本地样本生成脚本：确定性合成 8 位灰度文本行条带图像、对应图像清单 JSONL、候选文本框 JSONL 与识别词表 JSON。
准备覆盖不同图像尺寸、候选框重叠与不重叠、坐标越界与无法识别字符的样本集，并确认所有样本可在 Windows 本地文件系统读写。
确认 SQLite 可用（Python 内置 sqlite3 即可），规划数据库文件、分片目录与临时文件目录的位置。

业务要求：
1. 服务入口接收样本目录、图像清单、候选文本框文件与识别词表，校验 image id 与 box id 唯一、像素文件存在且尺寸与清单声明宽高一致、候选框坐标满足左上小于右下且落在图像范围内、嵌入维度与词表一致；任一非法返回 E_PARAM 业务码并指出出错文件与行号，且不创建任何结果文件或临时目录。
2. 识别结果须输出按候选框左上坐标行优先、同位置按 box id 字典序稳定排序的框序列，每框含坐标、识别出的字符序列与逐字符置信度；同一图像与配置下框顺序、字符序列与置信度须逐位可重复，不得依赖字典遍历顺序或文件系统枚举顺序。
3. 候选框须经确定性非极大值抑制：按置信度降序、同分按 box id 字典序处理，交并比阈值由请求参数给出且只在与保留框比较时生效；交并比须在 float64 下由像素坐标计算，被抑制框须记录抑制者 box id 与交并比值，任一阈值非法返回 E_NMS 并给出实际取值。
4. 字符识别须以候选框裁剪区域的像素投影与词表字符嵌入做余弦匹配，只保留余弦不低于最小识别置信度的字符并按列扫描顺序拼接；无法匹配任何字符的框须计入未识别统计并继续处理，不得使整图或整体任务失败，逐字符置信度须在框内构成有效概率分布，归一化误差超容差时返回 E_PRECISION。
5. 预览接口须在低延迟预算内返回所选图像的候选框数、非极大值抑制后保留数、前若干框的字符序列与置信度，且必须与用同一参数走全量识别得到的结果完全一致，包括框顺序、抑制结论、字符序列与置信度；检测到任何差异须返回 E_VERIFY 并给出 image id 与首个不一致的 box id。
6. 服务须实现以配置指纹（交并比阈值、置信度下限、字符集与词表版本的内容哈希）为键的预览缓存，任一参数或词表版本变化须使相关图像缓存失效；读取缓存时若指纹与当前请求不一致须返回 E_STALE 并给出新旧指纹摘要，禁止返回旧参数下的框序列。
7. 识别进度与结果须在 SQLite 中以图像粒度事务提交，逐图像结果以原子替换写入不可分割的分片文件并登记内容哈希，分片提交与统计汇总在同一事务中完成；进程被强制终止后重启须核对分片哈希与提交标记，重算未提交图像且不重复消费已提交图像，恢复后的逐图像框序列与快照版本序列须与无中断执行完全一致。
8. 每次全量识别完成须以整体替换方式生成版本化快照，含配置指纹、各图像识别摘要与分片哈希；结果验证工具读取快照时若检测到数据库版本与磁盘分片哈希不一致、配置指纹变化或残留旧版本分片，须返回 E_STALE 并定位到图像与分片；另须提供确定性演示入口，固定样本与参数跑出逐图像保留框数、未识别框数、预览与全量一致结论、恢复前后一致性结论的可重复结果，并给出可用 curl 复现的请求示例。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本验证预览与全量识别一致、缓存与快照失效判定及强制终止后的恢复结果，附运行输出。
