为注意力算子团队从零构建一个本地可运行的 FlashAttention 风格分块注意力算子组件与增量更新引擎，核心问题是分块调度参数、缩放因子与掩码策略变更时，已缓存的分块输出如何按依赖关系精确失效、只重算必要分块，并在进程被强制终止后保持状态一致。输入是本地确定性生成的注意力样本目录：一份序列清单 JSONL，每条含 seq id、查询长度与键长度（两者可不等，含不整除分块尺寸的尾块）、头维、批量下标，以及 Q、K、V 三个 float32 或 float64 张量分片文件相对路径；一份算子配置 JSON，声明查询分块尺寸、键分块尺寸、在线 softmax 缩放因子、掩码策略（无掩码、因果掩码或局部窗口掩码并给出窗口半宽）、累加精度策略与浮点容差。工作区为空，需从零创建项目：可集成组件与 FastAPI 服务，提供作业创建、按变更触发增量重算、查询分块依赖与输出、导出快照与诊断报告的接口。分块输出由数值路径决定，必须可复现。

任务环境与准备：
安装 Python 3.10 及以上版本，创建虚拟环境并安装 numpy、fastapi、uvicorn、pytest，记录版本。
确认工作区为空目录，SQLite 使用 Python 标准库 sqlite3，无需外部数据库服务。
准备本地生成脚本生成 Q、K、V 张量分片样本（含长度不等、尾块不对齐、三种掩码策略与两种 dtype），并生成中断恢复场景所需的变更序列。
验证启动脚本可在 Windows 本地监听回环端口，确认浮点计算与文件哈希在重复运行间一致。

业务要求：
1. 作业创建接口接收序列清单、算子配置与浮点容差，校验 seq id 唯一、查询长度与键长度为正整数、头维一致、张量分片文件存在且元素数与声明形状匹配、dtype 仅为 float32 或 float64、分块尺寸为正整数、缩放因子与窗口半宽合法、掩码策略只取声明三种取值；任一非法返回 E_PARAM 业务码并指出出错文件与行号，且不创建任何结果文件或临时目录。
2. 须实现确定性 FlashAttention 分块计算：按查询分块与键分块两级遍历，每个查询块对键块做在线 softmax 递推（维护运行最大值与运行累加和并按递推公式重标定），尾块（不整除部分）必须走同一递推路径而非退回整块拷贝；相同输入与配置下逐元素输出须逐位一致，不得依赖数组遍历顺序、字典序或系统时间。
3. 须显式支持 float32 累加与 float64 累加两条数值路径：同一次计算由策略参数选定主路径，另一条路径须作为对照同步算出并记录逐分块最大绝对差、相对差与首个差异元素下标；主路径输出、对照差值摘要与两路径分别在哪些分块上超出声明容差均须可查询，超容差时返回 E_PRECISION 并定位到 seq id、分块坐标与元素下标。
4. 分块输出须记录内容指纹，指纹由该分块的 Q、K、V 数据内容哈希、缩放因子、掩码策略（含窗口半宽）、累加精度策略与分块尺寸共同决定；触发更新时须沿“配置参数—受影响分块—受影响 seq”的依赖关系计算失效集合，仅指纹变化的分块及其下游软最大值递推状态进入失效，未受影响分块必须复用已持久化的分块结果。
5. 须支持批量变更提交：一次请求可同时修改查询分块尺寸、键分块尺寸、缩放因子与掩码策略中的多项，所有受影响分块的新结果与指纹版本须在同一 SQLite 事务中提交；事务中途失败不得留下部分更新的分块结果、半写结果文件或与分块指纹不一致的版本记录。
6. 须实现失效抑制：对因上游递推状态变化而被评估的分块，重新计算后若其最终输出与已有缓存逐元素相同，则不得标记为已重算并复用旧记录；诊断报告须区分“被失效评估但结果未变”与“实际重算”两类分块，给出各自计数、分块坐标与所属 seq id，并说明每个分块被判定的依据。
7. 进程被强制终止后重启，须从 SQLite 已提交的分块粒度进度继续，核对每个分块的指纹、结果文件内容哈希与快照版本，重算未提交分块且不重复消费已提交分块；须实现整体替换的版本化快照，含作业版本号、各分块指纹与输出摘要，读取快照时若检测到缓存文件与数据库版本不一致、版本变化或残留旧版本结果文件，须返回 E_STALE 并定位到具体分块，恢复后的分块指纹集合、最终输出矩阵与无中断执行须完全一致。
8. 须提供确定性演示入口与集成示例：用本地生成的覆盖非方阵查询键长度、尾块不对齐、三种掩码策略、两档累加精度与中断恢复场景的样本，跑出各 seq 的分块数量、所选数值路径、被失效评估与实际重算分块数、两路径差值分布、恢复前后一致性结论与快照版本序列的可重复结果，并给出可用 curl 复现的请求示例。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证分块注意力输出、增量失效抑制与强制终止恢复后结果一致，并附可复现运行结果。
