当前为空工作区，需从零构建一个本地可运行的模型量化误差传播审计与校准回滚引擎，面向模型与数据管线协同场景下的数值精度问题。输入为固定随机种子生成的本地权重分片（.npz 文件，含多层线性层权重与偏置，形状与层名清单齐全）与一份 YAML 量化配置，配置描述每层的量化位宽、对称/非对称模式、零点策略、校准样本比例与逐层误差预算；另附本地校准样本（.npy 激活张量，含小样本与含离群值样本）。引擎需按层序执行量化、反量化与激活前向，采集逐层输出误差，并沿层链做误差传播归因：把端到端输出偏差分摊到各层量化引入的噪声上，同时给出每层误差占预算比例与是否越界。系统还需支持校准集变更后的按层重算、误差预算超限时的回滚到上一可用校准版本，以及审计记录的原子持久化。不依赖真实模型、GPU 或外部服务。

任务环境与准备：
安装 Python 3.11 及以上版本，创建本地虚拟环境。
安装 numpy 与 PyYAML，版本以本地可获取的稳定版为准，无需容器化。
运行前由任务自带脚本用固定随机种子生成本地权重 .npz、校准激活 .npy 与层名清单，不依赖任何外部数据集或网络。
确认工作区可写以用于审计记录与锁文件，全部命令在 Windows 下执行。

业务要求：
1. 实现逐层量化与反量化核心：对每层权重与偏置按配置的位宽与对称/非对称模式计算缩放因子与零点，执行量化与反量化，并在量化域校验取值不超过位宽可表示范围；越界须钳制并将钳制次数、位置层名写入审计记录，缩放因子为零或激活张量含 NaN/Inf 时返回 E_QUANT_INVALID 并附层名。
2. 实现按层前向与误差采集：以校准样本按层序执行线性前向，分别记录全精度输出与量化后输出，计算逐层相对误差与绝对误差上界估计；误差估计须依赖显式的全精度参考值与本地样本，不得从缺失信息推断；同一输入与配置重复运行须得到逐字节一致的误差序列。
3. 实现误差传播归因：将端到端输出偏差按各层量化引入的噪声贡献分摊，采用一阶敏感度与逐层扰动重放两种方式交叉校验，两者归因排序不一致的层须标记为待复核并给出偏差来源；归因结果须满足各层贡献之和与端到端偏差在可配置容差内闭合，否则返回 E_ATTRIBUTION_GAP。
4. 实现逐层误差预算判定：按配置的每层误差预算与总预算计算每层占用比例，输出越界层清单与最接近预算的层的余量；预算判定须与归因结果关联，某层超出预算但其上游误差占比已高的情形须在诊断中标明不可单纯通过提高该层位宽解决，并给出建议动作。
5. 实现校准集变更后的按层重算：当校准样本、位宽、零点策略或量化模式任一变化时，通过由内容摘要构成的版本指纹识别受影响的最早层，仅重算该层及其下游，未受影响上游结果继续复用；增量重算结果须与从零全量运行逐字节一致，不一致时返回 E_INCREMENTAL_MISMATCH 并附差异层名。
6. 实现误差预算超限时的校准回滚：每次成功校准生成单调版本号并原子写入含版本号、各层参数指纹、预算配置指纹与结果摘要的审计记录，写入任意位置中断不得留下半写记录；当新版本因预算越界被判定不可用时，须回滚到最近一个全部层在预算内的版本，并保证回滚后重新查询的误差与预算状态与该历史版本一致。
7. 实现并发发布保护与版本整体替换识别：多工作进程对同一工作区发布校准版本时使用文件锁并比较版本号，仅允许版本号连续推进，落后或重复发布返回 E_STALE_VERSION，缺失前置层结果时返回 E_INVALID_STAGE；检测到审计记录被整体替换（版本号回退、摘要不匹配或参数指纹变化）时须区分回退与篡改，仅正常推进可被接受。
8. 提供命令行审计接口与本地确定性演示：支持导入权重与校准样本、执行全量与增量校准、查询逐层误差与归因、查看版本历史、触发回滚；演示数据至少含 5 层权重、含离群值的校准样本，层名保持确定性生成，一次完整运行生成固定摘要，并演示一次预算越界后回滚与一次版本整体替换被拒绝，同时验证异常注入均返回对应业务码。
