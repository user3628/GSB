空白工作区里只有这份检索服务需求，需要从零交付一套查询改写与前缀缓存收益裁决组件及可复现示例。程序内置固定种子生成器在本地产出 JSONL 查询会话分片（含 session_id、轮次、原始查询、locale、历史改写文本）与一份 YAML 服务配置，声明改写候选深度、各改写策略的千分比预算、缓存条目容量、前缀最短可缓存长度与缓存命中收益阈值。组件按四阶段推进：查询规范化与改写候选生成、按缓存前缀指纹判定各候选的预期命中情形、在改写收益与缓存失效成本之间做逐候选裁决、汇总并把裁决结果写入 SQLite。真实场景里多租户查询并发到达，缓存策略快照会被整体替换或局部追加，同一候选在不同轮次可能因上游改写改变而产生不同前缀指纹，进程也可能在写入中途被强制终止。

任务环境与准备：
安装 Go 1.22 或以上版本，并在 Windows 上使用官方安装包完成配置。
安装 SQLite 命令行工具便于检查数据库；Go 侧使用纯 Go SQLite 驱动，无需 C 编译器。
在空白工作区执行 go mod init 初始化模块并添加所选纯 Go SQLite 驱动依赖；如需本地 HTTP 演示服务，仅使用标准库 net/http。
运行程序内置固定种子生成器在本地写出会话分片与 YAML 策略快照，不依赖网络、真实账号或外部数据集。

业务要求：
1. 实现查询规范化与改写候选生成阶段：对原始查询做 Unicode NFKC、空白折叠、全半角统一与小写化，按中文单字与拉丁连续串切分并保留字符偏移，再按配置的候选深度从历史改写文本与本地同义词表中生成改写候选，输出候选文本、所用策略、与原始查询的词项重合度；空查询、候选数为零或改写后文本为空须返回带 session_id、轮次与阶段的稳定业务码，同一输入与配置必须产生逐字节一致的候选清单。
2. 实现前缀指纹与缓存命中情形判定：把每条候选按最短可缓存长度截出可缓存前缀，逐块以固定哈希生成指纹并记录块序号与字符跨度，再与缓存中的前缀槽位比对，输出精确命中、部分前缀命中、不可复用三种情形及各自依据；当候选前缀长度低于阈值、缓存条目容量已满需要裁决挤出项或某槽位被同一轮内多个候选争用时，须记录挤出与争用依据，同一轮内候选排序与挤出结果必须确定。
3. 实现改写收益与缓存失效成本的逐候选裁决：依据候选与原始查询的词项重合度、预期命中情形、缓存槽位年龄与配置的收益阈值，在对数域合成收益分与失效率估计，为每个候选给出采纳、拒绝两种结论并输出分量明细与失效率上界；失效率上界必须由显式的槽位年龄、前缀块数与命中情形推导并保留推导依据，出现权重为零、对数域非有限值或上界超出合法区间须返回带候选标识的 E_NUMERIC 结构化错误。
4. 实现预算约束下的逐轮裁决调度：以轮次为调度单元，在改写策略千分比预算、单轮候选评估次数预算与缓存条目容量三重约束下决定采纳哪些候选以及写入哪些新前缀槽位，预算不足时按确定性优先级放弃并按放弃原因留痕；累计消耗超出预算或千分比之和不为一千时须显式报告并降级处理，不得静默截断，且每轮的预算消耗须可事后复算。
5. 实现 SQLite 事务化阶段检查点与强制终止恢复：每轮每阶段完成时以事务写入含阶段名、session_id、轮次、输入内容指纹、配置版本、产物摘要与单调序号的记录，同一会话同一轮次同一阶段只允许一条有效记录；进程被强制终止后重启仅凭已提交事实重建进度，不承诺生成退出报告，恢复后的候选清单、命中情形、裁决结论与预算消耗必须具备与连续执行逐字节一致的结果。
6. 实现缓存策略快照的增量追加与整体替换识别：接受只含局部改动的策略增量片段（候选深度、千分比预算、缓存容量、最短前缀长度单字段调整），并通过各阶段内容摘要构成的版本指纹定位受影响的最早阶段；当策略快照被整体替换时须通过内容摘要与版本序号区分正常追加、整体替换与版本回退，整体替换使全部槽位与裁决缓存失效重建，回退则拒绝并返回 E_STALE_VERSION 并附当前生效版本。
7. 实现并发轮次发布互斥与陈旧读裁决：多个工作进程对同一 SQLite 库发布轮次产物时使用条件更新与真实文件锁，仅允许会话内轮次序号连续推进，落后、重复或跨会话错位发布返回 E_STALE_CHECKPOINT；携带观察版本读取裁决结论时，低于当前生效版本的读取须明确返回需重算而不得给出陈旧结论，并发下同一候选不得被两个轮次同时占用同一槽位。
8. 提供本地 HTTP 与命令行交互接口及确定性演示：支持导入会话分片与策略快照、提交增量片段、触发分阶段裁决、查询各阶段状态与版本指纹、查看逐候选失效率上界与挤出争用明细、请求优雅停止与执行恢复、导出裁决报告；演示数据由内置生成器产出至少 3 个会话，覆盖命中、部分命中、不可复用与前缀争用情形，完整运行产生固定摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
