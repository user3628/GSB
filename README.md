当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的“多视角图像→体素化场景表示”重建引擎与可复现实验环境。与位姿图优化类任务不同，本引擎不求解相机位姿：相机位姿与内参由清单显式给定并视为不可变输入，核心业务问题是对同一场景做体素化三维表示的分层构建，并在视角图像或体素表示参数变化时做增量重建与依赖失效裁决。输入为固定随机种子生成器产出的本地确定性样本：一组视角图像分片（小尺寸 RGB PNG，同一合成几何体在不同固定位姿与明暗下的视图）与一份 JSON 场景工程清单，逐分片声明相机外参与内参、该视角可见的地标投影坐标、场景节点归属，以及全局的体素分辨率、截断距离、融合半径、稀疏度阈值与体素特征维度。真值来自本地生成器与清单中显式声明的参数，不依赖真实三维数据集、预训练模型或 GPU。引擎按四阶段推进：视角像素到地标的投影采样、各视角体素贡献体、场景体素场融合、稀疏化与摘要汇总。

任务环境与准备：
安装 Python 3.11 与 NumPy、Pillow，使用 pip 安装到本地虚拟环境，不引入其他第三方依赖。
在空工作区新建项目目录，包含引擎库、命令行与本地 HTTP 接口入口，以及固定种子的样本生成器。
运行样本生成器产出至少 4 个视角 PNG 分片与对应场景工程清单，输出内外参与参数声明文件，确保可重复生成。
准备本地临时工作区目录用于阶段检查点、文件锁与恢复实验，确认路径可在 Windows 上读写。
无需 GPU、外部服务、账号或线上素材，所有验证均在本地确定性样本上执行。

业务要求：
1. 实现视角投影采样阶段：按清单声明的外参与内参把每张图像的地标像素坐标映射到世界射线，沿射线按配置步长采样并读取图像颜色，输出带分片标识、世界坐标采样点与颜色值的贡献记录；同一输入与配置必须产生逐字节一致的贡献记录，采样点落在视锥外或图像边界外时须裁剪并统计被裁剪点数。
2. 实现各视角体素贡献体构建：把采样点按体素分辨率量化到体素坐标，在截断距离内累计颜色与命中计数并生成视角局部体素块，记录每视角的占用体素数与被遮挡跳过数；同一体素被同视角多次命中时按确定性顺序合并，颜色出现 Inf 或量化后坐标为负且越界时返回 E_VOXEL_INVALID 并附分片标识与体素坐标。
3. 实现场景体素场融合与稀疏化：按分片序与视角内顺序把各视角局部体素块融合为全局体素场，按融合半径加权平均颜色并按稀疏度阈值剪枝，输出全局体素占用、颜色摘要与稀疏度统计；融合顺序与权重归一化须显式可复算，剪枝后出现零权重体素或空场景时返回 E_SPARSE_EMPTY 并保留剪枝前后计数。
4. 实现持久化阶段检查点：每个分片或全局阶段完成时以原子方式写入包含阶段名、输入分片内容指纹、配置版本、产物摘要与单调序号的记录，写入过程任意位置中断不得留下半写记录；恢复时必须忽略损坏、不完整或序号重复的记录并从最近一致检查点继续，已发布阶段产物不得被重复计算。
5. 实现版本变化检测与失效传播：当某分片像素内容、相机内外参、体素分辨率、截断距离、融合半径或稀疏度阈值任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建；未受影响上游产物继续复用，失效原因与指纹须在查询接口中可观测，禁止用旧版本结果冒充新结果。
6. 实现增量与全量一致性校验：提供单视角替换与单配置变更入口，仅重建失效链路后与从零全量构建的贡献记录摘要、全局体素场摘要与稀疏度统计做逐字节比对；不一致须返回 E_INCREMENTAL_MISMATCH 并附首个差异阶段与体素坐标，多次连续增量构建后结果须仍与一次全量构建一致。
7. 实现并发安全的阶段发布与稳定业务错误码：多个工作进程对同一工作区发布阶段产物时使用真实文件锁并比较检查点序号，仅允许序号连续推进，落后、重复或跨阶段错位发布须返回 E_STALE_CHECKPOINT，缺失前置阶段产物时请求后续阶段返回 E_INVALID_STAGE；锁等待超时须返回结构化超时错误，不得以固定延迟代替真实锁机制。
8. 提供本地 HTTP 与命令行交互应用及确定性演示：支持导入分片与场景清单、触发分阶段构建、查询各阶段状态与版本指纹、查看失效原因与稀疏度统计、请求停止、执行恢复、导出全局体素摘要与校验报告；演示数据至少 4 个视角分片，含不同体素分辨率配置与至少 1 个被整体替换的分片，完整运行生成固定摘要，并演示阶段间停止后恢复与增量更新结果同全量结果一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
