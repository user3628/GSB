当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的模型评估与校准格式互操作工作台，交付领域数据编辑与操作应用。输入为固定随机种子生成器产出的本地 JSONL 评估记录分片：每条含 model_id、sample_id、原始预测分数、二分类标签、语言标签、来源批次与结构版本号，并附一份独立的本地校准配置（JSON），声明分桶数、校准方法（Platt 缩放或等距回归）、可靠性阈值与期望正例率区间。评估记录存在两种结构版本：版本 2 以浮点分数与显式分桶字段描述，版本 1 以整数百分比分数、缺少分桶字段且样本标识为字符串拼接形态。工作台需把两种版本统一为内部评估模型，完成分桶校准、可靠性诊断与指标汇总，并支持配置文件与评估分片被编辑后识别版本变化、判定受影响阶段并重建，同时保证优雅停止后恢复结果与完整运行逐字节一致。

任务环境与准备：
安装 Python 3.11 与 NumPy、FastAPI、uvicorn，均为本地包，无需网络服务或账号。
编写固定种子生成器脚本，产出至少 3 个评估记录分片（覆盖版本 1 与版本 2、中英混排、至少两个来源批次）与两份不同结构版本的校准配置文件。
准备本地运行脚本与目录约定（工作区、检查点目录、导出目录），确认命令行与本地 HTTP 接口均可启动。
注入样本需以参数或输入文件方式提供，包括版本声明与内容不符的记录、非法阶段请求与越界配置，禁止修改源码制造失败。

业务要求：
1. 实现统一评估内部模型与两种记录结构版本的双向编解码：内部模型以模型标识、样本标识、浮点分数、标签、语言标签、来源批次与分桶编号描述一条记录；实现内部模型与版本 2 JSONL、版本 1 JSONL 的互转，版本 1 导入时须按可配置舍入规则做功分比换算、补齐分桶字段并从拼接样本标识中切出稳定标识，换算与切分依据须可回看；互转后再反向导出须能还原原始版本语义。
2. 实现分桶与两类校准器：按配置的分桶数对预测分数做确定性等宽或等频分桶，分桶边界冲突时须有确定性裁决规则；实现 Platt 缩放与等距回归两种校准器，Platt 以对数域牛顿迭代拟合参数并记录迭代轮数与收敛状态，等距回归以保序回归加线性插值得到单调映射，校准器拟合失败须给出稳定业务码而非空结果。
3. 实现可靠性诊断与指标汇总：按分桶统计预测概率与真实频率的偏差，输出可靠性表、期望校准误差、对数损失与 Brier 分数，并按语言标签与来源批次分层汇总；每个指标须说明所依赖的有效样本数与样本构成，各分层有效样本数低于可配置下限时须将该层标为样本不足并单独列出，不得静默并入总层。
4. 实现版本 1 旧配置兼容解析与显式升级：旧校准配置中校准方法以字符串别名表述、分桶数为整数百分比、缺少期望正例率区间字段；导入时须按可配置映射把别名解析为方法枚举、把百分比换算为分桶数、补齐缺省区间，并在诊断输出中标注每一处换算与补全依据；升级后的配置须能重新导出为版本 2 结构并与直接编写的版本 2 配置得到相同校准结果。
5. 实现格式往返一致性与版本兼容校验：对每个评估分片执行版本1→内部→版本2→内部→版本1 与 版本2→内部→版本1→内部的往返链，校验分数、标签、分桶与层级归属保持不变；当导入记录的结构版本号与内容形态不一致（声明为版本 2 却缺少浮点分数）时须识别并返回带分片标识与记录位置的 E_VERSION_MISMATCH，不得按猜测版本强行解析。
6. 实现持久化检查点与优雅停止恢复一致性：每个分片按解析、分桶校准、诊断汇总三阶段完成时以原子方式写入含阶段名、记录内容指纹、配置版本指纹、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分分片单元后退出，恢复后可靠性表、校准参数与汇总摘要须与一次完整运行逐字节一致。
7. 实现配置与分片变化的版本指纹与增量失效传播：当评估分片内容、校准方法、分桶数、可靠性阈值或期望正例率区间任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游校准与诊断产物失效并重建，未受影响分片的上游解析结果继续复用；失效原因与指纹须在查询接口中可观测，禁止沿用旧校准参数。
8. 实现并发发布保护与稳定业务错误码：多个工作进程对同一工作区发布阶段产物时使用真实文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布须被拒绝并返回 E_STALE_CHECKPOINT；请求非法阶段跳转或缺失前置阶段产物时返回 E_INVALID_STAGE，版本形态不符返回 E_VERSION_MISMATCH，拟合失败返回对应业务码，各错误码须在命令行与 HTTP 响应中保持一致。
