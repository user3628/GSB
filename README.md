当前为空工作区，需从零构建一个本地可运行的中文分词与词性标注组件，供其他 NLP 服务以库的形式集成。输入为若干本地 UTF-8 文本文件，每行一句中文，允许夹杂英文单词、数字与全角标点；输出为每个词的起止字符偏移、词面、词性标签，以及该句的联合标注概率。组件包含三个核心部分：基于字级 B/M/E/S 与词性联合标签的序列标注解码器、从本地已标注样本估计的转移与发射概率表、以及多句批量汇总的评估模块。所有概率在对数域计算，概率表来自带拉普拉斯平滑的计数统计。系统要用本地确定性样本运行，必须对数值下溢、平滑导致的概率漂移、批量解码中的误差传播和非法标签序列保持可观测、可复现的行为，并提供可直接集成的接口与完整演示。

任务环境与准备：
安装 Python 3.11 与 NumPy，建议在虚拟环境中完成，确认 python 与 pip 可用。
准备本地演示目录，创建至少 3 个 UTF-8 文本文件与一份带标签的本地训练样本，样本须含中英混排、数字与全角标点。
确认工作区为空白，运行脚本与库接口均在本地文件系统内完成，不依赖网络、真实账号或外部服务。
预先在演示脚本中写入非法平滑系数与会触发 E_NUMERIC 的输入样本注入入口，用于验证错误码行为。

业务要求：
1. 实现联合标签序列解码：为每个字符输出由分词位置 B/M/E/S 与词性组成的联合标签，使用对数域 Viterbi 求最优路径并返回联合对数概率；同一输入必须得到确定结果，且不得出现字符未覆盖或标签与字符边界冲突的路径。
2. 实现概率表估计：从本地标注样本统计初始、转移与发射计数，采用拉普拉斯平滑，并以对数概率存储；对未见字符和未见标签转移须回退到可配置的未知标记，且估计结果在重复运行时逐字节一致。
3. 实现数值稳定性与误差传播控制：解码全程在对数域进行，禁止直接连乘概率；当出现 -inf、NaN 或对数输入中出现非正概率时须以显式业务错误 E_NUMERIC 报告涉及句号与字符位置，不得静默返回空结果或伪造路径。
4. 实现词边界与词性约束校验：解码后按 B/M/E/S 重组词并检查每个词的连续性、单字词位置合法性与词性标签在词性表中的存在性，非法结果须回滚为带 E_INVALID_TAG 的错误对象，且不得部分写入输出。
5. 实现批量解码的确定性汇总：按输入文件与行序处理多句，记录每句的联合对数概率与词数，最终汇总的总对数概率必须与逐句单独解码结果按同序累加一致，容差不得超过 1e-9，防止批量归约引入顺序相关误差。
6. 实现平滑强度与解码结果的关联调优：提供可配置平滑系数，当系数变化时须检测概率表版本指纹变化、使缓存的解码结果失效并重建，且旧版本结果不得被误用；版本变化须在查询接口中可观测。
7. 实现对外集成接口与完整示例：提供库函数与命令行示例，支持录入文本、查看每句的词序列、词性、偏移与联合概率，并在输入非法标签或空句时返回稳定业务错误码；示例须用本地样本完整演示一次批量标注与一次错误注入。
8. 提供本地确定性演示样本与运行脚本：至少包含 3 个文本文件，含中英混排、数字、全角标点与至少 2 个未登录字，一次运行生成固定摘要；同时用注入了非法平滑系数及会触发 E_NUMERIC 的输入样本验证错误码行为。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证批量标注的词序列、词性与联合概率一致，并确认数值异常与非法标签返回稳定业务错误码。
