当前为空工作区，需从零构建一个本地可运行的文生图扩散管线工作台，用于领域可视化与诊断。输入为若干本地确定性图像分片（由固定随机种子的生成器产出的 PNG 小图）与一份 YAML 配置，配置描述每个分片的提示词、引导系数、采样步数、随机种子以及可选的参考图（图生图）。管线对每个分片执行：文本编码（本地哈希嵌入）、条件调度（引导系数与步数共同决定无条件分支权重）、沿采样轨迹逐步去噪（使用确定性的伪噪声，不依赖真实模型或 GPU）、最后量化输出 PNG，并记录每步的轨迹摘要。工作台需支持对单个分片的配置或输入图进行增量更新，并依赖版本指纹自动判定哪些分片的哪些阶段产物失效、需要重建；更新必须与一次从零全量构建的产物逐字节一致。所有数据、嵌入与噪声均在本地确定性生成，不依赖外部账号、在线服务或预训练权重。

任务环境与准备：
安装 Python 3.10 或以上版本，并创建本地虚拟环境。
安装依赖：pip install numpy pillow pyyaml。
使用固定随机种子生成至少 4 张本地 PNG 小图与对应 YAML 配置，确保无网络请求。
确认工作区可写并预留用于检查点与产物输出的目录；演示停止与恢复通过进程信号或输入注入触发。

业务要求：
1. 实现文本编码与条件调度模块：对每个分片的提示词做规范化后以固定哈希函数生成 16 维单位嵌入向量，并根据配置中的引导系数与采样步数计算每步的无条件分支权重调度序列；同一输入必须产生逐字节一致的嵌入与权重序列，权重序列长度必须等于采样步数，非法引导系数（负数或非有限值）须返回业务码 E_INVALID_CONFIG 并指明分片与字段。
2. 实现确定性去噪采样核心：从配置中的随机种子派生固定伪噪声张量，沿调度权重逐步执行线性插值去噪，每步记录有界的轨迹摘要（均值、方差与步索引），最终将张量量化为 8 位 PNG；禁止使用任何真实模型、GPU 或在线资源，同一分片在重复运行、不同工作进程与不同线程数下输出必须逐字节一致，量化前后值域须显式钳制并报告钳制次数。
3. 实现图生图参考融合路径：当配置指定参考图时，将其解码为同尺寸张量与初始噪声按可配置融合强度混合；融合强度越界须返回 E_INVALID_CONFIG，参考图缺失或尺寸不符须返回 E_MISSING_REFERENCE 且不得生成半成品 PNG；无参考图时路径必须与纯文生图逐字节一致，不得因分支存在引入额外随机性。
4. 实现持久化阶段检查点：每个分片按编码、调度、采样、量化四个阶段完成时原子写入包含分片标识、阶段名、输入版本指纹、配置版本、产物摘要与单调序号的记录；写入过程任意位置中断不得留下半写记录，恢复时必须忽略不完整临时文件并从最近一致阶段继续，已发布阶段产物不得重复计算。
5. 实现版本变化检测与失效传播：当分片提示词、引导系数、采样步数、随机种子、参考图内容或全局编码参数任一变化时，通过版本指纹识别受影响的最早阶段，使该阶段及其全部下游阶段产物失效并重建；未受影响的上游阶段可复用，但复用前必须校验其指纹与当前配置匹配，不匹配则一并失效；失效原因与重建决策须在状态查询接口中可观测。
6. 实现增量更新与全量一致性校验：提供更新入口接受单分片的配置或参考图变更，仅重建失效链路，并支持与从零全量构建的结果做逐文件摘要比对；增量构建完成后所有可见产物必须与全量构建逐字节一致，若检测到不一致须返回业务码 E_INCONSISTENT_STATE 且不得覆盖已有的合法产物。
7. 实现并发安全的阶段发布与诊断查询：多个工作进程对同一工作区发布阶段产物时使用文件锁并比较检查点序号，仅允许序号连续推进，落后或重复发布返回 E_STALE_CHECKPOINT，缺前置阶段产物时请求后置阶段返回 E_INVALID_STAGE；诊断查询须按分片列出各阶段状态、指纹、失效标记与当前 PNG 摘要，且查询不得触发任何构建副作用。
8. 提供本地确定性演示数据与领域可视化诊断工作台：至少 4 个图像分片，包含中英文提示词、不同引导系数与步数、至少 1 个带参考图的图生图分片；生成固定摘要的一次完整构建，演示期间人为在阶段间触发停止后恢复并完成一次增量更新，用注入的非法配置、缺失参考图与越界融合强度验证对应业务码，工作台以本地静态页面或命令行诊断视图展示各分片轨迹摘要与失效链，不引入网络依赖。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
