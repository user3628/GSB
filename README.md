在 Windows 空白工作区中，需要从零构建一个面向本地微服务测试环境的服务注册与健康探测中间件，核心问题是注册数据与探测结果的格式互操作与版本兼容。注册中心接受服务实例注册（服务名、实例 ID、端点、权重、租约 TTL、探测方式与探测参数），维护实例租约与健康状态，并按并行调度器对实例执行 HTTP 探针、TCP 拨号与租约心跳判定。为与外部注册中心与监控工具互换数据，实例注册快照与探测结果快照需要两种可互换的持久化格式：紧凑二进制格式（含魔数、格式版本字节、大小端标记、每条记录长度前缀、CRC32 校验与可选字段存在位图）与分片 JSON 行格式（每行含服务名、实例 ID、端点、权重、探测方式与探测参数）。两种格式的字段可选性、权重表示精度与时间单位不同，旧版本数据缺少探测参数、权重为浮点比例，新版本权重为千分比定点且新增探测窗口参数；外部工具还可能提交更高版本数据。系统须在导入导出、格式协商、版本兼容裁决、租约判定与健康状态演进之间保持跨模块一致，并在进程被强制终止后依据持久化事实恢复。所有数据来自本地确定性样本与本地测试服务，不依赖真实注册中心或外部网络。

任务环境与准备：
在 Windows 空白工作区创建项目目录，安装 Python 3.11 与 FastAPI、uvicorn、requests、pytest，使用 venv 隔离依赖。
准备本地确定性样本：一份旧版本 JSON 行注册快照（浮点权重、缺探测参数）、一份新版本二进制注册快照（千分比权重、含探测窗口），以及若干本地 HTTP 与 TCP 测试端点样本配置。
确认本地回环可用端口，测试服务与注册中心均绑定 127.0.0.1，不依赖外部网络、容器或真实注册中心。

业务要求：
1. 实现两种持久化格式的编解码：紧凑二进制格式必须包含魔数、格式版本字节、大小端标记、每条记录的长度前缀、CRC32 校验与可选字段存在位图；分片 JSON 行格式每行含服务名、实例 ID、端点、权重、探测方式与探测参数。两种格式必须能相互转换并保持语义等价，损坏或长度不符的记录返回业务码 E_FORMAT_CORRUPT 并指明记录序号，不得静默跳过。
2. 实现格式协商与版本兼容裁决：导入前检测输入格式与格式版本，按显式声明的兼容矩阵给出接受、降级接受或拒绝三种结论；旧版本缺少探测参数时降级接受并按声明的默认探测方式与参数补齐并记录降级明细，权重为浮点比例时按声明舍入规则转为千分比定点并输出每条舍入位；高版本含未知必填字段时返回 E_FORMAT_UNSUPPORTED 并整体拒绝该批数据。
3. 实现权重与时间单位的归一化：二进制格式的毫秒时间戳与 JSON 行格式的微秒时间戳须归一化为同一内部毫秒表示并按调用方声明的截断规则处理亚毫秒部分；权重统一为千分比整数且取值 1 至 1000，归一化过程中对溢出、负数与非整数输入返回 E_WEIGHT_INVALID，禁止在未声明规则时混用浮点与定点。
4. 实现实例注册与租约模型：同一服务名与实例 ID 重复注册按更新处理并递增租约版本，注册时校验端点可达性格式与探测方式在允许集合内；租约以毫秒精度记录授予与到期时刻，续约须携带当前租约版本，版本落后返回 E_STALE_LEASE 且不延长租约；同一实例并发续约只允许一个成功，其余等待并复用其结果。
5. 实现三类真实健康探测：HTTP 探针以本地测试服务返回的约定状态码与响应体标记判定成功，TCP 探针以真实连接成功或拒绝判定，租约心跳探针依据最近心跳时刻与 TTL 计算剩余寿命；每类探测具备独立超时，超时后必须真实关闭 HTTP 客户端连接或 TCP 套接字并释放资源，返回 E_PROBE_TIMEOUT，不得以等待冒充超时。
6. 实现并行探测调度与状态一致性：探测在全局并发上限与每轮时间预算内执行，超出并发上限的任务进入有界队列，队列满返回 E_PROBE_QUEUE_FULL；探测结果、权重调整与租约过期共同决定实例健康状态并在同一事务边界内更新实例记录与探测历史，禁止出现探测历史已记录失败而实例仍显示 UP 的中间可见状态；查询只能看到某一完整提交版本。
7. 实现导入冲突解决与批次原子生效：导入实例与现有实例同服务名同实例 ID 时，按租约版本、最后注册时刻与权重打破平局的确定规则解决，结局分为覆盖、跳过与拒绝三类并写入导入报告；整批导入须原子生效，任一条被拒绝则整批回滚并保持旧状态，报告须列出每条结局与依据；同一导入批次标识重复提交只执行一次，内容不一致返回 E_CONFLICTING_BATCH。
8. 使用 SQLite 持久化注册快照、租约、探测结果与意图日志，导入、注册、续约与探测轮次前先写意图记录再提交事务；进程在探测轮次或导入中途被强制终止后重启须扫描未完成意图，把未提交探测结果回滚为待探测、未完成导入标记为已中止，恢复报告只包含已持久化事实；并提供本地测试服务与端到端脚本，输出两格式互转后的等价性核对、降级明细与恢复差异。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本完成两种格式互转、版本兼容裁决与健康探测，核对降级明细、导入冲突结论及强制终止恢复报告。
