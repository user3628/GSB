客服中台意图与优先级联判服务的首个可运行版本，眼下要在 Linux 工作区一个尚未初始化的目录里落地。输入由程序内置固定种子生成器在本地产出 JSONL 工单分片，每条含 ticket_id、文本、渠道、语言标签、意图标签（多类单标签）、优先级标签（0-3）与标注一致度百分比，覆盖中英混排、同渠道重复文本、空文本、优先级越界与标注一致度缺失；另附带单调版本号的策略快照，声明意图词表权重、优先级阈值、分类平滑强度、哈希维度与每轮处理预算，并分小档（约 400 条、6 类意图）与大档（约 4000 条、12 类意图）两档。运维通过本地 HTTP 接口提交策略快照与只含局部字段改动的增量片段，触发联判轮次并查询诊断视图。难点在于同一快照在并行与串行下必须给出逐字节一致的意图分数与优先级明细，小档与大档须在精确打分、词表优先截断打分与哈希分桶预算打分之间做可复核取舍，且策略被整体替换须与正常推进、回退严格区分，强制终止后的恢复只能依赖 SQLite 已提交事实。

任务环境与准备：
在 Linux（WSL Ubuntu）上创建工作目录并初始化 Go 模块，安装 Go 1.22 或以上版本，确认 go version 可用。
准备 SQLite 开发库与 Go 驱动依赖（如 modernc.org/sqlite 或 mattn/go-sqlite3 及 gcc），执行 go mod tidy 拉取本地可用依赖。
无需外部数据集或网络服务：工单分片、策略快照与增量片段均由程序内置固定种子生成器在首次运行时写出。
预留本地回环端口用于 HTTP 接口，确保工作目录与临时文件目录可写，以便验证事务化检查点与强制终止恢复。

业务要求：
1. 实现规范化与词项抽取阶段：对工单文本做 Unicode NFKC、空白折叠、全半角统一与小写化，按中文单字与相邻二字组合切分、拉丁字母数字按连续串切分，输出带字符偏移与渠道标记的词项序列；空文本或仅含标点的工单须标记为不可分类并保留原文，同一输入必须产生逐字节一致的词项序列。
2. 实现意图分类打分解码：从本地已标注工单统计类别先验与词项条件计数，采用可配置平滑强度并全程在对数域累加后验分数，未见词项回退到显式未知标记，输出按分数降序、同分按意图名升序的候选及对数贡献；出现 NaN、Inf 或全部分量不可用时返回带 ticket_id 与意图名的业务码。
3. 实现优先级阈值判定与标签越界裁决：依据可配置阈值把意图分数与标注一致度合成为优先级判定，并与标注优先级比对输出命中、漏判、误判三类明细；标注优先级越界或标注一致度缺失时须按显式降级规则处理并在明细中标明降级依据，越界值不得静默钳制后当作正常标注。
4. 实现基于数据规模的策略取舍：依据档位、意图数、哈希维度与每轮处理预算，在精确全量打分、词表优先截断打分与哈希分桶预算打分三种策略中为当前档位选择一种，记录打分依据、选择理由与被淘汰策略原因；小档不得被选为为大档设计的重策略，大档在预算不足时须给出降级结论而非直接失败。
5. 实现并行打分与确定性归约：以工单为调度单元，在全局评估次数预算、单工作进程评估配额与并行工作进程上限三重约束下并行处理，各工单的候选分数、优先级判定与明细按 ticket_id 全局排序后归约，使并行运行结果与单进程顺序执行逐字节一致；工作进程异常须以结构化错误对象记录并保留已完成工单。
6. 实现 SQLite 事务化的阶段检查点与强制终止恢复边界：每条工单每阶段完成时在单个事务内写入含阶段名、ticket_id、输入内容指纹、配置版本、产物摘要与单调序号的记录，同一工单同一阶段只允许一条有效记录；进程被强制终止后重启仅凭已提交事实重建进度，不承诺生成退出报告，恢复后的意图分数、优先级判定与验证报告须与连续运行逐字节一致。
7. 实现策略增量片段应用、整体替换识别与失效传播：增量片段须携带基础版本并与当前生效版本校验，不一致返回 E_STALE_BASE；通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段与最小工单集合，使该集合及其全部下游产物失效重建；当策略记录被整体替换时须区分正常推进、整体替换与回退，整体替换使全部派生产物失效，回退返回 E_STALE_VERSION。
8. 实现并发发布互斥与本地确定性演示：多个工作进程对同一 SQLite 库发布阶段产物时使用事务条件更新与真实文件锁并比较阶段内序号，仅允许序号连续推进，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT；命令行与本地 HTTP 接口须支持两档样本、预算耗尽、策略整体替换与中途终止后恢复四类场景并导出验证报告。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地两档工单验证并行与串行联判结果逐字节一致，并覆盖策略取舍、越界降级与强制终止恢复。
