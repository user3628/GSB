当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的多模态图像编辑任务批处理与结果验证工作台，交付数据处理管线与结果验证工具，核心问题是并行调度与资源预算裁决。输入为固定随机种子生成器产出的本地小尺寸 RGB PNG 分片与一份 JSONL 编辑任务清单，每条任务含 task_id、输入分片文件名、编辑指令（中英混排的色调调节与局部区域操作描述）、允许的操作算子标签（如 crop、resize、rotate、color_shift）、期望输出尺寸与期望输出摘要声明；任务之间共享部分输入分片，且同一分片可被多条任务以不同算子链引用。另附一份 YAML 调度配置，描述并行工作进程上限、全局总操作步数预算、单工作进程步数配额、单任务执行时间预算、每任务允许的最大算子链长度与可达性规则。编辑算子为确定性实现：crop、resize、rotate 与 color_shift 均在浮点域计算并按整数运算完成最终取整。系统按算子链逐步执行，要求全程可中断恢复、版本可追溯、拒绝不可达算子链，并在预算约束下做出可解释的调度决策。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy 与 Pillow，全部依赖在 Windows 本地可用。
准备本地样本生成脚本，以固定随机种子产出至少 4 个 PNG 分片、JSONL 编辑任务清单与 YAML 调度配置，不依赖网络下载或附件。
确认工作区可写，为检查点、导出产物与锁文件准备独立工作目录，无需容器或外部服务。
使用本地命令行与 HTTP 端口运行演示，验证预算裁决、不可达算子链拒绝与中断恢复行为。

业务要求：
1. 实现算子链解析与可达性校验阶段：按任务清单声明的操作算子标签与编辑指令生成有序算子链，校验每个算子名在算子表中存在、链长不超过配置上限、上游算子输出尺寸可被下游算子接受（resize 目标尺寸为正、rotate 角度在合法区间、crop 区域与当前尺寸求交后非空）；不可达链须返回带 task_id、算子位置与具体原因的 E_CHAIN_INVALID 并避免进入执行。
2. 实现确定性编辑算子内核：crop、resize、rotate、color_shift 四个算子均以显式坐标与整数取整规则实现，resize 采用最近邻与双线性可选模式，rotate 采用固定角度采样与边界裁剪，color_shift 在浮点域计算后按 8 位量化钳制；同一输入与算子链必须产生逐像素一致输出，禁止依赖任何真实生成模型、外部图像服务或非确定性库默认行为。
3. 实现任务级预算裁决调度器：以任务为调度单元，在全局总操作步数预算、单工作进程步数配额与并行进程上限三重约束下决定接纳顺序与并发度；接纳前依据算子链长度与输入尺寸预估步数消耗，允许同分片被多任务复用但须计入各自消耗，超预算任务记录为未接纳并给出原因，保证任意时刻累计消耗不超过全局预算。
4. 实现并行执行与确定性归约：使用本地进程池并行执行已接纳任务，各任务结果按 task_id 全局排序后再归约，使并行运行的输出摘要、尺寸声明比对与验证报告与单进程顺序执行逐字节一致；工作进程异常须以结构化错误对象记录并保留已完成任务结果，不得以进程超时视为已终止失控代码。
5. 实现持久化阶段检查点：每个任务在解析校验、算子链执行、尺寸比对、导出验证四阶段完成时以原子方式写入含 task_id、阶段名、输入分片内容指纹、配置版本、产物摘要与单调序号的记录；写入过程任意位置中断不得留下半写记录，恢复时必须忽略损坏、不完整或序号重复的记录，从最近一致检查点继续。
6. 实现优雅停止与恢复一致性：进程收到停止请求时完成当前不可拆分任务后退出，不承诺强制终止后生成退出报告，强制终止后的恢复依赖已写入的持久化记录；恢复后最终导出摘要、尺寸比对结果与验证报告必须与一次从零完整运行的对应产物逐字节一致，且检查点序号连续推进。
7. 实现版本变化检测与增量失效传播：当输入分片像素内容、编辑指令、算子链、调度预算或可达性规则任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；失效原因与指纹须在查询接口中可观测。
8. 提供并发发布保护、稳定业务错误码与本地确定性演示：多工作进程对同一工作区发布阶段产物时使用真实文件锁并比较任务内序号，仅允许序号连续推进，落后、重复或跨任务错位发布返回 E_STALE_CHECKPOINT，请求非法阶段跳转或缺失前置阶段产物返回 E_INVALID_STAGE；命令行与本地 HTTP 接口支持导入分片与任务清单、触发分阶段执行、查询状态与版本指纹、查看预算消耗与未接纳原因、请求停止与执行恢复；演示数据至少 4 个分片与 5 条任务，含共享输入分片的复用、至少 1 条不可达算子链与 1 条必然超预算任务，一次完整运行生成固定摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
