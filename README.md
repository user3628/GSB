当前是空白工作区，需从零构建一个本地可运行的 RoPE 位置编码算子与交互式诊断应用，交付可交互的专业应用与可重复演示。输入为固定随机种子生成的本地 .npz 张量分片，包含查询与键向量（形如 [批量, 头数, 序列长度, 头维度]，覆盖短序列、长序列、奇数头维度与批量大于 1 的样本），另附形状清单与一份 YAML 编码配置，声明基础频率、缩放方式（不缩放、线性插值缩放、NTK 分段缩放）、缩放系数、旋转角度分块大小与数值容差。算子需实现分块旋转、查询键点积打分与注意力权重归一化，并支持对配置参数的会话内编辑后重算。诊断应用需提供本地 HTTP 接口与命令行，支持导入分片、编辑编码配置、查询各阶段状态与版本指纹、请求停止与恢复、查看逐步旋转角度与打分明细，并能在配置变更后仅重算受影响阶段。

任务环境与准备：
在 Windows 上安装 Python 3.10 或以上版本，并创建虚拟环境。
安装 numpy 与 fastapi，以及 uvicorn 作为本地 HTTP 服务运行时。
无需 GPU、外部模型或网络服务，全部样本由本地固定随机种子生成器产出并保存为 .npz 文件。
准备至少 3 个张量分片与形状清单、一份 YAML 编码配置，以及用于错误注入的非法配置样本。
运行前置检查确认 Python 与依赖可导入，演示脚本可在本地回环地址启动服务。

业务要求：
1. 实现 RoPE 分块旋转核心：对查询与键张量按配置的旋转角度分块大小沿头维度成对旋转，奇数头维度时最后一维不旋转并显式记录，支持线性插值缩放与 NTK 分段缩放两类频率缩放；输出旋转后张量与位置-通道旋转角度表，同一输入与配置必须产生逐字节一致结果。
2. 实现旋转后查询键打分与注意力归一化：按因果掩码开关计算查询键点积，先减去行最大值再在对数域做 softmax 归一化，输出注意力权重与每行归一化因子；当出现 NaN、Inf 或归一化因子为零时须返回带分片标识、行块序号与步索引的 E_NUMERIC，不得静默输出空结果。
3. 实现交互查询的延迟预算与缓存一致性：单次查询（旋转角度明细、打分摘要或权重统计）须在可配置延迟预算内返回，超出预算时返回带查询标识与已耗时字段的 E_LATENCY_BUDGET 结构化错误而非阻塞等待；缓存键须包含分片内容指纹、配置版本与旋转角度表指纹，命中后结果须与重新计算逐字节一致。
4. 实现配置变更后的增量重算与全量一致性校验：会话内修改基础频率、缩放方式、缩放系数或分块大小时，依据内容摘要构成的版本指纹识别受影响的最早阶段（频率生成、分块旋转、打分归一化），仅重算该阶段及其下游，未受影响上游结果复用；增量结果须与从零全量构建的旋转角度表、注意力权重与统计摘要逐字节一致，不一致须返回 E_INCREMENTAL_MISMATCH 并附差异阶段。
5. 实现阶段检查点持久化与优雅停止恢复：每个阶段完成时以原子方式写入含阶段名、分片内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；进程收到停止请求时完成当前不可拆分单元后退出，不承诺强制终止后生成退出报告；恢复后最终旋转张量摘要与注意力权重须与一次从零完整运行逐字节一致。
6. 实现并发发布保护与稳定业务错误码：多个工作进程对同一工作区发布阶段产物时使用文件锁并比较序号，仅允许序号连续推进，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT；请求非法阶段跳转、缺失前置阶段产物、非法缩放系数或分块大小为零时返回 E_INVALID_STAGE 或 E_INVALID_CONFIG 并附可读原因。
7. 实现峰值内存约束下的执行调度：在可配置峰值内存上限内规划旋转后张量、行块工作区与角度表缓冲的占用，超预算时按行块或批次拆分执行并记录拆分决策，或返回带预算明细的 E_MEMORY_BUDGET；不得以运行时内存溢出作为控制手段，调度决策须在诊断查询中可观测。
8. 提供可交互应用与本地确定性演示：命令行与本地 HTTP 接口支持导入 .npz 分片与配置、编辑编码配置、触发分阶段计算、查询各阶段状态与版本指纹、查看旋转角度与打分明细、请求停止、执行恢复、导出结果；演示数据至少 3 个分片，覆盖短序列、长序列与奇数头维度，一次完整运行生成固定摘要，并演示一次配置变更后的增量重算与一次错误注入。
