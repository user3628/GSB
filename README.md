当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的 LLM 预训练数据配比与去重增量更新管线及结果验证工具。输入为若干本地 JSONL 数据分片，每条样本含 id、source、lang、text 四个字段，由固定随机种子的本地生成器产出，覆盖中英混排、跨分片近似重复样本、同一 source 下多个 lang 层以及少量空文本异常样本。管线按四个阶段推进：规范化与 SimHash 近似去重（Unicode NFKC、空白折叠、小写化后计算 64 位 SimHash，以 4 个 16 位桶索引候选并在海明距离阈值内确认重复）、按 source 与 lang 分层配比（以空白切分估计 token，按目标权重用最大余数法分配采样数）、混合集组装（按确定性顺序抽样并在同分时按样本 id 仲裁）、一致性校验（产物摘要与分层统计）。管线需支持增量更新：当某个分片被替换、某层目标权重调整或去重参数变更时，识别受影响的最早阶段及其下游并重建，未受影响上游产物继续复用。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy；确保命令行可调用 python 与 pip。
创建全新工作目录作为工作区，本地数据分片与生成器脚本均在工作区内生成，不依赖外部数据集或网络。
准备本地确定性样本：至少 3 个 JSONL 分片，含跨分片近似重复文本、中英混排语言层与少量空文本样本，全部由固定随机种子的本地脚本产出。
确认工作区可创建文件锁文件与临时目录，用于原子写入与并发发布保护验证。

业务要求：
1. 实现规范化与 SimHash 去重阶段：对 text 做 Unicode NFKC、空白折叠与小写化，计算 64 位 SimHash，用 4 个 16 位桶索引候选并在海明距离阈值内确认重复；空文本须返回带样本 id 的 E_EMPTY_TEXT，同输入与配置必须产生逐字节一致的重复判定结果与保留清单。
2. 实现分层配比阶段：按 source 与 lang 统计样本数与 token 估计（按空白切分），依据配置目标权重以最大余数法分配采样数，余数并列时按 source 与 lang 排序做确定性仲裁；输出各层分配数与总混合集，空层须保留并标注，禁止静默丢弃某层。
3. 实现持久化阶段检查点：每阶段完成时以原子方式写入含阶段名、输入分片内容指纹、配置版本、产物摘要与单调序号的记录，写入过程任意位置中断不得留下半写记录；恢复时必须忽略损坏、不完整或序号重复的记录，从最近一致检查点继续推进。
4. 实现优雅停止与恢复一致性：进程收到停止请求时完成当前不可拆分样本单元后退出，不承诺强制终止后生成退出报告；恢复后最终保留清单、各层分配数与混合集必须与一次从零完整运行输出逐字节一致，且检查点序号连续推进、无跳跃与回绕。
5. 实现版本变化检测与增量失效传播：当输入分片内容、海明距离阈值、配比权重或 token 估计方式任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建；未受影响上游产物继续复用，失效原因与指纹须在查询接口中可观测。
6. 实现增量与全量一致性校验：提供单分片替换与单配置变更入口，仅重建失效链路后与从零全量构建的去重清单、各层分配数与混合集做逐字节摘要比对；不一致须返回 E_INCREMENTAL_MISMATCH 并附首个差异样本 id 或层标识，禁止以近似比较替代逐字节比对。
7. 实现并发发布保护与稳定业务错误码：多工作进程对同一工作区发布阶段产物时使用真实文件锁并比较阶段内序号，仅允许序号连续推进，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT；请求非法阶段跳转或缺失前置阶段产物返回 E_INVALID_STAGE，被拒绝方不得覆写已有产物。
8. 提供本地 HTTP 与命令行交互接口及确定性演示：支持导入分片、触发分阶段执行、查询各阶段状态与版本指纹、执行单分片替换与单配置变更、请求停止、执行恢复、导出混合集与校验报告；演示数据至少 3 个分片，含跨分片近似重复与中英混排语言层，一次完整运行生成固定摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证去重、分层配比、增量重建与检查点恢复，结果与全量运行逐字节一致并给出错误码。
