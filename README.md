当前是空白工作区，需从零构建一个本地可运行的对话语音情感与对话理解引擎，交付可集成的领域组件与完整示例。输入为固定随机种子生成器产出的本地 WAV 分片（16 kHz、单声道、16 位 PCM），每个分片模拟一段多轮对话，包含若干按毫秒标注的说话人轮次，轮次内含语音段、停顿与情感起伏；另附一份 JSON 对话清单，逐轮声明说话人编号、轮次起止毫秒、参考情感标签（平静/高兴/愤怒/悲伤）与参考对话行为标签（陈述/提问/确认/打断），作为真值与观测来源；清单还声明每个分片的样本总数与轮次数，导入时须以实际样本数与轮次边界校验清单一致性。系统不依赖任何真实语音模型、预训练权重或外部服务，情感识别以本地确定性声学特征与轻量分类器实现，对话理解以轮次转移与上下文状态机实现。核心难点是对话状态随轮次演进的持久化、版本识别与中断恢复一致性：引擎需按轮次推进状态，支持阶段检查点、优雅停止恢复、输入变化导致的增量失效重建，并在并发发布时保证状态序号连续。

任务环境与准备：
安装 Python 3.11 或以上版本，并安装 NumPy 与 SciPy（版本以本地 wheel 可用为准），无需 GPU 与网络服务。
确认工作区为空目录，生成器脚本将写入固定随机种子产出的 WAV 分片与 JSON 对话清单。
运行环境须支持文件锁与原子重命名语义（Windows 本地 NTFS），并允许子进程访问同一工作区目录。
准备可写临时目录用于检查点与阶段产物，不依赖任何真实账号、线上站点或付费资源。

业务要求：
1. 实现逐轮声学特征提取与情感打分：按可配置帧长与帧移对 16 位 PCM 做汉宁窗分帧，逐帧计算对数能量、过零率、频谱质心与梅尔频带能量，按轮次汇总为固定维度特征向量；再以本地确定性轻量分类器（基于固定哈希投影与余弦相似度）输出四类情感分数与置信度。同一分片与配置必须产生逐字节一致的特征与分数，分片样本数与清单声明不符须返回 E_INPUT_LENGTH。
2. 实现对话行为识别与轮次状态演进：依据轮次起止、语音停顿比例、能量变化与上一轮情感分数，按可配置规则与转移权重判定每轮的对话行为（陈述/提问/确认/打断），并维护对话状态（当前主导情感、累计情感趋势、已发生打断次数）。状态演进必须依赖显式的前序轮次结果与清单真值，不得从缺失信息推断；轮次边界非法或重叠须返回 E_INVALID_TURN。
3. 实现阶段检查点持久化：每个分片按特征提取、情感打分、行为识别、状态汇总四阶段完成时，以原子方式写入包含分片标识、阶段名、输入内容指纹、配置版本、状态序号、产物摘要的记录；写入过程任意位置中断不得留下半写记录，恢复时必须忽略损坏、不完整或序号重复的记录并从最近一致检查点继续。
4. 实现优雅停止与恢复一致性：进程收到停止请求时完成当前不可拆分轮次单元后退出，不承诺强制终止后生成退出报告；恢复后最终逐轮情感标签、对话行为、状态演进轨迹与汇总摘要必须与一次从零完整运行的对应产物逐字节一致，且检查点序号连续推进、无跳跃与无回退。
5. 实现版本变化检测与增量失效传播：当分片样本内容、轮次标注、特征参数、分类器投影、转移权重或阈值配置任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游状态失效并重建；未受影响上游产物继续复用，失效原因与指纹须在状态查询接口中可观测。
6. 实现并发状态发布保护与业务错误码一致性：多个工作进程对同一工作区发布状态时使用文件锁并比较状态序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT；请求缺失前置阶段产物或非法阶段跳转返回 E_INVALID_STAGE；当检测到检查点记录被整体替换（序号回退、指纹不匹配或摘要不符）时须区分回退、篡改与正常推进，仅正常推进可被接受。
7. 实现情感与行为指标汇总及异常链路：依据清单参考标签按可配置容差计算逐轮准确率、混淆矩阵、状态轨迹偏差与打断识别率，并统计各阶段耗时；当出现 NaN、Inf 分数、空轮次或声学特征维度不匹配时，在对应阶段返回带分片标识、轮次与阶段名的业务错误码（E_NUMERIC、E_EMPTY_TURN、E_FEATURE_DIM），不得静默跳过或部分写入。
8. 提供可集成组件接口与本地确定性演示：以库函数与命令行提供导入分片与清单、执行分阶段状态演进、查询逐轮结果与各阶段状态及版本指纹、请求停止、执行恢复、导出对话理解摘要；演示数据至少 3 个分片，覆盖 2 至 3 个说话人、中英混排轮次、情感转折与打断，一次完整运行生成固定摘要，并演示在轮次间触发停止后恢复以及用注入的非法轮次边界和声明长度不符验证错误码，最终恢复结果与完整运行一致。
