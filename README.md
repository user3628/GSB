奖励建模团队要把历史偏好标注整理成可训练的偏好对特征包，当前工作区还没有任何实现。程序内置固定种子生成器在本地产出 JSONL 标注分片，每条含 pair_id、prompt、chosen、rejected、source、lang 与标注一致度分值，覆盖中英混排、同一 prompt 下多个偏好对、单侧回复为空与分值越界等情形；另有一份 YAML 特征配置声明词项权重、长度惩罚系数、特征投影矩阵维度与各 source 的采样预算。组件要把偏好对加工成带归因说明的奖励特征包：先做文本规范化与特征抽取，再按可解释的因子分解合成偏好强度，随后在全局 token 预算与单 source 配额下决定保留哪些偏好对，最后产出可复核的归因报告；需求方会反复修订标注与配置，因此加工结果必须支持按最小受影响范围重建，而不是每次整体重算。

任务环境与准备：
安装 Go 1.22 或更新版本，确认 GOPATH 与工作区目录在 Windows 上可写。
安装 SQLite 3 命令行工具用于检查本地库文件，Go 侧使用纯 Go 驱动避免 CGO 依赖。
运行 go mod init 初始化模块，并准备固定种子生成器输出目录与本地 SQLite 文件目录，无需网络访问。
确认数据库文件所在目录未被编辑器占用，避免文件锁在 Windows 上因共享句柄失败。

业务要求：
1. 实现文本规范化与词项特征抽取阶段：对 prompt、chosen、rejected 做 Unicode NFKC、空白折叠、全半角统一与小写化，按中文单字与拉丁连续串切分并记录字符偏移，输出每条偏好对的词项集合、长度与语言标记；chosen 或 rejected 为空、仅含标点时须返回带 pair_id 与字段名的 E_EMPTY_TEXT，同一输入与配置必须产生逐字节一致的特征记录。
2. 实现偏好对的因子分解打分：把偏好强度分解为长度惩罚、词项重叠方向、标注一致度三个可解释因子，各因子在对数域计算并输出数值、对数贡献与最终强度的有效位数；任一因子不可计算时回退到配置下限并记录回退原因，出现 NaN 或 Inf 时返回带 pair_id 与因子名的 E_NUMERIC，不得静默置零。
3. 实现奖励特征向量构造与量化误差界：按配置投影矩阵把词项特征映射到固定维度并做单位归一化，再以可配置位宽做定点量化，逐维记录缩放因子与量化误差界；投影矩阵维度与特征维度不符、矩阵含 NaN 或量化缩放因子为零时返回带行号与列号的 E_DIM_MISMATCH，误差界须由缩放因子与本地高精度参考向量显式给出。
4. 实现预算约束下的偏好对保留裁决：在全局 token 预算与单 source 配额共同约束下，按偏好强度与语言覆盖要求决定保留哪些偏好对，采用确定性的配额分配与并列仲裁规则，输出保留清单、被淘汰对及其淘汰依据；某 source 可用对为零或配额小于最小保留单位时须保留空层记录并说明，不得静默跳过该来源。
5. 实现阶段检查点与优雅停止恢复：每个阶段以 SQLite 事务写入含阶段名、输入内容指纹、配置版本、产物摘要与单调序号的记录，同一阶段同一输入只允许一条有效记录；收到停止请求时完成当前不可拆分的偏好对单元后退出，被强制终止后仅凭已提交事实恢复，恢复后的特征记录、保留清单与归因报告须与一次完整运行逐字节一致。
6. 实现配置与标注变化的指纹识别与失效传播：当某条标注被编辑、某 source 分片被整体替换、词项权重、长度惩罚、投影矩阵或预算配置变化时，由各阶段内容摘要构成版本指纹并区分正常追加、标注级编辑、整体替换与回退四种情形，只让受影响的最早阶段及其下游产物失效重建；失效范围须可查询并附首个差异 pair_id。
7. 实现增量重建与全量一致性校验：提供单标注编辑与单 source 分片替换入口，仅重建失效链路后与从零全量构建的因子打分、特征摘要、保留清单与归因报告做逐字节比对，不一致须返回 E_INCREMENTAL_MISMATCH 并附首个差异 pair_id 与两路取值；整体替换导致的失效不得波及未涉及的 source 产物。
8. 实现并发发布保护、整体替换识别与稳定业务错误码：多工作进程发布阶段产物时使用 SQLite 条件更新与真实文件锁并比较阶段内序号，仅允许序号连续推进，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT；请求非法阶段跳转、缺失前置产物或提交版本号回退的快照时须返回对应业务码并附诊断上下文。
