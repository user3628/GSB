当前是空白 Windows 工作区，需要从零构建一个面向本地多租户任务调度平台的政策迁移组件，供平台控制面集成。平台的历史策略以旧版扁平 JSON 存储，包含租户标识、并发上限、优先级区间、抢占开关与若干已废弃字段；新版策略模型改为分层结构，引入继承自父租户的配额引用、权重化抢占档位与显式生命周期区间。运维团队需要把大量旧格式策略迁移到新模型，同时支持两种可互换的新版持久化格式：紧凑二进制格式（含魔数、格式版本字节、长度前缀、CRC32 校验与可选字段存在位图）与分片 JSON 行格式（每行一条策略记录）。迁移中会出现字段语义变化、区间重叠、父租户引用缺失与部分废弃字段无法映射等情况，需要在接受、降级接受与拒绝之间做裁决，并保证迁移批次原子生效与进程被强制终止后可依据持久化事实恢复。用户通过本地 HTTP 接口提交迁移批次、查询裁决明细与执行计划差分。

任务环境与准备：
在 Windows 上安装 Python 3.10 或以上版本，并确保 pip 可用。
SQLite 使用 Python 标准库 sqlite3，HTTP 服务使用标准库 http.server 即可，无需额外网络框架。
在空白工作区创建项目目录，准备本地固定样本：一份旧版扁平策略 JSON、一份含废弃字段与重叠区间的边界样本、一份父链成环样本。
无需外部网络、账号或数据库服务，全部数据与测试使用本地确定性样本与本地回环 HTTP 服务。

业务要求：
1. 实现旧版扁平策略与新版的解析：旧版含租户标识、并发上限、优先级整数区间、抢占开关与废弃字段，新版含父租户引用、权重化抢占档位与生命周期起止毫秒；解析时校验租户标识唯一、并发上限为正整数、优先级区间上下界有序、生命周期起止有序且起步不早于声明纪元时间，非法记录返回 E_POLICY_INVALID 并附字段路径。
2. 实现两种新版持久化格式的编解码：紧凑二进制必须含魔数、格式版本字节、每条记录长度前缀、CRC32 校验与可选字段存在位图；分片 JSON 行每行含租户标识、父租户引用、并发上限、抢占档位、生命周期与可选扩展字段。两格式往返编解码后语义等价的策略必须得到相同的规范化记录摘要，任一字节损坏须返回 E_RECORD_CORRUPT 并指明记录序号。
3. 实现格式协商与版本兼容矩阵：导入前检测输入格式与格式版本，按显式声明的兼容矩阵给出接受、降级接受与拒绝三种结论；旧版缺父租户引用或抢占档位精度较低时降级接受，按声明规则补齐默认继承与档位并记录降级明细；高版本含未知必填字段时拒绝并返回 E_FORMAT_UNSUPPORTED；所有结论与原因须写入迁移报告可供核对。
4. 实现跨版本语义迁移裁决：把旧版扁平策略映射到新版分层模型时，须判定废弃字段是否可迁移、优先级区间是否与生命周期内已有策略重叠、父租户引用是否存在于同批或已持久化数据中；可完整映射的接受并输出映射依据，需补齐的降级接受并记录补齐字段，无法映射或引用缺失的拒绝并返回 E_MIGRATION_REJECTED 并附拒绝原因清单。
5. 实现区间重叠与父链检测：同一租户在生命周期区间内的策略不得与该租户已生效策略的生命周期重叠，重叠时返回 E_LIFETIME_OVERLAP 并附双方起止毫秒；父租户引用链不得超过配置的最大深度且不得成环，成环返回 E_PARENT_CYCLE 并附环上租户标识，超出深度返回 E_PARENT_DEPTH_EXCEEDED；检测须在批次生效前完成且不得部分写入。
6. 实现迁移批次原子生效与版本识别：整批迁移须在同一事务边界内全部生效或全部不生效，任一条被拒绝则整批回滚并保留旧策略集合；批次携带基础快照版本，基础版本非当前版本时返回 E_STALE_BASE 且不改动任何状态；同一基础版本的两个并发迁移仅一个成功、另一个必须收到 E_STALE_BASE，已生效批次须产出单调递增的策略集合版本。
7. 实现单写者迁移与多读者查询的并发一致：迁移执行与策略集合版本推进按单写者串行，多个只读查询（裁决明细、执行计划差分、父链视图）可并发读取某一完整提交版本；同一批次标识重复提交只执行一次、其余等待并复用结果，内容不一致返回 E_CONFLICTING_BATCH；查询不得看到部分策略已迁入新版而依赖它的父链视图仍指向旧版的中间状态。
8. 使用 SQLite 持久化旧版与新版策略、迁移批次、裁决明细与意图日志，迁移前先写意图记录再提交事务；进程在批次裁决或写入中途被强制终止后重启须扫描未完成意图，把策略集合回滚到最后一个完整版本或将批次标记为已中止，并输出仅基于已持久化事实的恢复报告；API 覆盖迁移批次提交、按批次查询裁决明细、执行计划差分、父链视图与恢复报告查询，失败响应为含业务码的 JSON。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
