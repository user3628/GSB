当前是空白工作区，需从零构建一个本地可运行的多模态特征对齐存储互操作引擎与诊断工作台，核心难点是跨格式编解码与版本兼容。输入为固定随机种子生成的本地确定性样本：一组文本特征分片（.npz，含 id、64 维文本向量、语言标签）与一组视觉特征分片（.npy 加 JSON 侧车，含 id、96 维视觉向量、对应文本 id、来源算子标签），另有两份结构版本不同的对齐工程清单：版本 2 以浮点缩放系数与显式投影矩阵声明跨模态投影，版本 1 以整数百分比缩放、无投影矩阵字段且视觉维度登记为 64。引擎需在统一中间表示上完成维度校验、投影映射、特征拼接与对齐摘要，并与三份本地落盘格式（内部 JSON 工程格式、.npz 向量包、以及带侧车 JSON 的 .npy 目录包）做双向编解码；导入旧版清单时须做显式升级转换并可回导验证。样本不依赖任何真实模型、GPU 或外部服务。

任务环境与准备：
确认 Windows 本地具备 Python 3.10 或以上版本，可创建虚拟环境并安装 NumPy 与 PyYAML（版本以本地可用为准，无需联网检查）。
准备任务目录结构：样本生成器脚本按固定随机种子产出文本特征与视觉特征样本，以及版本 1 与版本 2 两份对齐工程清单，全部落盘为本地文件。
确认本地未被占用的 HTTP 监听端口用于诊断工作台，命令行入口可在无网络环境下运行。
准备本地临时工作区目录用于检查点、导出产物与注入异常样本，删除目录后可从生成器重建全部输入。

业务要求：
1. 实现统一中间表示与三种落盘格式的双向编解码：内部模型以分片标识、模态类型、向量矩阵、维度、模态元数据与结构版本描述一份对齐工程；实现内部模型与内部 JSON 工程格式、.npz 向量包、.npy 加侧车 JSON 目录包之间的双向转换，浮点向量须记录量化位宽与逐维缩放因子，转换后的向量须可按缩放因子还原到声明精度，不得出现维度错位或分片标识丢失。
2. 实现结构版本 1 清单的兼容解析与显式升级：版本 1 中跨模态缩放为整数百分比、视觉维度登记为 64 且缺少投影矩阵；导入时须按清单中显式声明的实际视觉维度做维度纠正、按可配置规则换算缩放系数并生成确定性投影矩阵，升级后的内部工程须可通过回导生成版本 2 等价结构，且回导结果与直接导入版本 2 的内部工程在向量矩阵、维度与缩放系数上逐字节一致。
3. 实现维度校验与投影映射阶段：对文本与视觉分片按文本 id 关联，校验视觉向量实际维度与清单声明维度一致、投影矩阵形状与两模态维度匹配；不一致须返回 E_DIM_MISMATCH 并附分片标识、声明维度与实际维度，且不得部分写入。投影映射在浮点域进行，映射后向量做单位归一化，同一输入与配置须产生逐字节一致的映射结果与余弦相似度矩阵。
4. 实现特征拼接与对齐摘要阶段：把映射后的视觉向量与对应文本向量按可配置拼接规则合成为对齐向量，输出逐样本对齐置信度（由余弦相似度与来源算子权重合成）、模态覆盖统计与维度清单；来源算子标签缺失或某文本 id 在视觉侧无对应时须在摘要中标注为未覆盖并记录原因，不得静默补零。拼接规则或权重变化须反映在摘要的新配置版本指纹中。
5. 实现阶段检查点与优雅停止恢复：对齐流程按维度校验、投影映射、拼接汇总、格式导出四阶段推进，每分片每阶段完成时以原子方式写入含分片标识、阶段名、输入内容指纹、结构版本指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分分片单元后退出，不承诺强制终止后生成退出报告；恢复后最终对齐向量、摘要与导出文件须与一次从零完整运行逐字节一致。
6. 实现版本变化检测与失效传播：当分片向量内容、结构清单版本、投影矩阵、拼接规则、量化位宽或来源算子权重任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；失效原因、命中指纹与复用范围须在查询接口中可观测，禁止用旧版本产物顶替重建结果。
7. 实现并发发布保护与稳定业务错误码：多个工作进程对同一工作区发布阶段产物时使用文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT；请求非法阶段跳转或缺失前置阶段产物返回 E_INVALID_STAGE；检测到检查点被整体替换（序号回退或摘要不匹配）时须识别版本变化并返回 E_STALE_CHECKPOINT 附差异说明，而非静默继续。
8. 提供本地 HTTP 与命令行诊断工作台及确定性演示：支持导入分片与两份版本清单、触发分阶段对齐、执行三种格式互转与旧版回导验证、查询各阶段状态与版本指纹、查看未覆盖样本与降级项、请求停止、执行恢复、导出对齐工程；演示数据至少含 3 组文本与 3 组视觉分片、中英混排、至少 1 个视觉维度与声明不符的样本，一次完整运行生成固定摘要，并用注入的非法维度与错位阶段请求验证错误码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证三格式双向互转保真、旧版清单回导一致、停止恢复结果一致及注入异常返回对应错误码。
