当前是空白工作区，需要在 Windows 本地从零构建一个资源编排依赖图工作台，用于在多格式互操作与版本兼容的前提下完成资源依赖的编排与诊断。编排对象为若干服务资源，每个资源声明标识、副本预算、依赖的父资源列表、期望格式版本与权重；依赖关系形成有向图，用于计算拓扑分层、影响面与编排批次。为对接外部工具，编排快照需要支持三种可互换的持久化格式：紧凑二进制（含魔数、格式版本字节、长度前缀、CRC32 与可选字段存在位图）、分片 JSON 行（每行含资源标识、父资源列表、预算与权重）与较旧的 YAML 子集行格式（仅含标识与父列表）。三种格式字段可选性不同、权重精度不同（二进制为定点千分比，JSON 为浮点，YAML 缺权重），导入时必须协商版本并按兼容矩阵处理降级。工作台还需在导入与增量更新后重建拓扑分层、影响面与编排批次，并把新旧快照的统计整体替换而不混用。所有数据来自本地确定性样本，用户通过本地 HTTP 接口提交快照、导入导出与查询诊断结论。

任务环境与准备：
安装 Python 3.11 及以上版本，使用 pip 安装 fastapi、uvicorn、numpy、pydantic 与 pytest，版本以本地可用稳定版为准
在空白工作区创建项目目录与虚拟环境，确认 Python 标准库 sqlite3、zlib、struct、json 可用
准备本地确定性样本：一份二进制格式编排快照、一份分片 JSON 行格式（含浮点权重与缺字段记录）、一份 YAML 子集行格式（无权重）、一份含依赖环的样本，全部置于本地 samples 目录
启动本地 HTTP 服务使用回环地址与固定端口，确认无外部网络与数据库依赖

业务要求：
1. 实现三种持久化格式的编解码：紧凑二进制必须含魔数、格式版本字节、每条记录长度前缀、CRC32 校验与可选字段存在位图；分片 JSON 行每行含资源标识、父资源列表、预算与权重；YAML 子集行格式每行含资源标识与父资源列表且无权重字段；导出后再导入必须得到等价资源集合，畸形记录返回业务码 E_FORMAT_INVALID 且整批不生效
2. 实现格式协商与版本兼容裁决：导入前检测输入格式与版本，按显式声明的兼容矩阵给出接受、降级接受或拒绝三种结论；旧格式缺权重或权重精度较低时走降级接受并按声明规则补齐为千分比定点值并记录降级明细，高版本含未知必填字段时返回 E_VERSION_UNSUPPORTED，并输出协商结论与依据
3. 实现权重与预算的归一化：二进制千分比定点权重、JSON 浮点权重与 YAML 缺失权重须归一化为同一内部定点表示，按调用方声明的舍入规则处理小数部分并输出每条的舍入位与累计舍入误差；预算为非负整数并做溢出检查，归一化失败的条目不得进入依赖图且须计入导入报告的拒绝清单
4. 实现拓扑分层与编排批次生成：依据归一化后的依赖图计算分层序号，要求所有父资源层级严格小于子资源层级；当依赖出现环时返回业务码 E_DEPENDENCY_CYCLE 并附环上资源标识；同层资源按归一化权重与标识稳定排序，分层与批次结果同一输入重复计算必须逐位一致
5. 实现影响面与增量更新：对某个资源变化计算受影响下游集合与需要重排的批次范围，增量片段只含受影响资源并携带基础快照版本；若基础版本不是当前版本返回 E_STALE_BASE 且不改变任何状态；受影响资源的层级与批次必须级联重算并在同一事务边界内生效，禁止出现部分资源层级已更新而其下游批次仍为旧值
6. 实现快照整体替换与版本识别：快照文件携带格式版本、快照序号与生成时间，加载时校验版本兼容性与序号单调，加载过程在资源表、依赖索引与分层批次之间原子切换，切换成功后旧快照资源才可释放；任何校验失败须保持旧快照完整可用并返回 E_SNAPSHOT_INVALID，禁止新旧快照统计混用
7. 实现并发控制与幂等：快照提交与分层重建按提交单写者串行执行，多个只读诊断查询可并发读取已提交版本；同一提交标识的重复提交只执行一次、其余等待并复用结果，同一基础版本的两个并发增量只允许一个成功、另一个返回 E_STALE_BASE；查询不得看到资源已更新而依赖索引仍为旧版本的中间状态
8. 使用 SQLite 持久化快照版本、资源、依赖条目、分层批次与意图日志，导入、增量提交与层级重建均先写意图记录再提交事务；进程在导入或重建中途被强制终止后重启须扫描未完成意图，回滚到最后一个完整快照版本或将批次标记为已中止，恢复报告只基于已持久化事实；提供本地 HTTP 接口与端到端演示脚本完成一次二进制导入、一次 JSON 降级导入、一次含环导入失败与一次强制终止后恢复

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地三格式样本验证导入导出、版本兼容裁决、分层与增量重建及恢复，输出诊断结论。
