当前为空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的低精度量化算子库与可复现实验环境，核心是并行调度与资源预算约束下的量化算子执行。输入为固定随机种子本地生成的权重张量分片与激活张量分片（.npz 文件），覆盖 8 位与 4 位量化、对称与非对称模式、逐张量与逐通道量化粒度，以及包含离群值、全零通道与含 NaN 的异常样本；另附一份算子清单与形状声明，记录每个分片需执行的量化线性算子链、各层位宽与模式、期望输出形状与精度区间。算子库需实现量化-反量化与量化域线性算子核心，并在总计算元素预算、单工作线程配额与峰值内存上限三重约束下做分片调度，使用本地进程池并行执行并按分片序号确定性归约，同时提供版本化检查点、优雅停止恢复、并发发布保护与稳定的业务错误码。交付物为可集成的算子组件、并行调度器与可复现的实验脚本。

任务环境与准备：
安装 Python 3.10 及以上版本，并确认 python 与 pip 在 Windows 命令行可用。
创建虚拟环境后安装 numpy、pyyaml 与 pytest，版本以本地可安装的稳定版为准，不引入 GPU 或网络服务依赖。
在工作区根目录准备 data 与 runs 两个空目录，用任务内附带的固定种子生成脚本产出 .npz 分片、算子清单与含 NaN 的异常样本。
确认进程池与文件锁在 Windows 下可用（使用标准库 multiprocessing 与 msvcrt 文件锁路径），并预留可写目录用于检查点与演示摘要输出。

业务要求：
1. 实现量化-反量化与量化域线性算子核心：对每个分片按配置的位宽（8 位或 4 位）、对称或非对称模式与逐通道或逐张量粒度计算缩放因子与零点，越界值钳制并记录钳制次数与位置；量化域矩阵乘须按缩放因子正确还原为浮点输出，同一输入与配置必须产生逐字节一致的输出与审计记录。
2. 实现并行分片调度器：以分片为单位，在总计算元素预算、单工作线程元素配额与峰值内存上限共同约束下决定接纳的分片与并发进程数；接纳前依据形状声明与位宽预估元素消耗与工作集，超预算分片记录为未处理并给出原因，保证任何时刻累计消耗不超预算。
3. 实现进程池并行执行与确定性归约：使用本地进程池并行处理已接纳分片，各分片的结果摘要、钳制统计与精度指标按分片序号全局排序后归约，使并行运行的汇总输出与串行顺序执行逐字节一致；工作进程异常须以结构化错误对象记录分片标识与阶段，不得以线程或进程超时描述为已终止失控计算。
4. 实现版本化检查点与优雅停止恢复：每个分片完成时以原子方式写入含分片标识、输入内容指纹、算子配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分分片单元后退出，恢复后最终输出与审计摘要必须与一次从零完整运行逐字节一致，且序号连续推进。
5. 实现版本变化检测与增量失效传播：当分片张量内容、位宽、量化模式、量化粒度、算子链或预算配置任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；失效原因与指纹须在查询接口中可观测，禁止用旧版本缓存冒充新结果。
6. 实现精度自校验与误差传播诊断：对每层输出与本地高精度参考实现按抽样位置比对，计算量化误差与相对误差上界估计，输出逐层误差贡献与最接近预算的层余量；当误差超出可配置容差时返回带分片标识、层名与最大偏差的业务码 E_NUMERIC_MISMATCH，输入含 NaN 或 Inf 时按 IEEE 语义传播并显式报告 E_NUMERIC_INPUT。
7. 实现并发发布保护与稳定业务错误码：多个工作进程对同一工作区发布分片结果时使用文件锁并比较分片序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT；请求非法阶段跳转、缺失前置分片产物、位宽非法与内存超预算时分别返回 E_INVALID_STAGE、E_MEMORY_BUDGET 并附预算明细，不得静默降级。
8. 提供可集成的算子库接口、命令行与本地确定性演示：支持导入分片与算子清单、查询各阶段状态与版本指纹、查看调度决策理由与误差诊断、请求停止与执行恢复、导出审计报告；演示数据至少 4 个分片，覆盖 8 位与 4 位、两种量化模式、逐通道粒度、离群值与含 NaN 异常样本，一次完整运行生成固定摘要并演示停止后恢复与注入异常的错误码验证。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
