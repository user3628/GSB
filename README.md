当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的激活与转置重排分块算子工作台，交付可交互的专业应用与可重复演示。输入为固定随机种子生成器产出的本地 .npz 张量分片，形状覆盖 [批量, 头数, 序列长度, 头维度] 与二维矩阵两类布局，含奇数列数、非整除分块、极端值（如 1e4 与 -1e4 混合）、全零行与含 NaN/Inf 的异常分片，另附形状清单与一份 YAML 算子配置，声明激活类型（GELU、SiLU、Sigmoid）、转置重排模式（头维度与序列维度互换、按分块瓦片重排）、行块与列块大小、求和策略与数值容差。算子需按阶段推进：激活计算、转置重排、结果归约汇总，每阶段产物可按分块粒度持久化，支持中断后从一致状态继续，并在输入或配置变化时识别失效范围重建。所有张量与形状由本地生成器确定性产出，不依赖 GPU、外部服务或真实数据集。

任务环境与准备：
安装 Python 3.10 或以上版本，并安装 NumPy 与 PyYAML 两个本地依赖，无需 GPU 与外部服务。
在工作区创建 samples 目录，用固定随机种子的本地生成器脚本产出至少 3 个 .npz 张量分片与形状清单、算子配置样例，生成脚本随项目提供以便重建相同样本。
准备本地 HTTP 服务与命令行的启动方式说明，全部读写限于工作区内路径，不访问网络与真实数据集。

业务要求：
1. 实现三种激活函数的统一分块计算内核：GELU（使用误差函数近似）、SiLU 与 Sigmoid 均按行块与列块组织计算，先减去块内参考极值再在浮点域求值，支持奇数列数与非整除分块且越界块按声明形状裁剪；同一输入与配置必须产生逐字节一致的输出张量与每块摘要。
2. 实现转置重排阶段：支持头维度与序列维度互换以及按分块瓦片重排两种模式，重排须依据分块大小把源张量切片搬运到目标布局并记录每块来源坐标与目标坐标，奇数列数与非整除分块时须处理尾块；重排后形状须与形状清单声明的目标形状一致，不一致返回 E_SHAPE_MISMATCH 并附声明形状与实测形状。
3. 实现数值稳定性与异常链路：激活计算与重排后的归约全程避免直接连乘，出现 NaN、Inf 或全零行时须在对应块返回带分片标识、块行列区间与异常值的业务码 E_NUMERIC 并保留诊断上下文，不得静默把异常值替换为零；极端值输入下的输出须落在激活函数的合法值域内。
4. 实现分块粒度的持久化检查点：每个分片在每个阶段的小块完成后以原子方式写入含分片标识、阶段名、块坐标、输入内容指纹、配置版本、块产物摘要与单调序号的记录，写入过程任意位置中断不得留下半写记录；恢复时必须忽略损坏、不完整或序号重复的记录，从最近一致块继续。
5. 实现优雅停止与恢复一致性：进程收到停止请求时完成当前不可拆分块后退出，不承诺强制终止后生成退出报告；恢复后最终激活输出、重排张量与汇总摘要必须与一次从零完整运行的对应产物逐字节一致，且检查点序号连续推进、无跳跃与重复，已完成块不得重复计算。
6. 实现版本变化检测与增量失效传播：当分片张量内容、激活类型、重排模式、分块大小或求和策略任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段与块区间，使该区间产物及其全部下游块失效并重建，未受影响块继续复用；失效原因与指纹须在查询接口中可观测。
7. 实现并发块发布保护与业务错误码：多个工作进程对同一工作区发布块产物时使用真实文件锁并比较块序号，仅允许序号连续推进，落后、重复或跨块错位发布须被拒绝并返回 E_STALE_CHECKPOINT；请求缺失前置块阶段、非法阶段跳转或跨越未完成块继续时返回 E_INVALID_STAGE 并附请求阶段与当前可用序号。
8. 提供本地 HTTP 与命令行交互应用及确定性演示：支持导入 .npz 分片与配置、触发分阶段计算、查询各阶段状态与版本指纹、查看块级数值诊断与失效原因、请求停止、执行恢复、导出结果摘要；演示数据至少 3 个分片，覆盖奇数列数、非整除分块、两类重排模式与含 NaN 异常分片，一次完整运行生成固定摘要，并演示阶段间停止后恢复结果与完整运行逐字节一致。
