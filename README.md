内部搜索排序组刚完成精排与重排模块的立项评审，工作区尚无任何代码，需要在本地从零实现一个可集成的精排重排计算与结果验证工具。业务对象是精排与重排链路上的数值精度问题：同一批候选在定点量化、对数域特征加权与重排融合过程中会产生可观测的误差累积，评分差异会改变候选排序与最终展示位次，因此每次排序结果都必须附带可复核的误差上界，并能与本地高精度参考结果逐位比对。输入由程序内置固定种子生成器在本地产出 JSONL 样本分片：每片含一批候选文档（doc_id、粗排分数、类目、语言、若干数值特征）与对应查询组（query_id、locale、channel），覆盖数值极端值、重复候选、缺失特征与空查询组等情形；另附一份带单调版本号的排序策略快照，声明特征权重、重排窗口大小、多样性惩罚系数、定点量化位宽与缩放规则、评分误差容差。系统不依赖任何真实排序模型或外部服务，全部计算在本地确定性完成。

任务环境与准备：
安装 Go 1.22 或以上版本，确认可离线编译标准库与 SQLite 驱动；如使用第三方 SQLite 驱动，需在任务开始前完成依赖下载。
确认工作区为空目录，程序内置的固定种子生成器与样本清单由实现方在代码中提供，不依赖外部数据附件。
确保本地回环端口可用以启动 HTTP 接口，SQLite 数据库文件落在工作区内，无需外部服务或容器环境。

业务要求：
1. 实现候选特征装配与定点量化阶段：对每个候选按 doc_id 与 query_id 以固定哈希生成嵌入并与数值特征拼接，缺失特征写入显式缺失标记，按策略声明的量化位宽与缩放规则做定点量化，逐维记录缩放因子与量化步长；同一输入与配置必须产生逐字节一致的特征记录，缩放因子为零或特征维度与声明不符时返回带分片标识与候选标识的 E_QUANT_INVALID。
2. 实现对数域精排打分核心：以显式特征权重在自然对数域或缩放定点域累加打分，禁止直接累乘概率，并对每个候选输出分数分量明细、对数贡献与有效位数；累加中出现非有限值、全部分量不可用或分数超出声明位宽时返回带候选标识与分量名的 E_NUMERIC，不得静默钳制后继续排序。
3. 实现候选误差上界推导与参考比对：每个候选的分数须附带由量化步长、累加顺序与特征权重推导的误差上界，上界推导依据随结果保留；再与本地高精度参考实现按显式抽样位置比对，偏差超出策略容差的候选须报告最大绝对偏差、相对偏差与越界维度，并返回 E_TOLERANCE_EXCEEDED。
4. 实现重排选择与排序稳定性裁决：在可配置窗口内做贪心多样性选择，分数由精排分与类目、语言多样性惩罚合成，窗口大于候选数时按候选数截断并记录；误差上界跨越相邻候选分差的位次须标记为不稳定位次并记录跨越幅度，窗口为零、惩罚系数为负或候选重复出现时返回带查询组标识的 E_RERANK_INVALID。
5. 实现基于策略快照与样本内容摘要的版本指纹与增量失效传播：当分片候选内容、查询组、特征权重、量化位宽、重排窗口或容差任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段与最小候选集合，使该集合及其全部下游打分与重排结果失效重建，未受影响候选结果继续复用；增量重建结果须与从零全量重算逐字节一致。
6. 实现 SQLite 事务化的阶段检查点与优雅停止恢复：每分片每阶段完成时在单个事务内写入含阶段名、分片输入内容指纹、策略版本、产物摘要与单调序号的记录，同一分片同一阶段只允许一条有效记录；写入任意位置中断不得留下半写记录，收到停止请求时完成当前不可拆分单元后退出，恢复后最终打分、重排位次与误差报告须与一次连续执行逐字节一致。
7. 实现并发发布保护与陈旧发布拒绝：多个工作进程对同一数据库发布阶段产物时使用事务条件更新与真实文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT；检测到记录被整体替换（序号回退、摘要与内容不符）时须区分正常推进、整体替换与回退，整体替换使全部派生结果失效重建。
8. 提供本地 HTTP 与命令行交互接口及确定性演示：支持导入分片与策略快照、触发分阶段执行、查询各阶段状态与版本指纹、查看候选分数分量与误差上界、查看不稳定位次与失效原因、请求优雅停止、执行恢复、导出排序结果与验证报告；演示数据须用内置生成器覆盖极端数值、重复候选与至少两个查询组，完整运行产生可复现摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
