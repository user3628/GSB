语音内容平台的发音评测线准备把“音素边界是否可靠”变成可复核的本地能力，独立开发者接到的起点是一份说明文档和未初始化的空目录。输入由程序内置固定种子生成器在 Linux（WSL Ubuntu）本地确定性产出：16 kHz、单声道、16 位 PCM WAV 分片，每片由若干已知时长的合成音素块串接而成，块内含能量包络与共振峰变化的确定性合成信号，并叠加静音间隙与一段低能量噪声；另附音素清单，逐分片声明参考音素序列、每个音素的参考起止毫秒、基频参考区间与说话人编号，以及一份带单调版本号的边界策略快照，声明能量阈值、最小音素时长、边界搜索窗口毫秒与允许的边界偏差容差。参考起止毫秒是边界裁决的唯一真值来源。

任务环境与准备：
安装 Go 1.22 或以上版本（如 go1.22.4），并使用纯 Go SQLite 驱动（如 modernc.org/sqlite）以便在 Linux（WSL Ubuntu）本地构建，无需 CGO。
在工作区初始化 Go module，提供本地 HTTP 接口与命令行入口，不依赖真实声学模型、GPU 或外部服务。
由程序内置固定种子生成器产出 16 kHz、单声道、16 位 PCM WAV 分片、音素清单与带单调版本号的边界策略快照，首次运行落盘到本地样本目录。
准备本地验证脚本注入帧移为零、分片样本数与声明不符、参考区间倒置、预算越界与强制终止等情形，核对业务码与恢复结果。

业务要求：
1. 实现分帧与能量包络提取阶段：按策略声明的帧长与帧移（毫秒）对 16 位 PCM 做汉宁窗分帧，帧长与帧移须显式换算为整数采样点并记录换算值，逐帧计算对数能量与过零率并合成边界候选得分；同一输入与策略必须产生逐字节一致的帧级得分序列，帧移为零或大于帧长、分片样本数与清单声明不符时返回 E_FRAME_INVALID 并附分片标识与参数值。
2. 实现边界候选检测与音素切分核心：在对数能量包络上以高低双阈值确定候选边界，再在策略声明的边界搜索窗口内以得分峰值为边界定位，并按最小音素时长合并过短片段；每次合并须记录被合并片段、合并依据与合并后时长，输出音素片段序列及每段起止采样点与毫秒；当切分出的片段数与参考音素数不一致时须在诊断中标明并给出对齐差异，不得直接截断或补空。
3. 实现与参考音素序列的对齐裁决：以参考起止毫秒为唯一真值，按动态规划做片段到参考音素的单调对齐，允许跳过片段但须记录跳过原因与代价，输出每个片段对齐到的参考音素、起止偏差毫秒与偏差是否超出容差；动态规划过程须在整数毫秒域进行以保证可复算，参考音素为空、参考起止区间倒置或对齐代价出现无界值时返回 E_ALIGN_INVALID 并附首个冲突音素序号。
4. 实现候选边界搜索窗口的并行调度与资源预算：以分片为调度单元，在全局帧处理预算、单工作进程帧配额与并行工作进程上限三重约束下决定接纳顺序与并发度，接纳时依据清单声明音素数与搜索窗口预估帧消耗，超预算分片记为未处理并给出预算余量与原因；缩减预算后的切分与裁决结果须与按缩减后策略从零重新运行逐字节一致，工作进程异常须以结构化错误对象记录并保留已处理片段的诊断。
5. 实现并行执行与确定性归约：使用本地进程池并行处理已接纳分片，各分片的片段序列、对齐裁决与偏差统计按分片标识与片段起始采样点全局排序后归约，使并行运行的汇总与单进程顺序执行逐字节一致；查询结果须按分片内容指纹与策略版本缓存，缓存命中结果与重新计算逐字节一致，缓存键冲突或版本错配返回 E_CACHE_STALE 而非返回陈旧值。
6. 实现定点域偏差统计与误差界推导：边界偏差毫秒与基频均值按策略声明的缩放因子做定点量化，统计每分片偏差均值、最大偏差、超容差音素数及按音素类别的分布，累加须在缩放域或进位可控的补偿求和中进行；每项不可计算时须显式记为不适用并计数；对每个分片给出由缩放因子、量化步长与帧移推导的偏差误差上界与有效位数，上界推导依据随结果保留。
7. 实现 SQLite 事务化阶段检查点与恢复边界：导入、切分、对齐、统计四阶段每分片完成时以单个事务写入含阶段名、分片内容指纹、边界策略版本、产物摘要与单调序号的记录，同一分片同一阶段只允许一条有效记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分片段单元后退出，不承诺强制终止后生成退出报告；被强制终止后重启仅凭已提交事实恢复，恢复后的片段序列与偏差统计须与一次连续执行逐字节一致。
8. 实现策略快照增量片段应用、整体替换识别与并发发布保护：接受只含局部字段改动的增量片段并校验基础版本，版本不一致返回 E_STALE_BASE 并附当前版本；当快照或分片集被整体替换时通过内容摘要与版本序号区分正常推进、整体替换与回退，整体替换使全部片段序列与偏差统计失效重建，回退拒绝；多工作进程发布阶段产物时使用 SQLite 条件更新与真实文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地分片验证音素切分、参考对齐、预算调度与中断恢复的确定性。
