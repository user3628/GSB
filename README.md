为文生视频与图生视频团队从零构建一个本地可运行的视频生成作业工作台，核心问题是交互预览的低延迟与预览结果同全量重算结果的一致性。输入是本地样本目录：一份生成作业清单 JSONL，每条含 job id、模式 text2video 或 image2video、基准种子、分辨率（宽高均为 16 的整数倍）、总帧数、帧率与一组关键帧片段定义（片段 id、起止帧、局部提示词、局部种子、运动强度）；一份参考帧摘要目录，存放每个作业若干指定帧的期望像素摘要，用于验证重算是否走样。视频合成采用本地确定性伪渲染器：由提示词、种子与片段运动强度派生低频噪声场，逐帧遍历像素生成 RGB 三通道 8 位像素，不依赖任何外部模型或网络。工作区为空，需从零创建项目：一个可交互的 FastAPI 服务，提供工程创建、低成本帧预览、按作业触发全量生成、查询作业状态与分片进度、导出快照与一致性诊断报告的接口。核心难点在于：用户会以毫秒级交互反复调整局部提示词与运动强度来预览少数帧，预览必须与之后的全量重算结果逐字节一致，不能因走近似采样、缓存陈旧或缺帧补帧而产生差异；同时全量生成需在强制终止后可恢复，且恢复后的结果必须与无中断执行完全一致。

任务环境与准备：
安装 Python 3.11 及以上版本，并安装 fastapi、uvicorn、numpy、pytest 与 requests 的兼容版本；版本以本地 wheel 安装为准，不依赖网络服务。
在空工作区创建项目目录与样本目录，作业清单、参考帧摘要与生成脚本均以本地确定性方式构造，不引用真实模型、数据集或线上站点。
确认 Windows 本地回环端口可用并在演示脚本中以显式端口启动服务；所有路径使用相对工程根目录的相对路径。
准备强制终止与重启的演示脚本，用整数进程退出码区分正常退出与强制终止，并通过持久化的 SQLite 状态与磁盘文件核对恢复结果。

业务要求：
1. 工程创建接口接收作业清单、参考帧摘要目录与渲染参数，校验 job id 唯一、模式只能是 text2video 或 image2video、宽高均为 16 的整数倍、总帧数为正整数、关键帧片段起止帧在 [0, 总帧数) 内且区间不重叠、运动强度为有限实数、image2video 模式必须声明源图引用；任一非法返回 E_PARAM 业务码并定位 job id 与字段名，且不得创建任何帧文件、缓存或临时目录。
2. 须实现确定性伪渲染器：由局部提示词、局部种子、运动强度与帧下标共同派生该帧的低频噪声场并逐像素合成 RGB 三通道 8 位像素，帧内像素按行优先升序、通道按 R、G、B 固定顺序写入；相同输入在任何执行顺序、任何并发度与任何机器时钟下产出的帧像素文件必须逐字节一致，渲染器不得依赖全局随机状态、系统时间或字典遍历顺序。
3. 帧预览接口须在低延迟预算内返回指定帧集合的像素摘要与若干采样像素值，且预览结果必须与用同一参数走全量生成得到的结果逐字节一致，包括所选帧的像素、逐帧摘要与帧序号对应关系；预览不得走抽样、降分辨率或跳过片段合成的近似路径，检测到与全量结果不一致须返回 E_VERIFY 并给出首个不一致帧号。
4. 须实现预览缓存与失效判定：以配置指纹（局部提示词、局部种子、运动强度、分辨率与基准种子的内容哈希）为键缓存已渲染帧；任何片段参数变更都必须使受该片段影响的帧缓存失效，未受影响帧不得重算；读取缓存时若指纹与当前配置不一致或残留旧版本帧文件，须返回 E_STALE 并定位到片段与帧区间，禁止返回旧像素。
5. 须实现片段拼接与帧序一致性：各关键帧片段定义覆盖的帧范围须按帧下标升序拼接，片段之间若有未覆盖帧须由基准种子与前序片段状态确定性外推并记录外推帧数；同一作业在任何片段增删改后重新生成，未受影响片段的帧像素必须逐字节保持不变，受影响片段及其后续外推帧须整体重算。
6. 全量生成进度须在 SQLite 中以作业、片段、帧三段记录事务提交，单帧像素写入与帧进度标记须在同一事务中完成，帧文件先写临时文件再原子替换并登记内容哈希；单个片段失败时该片段整体回滚且不得留下半写帧文件，同作业其余已提交片段状态保持不变，统计只读已提交帧。
7. 每次全量生成完成须以整体替换方式生成版本化快照，含作业版本号、各片段帧区间、逐帧像素摘要与帧文件内容哈希；读取快照时若检测到数据库版本与磁盘帧文件哈希不一致、作业版本变化或缺帧，须返回 E_STALE 并定位到片段与帧号，禁止汇入旧帧或按缺帧静默补齐。
8. 进程被强制终止后重启，须从 SQLite 已提交帧进度继续，核对每个片段的帧标记、帧文件内容哈希与快照版本，重算未提交帧且不重复渲染已提交帧；恢复后的逐帧像素、逐帧摘要、外推帧数与快照版本序列须与无中断执行完全一致，并须提供确定性演示入口用固定作业与一组覆盖预览、片段变更与中断恢复的交互序列跑出可重复结果。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地固定作业与交互序列验证帧预览与全量重算逐字节一致、片段变更后缓存精确失效及强制终止后恢复结果一致。
