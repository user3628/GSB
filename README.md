当前是空白工作区，需从零构建一个本地可运行的音色克隆与发音建模工作台，交付领域数据编辑与操作应用，核心难点是音色与发音数据的格式互操作与版本兼容。输入为固定随机种子生成器产出的本地确定性 WAV 分片（16 kHz、单声道、16 位 PCM），每个分片模拟同一说话人在不同发音上下文下的短语音段，含元音段、辅音段与停顿段；另附一份 JSON 声音工程清单，逐分片声明音色标识、参考基频均值、共振峰目标区间、发音单元序列与可选音高曲线标注，并支持以结构版本 2 与结构版本 1 两种形态声明（版本 1 以整数百分比表示音高偏移、发音单元为整体字符串且缺少共振峰字段）。系统须在导入时以声明的样本总数与各分片实际样本数上界校验清单一致性。系统不依赖任何真实克隆模型、外部服务或 GPU，音色特征以确定性频谱包络与谐波结构统计提取，发音建模以确定性共振峰轨迹合成实现。工作台须支持内部工程格式与 WAV、JSON、发音单元标注三种外部形态之间的双向编解码，版本兼容导入后的结果可再次导出并通过往返校验。

任务环境与准备：
安装 Python 3.10 及以上与 NumPy、soundfile；在题面工作区新建项目目录并初始化虚拟环境
用固定随机种子脚本生成本地 WAV 分片与版本 2、版本 1 两份 JSON 清单，落盘到 data 目录并记录样本总数与分片顺序
准备本地 HTTP 服务端口配置与运行脚本入口，确认无需真实模型、GPU 或外部账号即可执行演示
确认导出目录与检查点目录可写，运行一次从零全量构建以得到基准摘要文件

业务要求：
1. 实现统一内部声音工程模型与三种外部形态的双向编解码：内部模型以分片标识、音色标识、PCM 样本序列、归一化音高曲线、发音单元序列与结构版本描述一个声音工程；实现内部模型与 WAV（音高曲线写入配套 JSON 侧车）、声音工程 JSON、发音单元标注（每单元起止毫秒与单元符号）三种形态的互转；导出 WAV 时采样率与位深须逐字保持声明值，导入时声道数或采样率与声明不符须返回 E_FORMAT_MISMATCH 并附分片标识与声明值、实际值。
2. 实现结构版本 1 清单的兼容解析与显式升级：版本 1 中音高偏移为整数百分比、发音单元为整体字符串、缺少共振峰字段；导入时须按可配置规则做百分比与绝对音高换算、把整体字符串按可配置分隔符切分为带起止的单元序列、按缺省规则补齐共振峰字段并生成稳定分片标识；换算与补齐规则须可由配置改变，且升级后的工程可再导出为版本 1 形态并通过往返校验。
3. 实现确定性音色特征与发音建模核心：对每个分片分帧加窗后提取频谱包络与谐波结构统计作为音色特征，按发音单元序列与归一化音高曲线在浮点域合成共振峰轨迹并生成发音建模参数；同一输入与配置必须产生逐字节一致的特征与参数，帧边界超出样本末尾时须按声明的样本总数截断并记录截断帧数，禁止使用任何真实克隆模型或外部语音服务。
4. 实现音高曲线与发音单元的数值精度校验：音高曲线与共振峰轨迹在定点量化后存储并记录每分片缩放因子，量化误差界须由显式缩放因子估计；检测到发音单元区间为负、结束早于开始、超出分片总时长，或音高出现 NaN、Inf 及超出可配置范围时，须返回带分片标识、单元索引与位置的 E_NUMERIC 或 E_TIMELINE_INVALID，并保留诊断上下文。
5. 实现版本指纹与增量失效传播：当分片样本内容、音高曲线、发音单元序列、音色特征参数、结构版本或量化位宽任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段（特征提取、发音建模、量化、导出），使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；失效原因与指纹须在查询接口中可观测。
6. 实现增量与全量一致性校验：提供单分片样本替换、单单元编辑与单分片版本升级入口，仅重建失效链路后与从零全量构建的音色特征摘要、发音建模参数、量化产物与导出文件摘要做逐字节摘要比对；检测到不一致须返回 E_INCREMENTAL_MISMATCH 并附差异分片与阶段，不得以部分一致或容差代替逐字节比对。
7. 实现持久化检查点、优雅停止与并发发布保护：每阶段完成时以原子方式写入含阶段名、分片指纹、结构版本指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分分片后退出，不承诺强制终止后生成退出报告，恢复后结果须与从零完整运行一致；多工作进程发布时使用文件锁并比较序号，仅允许连续推进，落后或重复发布返回 E_STALE_CHECKPOINT，缺失前置产物返回 E_INVALID_STAGE。
8. 提供可交互编辑工作台与本地确定性演示：命令行与本地 HTTP 接口支持导入分片与两种版本清单、执行分阶段特征提取与发音建模、编辑音高曲线与发音单元、查询各阶段状态与版本指纹、请求停止、执行恢复、导出三种形态并执行往返校验；演示数据至少 4 个分片，含中英混排发音上下文、至少 1 个版本 1 清单分片与一次异常注入，一次完整运行生成固定摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
