当前为空工作区，需从零构建一个本地可运行的依存句法分析并行调度与资源预算工作台，交付领域数据编辑与操作应用。输入为若干本地 UTF-8 句子分片（每行一句中文或中英混排文本）与一份 YAML 配置，配置描述分析模型参数（转移动作打分权重、最大依存距离上限、根节点唯一性约束）、并行工作线程数、单句最大 token 预算与全局总 token 预算。分片文件由固定随机种子的本地生成器产出，另附一份分片清单记录每个分片文件名与句数，作为分片边界的显式观测。分析器采用本地确定性转移式依存分析：以固定哈希函数从 token 与词性派生的特征向量与配置权重做点积作为转移动作分数，通过移进-归约贪心解码生成依存弧，不依赖任何真实模型、预训练权重、GPU 或外部服务。工作台需要在资源预算约束下并行分析句子分片，支持分片级检查点、优雅停止与恢复、版本变化检测与增量失效、并发发布保护，并提供可交互的导入、查询、停止、恢复与统计界面。所有输入、阈值、预算与错误码须在题面内自洽可验证。

任务环境与准备：
安装 Python 3.11 及依赖 numpy、PyYAML、pytest，使用本地虚拟环境管理。
在工作区创建 samples 目录，用固定随机种子脚本生成含中英混排与跨分片重复句的 3 个以上句子分片，另生成分片清单文件记录文件名与句数，以及一份含权重、距离上限、线程数与预算字段的 YAML 配置。
创建工作区与检查点目录，确认运行账户对目录有读写权限；无需网络、容器、GPU 或外部账号。
准备本地 HTTP 与命令行启动脚本位置，用于导入分片、查询状态、停止与恢复；测试仅在本地执行。

业务要求：
1. 实现转移式依存分析解码核心：对每句按空白与标点切分为 token 序列，依据配置权重与固定哈希特征计算移进/左归约/右归约动作分数，贪心选择最高分动作生成依存弧，输出每 token 的中心词下标、依存关系标签、依存距离与句级总得分；同一输入与配置必须得到逐字节一致结果，且每个非根 token 必须恰好有一个中心词、根节点唯一。
2. 实现资源预算约束下的分片调度：以句子分片为单位，在全局总 token 预算与单工作线程 token 配额共同约束下决定接纳哪些分片，接纳前按分片清单与实际切分结果统计的 token 总数预估消耗，超预算分片记录为未处理并给出原因码；须保证任意时刻累计消耗不超过全局预算，预算配置变化时须使既有调度决策失效并重新规划。
3. 实现并行执行与确定性归约：使用本地线程池并行分析分片，各分片结果按分片序号与句内序号全局排序后再归约统计，使并行输出与单线程顺序执行逐字节一致；线程池不得以线程超时方式描述为已终止失控计算，异常须以结构化错误对象上报并保留已完成分片结果。
4. 实现分片级持久化检查点与优雅停止恢复：每分片完成时以原子方式写入含分片序号、输入指纹、配置版本、结果摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分分片后退出，恢复时忽略损坏记录并从最近一致检查点继续，最终统计须与一次完整运行逐字节一致。
5. 实现版本变化检测与增量失效传播：当输入句子内容、打分权重、最大依存距离或预算配置任一变化时，通过版本指纹识别受影响的最早分片，使该分片及其下游聚合产物失效并重建；未受影响分片结果继续复用，失效原因与指纹须在查询接口中可观测，禁止用旧版本结果填充统计。
6. 实现并发发布保护与业务错误码：多工作进程对同一工作区发布分片结果时使用文件锁并比较分片序号，仅允许序号连续推进，落后或重复发布返回 E_STALE_CHECKPOINT；请求缺失前置分片的聚合或非法阶段跳转返回 E_INVALID_STAGE；在 YAML 中注入的越界依存距离上限与非法权重返回 E_INVALID_CONFIG。
7. 实现句法约束校验与数值诊断：解码后校验依存树无环、根节点唯一、依存距离不超过配置上限，违反时返回带句子标识与 token 位置的 E_TREE_INVALID；当动作分数中出现 NaN 或 Inf（由注入的权重或特征构造触发）时返回 E_NUMERIC 并指出句号与 token 下标，不得静默跳过或返回部分结果。
8. 提供可交互工作台应用与本地确定性演示：命令行与本地 HTTP 接口支持导入分片、查看各分片状态与版本指纹、查询依存弧统计与预算消耗、请求停止、执行恢复、导出分析结果；演示数据至少含 3 个句子分片、中英混排与跨分片重复句，一次完整运行生成固定摘要，并演示分片间触发停止后恢复以及预算超限与非法配置的错误码验证。
