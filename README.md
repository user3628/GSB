当前是空白工作区，需从零构建一个本地可运行的稀疏矩阵乘（SpMM）算子组件与完整示例，供上层训练推理代码以库形式集成。输入为固定随机种子生成器产出的本地矩阵样本：稀疏矩阵以 CSR 三元组（indptr、indices、data）存储在 .npz 文件中，覆盖不同稀疏率（约 1%、10%、40%）、不同形状（方阵、高瘦、矮胖）以及含结构性退化的样本（空行、全零行块、重复列索引、显式存储的零值），并提供形状与稀疏率清单；稠密矩阵为对应右乘矩阵，以 .npy 落盘。算子需以行分块与列分块的稀疏专用内核完成 CSR×稠密矩阵乘法，累加顺序与稀疏结构相关，不同分块方案会导致浮点求和顺序变化，因此必须同时给出数值误差控制与可验证的误差上界，而非仅追求结果近似一致。系统不得依赖外部数值库的稀疏算子，需自行实现内核、调度、误差审计与配置版本管理，并提供本地确定性样本与运行脚本。

任务环境与准备：
确认 Windows 上可用 Python 3.10 及以上与 NumPy，并可用 pip 安装到本地虚拟环境。
在空工作区创建项目目录结构，准备本地固定随机种子的矩阵生成脚本以产出 .npz 稀疏矩阵、.npy 稠密矩阵与形状稀疏率清单。
准备含空行、重复列索引、显式零值与含 NaN 的退化样本，并生成高精度参考结果供误差审计使用。
确认无需 GPU、外部数据集、真实账号或网络服务，全部样本与脚本在本地可重复生成。

业务要求：
1. 实现 CSR×稠密矩阵的稀疏专用分块内核：按行块与列块组织计算，仅遍历非零元，支持方阵、高瘦与矮胖形状；每行输出的累加顺序须显式可配置（按列索引升序或按分块顺序），且对重复列索引按其出现次序累加、对显式零值不得跳过其位置语义；同一输入与配置必须产生逐字节一致的输出。
2. 实现基于稀疏结构的自动分块参数选择：依据非零元数、平均每行非零数、空行比例、稠密矩阵列宽与可配置缓存预算估算工作集，从候选行块与列块方案中按预测访存量与负载均衡度打分选出方案，并记录打分明细与选择理由；稀疏率极高或空行占比很大时须避免选择导致大量空转的方案，且选择结果可复现。
3. 实现数值精度与误差传播控制：累加支持顺序求和与补偿求和两种策略，全程在相应精度域内执行，并对每个输出块给出与高精度参考结果比较的误差上界估计；估计须依赖显式的本地高精度参考值与随机抽样位置，不得从缺失信息推断；出现 NaN 或 Inf 时须按 IEEE 语义传播并记录其来源行与非零元位置。
4. 实现结果自校验与异常链路：对输出抽样行块与按非零元逐项朴素累加的参考实现比对，超出可配置容差的块须报告行列区间、最大绝对偏差与相对偏差，并返回业务码 E_NUMERIC_MISMATCH；当出现形状非法、indptr 非单调、列索引越界或重复索引超出容差时，须返回带具体位置的稳定业务码（E_SHAPE_INVALID、E_BAD_CSR、E_DUP_INDEX）。
5. 实现分块方案与结果缓存的版本化管理：把自动选择或用户指定的分块方案连同矩阵形状指纹、稀疏结构指纹、求和策略与缓存预算原子写入版本化配置存储，每版本含单调序号与摘要；缓存键须包含形状指纹、结构指纹、分块方案与求和策略，任一变化须使旧缓存失效并重建，禁止复用旧版本结果。
6. 实现并发发布保护与版本整体替换识别：多个工作进程对同一工作区发布分块方案或缓存结果时使用文件锁并比较版本序号，仅允许序号连续推进，落后、重复或跨方案错位发布返回 E_STALE_PUBLISH；当检测到配置记录被整体替换（序号回退或摘要不匹配）时须识别版本变化并拒绝，而非静默接受。
7. 实现峰值内存约束下的执行调度：在可配置峰值内存上限内规划输出缓冲、行块工作区与稠密矩阵切片的占用，超预算时须按列块或行块拆分执行或返回带预算明细的 E_MEMORY_BUDGET，不得依赖运行时内存溢出；拆分执行的结果须与不拆分时在容差内一致，且拆分次数与占用峰值记录在诊断输出中。
8. 提供可集成的算子库接口与完整示例：以库函数与命令行提供 SpMM 调用、分块方案查询、误差报告、版本状态查询与缓存管理；示例须用本地确定性样本覆盖三档稀疏率、方阵/高瘦/矮胖形状、重复列索引与含 NaN 的异常样本，一次完整运行生成固定摘要，并演示分块方案变更后缓存失效与重建。
