当前为空工作区，需从零构建一个本地可运行的关系与事件抽取（REE）格式互操作与版本兼容管线，交付算法实现与可复现的实验环境。输入为若干本地确定性 JSONL 文档分片，每条含 doc_id、tokens（已切分 token 列表）、中英混排文本、来源 source 与标注结构版本号；另附本地种子标注分片（含实体、关系与事件标注）及一份 YAML 抽取配置，描述实体类型表、关系类型表、事件类型与论元角色表、触发词词表、特征开关、平滑强度与置信阈值。系统不依赖任何真实模型、GPU 或外部服务，以本地计数估计与规则打分实现实体识别、关系分类与事件论元抽取，并输出统一中间表示。核心难点在于三种标注格式（BIO 序列、JSON 区间、旧版扁平结构）之间的双向转换、结构版本兼容解析以及转换过程中的格式互操作校验。管线需支持分阶段执行、持久化检查点、优雅停止恢复、版本指纹识别与增量失效传播，并提供本地 HTTP 与命令行交互接口及确定性演示脚本。

任务环境与准备：
安装 Python 3.11 并在空工作区创建虚拟环境，安装 numpy、pydantic 与 fastapi，版本写入 requirements.txt。
准备本地确定性样本生成脚本：以固定随机种子生成至少 4 个 JSONL 文档分片（含中英混排、重叠实体与嵌套事件）与对应种子标注分片，另生成 1 个结构版本 1 的旧版分片。
准备 YAML 抽取配置，包含实体类型表、关系类型表、事件类型与论元角色表、触发词词表、特征开关、平滑强度与置信阈值。
确保所有路径为工作区相对路径，不依赖网络、真实账号、GPU 或外部数据集；运行前先执行样本生成脚本使分片与种子标注就位。

业务要求：
1. 实现统一中间表示与三种标注格式的双向编解码：内部模型以文档为单位维护实体区间（类型、起止 token 下标）、关系三元组（头实体、尾实体、关系类型）与事件（类型、触发词区间、论元角色到实体的映射）；实现与 BIO 序列格式、JSON 区间格式、旧版扁平结构格式的双向转换，BIO 标签须支持 B-/I-/E-/S- 前缀与类型后缀，关系与事件在 BIO 侧以伴随记录承载；同一内部模型任一经由两种格式往返后须逐字段一致。
2. 实现旧版结构兼容解析与显式升级：支持结构版本号为 1 的旧分片，其中实体以字符偏移描述而非 token 下标、关系以实体名称字符串引用而非 id、事件论元为单值而非列表；导入时须按可配置规则做字符偏移到 token 下标的对齐、名称到实体的消歧与单值到列表的规范化，无法对齐的字符偏移须返回带 doc_id 与偏移量的 E_ALIGN_FAIL 并保留在诊断输出中，升级结果须可追溯来源版本。
3. 实现本地计数估计与约束感知抽取核心：从种子标注分片统计实体类型、关系类型与事件论元角色的计数与转移计数，采用可配置平滑强度并回退到未知标记；以对数域打分并施加类型约束（关系头尾实体类型须在关系类型定义域内，论元角色只接受事件类型允许的实体类型），非法组合不得出现在最终结果；同一输入与配置必须产生逐字节一致的抽取结果。
4. 实现跨格式往返一致性与版本兼容校验：对每个文档执行 BIO→内部→JSON→内部→BIO 与旧版→内部→JSON→内部→旧版两条往返链，校验实体区间、关系三元组、事件论元与类型标签保持不变；当导入的 JSON 声明结构版本高于当前支持版本时须返回 E_UNSUPPORTED_VERSION，低于支持版本时走兼容升级路径，校验结果与降级/升级项须在查询接口中可观测。
5. 实现持久化阶段检查点与优雅停止恢复：管线按解析、估计、抽取、校验四阶段推进，每阶段完成时以原子方式写入含阶段名、输入分片内容摘要、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分文档后退出，不承诺强制终止后生成退出报告；恢复后最终抽取结果与校验报告须与一次从零完整运行的输出逐字节一致，且检查点序号连续推进、无跳跃与重复。
6. 实现版本变化检测与增量失效传播：当分片文本、种子标注、类型表、触发词词表、特征开关、平滑强度或置信阈值任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；失效原因、受影响阶段与新旧指纹须在状态查询中可观测，禁止以旧版本产物冒充新版本结果。
7. 实现并发发布保护与稳定业务错误码：多个工作进程对同一工作区发布阶段产物时使用文件锁并比较检查点序号，仅允许序号连续推进，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT；请求非法阶段跳转、缺失前置阶段产物或对已被标记失效的阶段请求结果时分别返回 E_INVALID_STAGE、E_MISSING_ARTIFACT、E_STALE_ARTIFACT，错误对象须含阶段名与可读原因。
8. 提供本地 HTTP 与命令行交互接口及确定性演示：支持导入分片与种子标注、触发分阶段执行、查看各阶段状态与版本指纹、查询抽取结果与格式转换诊断、请求停止、执行恢复、导出统一中间表示；演示数据至少 4 个文档分片，含中英混排、重叠实体、嵌套事件与至少 1 个旧版结构分片，一次完整运行生成固定摘要，并演示阶段间停止后恢复与旧结构升级，注入非法结构版本与缺失前置产物验证错误码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地分片验证三类格式往返一致、旧版升级、停止恢复与版本失效，并检查错误码与固定摘要。
