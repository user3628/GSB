当前是空白工作区，需要在 Windows 本地从零构建一个面向本地微服务测试环境的应急预案演练编排工作台。工作台读取本地确定性样本：演练场景（服务拓扑、故障注入项、预期处置动作、演练轮次与判定阈值）与演练计划（按阶段推进的演练步骤、每阶段时间预算与并发预算）。执行时按阶段在固定并发上限与每阶段时间预算内并行向本地测试端点注入故障、采集成败与恢复耗时，据此裁决每个处置动作是否达标，并推进演练轮次状态。数据规模会从十余个服务增长到数千个注入项与处置动作，候选筛选与达标判定需要在精确全量评估与分桶采样评估之间取舍，同时保证轮次状态、预算占用与处置结论在进程被强制终止后仍可依据持久化事实恢复一致。

任务环境与准备：
确认 Windows 本地已安装 Python 3.11 及以上版本，并能使用 pip 安装依赖。
创建空白工作目录，安装 FastAPI、Uvicorn、NumPy 与 pytest，版本按 pip 当前稳定版安装；SQLite 使用 Python 标准库 sqlite3，无需额外安装。
准备本地确定性样本：服务拓扑与故障注入场景 JSON、演练计划 JSON（含阶段时间与并发预算）、固定随机种子与注入端点清单。
准备本地测试端点：分别监听可返回成功、返回错误响应与不响应的回环端口，并提供未监听端口用于连接拒绝场景；确认无外部网络依赖。
启动本地服务前确认 SQLite 数据库文件路径可写，运行演示脚本与 pytest 用例以本地回环地址执行，不依赖真实账号、线上站点或付费资源。

业务要求：
1. 实现演练场景与计划样本的解析和归一化：场景声明服务标识、拓扑依赖边、故障注入项、预期处置动作与判定阈值，计划声明阶段序列、每阶段毫秒时间预算与并发预算；解析时校验服务标识唯一、依赖引用存在、时间与并发预算为正整数并做溢出检查，解析失败或依赖成环返回业务码 E_PLAN_INVALID 且不改变任何已提交状态。
2. 定义演练轮次与注入项状态机，轮次至少包含 PLANNED、RUNNING、PAUSED、COMPLETED、ABORTED 五种状态，注入项至少包含 PENDING、INJECTING、OBSERVED、VERIFIED、FAILED 五种状态，并规定合法迁移路径；非法迁移返回 E_INVALID_TRANSITION，迁移被拒绝时不得修改已持久化的状态或预算占用。
3. 实现并行注入调度器，以全局并发上限、每阶段时间预算与每阶段注入项数量预算三重约束推进；预算内按注入项优先级与服务轮转取任务，超出并发上限者进入有界等待队列，队列满返回 E_INJECTION_QUEUE_FULL；同一服务在同一阶段内不得并发注入两项故障，并输出本轮选择依据与被跳过项清单。
4. 实现真实可中断的故障注入与恢复观测：注入必须通过本地测试端点的真实连接体现（连接拒绝对未监听端口、超时对真实不响应端点、错误响应对可解析端点），每次注入与观测具备独立超时，超时后必须真实关闭底层连接并释放其占用的并发名额，返回 E_INJECT_TIMEOUT，不得以等待冒充超时，也不得把线程超时描述为已终止失控代码。
5. 实现数据规模自适应的达标判定：当注入项与处置动作规模不超过配置的精确上限时对全部动作做精确逐项判定；超过上限时改为按服务与阶段分桶采样评估，并输出采样率、分桶方式与结论置信说明；两条路径对同一场景版本与同一样本必须给出相同结论或给出可逐项核对的差异说明，降级路径不得把未评估动作记为达标。
6. 实现预算耗尽时的确定性降级裁决：当注入项规模超出并发与时间预算可覆盖范围时，按注入项优先级、服务轮转与已消耗预算给出确定性降级次序，被降级注入项迁移为 FAILED 并附降级依据；降级后仍须保证已注入项完成观测与结论写入，且降级与真实超时必须区分并分别输出，不得以延迟代替真实超时。
7. 实现单写者执行、多读者查询与幂等复用：轮次推进、注入项状态迁移与处置结论写入按轮次单写者串行执行，多个只读查询可并发读取某一完整提交版本；同一注入批次标识重复触发只执行一次、其余等待并复用结果，内容不一致返回 E_CONFLICTING_BATCH；查询不得看到注入项已 OBSERVED 而其预算占用未更新、或轮次已 COMPLETED 而存在未 OBSERVED 注入项的中间可见状态。
8. 使用 SQLite 持久化场景版本、演练轮次、注入项状态、预算占用与意图日志，所有写操作先写意图记录再提交事务；进程在注入或结论汇总中途被强制终止后重启须扫描未完成意图，把未提交注入项回滚为 PENDING 重排或标记为 ABORTED，恢复报告只包含已持久化事实，并附统一含业务码与上下文的 JSON 失败响应与本地 HTTP API 及可重复演示脚本。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用固定本地样本完成多阶段演练、规模自适应达标判定、预算降级与强制终止后恢复，核对轮次状态与预算占用一致。
