当前为空工作区，需从零构建一个本地可运行的 LLM 预训练数据配比与去重流水线。输入为若干本地 JSONL 数据分片，每条样本包含 id、source、lang、text 四个字段；流水线需对每个分片做规范化、按 SimHash 与分桶近似去重、按 source 与 lang 分层计算目标配比，并输出训练混合集。流水线要求支持多阶段执行：每个阶段完成后以持久化检查点记录版本，进程被强制终止后可从最近一致检查点恢复；恢复时若发现上游分片内容或配比配置发生版本变化，必须识别并判定受影响阶段与输出产物失效，不允许整体替换后直接沿用旧中间产物。演示需提供可交互接口：提交样本、查看阶段状态、触发停止后恢复、查询混合集统计。

任务环境与准备：
安装 Python 3.11，使用标准库与 NumPy、SQLite3；无需外部网络与真实账号。
准备本地 JSONL 数据分片与配比配置样例，放入工作区 data 目录；演示脚本与工作区目录结构一并创建。
在 Windows 上执行演示脚本，确保进程可被外部信号请求停止以验证恢复流程。

业务要求：
1. 实现规范化与 SimHash 去重阶段：对 text 做 Unicode NFKC、空白折叠与小写化，计算 64 位 SimHash，使用 4 个 16 位桶索引候选，并在海明距离阈值内确认重复；注意保留首次出现样本的顺序以保障可重复性。
2. 实现分层配比阶段：按 source 与 lang 计算样本数与 token 估计（按空白切分为近似 token），依据配置中的目标权重做最大余数法分配，输出各层实际采样数与总混合集，并保证同输入同输出且层内抽样由固定种子决定。
3. 实现持久化检查点：每阶段完成时以原子方式写入包含阶段名、输入分片版本指纹、配置版本、阶段产物摘要与序号的状态记录，并允许中断发生在写盘任意位置而不产生半写记录。
4. 实现中断恢复流程：进程捕获到终止要求时完成当前不可拆分单元后退出；恢复时从最近一致检查点继续，且已成功发布的阶段产物不重复计算，未完成阶段从该阶段起点重算，保证最终混合集与一次完整运行结果逐字节一致。
5. 实现版本变化检测与失效传播：当输入分片内容、去重参数或配比配置变化时，通过版本指纹识别受影响阶段，使该阶段及其下游产物被标记失效并重建，未受影响上游产物继续复用，且失效标记与重建结果在状态查询中可观测。
6. 实现并发安全的阶段发布：多个工作进程对同一工作区执行阶段发布时使用文件锁与检查点序号比较，仅允许序号连续推进，落后或重复发布须被拒绝并返回稳定的业务错误码 E_STALE_CHECKPOINT，不得覆盖较新状态。
7. 提供有文件与接口定义的可交互应用：支持录入或导入数据分片、查看各阶段状态与版本指纹、请求停止、执行恢复、查询混合集统计；当请求非法阶段跳转或缺失前置阶段产物时返回 E_INVALID_STAGE 与可读消息，交互过程可重复演示。
8. 提供本地确定性演示数据与脚本：至少 3 个分片并含跨分片重复样本与中英混合语言层，一次完整运行生成固定摘要；演示中人为在阶段间触发停止后恢复，使用输入注入验证恢复结果与完整运行结果一致且状态列表与产物摘要可追溯。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地分片完整运行后触发停止再恢复，校验混合集摘要一致、版本变更触发失效重建及业务错误码正确。
