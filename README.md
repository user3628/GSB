为大模型参数高效微调（PEFT）团队从零构建一个本地可运行的 LoRA 适配器并行训练调度引擎，核心问题是多任务适配器训练在进程内多线程并行下的资源预算控制、确定性梯度累积与训练状态恢复一致性，交付算法实现与可复现的实验环境。输入是本地样本目录：一份任务清单 JSONL，每条含 task id、基座模型标识、LoRA 秩与目标模块列表、训练样本文件引用、最大步数与学习率；每个训练样本文件为 JSONL，每条含样本 id、token 序列（整数列表，长度固定上限）与标签序列；另有一份预算配置，声明全局显存预算单元数、单任务步预算、线程池上限、浮点容差与随机种子。工作区为空，需从零创建项目：一个 FastAPI 服务，提供训练作业创建、按阶段推进、查询作业进度与逐模块适配器状态、导出快照与诊断报告。基座权重与 LoRA 增量均由本地确定性伪训练器模拟：给定种子、模块形状与输入 token 序列，用 NumPy 生成确定性初始权重与前向激活，反向梯度按解析公式计算并做梯度累积，从而可在无 GPU 环境验证资源预算与更新正确性。团队真实关心的是：资源预算耗尽时如何排队与降级、多线程并发扣减预算不得超额、梯度累积的数值路径可复现、中断后从持久化进度恢复且不重复消费样本。

任务环境与准备：
Windows 10/11，安装 Python 3.11 并确保 python 与 pip 在 PATH 中可用。
创建虚拟环境并安装 numpy、torch（CPU 版）、fastapi、uvicorn、httpx、pytest，版本以 pip 安装记录为准。
在项目内准备本地样本：生成若干任务清单 JSONL、训练样本 JSONL 与预算配置 JSON，全部由确定性脚本或手工固定内容给出，不依赖网络与外部数据。
确认 SQLite 随 Python 内置可用，准备临时工作目录用于权重缓存与快照文件，运行前确认目录可写。
启动服务使用本地回环地址与固定端口，演示与恢复测试通过本地 curl 或 httpx 发起，不连接任何外部站点。

业务要求：
1. 服务须提供作业创建接口，接收任务清单、预算配置与随机种子，校验任务 id 唯一、任务引用的样本文件存在且字段完整、LoRA 秩为正整数、目标模块列表非空且模块名合法、预算单元与线程池上限为正整数；任一非法返回 E_PARAM 业务码并指出出错文件与行号，且不得创建训练状态、结果文件或临时目录。
2. 须实现确定性伪训练器：由种子、模块形状与任务 id 派生基座权重与 LoRA 增量初值，前向按输入 token 序列计算激活，反向梯度按解析公式得出并执行梯度累积；相同种子、任务与样本顺序下任何线程与机器上得到的前向激活、梯度与更新后权重须逐位一致，训练器不得依赖全局随机状态或系统时间。
3. 资源预算须按全局显存预算单元计数：每个任务每一步训练按其模块参数量与激活规模估算消耗的预算单元，步开始前原子扣减、步结束后归还，预算不足时该步所属任务按 task id 字典序进入等待队列；并发场景下任一时刻已扣减预算总数不得超过配置上限，且不得以固定 sleep 或线程超时充当资源隔离。
4. 须支持进程内多线程并行推进多个任务，线程池并发度受创建时给定的线程池上限约束，任务调度须按 task id 字典序稳定分配；同一步内多个任务的执行顺序不得改变各自梯度累积结果，相同输入与并发度下全部任务的逐模块权重与步进度须完全可重复，队列与降级决策须写入诊断记录。
5. 训练进度须在 SQLite 中以任务、阶段、步三级记录提交，单步的梯度累积中间量摘要、模块权重哈希与步进度须在同一事务中写入；任务按 data_loaded、adapters_initialized、training、committed 四阶段推进且不可跳步，乱序推进返回 E_STAGE 并给出当前阶段，重复调用已完成阶段须幂等返回既有摘要。
6. 每次阶段完成须以整体替换方式生成版本化快照，含作业版本号、各任务模块权重摘要、已消费样本集合哈希与结果文件内容哈希；读取快照时若检测到数据库版本与磁盘结果文件哈希不一致、作业版本变化或残留旧版本权重缓存，须返回 E_STALE 并定位到任务与文件，禁止汇入旧数据。
7. 进程被强制终止后重启，须从 SQLite 已提交步进度继续，核对每个任务的步标记、权重缓存摘要与快照版本，重算未提交步且不重复消费已提交样本、不重复累加已提交梯度；恢复后的逐任务模块权重、已消费样本集合与快照版本序列须与无中断执行完全一致；可处理的终止信号须完成当前事务后写出退出报告，强制终止后的恢复只依赖持久化状态。
8. 须提供诊断与演示接口：输出预算扣减峰值与归还总量、任务等待与降级次数、线程池实际并发度、逐任务损失曲线摘要与快照版本序列；固定种子与任务集下的演示须跑出可重复结果，并给出可用 curl 复现的请求示例与等价参数说明。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
