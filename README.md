当前是 Windows 空白工作区，需要从零构建一个面向本地回环环境的丢包与网络故障诊断工作台，交付可交互的领域可视化与诊断应用。工作台需采集并持久化多源诊断数据：本地 TCP 探测结果（真实套接字连接成功、拒绝或超时）、链路抖动与丢包事件的确定性样本、以及本地测试服务端的吞吐与错误计数。这些数据需要支持两种可互换的持久化格式：紧凑二进制诊断包（含魔数、格式版本字节、大小端标记、长度前缀、CRC32 校验与可选字段存在位图）与分片 JSON 行格式（每行一条诊断记录）。不同工具产出的诊断包版本不一，字段可选性与时间戳精度也不同，工作台必须完成格式协商、版本兼容判定与归一化，并基于归一化数据计算丢包率、抖动与根因候选，输出可核验的诊断结论。数据全部来自本地确定性样本与本地测试服务，不依赖真实站点或网络设备。

任务环境与准备：
在 Windows 空白工作区创建项目目录，使用 Python 3.11 及以上版本，创建虚拟环境并安装 FastAPI、uvicorn、NumPy 与 pytest，全部从本地已缓存或可访问的包源安装。
准备本地确定性样本：若干候选诊断包（含不同格式版本的二进制与 JSON 行文件、损坏 CRC 与非法长度前缀的样本）及本地测试服务脚本，脚本可返回成功、拒绝与挂起三类行为。
确认本地回环端口可用，测试服务与工作台通过本机端口通信；SQLite 使用标准库 sqlite3，无需外部数据库。
提供启动脚本与端到端演示脚本，脚本以固定输入生成两次导入导出与一次强制终止后恢复，并打印格式协商结论、丢包率与错误码等结果，便于人工核验。

业务要求：
1. 实现诊断记录的内部模型与两种持久化格式的编解码：内部记录含毫秒时间戳、探测标识、路径节点、探测协议、成功标志、往返时延微秒与载荷字节数；紧凑二进制格式必须含魔数、格式版本字节、大小端标记、每条记录长度前缀、CRC32 校验与可选字段存在位图，分片 JSON 行格式每行含上述字段；两种格式编解码必须互为逆运算，且对损坏长度前缀或 CRC 不符的记录返回业务码 E_FRAME_CORRUPT。
2. 实现格式协商与版本兼容裁决：导入前检测输入格式与格式版本，按显式声明的兼容矩阵给出接受、降级接受或拒绝三种结论；旧版本缺往返时延或载荷字段时降级接受并按声明缺省规则补齐并记录降级明细，高版本含未知必填字段时返回 E_FORMAT_UNSUPPORTED 且不改变已存数据；裁定结论与降级明细须可查询。
3. 实现时间与量纲归一化：二进制毫秒时间戳与 JSON 行微秒时间戳须归一化为同一内部毫秒表示，并按调用方声明的截断规则处理亚毫秒部分，输出每条记录的舍入位与累计舍入误差；载荷字节与往返时延按各格式声明的单位换算为内部整数并做溢出与负数检查，越界记录整批拒绝并返回 E_UNIT_INVALID。
4. 实现真实探测采集并与诊断包互操作：对本地测试端点的连接拒绝、连接成功与真实超时三类结果，须以实际套接字关闭与超时释放为判定，超时返回 E_PROBE_TIMEOUT；采集结果写入工作台后可导出为两种格式并再次导入，导出再导入后的记录经归一化必须与原始采集逐字段一致。
5. 实现丢包率与抖动计算并声明数值契约：按路径节点与时间窗口计算丢包率、往返时延分位与抖动统计，分位使用确定性最近秩法并注明样本规模，累计时延使用补偿求和并给出可量化误差上界；同一诊断包重复计算必须逐位一致，比例类输出保留固定小数位并附舍入说明，两路径比较使用带相对容差比较。
6. 实现诊断结论与根因候选输出：依据归一化数据判定各路径节点的故障等级并给出根因候选排序，排序依据须包含丢包率、抖动与探测失败类型的可核对数值；当某节点样本数不足以支撑分位判定时返回 E_INSUFFICIENT_SAMPLES 并注明所需与实有样本数，不得以零值冒充统计结论。
7. 实现并发控制与增量导入的版本一致：诊断包导入与探测采集按提交单写者串行执行，多个只读诊断查询可并发；同一导入批次标识重复提交只执行一次、其余等待并复用结果，内容不一致返回 E_CONFLICTING_BATCH；查询只能看到某一完整提交版本，不得出现部分记录已导入而丢包统计仍为旧值的中间状态。
8. 实现基于 SQLite 的意图持久化与强制终止后恢复，并提供可视化诊断工作台：导入、采集与统计重算前先写意图记录再提交事务，进程被强制终止后重启须扫描未完成意图回滚到最后一个完整版本或把批次标记为已中止，恢复报告只基于已落盘事实；本地 HTTP 接口与页面覆盖格式协商预检、双向导入导出、探测触发、按路径查询丢包率与根因候选、恢复报告查询，失败响应为含业务码的 JSON。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本与测试端点验证双向格式互操作、降级裁决、真实超时与统计一致性，并附断点恢复差异报告。
