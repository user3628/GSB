在全新工作区中，需要从零构建一个面向本地块存储场景的快照链增量核算与回滚裁决组件，供上层备份编排器集成。卷由固定大小的块组成，每块携带块号、版本号、最近写入时刻与内容摘要；快照以写时复制方式记录冻结的块版本集合，并支持增量快照引用父快照。运维人员通过本地 HTTP 接口写入块、创建全量与增量快照、合并快照链并回滚，组件需据快照链计算已用容量占比、快照链回滚余量比例、跨快照加权一致度与回滚代价估计等派生指标。真实场景中块大小与卷块数跨越多个数量级，容量以字节整数、比例以定点小数呈现，派生指标经多级乘除与累计求和，运算顺序、舍入方式与量纲归一化都会放大误差，导致同一快照链在不同计算路径下得出不同的回滚裁决结论。

任务环境与准备：
安装 Go 1.22 或更高版本（Windows 官方安装包），确认 go version 可执行；本题仅使用标准库 net/http、database/sql、crypto/sha256 等，无需第三方网络依赖。
使用 CGO 可用的 Go 工具链构建 SQLite 驱动，例如执行 go get github.com/mattn/go-sqlite3 并设置 CGO_ENABLED=1；或改用纯 Go 的 modernc.org/sqlite 驱动，二者择一并在提交说明中固定。
在空工作区初始化 Go module 并准备固定本地样本：卷块数、块字节大小、若干固定种子的块内容、全量与增量快照序列、合并与回滚请求序列，样本随机性只来自固定种子。
准备两个本地 HTTP 测试入口：一个由组件自身监听供 API 调用，一个作为演示脚本调用方；脚本需包含一次模拟强制终止后重启的恢复步骤，进程终止使用整数退出码。

业务要求：
1. 实现卷、块与快照模型：卷由配置的固定块数组成，每块在 SQLite 中保存块号、版本号、最近写入时刻与 SHA-256 摘要；全量快照记录全部块版本集合与一致性序号，增量快照只记录相对父快照发生变化的块并引用父快照。写入后版本号须单调递增且摘要与实际内容一致，摘要不一致返回 E_BLOCK_CHECKSUM 且不改变已持久化块状态；父快照被删除但仍被未合并子快照引用时返回 E_SNAPSHOT_REFERENCED。
2. 实现派生指标计算并定义统一内部表示：由各块已用字节与卷容量字节计算已用容量占比，由已用容量与快照链引用的块版本集合计算快照链回滚余量比例，由各快照声明的整数权重计算跨快照加权一致度，由需写回块数与字节量计算回滚代价估计。整型部分一律为整数，比例类中间量统一为固定小数位的定点整数并输出每步舍入方式与累计舍入误差，禁止在中间步骤混用浮点与定点。
3. 实现累计求和的数值稳定性：多块容量与多快照权重累计时使用 Kahan 或等价补偿求和，并与朴素求和在混合大数小数的固定样本上对比，输出可量化误差上界；同一快照链同一版本重复重算必须逐位一致，回滚裁决结论不得因块遍历顺序或快照枚举顺序变化而翻转。
4. 实现带容差契约的回滚裁决：判断快照链回滚余量比例是否低于声明下限、回滚代价是否超过声明预算时，使用带相对容差的定点比较，容差以定点表示声明而非裸浮点比较，容差内视为满足并按快照标识稳定字典序打破平局；输出 JSON 中比例保留固定小数位并附舍入与误差说明，使同一版本在同一容差下输出完全一致。
5. 实现跨模块一致性校验：某块写入或某快照合并后，受影响快照的引用块集合、回滚余量比例与依赖它的加权一致度必须级联重算并在同一事务边界内生效，禁止出现块已写入而快照链余量仍为旧值、或快照元数据已合并而部分块引用未重写的中间可见状态；快照创建期间发生的新写入不得进入该快照。
6. 实现并发写入与单写者快照控制：卷写入按卷单写者串行执行，快照创建、合并与回滚不得与同一卷的其他变更操作并行生效，多个只读查询可并发读取某一完整提交版本；同一请求标识重复提交只生效一次、其余等待并复用结果，内容不一致返回 E_CONFLICTING_REQUEST；并发写入同一块时仅一个成功、其余按版本冲突返回 E_BLOCK_CONFLICT。
7. 使用 SQLite 持久化块、快照、引用关系与意图日志，写入、快照提交、合并与回滚的操作前均先写意图记录再提交事务；进程在合并或回滚中途被强制终止后重启须扫描未完成意图，把卷与快照链回滚到最后一个完整版本或将操作标记为已中止，恢复报告只基于已落盘事实。
8. 提供本地 HTTP API 与端到端演示脚本：API 覆盖块写入、创建全量快照、创建增量快照、合并、回滚、按版本查询快照链与回滚裁决明细、误差说明查询与恢复报告查询，失败响应统一为含业务码与上下文的 JSON；脚本用固定本地样本完成一次全量与两次增量快照、一次合并、一次回滚裁决、一次强制终止后恢复，输出各版本占比、余量比例、误差上界与裁决结论。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
