团队目前只有一个笼统目标：在本地可复现条件下判断一个小型掩码语言模型中哪些注意力头可以在推理前被裁剪，并让每次裁剪决策都留下可回滚的版本记录；工作区没有任何现成代码、权重文件或样本，需要从零实现。输入由程序内置固定种子生成器在本地产出：若干层的注意力头权重分片（JSON，含层号、头号、头维度、权重与逐头激活样本），一组掩码标注句对（masked_token 与真值候选），以及一份带单调版本号的裁剪策略快照，声明候选裁剪比例、逐头激活量化位宽、重建误差容差、探测句采样上限与回滚保留代数。工作台按探测句采样、逐头裁剪重放、重建误差聚合、决策与版本提交四阶段推进。核心冲突是：逐头独立裁剪的误差并非简单可加，头间耦合会令局部误差放大，因此决策必须同时依赖逐头敏感度与组合重放，而版本回滚又要求任何一次提交都能在 SQLite 中精确复原当时生效的裁剪集合。

任务环境与准备：
安装 Go 1.22 或更高版本，并确认 go 命令在 PowerShell 中可用。
执行 go mod init 初始化模块，引入 modernc.org/sqlite 作为纯 Go 的 SQLite 驱动，执行 go mod tidy 完成依赖下载。
在工作区创建 samples 目录，运行程序内置固定种子生成器产出注意力头权重分片、掩码标注句对与裁剪策略快照。
使用 go build ./... 与 go test ./... 确认构建与本地测试可运行，无需外部服务、GPU 或网络资源。

业务要求：
1. 实现探测句采样与逐头裁剪重放阶段：依据策略快照声明的采样上限与固定种子，从掩码标注句对中确定性选取探测句，对每个头分别单独裁剪后用其余头重算被掩码位置的重建分布，输出该头的重建误差、被裁剪头标识与探测句覆盖范围；同一输入与快照必须产生逐字节一致的逐头误差表，探测句为空或样本数低于可配置下限时须返回 E_INSUFFICIENT_PROBE 并附层号与头号。
2. 实现头间耦合的组合重放与误差不可加性裁决：在逐头误差基础上按候选裁剪比例选取多个头的组合，对组合做整体重放得到真实重建误差，并与逐头误差简单求和或加权求和的预测值比对，输出耦合放大系数与超过可配置偏差的头组合清单；组合重放结果不得用逐头误差推算替代，出现某组合重放发散或重建分布全零时返回 E_NUMERIC 并保留该组合下各头贡献日志。
3. 实现基于精度的裁剪决策与预算约束：在可配置重建误差容差与裁剪数量上限内，从通过组合重放的候选集合中选出最终裁剪集合，逐头与逐组合记录取舍理由、误差余量与被否决原因；当无任何组合满足容差时须明确输出空裁剪集合并说明最接近容差的组合，不得静默放宽容差；同一快照与样本必须产生逐字节一致的决策摘要。
4. 实现逐头激活量化位宽对敏感度估计的误差界：按快照声明位宽对头激活做定点量化并记录每头缩放因子，给出逐头敏感度估计的误差界与有效位数，量化误差须由显式缩放因子推导并在结果中保留推导依据；缩放因子为零、激活含 NaN 或截断后概率和为零时返回带层号与头号的 E_QUANTIZATION，不得以截断代替数值处理。
5. 实现 SQLite 事务化的版本提交与回滚复原：每次决策提交生成单调版本号并以事务写入裁剪集合指纹、探测句摘要、量化参数指纹与决策摘要，同一版本只允许一条有效记录；回滚须恢复上一可用版本的裁剪集合与决策依据，读取任何版本不得看到半提交状态，被回滚版本保留可查，版本号回退、重复或摘要不符时返回 E_STALE_VERSION。
6. 实现策略快照或样本集整体替换的识别与失效传播：当裁剪策略快照、注意力头权重或掩码句对被整体替换时，通过内容摘要与版本序号区分正常追加、整体替换、回退与分叉，整体替换使探测重放、误差聚合与决策全部失效重建，正常追加仅让受影响头的逐头误差及其下游组合重放失效，未受影响头的误差表继续复用并须在结果中标注复用来源版本。
7. 实现并发提交互斥与结构化异常链路：多个执行进程对同一数据库提交版本时使用 SQLite 条件更新与真实文件锁，仅允许版本号连续推进，落后或并发冲突返回 E_STALE_VERSION 并附当前生效版本号；对头维度与权重不一致、句对缺少真值候选、采样上限为零、容差为负等情况须在对应阶段返回稳定业务码并在 JSON 中记录层号、头号或探测句标识。
8. 实现本地 HTTP 与命令行交互应用及确定性演示：支持导入注意力头分片与掩码句对、设置裁剪策略、触发分阶段执行、查询逐头误差与耦合放大明细、查看版本历史并触发回滚、请求优雅停止与恢复；演示数据须由内置生成器产出至少 3 层、每层 4 个头、含至少一个强耦合头组合与一个量化误差显著的头，完整运行两次得到相同摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
