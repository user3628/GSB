当前是空白工作区，没有现存项目、代码或数据附件。需要从零实现一个面向本地多可用区服务的故障隔离与容灾切换决策工作台，复现真实 SRE 场景中基于数值健康指标做切换判定的核心机制。系统管理若干可用区与其中的服务实例，每个实例周期上报健康指标（错误率、延迟分位、饱和度），工作台对每个可用区聚合指标并计算容灾切换评分；切换评分由多个加权指标项构成，各项按小数位精度截断后加权求和，指标采集存在时间窗口错位与采样规模差异，导致评分存在误差传播。工作台须在评分差值小于容差时按固定次序裁决是否切换，并在切换决策、隔离演练与恢复回切之间维护版本化状态，支持进程重启后的恢复。

任务环境与准备：
安装 Python 3.11 或更高版本，并确保 pip 可用
安装依赖：numpy、pytest，使用 pip install numpy pytest 完成
在空白工作区创建项目目录，无需外部数据库或网络服务；SQLite 使用 Python 标准库 sqlite3
准备本地确定性样本生成器所需的随机种子配置文件，不依赖外网或附件

业务要求：
1. 实现可用区与实例健康指标的摄入模型及校验：实例上报记录含可用区标识、实例标识、指标名称、指标值、采集时刻与采集序号；须校验指标值落在声明值域内、采集序号单调且同一实例同一指标重复上报须按序号大小幂等覆盖。非法记录返回固定业务码 E_BAD_METRIC 且不得进入聚合。
2. 实现多窗口指标聚合与时间对齐：按滚动窗口聚合各可用区的错误率、延迟分位与饱和度，窗口归属以采集时刻落在闭开区间 [起始, 结束) 判定；采样间隔与窗口长度不整除时尾窗须显式标记并参与聚合。聚合结果须保留至少六位十进制有效位，并记录每个可用区在各窗口内的有效采样数。
3. 实现切换评分的加权计算与误差上界量化：每个指标项按配置的小数位截断后乘以权重求和得到切换评分；须依据各项截断位数、采样数差异与窗口错位时长计算评分的误差上界，并以十进制定点字符串输出各误差来源的分解项与合成值，误差贡献从大到小排序。
4. 实现容差内并列的确定性裁决与切换决策：当最高分与次高分可用区的评分差值小于配置的相对容差（默认 0.02）时判定为并列，按更低错误率、更高可用采样数、可用区标识字典序的固定次序裁决；裁决结果须在诊断报告中标记为 tied 并附裁决键，相同输入必须产出相同决策。
5. 实现故障隔离演练与恢复回切的状态机：可用区合法状态为 active、isolated、switching、recovering，迁移由隔离演练指令、切换决策、恢复演练与健康恢复驱动，非法迁移须拒绝并返回 E_INVALID_TRANSITION。回切前须校验目标可用区连续若干窗口评分不低于当前主可用区，否则回切须被拒绝并给出未达标窗口数。
6. 实现并发演练与状态持久化的互斥及重启恢复：同一可用区的隔离、切换与回切指令须串行化到可用区一致性边界内，并发锁等待须有真实超时并返回 E_CONTENTION_TIMEOUT；决策提交点须以单事务写入 SQLite，重启后须回滚中断的切换中间状态、恢复可用区状态与版本号，且对同一输入重新计算的评分与历史记录一致。
7. 实现误差传播的可视化诊断报告与本地 HTTP 接口：提供摄入指标、触发隔离或回切演练、查询可用区状态、查询评分与误差分解报告、查询决策历史的接口，错误以固定业务码在 JSON 中返回；报告须包含各指标项截断误差、窗口错位误差、采样数差异误差、合成上界与并列裁决依据，并支持按可用区与时间窗口过滤。
8. 提供本地确定性样本与可重复测试：内置固定随机种子的指标流生成器，产出至少三个可用区、覆盖采样数差异悬殊、窗口错位与评分接近容差的场景；pytest 用例须在 Windows 离线覆盖非法指标拒绝、误差上界计算、容差并列裁决、非法状态迁移、回切未达标拒绝与重启恢复一致性。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本验证评分误差分解、容差并列裁决与切换回切状态机，并确认重启后决策一致。
