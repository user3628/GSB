项目组在一个空目录里启动文档版面阅读顺序分析的首个可运行版本，需要交付引擎本体与可交互演示应用。输入由程序内置固定种子生成器产出：一组 JSON 版面样本，每个文档声明 doc_id、页面宽高与文本框清单，每框含归一化坐标、字号档位、文本片段、语言标签与栏归属提示，覆盖单栏、双栏、分栏夹杂通栏标题、页眉页脚与中英混排。另附一份带单调版本号的阅读顺序策略快照，声明框合并间隙阈值、页边距识别阈值、栏判定参数、跨栏块优先级与顺序置信度权重。引擎按框规范化合并、栏结构推断、阅读顺序生成、结果汇总四阶段推进，对外提供可配置毫秒延迟预算的交互查询，并须保证增量更新后的重排结果与全量重建逐字节一致。

任务环境与准备：
安装 Go 1.22 或以上版本，确认 go version 可在 Linux（WSL Ubuntu）终端执行。
安装 SQLite 命令行工具用于核对持久化事实，Go 侧使用纯 Go 的 SQLite 驱动，不启用 CGO。
无需外部数据集或网络，版面样本与策略快照均由程序内置固定种子生成器在本地产出。
在工作区初始化 Go module，直接 go build 与 go test 即可运行，不依赖容器或图形界面。

业务要求：
1. 实现框规范化合并阶段：把归一化坐标按页面宽高换算为像素坐标并保持宽高一致，对水平或垂直间隙小于可配置阈值的相邻框按阅读方向确定性合并，依据距页边距离与字号档位识别页眉页脚并单独归类；同一输入与配置必须产生逐字节一致的框集合，坐标越界或宽高为零的框须返回带 doc_id 与框序号的 E_BOX_INVALID 并保留在诊断输出中。
2. 实现栏结构推断阶段：依据框的水平起点与宽度分布直方图判定页面栏数与各栏水平区间，栏区间须互不重叠且覆盖声明的有效版面宽度，通栏框须能被识别并单独标记；当栏数为零或某框无法归属任何栏时返回带 doc_id 与框序号的 E_COLUMN_UNASSIGNED，不得静默归并到相邻栏。
3. 实现阅读顺序生成阶段：把框组织为块并按栏内自上而下、栏间自左向右生成顺序，跨栏块与并列块按可配置优先级裁决且同一文档内不得出现重复框；顺序置信度须由参与裁决的框间垂直间隙与栏归属显式计算，全部置信度为零或裁决出现环时返回 E_ORDER_CONFLICT 并附冲突框对。
4. 实现交互查询的毫秒延迟预算与缓存一致性：单次查询块序列摘要、置信度明细或栏统计须在可配置延迟预算内返回，超出预算时返回带查询标识与已耗时字段的 E_LATENCY_BUDGET 结构化错误而非阻塞等待；查询缓存键须包含文档框内容指纹、策略版本与查询范围，缓存命中的结果必须与重新计算结果逐字节一致，不得返回陈旧缓存。
5. 实现 SQLite 事务化阶段检查点与优雅停止恢复：每个文档每阶段完成时在单个事务内写入含 doc_id、阶段名、输入内容指纹、策略版本、产物摘要与单调序号的记录，同一文档同一阶段只允许一条有效记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分文档后退出并保持检查点一致，恢复后结果须与一次连续运行逐字节一致，强制终止后仅凭已提交事实恢复且不承诺生成退出报告。
6. 实现策略或样本内容变化的版本指纹与增量失效传播：当文档框内容、合并阈值、栏判定参数、跨栏优先级或置信度权重任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段与最小文档集合，使该集合及其全部下游产物失效并重建，未受影响文档的上游产物继续复用，且重建后的块序列与统计须与全量重建逐字节一致。
7. 实现并发发布保护与快照整体替换识别：多个工作进程对同一 SQLite 库发布阶段产物时使用事务条件更新与真实文件锁并比较文档内序号，仅允许序号连续推进，落后、重复或跨文档错位发布须被拒绝并返回 E_STALE_CHECKPOINT；当检测到检查点记录被整体替换（序号回退、内容指纹变化或摘要不匹配）时须区分正常推进、整体替换与回退，仅正常推进被接受。
8. 提供本地 HTTP 与命令行交互应用及确定性演示：支持导入版面样本与策略快照、触发分阶段分析、查询各阶段状态与版本指纹、查看块序列与栏统计、请求停止、执行恢复与导出结果；演示数据至少 4 个文档，覆盖单栏、双栏、通栏标题与页眉页脚，一次完整运行产生固定摘要，两次相同配置运行结果逐字节一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证阅读顺序、延迟预算及增量重排与全量重建的一致性，并附运行结果。
