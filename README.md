当前是空白工作区，需从零构建一个本地可运行的分块声源分离系统，交付可交互的专业应用与可重复演示。输入为固定随机种子生成器产出的本地 WAV 分片（16 kHz、单声道、16 位 PCM），每片为 2 至 3 个合成声源混合的短音频，每片总时长 2 至 4 秒；另附 JSON 清单逐片声明声源数、各声源参考基频区间与可见性标记作为真值来源，并声明分片样本总数供一致性校验；另附 YAML 分离配置，声明帧长、帧移、频带数、掩码迭代次数、声源数上限与分块重叠比例。帧长与帧移均以样本点给出且为整数，频带数须整除奈奎斯特频率区间，分块重叠比例以百分比整数给出。系统按五个阶段推进：分帧短时傅里叶变换、频带特征提取、掩码初始化、迭代掩码精化与分块重叠相加重建。核心业务目标是对单个声源或单段频带做增量更新：当某声源的参考基频区间或某分块的掩码参数变化时，仅重建受影响的频带与分块，未受影响上游特征继续复用，且复用链路的正确性必须可验证。全部计算仅用本地 CPU 与确定性伪随机源。

任务环境与准备：
安装 Python 3.11，并通过 pip 安装 numpy、soundfile、pyyaml、pytest（版本以本地缓存可用为准，无需联网模型或 GPU）。
在空工作区创建项目目录，预留 samples、configs、state 三个子目录用于存放 WAV 分片、清单与检查点。
提供固定随机种子的本地 WAV 生成脚本，产出至少 3 个含 2 至 3 个合成声源的 16 kHz 单声道 16 位 PCM 分片及对应 JSON 清单，分片时长控制在 2 至 4 秒。
确认本地端口可用于启动 HTTP 交互接口，文件锁与原子写盘依赖标准库即可，无需容器或外部服务。

业务要求：
1. 实现分帧与短时傅里叶变换阶段：按配置帧长与帧移对 16 位 PCM 做汉宁窗分帧，输出复数谱矩阵并记录帧索引与样本偏移，帧边界超出样本末尾时须以确定性零填充并标记；同一输入与配置必须产生逐字节一致的谱矩阵摘要，帧长或帧移非正、帧移大于帧长时须返回带分片标识与参数名的 E_INVALID_CONFIG。
2. 实现频带特征提取与掩码初始化：把谱矩阵按配置频带数划分为连续频率频带，逐帧逐带计算对数能量与频谱平坦度特征，以固定哈希投影与参考基频区间先验初始化各声源掩码；特征维度与频带数不符、频谱平坦度出现 NaN 或 Inf、参考基频区间为空或上界小于下界时须返回带频带索引与帧索引的 E_NUMERIC，不得静默填充。
3. 实现迭代掩码精化与分块重叠相加重建：按配置迭代次数精化掩码，每轮以确定性顺序更新并记录逐轮掩码变化量，最终对每个声源谱做逆变换并按重叠比例把分块重叠区样本累加重建波形，累加越界的整数幅值须钳制并统计次数；同一输入与配置输出的分离波形与逐轮变化量必须逐字节一致，各声源重建波形样本总数须与输入分片样本总数一致。
4. 实现频带级与分块级增量更新协议：接受以分片标识、声源编号与频带区间描述的更新请求，仅重算受影响频带及其下游掩码与重建分块，其余频带与分块的中间状态继续复用；更新后须同时刷新相邻分块重叠区的累加贡献；增量更新后的分离波形、掩码摘要与逐轮变化量必须与从零全量重算逐字节一致，不一致须返回 E_INCREMENTAL_MISMATCH 并给出首个不一致的频带与分块坐标。
5. 实现分块中间状态的版本化持久化：每个分块在每个阶段完成后以原子方式写入包含分片标识、阶段名、分块坐标、已覆盖频带范围、输入内容指纹、配置版本、产物摘要与单调序号的记录；写入过程任意位置中断不得留下半写记录，恢复时必须忽略损坏、不完整或序号重复的记录，从最近一致检查点继续。
6. 实现优雅停止与恢复一致性：进程收到停止请求时完成当前不可拆分的分块与掩码轮次单元后退出，不承诺强制终止后生成退出报告；恢复后最终分离波形、掩码摘要、逐轮变化量与重建统计必须与一次从零完整运行的对应产物逐字节一致，且检查点序号连续推进、无跳跃与无重复。
7. 实现版本变化检测与失效传播：当分片样本内容、参考基频区间、掩码迭代次数、重叠比例或频带划分任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段与频带区间，使该区间产物及其全部下游分块失效并重建；失效原因与受影响频带清单须在查询接口中可观测，未受影响的上游产物不得被重算。
8. 提供本地 HTTP 与命令行交互应用及确定性演示：支持导入分片与配置、触发分阶段构建、执行频带增量更新、查询各阶段状态与版本指纹、查看失效原因与掩码变化量、请求停止与执行恢复；多工作进程发布同一工作区分块产物时须使用真实文件锁并比较分块序号，仅允许序号连续推进，落后或重复发布返回 E_STALE_CHECKPOINT；演示数据至少 3 个分片与 5 个频带分块，一次完整运行生成固定摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地 WAV 样本与清单验证分离结果、频带增量更新与全量一致、优雅停止后恢复一致及失效传播可观测。
