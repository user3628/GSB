当前为空工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的 LLM 分层激活精度敏感度剖面与量化策略版本回滚工作台，交付领域可视化与诊断工作台。业务目标是让研究人员在激活数据规模变化（校准激活批次由数十条增至数百条并含离群值）时判断“哪些层对激活量化更敏感”，并对每次量化策略保留可回滚的版本轨迹。输入为固定随机种子生成器产出的本地权重分片（.npz，含多层线性层权重与偏置、层名与形状清单）、本地校准激活批次（.npy 激活张量，含小批次与含离群值批次）与一份 YAML 策略配置，声明候选激活位宽档（如 8 位与 4 位）、探测批次上限、逐层敏感度阈值、策略预算口径与并发工作进程上限。工作台按四阶段推进：按层探测激活量化扰动响应、构造分层敏感度剖面、按剖面给出激活位宽分配建议、提交或回滚量化策略版本。真值来源为本地全精度参考前向输出与显式高精度累加结果，不得从缺失信息推断。敏感度剖面需在有限探测批次下给出可信排序，而批次增多时全量探测代价上升，两者需要在精度与算力间做真实取舍；同时不可用的分配方案需要回滚，与剖面的版本可见性直接冲突。

任务环境与准备：
确认本地 Windows 环境已安装 Python 3.11，并可直接执行 python 与 pip 命令，无需容器、外部服务或真实模型。
安装依赖：NumPy 与 PyYAML（以 pip 安装并在 requirements.txt 中固定版本）。
在工作区创建 weights/、calib/、configs/、scripts/ 目录，把固定随机种子生成器放入 scripts/，首轮自带样本由生成器一次产出并落盘。
准备 configs/sensitivity.yaml 与层名清单，确保至少 5 层权重、一个小批次与一个含离群值批次、并有一个在预算下必然被降档的层配置。
执行 python -m venv .venv 并激活后安装依赖，运行生成器确认样本与层名清单可重复生成且摘要一致。

业务要求：
1. 实现分层激活扰动探测阶段：对每层仅对其激活输入按候选位宽档单独施加量化扰动、其余层保持全精度，用有限探测批次的前向输出差异计算该层激活敏感度，探测批次的选择须由配置上限与固定种子显式决定；层激活维度与校准批次形状不匹配或位宽档非正整数时返回带层名与参数名的 E_PROBE_PARAM，禁止静默跳过该层。
2. 实现分层激活敏感度剖面构造：把探测结果归一化为逐层敏感度分数并给出排序、分数置信区间与有效探测样本数，区间估计须由显式探测次数与本地参考偏差计算；当某层有效探测样本数低于可配置下限时须标为探测不足并在剖面中保留而非剔除，排序中并列分数须按稳定层名次序确定性裁决。
3. 实现基于剖面与预算的激活位宽分配建议：依据逐层激活敏感度排序与可配置全局量化收益预算，在候选位宽档间给出分配方案，并记录每层的取舍理由、被降档层与收益估计明细；某层敏感度排名靠前但已无剩余预算时须在诊断中标明受预算而非敏感度约束，分配方案生成须确定性可复现。
4. 实现探测批次规模变化下的增量重算与全量一致性校验：当探测批次扩充、敏感度阈值或位宽档变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，仅重算该阶段及其下游；增量结果须与从零全量运行得到的剖面、排序与分配方案逐字节一致，不一致返回 E_INCREMENTAL_MISMATCH 并附差异层清单。
5. 实现量化策略的版本化提交与原子记录：每次分配方案被提交时生成单调版本号，以原子方式写入含版本号、逐层激活位宽分配指纹、探测批次摘要、配置版本与剖面摘要的记录，写入任意位置中断不得留下半写记录；读取任何版本前须先经索引确认存在且摘要自洽，索引缺失、摘要不匹配或序号重复时返回 E_STATE_INCONSISTENT 并附版本号与层名。
6. 实现不可用方案回滚与历史并存：当提交的方案因敏感度阈值被触发或剖面摘要不自洽而被判不可用时，须回滚到上一个可用版本，使后续剖面查询与分配建议读取到该版本内容，回滚操作本身生成可追溯记录；被回滚版本须保留在历史中供审计，不得被删除，也不得再作为当前有效版本被引用。
7. 实现并发提交保护与版本整体替换识别：多工作进程对同一工作区提交版本时使用文件锁并比较版本号，仅允许版本号连续推进，落后或重复提交返回 E_STALE_VERSION；当检测到记录被整体替换（版本号回退、指纹变化或摘要不匹配）时须区分回退、篡改与正常推进，仅正常推进被接受，非法情形返回 E_VERSION_TAMPERED 并保留原记录。
8. 提供本地 HTTP 与命令行诊断工作台：支持导入权重与校准激活批次、设置敏感度配置、触发分层探测与增量重算、查询剖面排序与激活位宽分配理由、查看版本历史并触发回滚、请求优雅停止与恢复；演示数据至少 5 层权重、小批次与含离群值批次各一，一次完整运行生成固定摘要，并演示一次回滚与一次版本整体替换识别。
