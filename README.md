当前是空白工作区，需从零构建一个本地可运行的语音转换（Voice Conversion）流式推理工作台，交付领域可视化与诊断界面。输入为固定随机种子生成器产出的本地 WAV 分片（16 kHz、单声道、16 位 PCM），每片模拟源说话人短语音段，另有 JSON 转换清单逐片声明源说话人编号、目标说话人编号、基频偏移系数、频谱包络弯折系数、帧移与期望输出样本数上界，并给出参考基频均值区间作为真值来源。系统不依赖任何真实声学模型或外部服务：以分帧加窗、自相关基频估计、梅尔域频谱包络弯折与固定哈希投影实现确定性语音转换，流程为帧分析、声学参数映射、波形重建与一致性校验四阶段。工作台须支持异常注入（声道数不符、采样率声明冲突、含 NaN 样本、清单样本数与文件不符等）并返回稳定业务码，且全过程输出可逐字节复现；同时要求流式逐块推理与整段一次性推理在拼接后结果一致，并可在逐帧延迟预算下返回诊断查询。

任务环境与准备：
安装 Python 3.10 及以上，并准备 NumPy 依赖，用于分帧、自相关基频估计与梅尔滤波器组计算。
在空工作区建立项目目录，首次运行前由本地固定种子生成器产出演示 WAV 分片与转换清单，不依赖真实音频数据集。
确认本地 HTTP 服务端口可用，命令行与 HTTP 接口共享同一工作区状态目录与文件锁实现。
准备测试入口以模拟样本数与清单不符、采样率冲突等注入参数，注入仅通过输入与参数进行，不修改源码。

业务要求：
1. 实现帧分析与声学参数提取阶段：按清单声明的帧移对 16 位 PCM 做汉宁窗分帧，逐帧以自相关法估计基频并计算梅尔频带对数能量，输出带帧索引、基频与梅尔能量摘要的帧级参数表；同一输入与配置必须产生逐字节一致的参数表，基频不可判定的静音帧须以显式未定标记记录而非填零。
2. 实现声学参数映射与波形重建核心：按目标说话人编号与基频偏移系数调整逐帧基频，按频谱包络弯折系数在梅尔域重排频带能量后经三角滤波器组与逆变换合成波形，乘以固定相位包络并量化为 16 位 PCM；输出样本数须与清单声明上界一致，量化越界须钳制并统计钳制次数。
3. 实现流式逐块推理与整段推理的一致性校验：支持把源语音按可配置块长（以帧为单位）逐块送入推理并逐块输出 PCM，流式拼接后的样本总数、逐帧基频序列、梅尔能量摘要与整段一次性推理结果必须逐字节一致；块长变化不得改变最终结果，不一致须返回 E_STREAM_MISMATCH 并附分片标识与首个失配帧索引。
4. 实现目标说话人基频区间的真值对齐诊断：以清单给出的参考基频均值区间为唯一真值来源，统计转换后基频落在区间内的帧比例、偏离均值与越界帧的帧索引清单；输出须区分插值与外推帧，偏差超过可配置容差时返回带分片标识与帧索引的 E_PITCH_OUT_OF_RANGE，不得从缺失信息推断真值。
5. 实现异常注入与业务错误码一致性：提供参数注入入口，支持声道数不为单声道、实际采样率与清单声明冲突、样本中出现 NaN、清单声明样本总数与文件实际不符、基频偏移系数为零或负等情况；各异常须在对应阶段返回稳定业务码（E_CHANNEL_UNSUPPORTED、E_SAMPLE_RATE_MISMATCH、E_NUMERIC、E_MANIFEST_MISMATCH、E_INVALID_PARAM）并附分片标识与阶段名，不得静默跳过该分片。
6. 实现阶段检查点持久化与优雅停止恢复：每分片每阶段完成时以原子方式写入含分片标识、阶段名、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；进程收到停止请求时完成当前不可拆分帧块后退出，不承诺强制终止后生成退出报告；恢复后最终 PCM 摘要、基频诊断与逐帧参数必须与一次从零完整运行逐字节一致。
7. 实现版本指纹、增量失效传播与并发发布保护：当分片样本内容、目标说话人、基频偏移系数、包络弯折系数、帧移或量化位宽任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；多工作进程发布阶段产物时使用真实文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_INVALID_STAGE，检查点被整体替换（序号回退或摘要不匹配）须识别并拒绝静默复用。
8. 提供本地 HTTP 与命令行诊断工作台及确定性演示：支持导入分片与转换清单、触发分阶段转换、按帧查询诊断并遵守可配置逐帧延迟预算（超出返回 E_LATENCY_BUDGET）、查看逐帧基频与偏差明细、执行异常注入、请求停止、执行恢复、导出 WAV 与转换报告；演示数据至少 3 个分片、覆盖中英混排语音段与至少 2 个目标说话人，并演示一次注入与一次停止后恢复的一致性比对。
