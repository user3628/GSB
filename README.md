为空工作区从零构建一个面向全景分割（panoptic segmentation）离线评估的数据处理管线与结果验证工具，核心问题是像素掩码在多种序列化格式之间互操作，以及类别词表版本演进后的兼容判定。输入是本地样本目录：一份图像清单 JSONL，每条含 image id、宽高与若干真实全景掩码段，每段给出类别名、segment 序号与像素覆盖信息；一份类别词表 JSON，含每个类别的名称、是否 thing 或 stuff、固定维度嵌入向量与类别版本号；一份候选掩码文件，格式在两种互操作表示间切换——一种是 RLE 式行段编码（按行给出起止像素列区间），另一种是 COCO 风格的 counts 压缩字符串（列差分后变长编码的游程），同一候选可能来自不同格式版本。任务需要完成两种格式到统一掩码表示的确定性互转、候选与真实掩码的匹配、按类别版本的重映射与兼容判定，输出逐图像匹配摘要与整体全景质量指标，并将处理进度持久化以支持中断恢复。工作区为空，需自行初始化项目与本地确定性样本生成脚本。

任务环境与准备：
确认 Windows 上已安装 Python 3.10 及以上，并能执行 python -m pip。
安装 NumPy、FastAPI、uvicorn 与 pytest，版本以安装时最新稳定版为准，无需特定 GPU。
在工作区根目录创建项目结构，并运行本地确定性样本生成脚本产出图像清单、两种格式候选文件与两个版本的类别词表。
启动本地 uvicorn 服务并用 curl 或 pytest 复现演示入口与错误码场景。

业务要求：
1. 入口须接收样本目录、类别词表文件、候选掩码文件、IoU 匹配阈值与并行 worker 数，校验文件存在、嵌入维度与词表一致、阈值位于开区间、worker 数为正整数；任一非法返回 E_PARAM 业务码并指出出错文件与行号，且不得创建结果文件或临时目录。
2. 须实现行段编码与 COCO counts 压缩字符串两种表示到统一掩码的确定性互转：counts 串须先做列差分与变长解码还原行段，两种方向互转后逐像素必须完全一致；行段须按起始列升序排序并合并重叠或相邻区间，越出图像宽度或行索引越界返回 E_MASK 并定位 image id 与段序号。
3. 须显式处理两种格式的互操作边界：空行在行段编码中不出现、在 counts 串中以零游程表示，互转规则须声明归一化约定并校验像素面积守恒；相邻但不相交区间的合并须按声明规则执行，往返转换后面积与段数须与声明一致，违反时返回 E_FORMAT 而非静默修复。
4. 候选与真实掩码的匹配须采用确定性贪心：按候选置信度降序、同分按候选 id 字典序处理，每个候选匹配当前 IoU 最大且尚未被占用的真实段，IoU 相同时按真实段序号升序选择；IoU 计算须只基于统一表示后的像素面积，在任意 worker 分配与执行顺序下结果逐位一致。
5. 须实现类别版本兼容判定与重映射：类别词表声明版本号，候选掩码携带生成时的类别版本；对旧版本类别名按词表历史映射表逐条判定，只有 thing 或 stuff 属性未变、嵌入维度一致且类别未被删除时才允许迁移，无法映射时返回 E_COMPAT 并列出类别名与不兼容原因，禁止静默归入忽略集。
6. 须按类别合成全景分割结果：thing 类按匹配段实例化、stuff 类按像素合并，重叠像素按匹配置信度与类别优先级确定唯一归属并统计冲突像素数；每张图的实例数与像素总数须在匹配摘要中给出，类别名不在词表或已见未见判定缺失时返回 E_CLASS 并定位 image id 与类别名。
7. 匹配进度与统计须在 SQLite 中以图像粒度事务提交，逐图像匹配结果以原子替换写入不可分割的分片文件并登记内容哈希；进程被强制终止后重启须核对分片哈希与数据库提交标记，重算未提交图像且不重复消费已提交图像，恢复后的逐图像摘要与整体指标须与无中断执行完全一致。
8. 每次完整评估须生成整体替换的版本化快照，含类别版本号、逐图像匹配摘要与分片哈希；结果验证工具读取快照时若检测到数据库版本与磁盘分片哈希不一致、类别版本变化或残留旧分片，须返回 E_STALE 并定位到 image id 与分片，禁止汇入旧数据；另须提供确定性演示入口，固定样本覆盖两种格式与旧类别版本跑出可重复结果并给出可复现请求示例。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地两种格式与旧版本类别样本验证互转一致、兼容判定及恢复后指标不变。
