当前是空白工作区，需从零构建一个本地可运行的批处理文本分类流水线，交付数据处理管线与结果验证工具。输入为固定随机种子生成的本地 JSONL 文本分片，每条含 doc_id、正文、语言标签、来源通道与人工标注类别（多类单标签，0-3 级风险）；分片按批次到达，分小规模（约 800 条、4 类）与大规模（约 8000 条、7 类）两档，含中英混排、类别极度不均衡与少量空正文样本。另附一份 YAML 判定配置，声明特征哈希维度、多项朴素贝叶斯平滑强度、各类别判定阈值、误报率上限、批量评估预算与并行工作线程数。管线需完成文本规范化与特征哈希、按批训练与打分、阈值校准与误报抑制裁决、以及结果的可复现汇总。所有判定结论必须能追溯到显式的打分明细与校准样本，不能从缺失信息推断。

任务环境与准备：
安装 Python 3.10 及以上与 NumPy（建议 1.24 及以上），确认 numpy 可导入。
准备本地工作区目录与用于并发发布锁定的写权限目录，确保多进程可创建锁文件。
运行前用固定随机种子生成器产出两档 JSONL 文本分片与 YAML 判定配置，并核对批号、语言标签与类别分布。

业务要求：
1. 实现文本规范化与特征哈希阶段：对正文做 Unicode NFKC、空白折叠、全半角统一与小写化，中文按单字与相邻二字组合切分、拉丁字母数字按连续串切分，再以固定哈希函数映射到配置维度并处理哈希冲突，输出带 doc_id、词项偏移与冲突计数的特征记录；空正文须返回带 doc_id 的 E_EMPTY_DOC 并保留在诊断输出中。
2. 实现按批多项朴素贝叶斯训练与打分核心：从各批已标注样本统计类别先验与词项条件计数，采用可配置平滑强度并全程在对数域累加后验分数，未知词项回退到可配置未知标记；同一批样本与配置必须产生逐字节一致的参数摘要与逐条分数，平滑强度为零或某类无样本时须显式处理而非静默丢弃。
3. 实现类别阈值校准与误报抑制裁决：以留出折的分数与标注估计每个类别的判定阈值，使预测误报率不超过配置上限，并输出阈值、命中率、误报率与校准样本范围；某类别校准样本低于可配置下限或误报率上限无法达成时须标记为待复核并给出可达的最优阈值，裁决结论须依赖显式校准样本而非假设分布。
4. 实现跨批一致性与不均衡类别的加权汇总：按语言标签与来源通道分层统计各类别的精确率、召回率与误报数，类别不均衡时采用可配置类别权重并全程在对数域或定点域累加，汇总结果须与逐条结果按 doc_id 排序后累加一致，误差不得超过 1e-9；某层样本为零时须保留空层记录。
5. 实现批量评估预算下的分片调度与并行归约：以批次为调度单元，在全局评估条数预算与并行工作线程数共同约束下决定接纳顺序与并发度，接纳前依据分片行数预估消耗，超预算批次记录为未处理并给出原因；并行输出经按批号与 doc_id 全局排序归约后须与单线程顺序执行逐字节一致，线程池不得以线程超时描述为已终止失控计算。
6. 实现阶段检查点持久化与优雅停止恢复：每批按特征哈希、训练打分、阈值校准、汇总四阶段完成时以原子方式写入含阶段名、批号、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分批次后退出，恢复后最终参数摘要、逐条判定与汇总报告必须与一次从零完整运行逐字节一致，检查点序号连续推进。
7. 实现版本变化检测与增量失效传播：当某批正文内容、平滑强度、哈希维度、类别阈值或误报率上限任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；提供单批替换入口仅重建失效链路，并与从零全量结果逐字节比对，不一致返回 E_INCREMENTAL_MISMATCH 并附首个差异批号与字段。
8. 实现并发发布保护、稳定业务错误码与本地确定性演示：多工作进程对同一工作区发布阶段产物时使用真实文件锁并比较批内序号，仅允许序号连续推进，落后、重复或跨批错位发布返回 E_STALE_CHECKPOINT，请求非法阶段跳转或缺失前置产物返回 E_INVALID_STAGE；演示数据至少 4 个批次覆盖两档规模、不均衡类别与空正文，并用注入的非法平滑强度与不可达误报率上限验证错误码与待复核标记。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地批次样本验证训练打分、阈值校准、误报抑制与中断恢复；增量结果须与全量逐字节一致并验证注入异常的错误码。
