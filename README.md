内部文档数字化流程要新增一个 OCR 文字检测与识别诊断工作台，当前工作区还是一片空白，需要直接实现可运行系统。输入为程序内置固定种子生成器在本地产出的小尺寸 RGB PNG 分片（含多行文字色块、不同字号与倾斜角）与一份 JSON 任务清单，逐分片声明宽高、真值文本框（归一化坐标与文本内容）、语言标签与 image_id，并提供小档（约 4 个分片）、中档（约 16 个分片）、大档（约 40 个分片）三档规模分组，每组声明分片数与总字符数作为显式观测。工作台按文本检测、文本识别、策略取舍、诊断汇总四阶段推进，运行时允许运维人员通过本地 HTTP 接口进行交互查询，查询须在可配置延迟预算内返回；同时同一分片在不同批次、不同查询路径下必须得到逐字节一致的检测框与识别文本。难点在于交互延迟预算与计算结果一致性互相牵制：缓存可缩短查询时延，但会掩盖上游变更；增量重建能降低重算成本，但可能引入与全量结果的分歧。真值只来自清单声明，不得从缺失信息推断。

任务环境与准备：
在 Windows 本地安装 Go 1.22 或更高版本，确认 go version 可用。
使用 Go 标准库实现图像解码与 PNG 读取，SQLite 通过纯 Go 驱动接入（如 modernc.org/sqlite），版本在 go.mod 中固定。
工作目录为空，从零初始化模块；确定性样本与任务清单由程序内置固定种子生成器在首次运行时产出，不依赖外部数据或网络。
运行前确认本地回环端口可用于内置 HTTP 接口，文件系统可创建 SQLite 数据库与检查点目录。

业务要求：
1. 实现文本检测阶段：对每个分片做灰度化与二值化，以可配置的字符级连通域与行投影合并规则产出候选文本框，输出归一化坐标、置信度与来源策略；同一输入与配置必须产生逐字节一致的候选框清单，候选框越界或宽高为零须返回带 image_id 与框序号的 E_BOX_INVALID 并保留在诊断输出中。
2. 实现文本识别阶段：对每个候选框依据真值文本字符集合构造本地确定性模板库，以像素归一化哈希词袋最近邻输出识别文本与置信度，并记录每个候选的匹配距离与所用模板量；模板库为空或候选框尺寸不匹配时须返回带 image_id 与候选序号的 E_TEMPLATE_MISS，不得静默跳过候选。
3. 实现基于数据规模的检测与识别策略取舍：依据规模档、总字符数、候选框数与可配置计算预算，在检测侧与识别侧各三档策略中选择组合，记录选择理由、候选打分明细、被淘汰策略与原因；小档须避免选用为大档设计的重策略，选择结果须可复算，同一输入与配置产生逐字节一致的取舍记录。
4. 实现交互查询的延迟预算与缓存一致性：单次查询（候选框摘要、识别明细或诊断统计）须在可配置延迟预算内返回，超出预算时返回带查询标识与已耗时字段的 E_LATENCY_BUDGET 结构化错误而非阻塞等待或静默截断；缓存键须同时包含分片内容指纹、配置版本与阶段版本，缓存命中结果与重新计算结果必须逐字节一致。
5. 实现诊断聚合与指标统计：按分片与规模档计算检测召回率、识别准确率、平均匹配距离、预算消耗与策略命中分布，并给出与样本规模相关的误差带估计；指标须依赖清单真值与显式候选结果，分母为零时须显式记为不适用并计数，同输入与配置的指标摘要须逐字节一致。
6. 实现 SQLite 事务化阶段检查点与优雅停止恢复：每分片每阶段完成时以事务写入含阶段名、image_id、输入内容指纹、配置版本、产物摘要与单调序号的记录，同一分片同一阶段只允许一条有效记录；写入中断不得留下半写记录；收到停止请求时完成当前不可拆分单元后退出，恢复后最终候选框、识别文本与诊断报告须与一次连续执行逐字节一致。
7. 实现版本变化检测与增量失效传播：当分片像素内容、清单真值、二值化参数、合并规则、模板库或预算配置任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物与缓存失效并重建，未受影响上游产物继续复用；增量结果须与从零全量构建做逐字节比对，不一致返回 E_INCREMENTAL_MISMATCH 并附首个差异项。
8. 实现并发发布保护与稳定业务错误码：多个工作进程对同一工作区发布阶段产物时使用 SQLite 条件更新与真实文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT；当检测到检查点被整体替换（序号回退、指纹变化或摘要不匹配）时须区分回退与正常推进，仅正常推进被接受；提供命令行与本地 HTTP 接口支持导入、执行、查询与导出。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地三档样本验证检测识别结果、延迟预算错误、增量重建与恢复的一致性，导出诊断报告。
