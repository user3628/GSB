当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的无监督异常检测与增量更新诊断工作台。输入为固定随机种子生成的本地 NPZ 样本分片：每片含特征矩阵、样本来源标识与批次编号，分小规模（约 800 行、10 列）与中规模（约 6000 行、30 列）两档，含连续列、重尾列、相关冗余列与少量缺失值，并附 JSON 声明文件记录每档行数、列数、缺失列下标与期望统计口径，作为预处理与规模判断的显式观测；数据分片按批次到达，参考分数由本地生成器在固定种子下按同一预处理与检测算法独立计算出并落盘，作为数值真值来源。工作台以确定性方式实现基于稳健协方差与孤立森林的两类无监督异常检测器，按配置完成缺失填充与标准化、模型拟合、逐样本异常分数与阈值判定、检测质量诊断（分数分布、检出率、阈值敏感度）。核心业务难点在于样本分片分批到达时的增量更新与依赖失效：新批次可能改变数据分布或缺失结构，必须识别配置与数据版本变化对下游产物的影响，仅重建失效链路，并保证增量结果与从零全量构建逐字节一致；同时需在并发发布、优雅停止与恢复、异常输入等约束下保持状态一致。

任务环境与准备：
安装 Python 3.10 及以上版本，并用 pip 安装 numpy 与 scikit-learn，均为纯本地依赖，不需要 GPU 或外部服务。
确认工作区为空目录，预留本地可写的样本、检查点与导出目录，并保证文件系统支持原子重命名与文件锁。
准备固定随机种子生成两档 NPZ 样本与声明文件的脚本，行数、列数、缺失列下标与重尾列在生成前确定并可重建。
准备按同一预处理与检测算法、在固定种子下独立生成参考分数与参考诊断文件的本地脚本，作为数值比对真值来源。
确认可启动本地 HTTP 服务端口用于诊断工作台，并验证命令行入口可执行。
不引入容器环境、真实数据集或线上资源；所有演示样本与参考诊断由本地生成器产出。

业务要求：
1. 实现预处理与两类无监督检测器拟合阶段：依据声明文件与列统计识别连续列、重尾列与含缺失列，缺失按配置填充、连续列按稳健尺度标准化；实现稳健协方差（马氏距离）与本地确定性孤立森林两类检测器，森林的切分点由固定种子派生而非外部随机源，并记录每棵树的深度与叶样本数摘要；同一输入与配置必须产生逐字节一致的预处理产物与模型参数。
2. 实现逐样本异常分数与阈值判定：稳健协方差检测器输出马氏距离分数，孤立森林输出路径长度派生的分数，两者先各自按本地参考分数的分位尺度归一化再按可配置权重合成最终异常分数，合成过程须在对数域或标准化域进行以避免重尾分数放大误差；阈值由可配置分位数规则显式确定并记录所用分位点，合成分数出现 NaN、Inf 或权重为负时须返回带样本标识与阶段的 E_NUMERIC 并保留诊断上下文，不得静默输出默认判定。
3. 实现检测质量诊断与阈值敏感度分析：输出分数分布分位数、按来源标识的检出率、不同阈值下检出率与误报估计的变化曲线，并给出与样本规模相关的误差带估计；指标计算须依赖显式的模型分数与声明文件口径，不得从缺失信息推断；诊断摘要须在相同输入与配置下逐字节一致，并按两档规模分别汇总。
4. 实现阶段检查点持久化：按预处理、拟合、打分判定、诊断四阶段，每阶段与小规模分档完成时以原子方式写入含阶段名、分档标识、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入过程任意位置中断不得留下半写记录；恢复时必须忽略损坏、不完整或序号重复的记录，从最近一致检查点继续，已发布阶段产物不得重复计算。
5. 实现优雅停止与恢复一致性：进程收到停止请求时完成当前不可拆分的拟合轮次或分档单元后退出，不承诺强制终止后生成退出报告；恢复后最终模型参数摘要、逐样本分数向量、判定结果与诊断报告必须与一次从零完整运行的对应产物逐字节一致，且检查点序号连续推进、无跳跃与重复。
6. 实现版本变化检测与增量失效传播：当样本分片内容、缺失列结构、标准化方式、检测器权重、森林参数或阈值分位数任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游产物继续复用；失效原因、受影响阶段与指纹须在查询接口中可观测，禁止用旧版本分数与诊断结果冒充新版本。
7. 实现增量重建与全量一致性校验及并发发布保护：提供单分片替换与单配置变更入口，仅重建失效链路后与从零全量构建的预处理摘要、模型参数摘要、分数向量与诊断报告做逐字节比对，不一致须返回 E_INCREMENTAL_MISMATCH 并附差异阶段；多工作进程对同一工作区发布阶段产物时使用文件锁并比较序号，仅允许序号连续推进，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT，非法阶段跳转或缺失前置阶段产物返回 E_INVALID_STAGE。
8. 提供本地 HTTP 与命令行诊断工作台及确定性演示：支持导入分片与声明文件、修改检测配置、触发分阶段执行、查询各阶段状态与版本指纹、查看失效原因与阈值敏感度曲线、请求停止、执行恢复、导出分数与诊断报告；演示数据至少覆盖两个规模档、含缺失列与重尾列，一次完整运行生成固定摘要，并演示一次阶段间触发停止后恢复、一次分片替换后的增量重建与一次注入非法阈值的错误码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
