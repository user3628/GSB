这项需求没有既有代码，需要在 Windows 本地从零构建一个面向服务网格流量治理的策略迁移与兼容裁决管线，交付数据处理管线与结果验证工具。运维团队维护多套带版本号的流量治理策略快照，内容涵盖虚拟服务路由匹配、限流阈值、超时与熔断窗口，并需与外部治理工具互换数据。外部工具同时使用紧凑二进制格式（含魔数、格式版本字节、大小端标记、长度前缀、CRC32 校验与可选字段存在位图）与分片 JSON 行格式，历史版本存在字段缺省与精度差异。管线需在导入时完成格式协商与版本兼容矩阵裁决，把策略归一化到统一内部模型，并在策略版本切换时保证派生路由索引、限流窗口统计与熔断状态整体一致，不得出现新旧策略混用。进程可能在导入或重建中途被强制终止，重启后须依据持久化事实恢复或中止批次，恢复报告只能包含已落盘事实。所有样本与端点均在本地回环生成，不依赖真实网格控制面。

任务环境与准备：
安装 Go 1.21 或更高版本并配置 GOPATH 与 PATH，在 Windows PowerShell 中执行 go version 确认可用。
准备 SQLite 与可离线获取的 Go 驱动，可预先把 mattn/go-sqlite3 或纯 Go 的 modernc.org/sqlite 拉入本地模块缓存后以离线模式构建。
准备本地固定样本：两份策略快照（二进制与 JSON 行各一，含旧版本缺字段与高版本未知字段情形）、一份导入冲突清单与一份强制终止测试脚本。
准备本地回环 HTTP 端点用于导入、查询与恢复报告验证，所有样本与端点均在回环地址上运行，不依赖外部网络与真实账号。

业务要求：
1. 实现两种持久化格式的编解码：紧凑二进制格式必须包含魔数、格式版本字节、大小端标记、每条记录长度前缀、CRC32 校验与可选字段存在位图；分片 JSON 行格式每行含虚拟服务标识、路由匹配规则、限流阈值、超时毫秒、熔断窗口毫秒与可选字段标记；任一记录的魔数、校验或长度前缀不一致时返回 E_FORMAT_CORRUPT 并指明偏移，不得部分导入。
2. 实现格式协商与版本兼容矩阵裁决：导入前检测输入格式与格式版本，按显式声明的兼容矩阵给出接受、降级接受或拒绝三种结论；旧版本缺限流阈值或熔断窗口时降级接受并按声明默认值补齐且记录降级明细，高版本含未知必填字段时返回 E_FORMAT_UNSUPPORTED 并附未知字段名；同一输入重复协商必须得到逐字一致的结论。
3. 实现速率、时间窗口与时间戳的归一化：二进制格式以 bps 与毫秒为单位、JSON 行格式以 kbps 与微秒为单位，须归一化为 bps 整数与毫秒整数并做溢出检查；微秒时间戳按调用方声明的截断规则处理亚毫秒部分并输出每条记录的舍入位与累计舍入误差；限流窗口长度须统一为毫秒并与策略声明的窗口边界对齐规则一致。
4. 实现策略快照整体替换与版本识别：快照携带单调递增版本号、生成时间与整体校验摘要，加载时须校验版本单调与摘要并整体替换旧策略，加载失败必须保持旧策略完全可用；请求携带的策略版本若在导入期间被新版本替换，须在该绑定版本上完成或返回 E_VERSION_RETIRED，不得返回跨版本混合结果。
5. 实现派生结构级联失效与原子重建：每个虚拟服务的路由匹配索引、限流窗口统计与熔断状态须维护对策略版本的引用关系；策略关键字段变化时，受影响服务的全部派生结构及依赖它们的汇总视图必须级联失效并在同一事务边界内原子重建，禁止出现路由索引已更新而限流窗口统计仍为旧值的中间可见状态。
6. 实现导入冲突解决与批次原子生效：导入策略与现有策略标识相同时，按版本号优先级、最后写入时间与稳定字典序打破平局的确定规则解决，结局分为覆盖、跳过与拒绝三类并写入导入报告；整批导入须原子生效，任一条被拒绝则整批回滚并保留旧策略集合，报告须列出每条结局与依据。
7. 实现单写者提交与多读者查询的并发一致：策略导入、版本切换与级联重建按单写者串行执行，多个只读查询（策略详情、派生结构、导入报告）可并发读取某一完整提交版本；同一请求标识重复提交只执行一次、其余等待并复用结果，内容不一致返回 E_CONFLICTING_REQUEST；查询不得看到部分重建后的中间状态。
8. 使用 SQLite 持久化策略版本、派生结构、导入报告与意图日志，所有写操作先写意图记录再提交事务；进程在导入或级联重建中途被强制终止后重启须扫描未完成意图，把策略与派生结构回滚到最后一个完整版本或将批次标记为已中止，恢复报告只基于已落盘事实，并提供本地 HTTP 接口与结果验证工具供固定样本端到端回放。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地固定样本验证两种格式互操作、版本兼容三态裁决、级联重建原子性与强制终止后恢复报告，结果逐项可核对。
