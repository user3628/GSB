当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的 Embedding 查找与 Gather 算子组件及完整示例，供上层训练推理代码以库形式集成，核心难点是分片索引描述的格式互操作与版本兼容。输入为固定随机种子生成的本地 .npz 分片：一张嵌入表按行切分为若干权重分片（每片含行区间、行偏移、embedding 维与分段摘要），另有若干索引批次分片（含索引 id 数组、批次号与可选的 gather 轴与逐元素权重），覆盖嵌入维整除与不整除分块、行区间跨界索引、重复索引、负索引、越界索引与含空批次的情形；同时提供两份结构版本不同的索引工程清单：版本 2 以显式行区间、逐分片摘要与浮点 pad 标记描述，版本 1 以整数百分比的行占比、缺少行偏移字段且把 pad 行登记为正常行。组件需要实现统一的嵌入查找与 Gather 内核、两种清单结构的双向编解码与降级回补、越界与 pad 行语义裁决、增量失效传播以及并发发布保护，并给出完整示例与本地确定性演示。

任务环境与准备：
确认 Windows 本地可运行 Python 3.10 及以上，安装 numpy 与 pytest（版本以本地可安装的稳定版为准），不依赖任何容器环境。
在空工作区创建项目目录，并准备固定随机种子的本地样本生成脚本，产出嵌入权重分片与索引批次分片 .npz 文件及两份结构版本清单，样本随项目落盘以便重复运行。
准备本地运行与验证入口（命令行脚本与测试用例），确保可在无网络、无 GPU 的机器上完成完整构建、停止恢复与错误注入演示。

业务要求：
1. 实现统一内部索引工程模型与两种清单结构版本的双向编解码：内部模型以分片标识、行区间、行偏移、嵌入维、分段摘要、pad 行标记与结构版本描述一张嵌入表的切分方式，并记录索引批次与嵌入表的关联；实现内部模型与版本 2、版本 1 清单的互转，导出后重新导入须能重建相同的行区间与 pad 行语义，不得丢失行偏移或把 pad 行静默丢弃。
2. 实现版本 1 清单的兼容解析与显式升级：版本 1 中行区间以整数百分比行占比表述、缺少行偏移字段且把 pad 行登记为正常行；导入时须按可配置规则把百分比换算为实际行号区间、推导行偏移并在结果中标注换算与降级依据，并依据分片声明的嵌入维纠正版本 1 中登记错误的维度；换算规则须可配置且转换结果可导出回版本 2 清单后再导入而语义不变。
3. 实现 Embedding 查找与 Gather 算子内核：按索引 id、配置的 gather 轴与逐元素权重在多分片嵌入表上完成查找与聚合，跨分片行区间时须按分片行偏移正确拼接，重复索引须按出现次序累加并记录命中分片，负索引须按可配置规则映射或拒绝，pad 行命中须返回零向量并计数；同一输入与配置必须产生逐字节一致的输出张量与命中明细。
4. 实现分片索引描述与算子输出的数值精度控制：嵌入输出以定点量化存储并记录每分片缩放因子与量化误差界，加权聚合须在缩放域或对数域执行以避免量级溢出；误差界须由显式缩放因子与本地高精度参考结果给出，当嵌入值出现 NaN、Inf、缩放因子为零或聚合权重全零时须返回带分片标识、索引 id 与分量位置的业务码 E_NUMERIC，不得静默输出零向量。
5. 实现索引批次异常链路与业务错误码一致性：对越界索引、索引 id 非整数、索引批次为空、分片嵌入维与清单声明不一致、pad 行与正常行区间重叠等情况，须在对应环节返回稳定业务码（E_INDEX_OOB、E_DIM_MISMATCH、E_EMPTY_BATCH、E_PAD_OVERLAP 等）并附分片标识与索引 id，非法批次不得部分写入产物，诊断输出须保留可复算的上下文。
6. 实现持久化阶段检查点与优雅停止恢复：每分片按索引校验、查找聚合、量化输出、校验四阶段完成时以原子方式写入含分片标识、阶段名、输入内容指纹、清单结构版本指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分批次后退出，恢复后输出张量、命中明细与校验摘要须与一次从零完整运行逐字节一致。
7. 实现版本变化检测与增量失效传播：当某分片嵌入权重内容、索引批次内容、清单结构版本、pad 行标记、量化位宽或聚合权重任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游分片结果继续复用；失效原因与指纹须在查询接口中可观测，禁止用旧版本结果顶替。
8. 实现并发发布保护与整体替换识别：多工作进程对同一工作区发布阶段产物时使用真实文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布须被拒绝并返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_INVALID_STAGE；当检测到记录被整体替换（序号回退、摘要不匹配或清单结构版本倒退）时须识别并区分回退、篡改与正常推进，仅正常推进可被接受。
