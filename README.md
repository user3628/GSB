当前是空白工作区，需从零构建一个本地可运行的时序预测滚动回测与并行调度工作台，交付领域可视化与诊断工作台。输入为固定随机种子生成器产出的本地确定性 CSV 序列分片：每个分片含时间戳（毫秒整数）、序列 id、目标值与若干外生变量列，覆盖日周期、趋势、缺失点与突变点，并附一份 YAML 回测配置，描述预测方法（移动平均、带衰减的指数平滑、线性自回归三种候选）、回测窗口长度、步长、预测步数、并行工作进程上限、全局最大拟合次数预算、单进程拟合配额与每次拟合的时间预算。分片清单声明每个分片的行数、时间戳范围与序列数量，作为调度预估与真值观测的显式来源，系统不依赖任何真实数据集、外部服务或 GPU。工作台需以滚动验证方式逐窗口拟合与预测，产出逐窗口误差与聚合指标。

任务环境与准备：
确认使用 Windows 10/11 且可执行 Python 3.11，安装 numpy 与 PyYAML（pip install numpy pyyaml），不引入任何容器或外部服务。
在空工作区准备目录结构（如 src、samples、config），用固定随机种子脚本生成至少 3 个 CSV 序列分片与一份分片清单，样本含缺失时间戳、缺失目标值与突变点。
准备一份 YAML 回测配置，声明预测方法、窗口长度、步长、预测步数、并行进程上限、全局拟合预算与单进程配额；确认可读写本地文件与启动多进程。
准备本地 HTTP 与命令行入口的测试脚本，仅使用本机回环地址；确认可在阶段间发送停止请求并再次启动恢复流程。

业务要求：
1. 实现三种候选预测方法与滚动窗口切分：按配置的窗口长度、步长与预测步数把每条序列切分为相互重叠的滚动折，逐折以移动平均、带衰减的指数平滑或线性自回归完成拟合与多步预测，参数采用最小二乘或显式衰减公式确定性求解；同一输入与配置必须产生逐字节一致的预测值与拟合参数。
2. 实现缺失点与突变点的显式处理：对含缺失时间戳或缺失目标值的序列按可配置规则打标并从窗口切分中剔除不可用折，对突变点按可配置相对变化阈值标记，逐折记录被剔除折数与原因；缺失点超过可配置比例或序列长度不足一个窗口时须返回带序列 id 与原因码的业务错误，不得静默产生空预测。
3. 实现预算约束下的折级并行调度：以序列折为调度单元，在全局最大拟合次数预算、单工作进程拟合配额与并行进程上限三重约束下决定接纳哪些折与并发度；接纳前依据分片清单行数与窗口参数预估拟合消耗，超预算折记录为未处理并给出原因，任何时刻累计拟合次数不得超过全局上限。
4. 实现并行执行与确定性归约：使用本地进程池并行执行已接纳折的拟合与预测，各折结果按序列 id、折序与预测步全局排序后再归约，使并行运行的逐折误差与聚合指标同串行顺序执行逐字节一致；工作进程异常须以结构化错误对象记录并保留已完成折的结果，不得以进程超时描述为已终止失控计算。
5. 实现分片级持久化检查点与优雅停止恢复：每个分片完成时以原子方式写入含分片标识、已完成折数、输入内容指纹、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分的折单元后退出，恢复后最终逐折误差、聚合指标与摘要须与一次从零完整运行逐字节一致。
6. 实现版本变化检测与增量失效传播：当分片序列内容、预测方法、窗口长度、步长、预测步数或预算配置任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早分片，使该分片及其全部下游聚合产物失效并重建，未受影响分片结果继续复用，失效原因与指纹须在查询接口中可观测。
7. 实现并发发布保护与稳定业务错误码：多个工作进程对同一工作区发布分片结果时使用文件锁并比较分片序号，仅允许序号连续推进，落后、重复或跨分片错位发布返回 E_STALE_CHECKPOINT；请求缺失前置分片的聚合、非法阶段跳转或配置越界时返回 E_INVALID_STAGE，已完成未提交结果须可安全丢弃。
8. 实现指标汇总与本地确定性诊断工作台：按序列与分片计算 MAE、RMSE、MAPE（分母为零时须显式跳过并计数）与预测区间覆盖率，输出逐折误差曲线与预算消耗明细；命令行与本地 HTTP 接口支持导入分片与配置、触发执行、查询各阶段状态与版本指纹、查看未处理折原因、请求停止、执行恢复与导出报告，演示数据须覆盖多序列与突变点。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地多分片样本验证滚动回测指标、预算裁决一致性及停止后恢复结果与完整运行逐字节一致。
