当前是空白工作区，需要从零构建一个面向本地 SQLite 数据的流式分组聚合执行引擎，交付一个可交互的领域数据编辑与操作应用。业务方在数据编辑界面中持续录入或修订带毫秒时间戳的事件记录（分组键、度量列、标签），并可以随时回看某个时间范围内的聚合结果。引擎需要按请求声明的窗口规格（滚动、滑动、会话）把事件归入窗口，并对每个窗口的每个分组计算计数、求和、最小与最大值，同时维护窗口状态在多轮增量输入下的迁移。真实数据存在两个耦合难题：一是度量列类型会随批次演化，前一批可能是整数、后一批可能是定点小数甚至被改回整数，聚合结果必须在类型切换时保持可解释且可复核；二是引擎需要周期性写入状态快照，进程可能在任意时刻被强制终止，重启后继续摄入事件所得的聚合结果必须与从未中断时逐项一致。所有样本来自本地确定性文件，服务以本地 HTTP 暴露，使用 SQLite 持久化。

任务环境与准备：
安装 Python 3.11，创建虚拟环境并用 pip 安装 fastapi、uvicorn、sqlalchemy、pytest。
在空白工作区创建项目目录，准备本地确定性事件样本文件、窗口规格与快照文件，样本含整数与定点小数两段度量列以及含迟到事件的批次。
确认 SQLite 可用且不依赖任何外部服务或容器；启动本地 HTTP 服务后先运行演示脚本，再运行测试验证窗口聚合、类型演化、快照替换与强制终止后续算一致性。

业务要求：
1. 实现事件录入与类型演化处理：事件记录含毫秒时间戳、分组键、度量值与标签，度量值可为整数、定点小数或空值；每批次需声明该批度量列的类型，引擎须校验批次内所有非空度量值与声明类型一致，不一致返回业务码 E_MEASURE_TYPE_MISMATCH 且整批不入库，并记录每个分组密钥当前生效的类型演化序列。
2. 实现三类窗口划分与归属判定：滚动窗口按固定宽度对齐到纪元边界，滑动窗口按宽度与步长生成相互重叠的窗口，会话窗口按同一分组键的空闲间隔切分；窗口起止以毫秒整数表示，边界包含关系须显式定义为左闭右闭或左闭右开并在接口返回中回显，同一事件被分配到其时间戳所属的全部窗口且不得遗漏，时间戳非单调的批次须按声明规则拒绝或排序后处理。
3. 实现分组聚合计算与类型切换语义：对每个窗口的每个分组计算计数、求和、最小值与最大值，求和全程使用定点整数或补偿求和并在度量列类型跨批次切换时输出类型提升或降级依据与每步舍入方式；空值度量不计入求和与最值但计入计数，分组无样本或全为空值时返回确定值而非异常；分位类扩展不得改变上述四项主指标的结果。
4. 定义窗口状态机，至少包含 OPEN、CLOSED、EMITTED 三种状态并规定合法迁移路径，非法迁移返回业务码 E_INVALID_TRANSITION 且不得修改已持久化状态；窗口内新事件只允许在 OPEN 状态下合并进聚合，CLOSED 之后到达的事件必须按声明的迟到策略进入迟到队列或返回 E_LATE_EVENT，EMITTED 后的窗口不得再被后续批次改写。
5. 实现状态快照与版本单调替换：快照包含窗口聚合状态、迟到队列、会话切分状态、类型演化序列与单调递增的快照版本；加载快照时必须识别版本变化并整体替换旧状态，不得把新旧快照的窗口状态混合使用，版本不单调或校验摘要失败返回 E_SNAPSHOT_INVALID 且保持加载前状态完全不变。
6. 实现基于 SQLite 的意图持久化与强制终止后断点续算：每批次合入、窗口关闭与快照提交前先写意图记录再提交事务；进程在批次合入或快照提交中途被强制终止后重启，必须扫描未完成意图回滚到最后一个完整快照或把批次标记为已中止，续算后续批次所得各窗口聚合结果须与未中断路径逐项一致，恢复报告只包含已落盘事实。
7. 实现单写者摄入与多读者查询的并发一致：事件摄入与窗口状态迁移按全局单写者串行执行，多个按时间范围与分组过滤的窗口查询可并发读到某一完整提交版本；同一批次标识重复提交只生效一次、其余等待并复用结果，内容不一致返回 E_CONFLICTING_BATCH；查询不得看到部分事件已合并而窗口状态摘要未更新的中间可见状态。
8. 提供统一业务错误码 JSON 错误体与可重复演示脚本：失败响应为含业务码与上下文的 JSON，至少覆盖 E_MEASURE_TYPE_MISMATCH、E_INVALID_TRANSITION、E_LATE_EVENT、E_SNAPSHOT_INVALID、E_CONFLICTING_BATCH；脚本用固定本地样本完成整数到定点小数的类型切换、一次滑动窗口重叠聚合、一次迟到事件处置、一次快照加载与一次强制终止后续算比对，输出每窗口聚合结果与恢复差异。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地固定样本验证窗口聚合、类型演化、快照替换及强制终止后断点续算结果一致，并输出错误码与恢复报告。
