当前是空白工作区，需从零构建一个面向跨语言检索场景的相关性打分编辑与数值误差传播工作台，交付领域数据编辑与操作应用。输入为固定随机种子生成器产出的本地 JSONL 查询-文档对分片，每条含 pair_id、query（中文或英文）、doc（与查询可能不同语言）、lang_query、lang_doc、source、可选人工相关性等级（0-3）；覆盖跨语言对（中询英档、英询中档）、同语言对、重复文本对与少量超长文本与空查询样本。另附一份 YAML 打分配置，描述词项权重来源（字符 n-gram 与词项重叠）、跨语言桥接词典权重、BM25 类参数、词项权重定点量化位宽、平滑强度、分数截断上限与相关性阈值分档；桥接词典由本地确定性小词典文件提供，作为跨语言匹配的显式观测来源。系统不依赖任何真实检索服务、翻译模型、外部站点或付费资源。工作台按四个阶段推进：文本规范化与词项抽取、跨语言词项映射与权重估计、对数域相关性打分、分档标注与误差传播诊断；编辑人员可修改桥接词典条目、量化位宽与阈值，系统须保证编辑后增量重算结果与全量重建逐字节一致，并给出分数有效位数与误差上界。

任务环境与准备：
安装 Python 3.10 及以上版本，创建本地虚拟环境并安装 numpy 与本地 HTTP 服务所需的轻量依赖，全部从本地已缓存或可离线获取的包安装。
在项目根目录执行本地确定性生成脚本，产出至少 3 个查询-文档对分片、桥接小词典文件与分档配置，随机种子固定并记录在生成脚本参数中，样本与词典均可重建。
准备空工作区目录结构与可写的检查点存储路径，确认文件锁机制在 Windows 上可用，并保留一份从零全量运行的基准摘要用于增量一致性比对。

业务要求：
1. 实现文本规范化与词项抽取阶段：对 query 与 doc 做 Unicode NFKC、空白折叠、全半角统一与小写化，中文按单字与相邻二字组合切分、拉丁字母数字按连续串切分，输出带字符偏移与语言的词项序列；空查询或空文档须标记为 E_EMPTY_TEXT 并保留在诊断中，同输入同配置的词项序列与编号须逐字节一致。
2. 实现跨语言词项映射与定点量化权重估计：依据桥接词典把查询词项映射到文档语言侧候选词项，权重由字符 n-gram 重叠度与词典条目权重合成，按配置的 BM25 类参数与平滑强度计算文档词项权重，并以可配置位宽的定点量化存储、记录每词项量化缩放因子与舍入方式。
3. 实现对数域相关性打分核心：将量化权重还原为浮点后合成相关性分数，全程在对数域累加并避免直接连乘概率，分数按配置上限截断；当出现负权重、NaN、Inf 或缩放因子为零时须返回带 pair_id、词项与阶段的业务错误码 E_NUMERIC，不得静默返回零分或空结果
4. 实现分档标注与分数分布一致性校验：按可配置阈值把分数分为不相关、弱相关、相关、强相关四档，并与可选人工相关性等级做分桶比较，输出分桶偏移、档位混淆计数与越界样本清单；当某档样本占比偏离参考分布超过阈值或档位边界与人工等级偏差超过阈值时须标记待复核并给出建议，校验结果须可查询。
5. 实现数值误差传播诊断：对每个 pair 输出各权重来源对最终分数的对数贡献、定点量化引入的误差界与分数有效位数，并以语料级汇总给出误差界随分片规模变化的估计；误差界须由显式的量化缩放因子与本地高精度参考打分路径导出，不得从缺失信息推断；报告须与按量化步长解析推导的误差界交叉核对，两者不一致的 pair 标记为待复核并附偏差来源。
6. 实现编辑后的增量失效传播与全量一致性校验：当某桥接词典条目、某分片文本、量化位宽、平滑强度、截断上限或阈值任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建，未受影响上游继续复用；提供单分片与单词典条目更新入口，仅重建失效链路后与从零全量构建的分档结果、误差报告与汇总摘要做逐字节比对，不一致须返回 E_INCREMENTAL_MISMATCH 并附差异清单。
7. 实现版本化检查点、优雅停止与并发发布保护：每阶段完成时以原子方式写入含阶段名、分片输入内容摘要、配置版本、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分分片单元后退出，恢复后最终结果与一次从零完整运行逐字节一致且序号连续推进；多工作进程发布同一工作区产物时使用文件锁并比较序号，仅允许连续推进，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_INVALID_STAGE。
8. 提供可交互编辑工作台应用与本地确定性演示：命令行与本地 HTTP 接口支持导入分片与桥接词典、编辑词典条目与打分配置、查看各阶段状态与版本指纹、查询分档结果与误差传播报告、触发停止与恢复、导出打分结果；演示数据至少 3 个分片，含中询英档与英询中档、跨分片重复文本、超长文本与空查询注入，一次完整运行生成固定摘要，并演示编辑词典条目后的增量重建与全量重建一致性比对。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地跨语言样本验证分档打分、误差报告及编辑后增量与全量逐字节一致，附运行结果。
