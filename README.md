接手冷热分层工具链替换任务时，开发机上只有一个未初始化的目录和这份需求说明，首版必须先把热度推导与容量账本做成可运行的最小闭环。平台维护若干存储分层与一批数据分片，每个分片声明标识、字节大小、热度灰度与最近访问毫秒时刻；分片热度不由外部注入，而由程序内置固定种子生成器在本地产出的访问日志按声明的滑动窗口推导，日志记录毫秒时间戳、分片标识与访问权重。分层策略以带单调版本号的 JSON 快照提交，声明各层容量上限字节、目标热度区间、单批迁移数量上限、冷却时长与目标层容量安全比例。迁移候选依赖热度推导结果与目标层预测占用，而预测占用又依赖各层已用字节的累计；字节数跨多个数量级，窗口内权重合成、比例换算与跨层累计若用浮点会引入可观测误差，进而改变候选排序、批次构成与容量占用视图的一致性。

任务环境与准备：
安装 Go 1.22 或以上版本，并确认 go 命令与 go test 可运行。
安装 SQLite 3 命令行工具用于检查数据库，Go 侧使用纯 Go 的 SQLite 驱动，避免 CGO 依赖。
在空工作目录内初始化 Go module（go mod init），仅引入标准库与 SQLite 驱动。
内置固定种子生成器写出分层策略快照、分片清单与访问日志样本，样本随程序生成，无需外部数据文件。

业务要求：
1. 实现分层、分片、访问日志与策略快照的联合加载与整体替换：分层声明介质等级与容量上限字节，分片声明标识、字节大小、热度灰度占位与最近访问毫秒时刻，日志声明毫秒时间戳、分片标识与访问权重，策略快照携带单调递增版本号、生成时间、各层容量上限、目标热度区间、单批迁移上限、冷却时长与整体校验摘要；解析时校验分片标识唯一、字节大小为非负整数并做溢出检查、日志引用的分片必须存在，非法输入返回 E_SPEC_INVALID 且整份样本不入库，快照替换失败返回 E_SNAPSHOT_INVALID 并保持旧策略完全可用。
2. 实现热度推导与容量占用并定义统一定点数值契约：由访问日志按声明的滑动窗口计算每个分片的窗口权重合计与千分比活跃度，热度灰度由活跃度与最近访问衰减按整数运算合成并输出每步舍入方式与每条日志的舍入位；各层已用容量与迁移后预测占用按字节整数累计，比例类结果保留固定小数位并输出累计舍入误差；同一快照与同一天志无论一次摄入还是分段摄入，推导结果必须逐位一致。
3. 实现迁移候选选择与批次构造：按推导出的热度是否落入目标层区间、最近访问时刻是否早于声明冷阈值、目标层预测占用是否不超过容量安全比例筛出候选，并输出每条候选的触发依据；同一分片在同一批次内不得出现两次，批次数量受单批上限约束，候选为空时返回空批次而非错误；冷却未到期的分片返回 E_COOLDOWN_ACTIVE 并附剩余冷却毫秒，已处于目标层的分片不得选自当前层迁向自身。
4. 实现迁移执行的原子容量转移与跨模块一致：迁移须真实改变分片所在分层，源层释放字节与目标层占用字节在同一事务边界内一并更新，目标层占用超过容量上限时返回 E_CAPACITY_EXCEEDED 并附预测占用、上限与差额；禁止出现分片已迁移而源层占用未释放、或目标层占用已计入而分片状态未更新的中间可见状态。
5. 实现跨层加权一致度与误差可核对输出：由各层占用比例、活跃度分布与迁移完成率按声明权重合成跨层加权一致度，加权累计使用 Kahan 或等价补偿求和，并与朴素求和在混合量级固定样本上对比给出可量化误差上界；判断一致度是否越过声明阈值时使用带相对容差的定点比较而非裸浮点比较，容差内按分层标识稳定字典序打破平局；输出所用算法标识、每步舍入位与累计误差。
6. 实现增量片段提交与派生产物级联失效：增量片段只含受影响的分层参数或分片属性并携带基础版本号，基础版本不是当前已提交版本时返回 E_STALE_BASE 且不改变任何已提交状态，同一基础版本的两个并发增量只允许一个成功；为每个分片维护其推导热度、候选资格、批次归属与分层占用视图对日志、分片属性与策略参数的引用关系，任一被引用对象变化时受影响分片的全部派生产物必须级联失效并在同一事务边界内原子重建，禁止出现热度已更新而候选资格仍为旧值。
7. 实现单写者迁移与多读者查询的并发一致及幂等：日志摄入、迁移批次执行、容量占用更新与级联重建按提交单写者串行执行，多个只读查询可并发读取某一完整提交版本；同一批次标识重复触发只执行一次、其余等待并复用同一结果，内容不一致返回 E_CONFLICTING_BATCH；查询不得看到分片已迁移而源层占用仍为旧值，也不得看到热度已重算而一致度仍未落定。
8. 实现基于 SQLite 的意图持久化与强制终止恢复，并提供本地 HTTP 接口与可重复演示：迁移意图、分片状态变更与容量占用更新在提交前先写意图记录再提交事务；进程被强制终止后重启须扫描未完成意图，把未提交迁移回滚为待迁移或标记为已中止，依据已提交事实重建各层占用并保留仍有效的冷却截止时刻，恢复报告只包含已落盘事实；接口覆盖策略提交、日志摄入、迁移批次触发、按版本查询分层占用与误差说明、恢复报告查询，失败响应为含业务码与上下文的 JSON，至少覆盖 E_SPEC_INVALID、E_SNAPSHOT_INVALID、E_STALE_BASE、E_COOLDOWN_ACTIVE、E_CAPACITY_EXCEEDED、E_CONFLICTING_BATCH。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
