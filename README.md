当前是空白工作区，没有现存项目、代码或数据附件，需从零构建一个本地可运行的视觉表征与检索系统，交付可交互的专业应用与可重复演示，核心难点是数值精度与误差传播。输入为固定随机种子生成器产出的本地小尺寸 RGB PNG 分片（几何色块与渐变区域构成，含明暗差异视角）与一份 JSONL 图文对清单，每条含 item_id、image_file、caption（中英混排）、lang 与 source；系统不依赖任何真实视觉模型、GPU 或外部服务。系统需为每张图提取确定性视觉描述子（分块颜色矩与梯度方向直方图），对文本描述做规范化后提取词袋与字符 n-gram 特征，两路特征经可配置投影矩阵映射到同一 64 维检索空间，以可配置定点量化位宽落盘为表征库，再建立倒排索引与稠密索引以支持双向检索。表征库须记录每维量化缩放因子与量化误差界，检索排序须给出相似度分解与误差传播诊断；同输入同配置的检索结果与诊断摘要须逐字节一致。

任务环境与准备：
安装 Python 3.11，并通过 pip 安装 numpy 与 Pillow（版本固定写入本地 requirements 记录），不安装任何深度学习框架或 GPU 依赖。
准备本地确定性生成器脚本，用固定随机种子产出至少 4 个 64×64 RGB PNG 分片与对应 JSONL 图文对清单，清单覆盖中英混排 caption、跨分片近似重复项与空 caption 异常样本。
准备两份配置：一份基线投影矩阵与 8 位逐维量化配置，一份变更后的投影或 4 位量化配置，用于增量重建与全量一致性比对。
确认工作区可写且支持文件锁，预留表征库、索引与检查点写入目录，运行前清空以复现首次构建。
确保本地可用 HTTP 端口与命令行入口，无需外网访问或真实账号。

业务要求：
1. 实现视觉描述子与文本特征提取阶段：图像按可配置网格切块，逐块计算颜色均值、标准差与梯度方向直方图并拼接为固定维度视觉特征；caption 经 Unicode NFKC、空白折叠与小写化后提取词袋与字符 n-gram 特征；同一输入与配置必须产生逐字节一致的特征与分块摘要，空图像、网格越界或 caption 为空须返回带 item_id 与阶段的业务错误码而非静默跳过。
2. 实现跨模态投影与定点量化落盘：以可配置投影矩阵把视觉与文本特征映射到同一 64 维空间并做单位归一化，按可配置位宽（8 位或 4 位）与逐维或逐向量粒度做定点量化，每维记录缩放因子、零点与量化误差界；反量化后的余弦相似度须与全精度相似度在声明容差内一致，缩放因子为零或矩阵形状与特征维度不匹配须返回 E_DIM_MISMATCH 或 E_NUMERIC 并附维度明细。
3. 实现误差传播追踪与有效位数诊断：对每个检索结果输出视觉路与文本路各自的对数贡献、量化引入的误差界与最终相似度的有效位数，并给出语料级误差界随分片规模变化的估计；误差界须由显式缩放因子、量化步长与本地高精度参考相似度计算，不得从缺失信息推断；出现 NaN、Inf 或负缩放因子时在对应阶段返回带 item_id 与维度位置的结构化错误。
4. 实现双向检索与相似度分解：支持文本检索图像与图像检索文本，排序按余弦相似度与倒排命中加权的可配置组合，输出 top-k 结果及每个结果的相似度分量、量化误差界与来源分片；k 超出索引规模、查询文本为空或索引尚未构建时须返回稳定业务码；相同分数须按 item_id 升序做确定性仲裁，使同输入两次运行的排序逐字节一致。
5. 实现增量更新与全量一致性校验：当图像内容、caption、投影矩阵、量化位宽或排序权重任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游表征与索引失效并重建，未受影响上游产物继续复用；增量结果须与从零全量构建的表征摘要、索引摘要与检索排序做逐字节比对，不一致须返回 E_INCREMENTAL_MISMATCH 并附差异阶段与首个差异项标识。
6. 实现持久化阶段检查点与优雅停止恢复：每个分片按特征提取、投影量化、索引构建、召回校验四阶段完成时以原子方式写入含分片标识、阶段名、输入内容指纹、配置版本、量化参数指纹、产物摘要与单调序号的记录，写入任意位置中断不得留下半写记录；收到停止请求时完成当前不可拆分分片后退出并保证检查点一致，恢复后最终表征库与检索诊断摘要须与一次从零完整运行逐字节一致，检查点序号连续推进无跳跃与重复。
7. 实现并发发布保护与快照整体替换识别：多个工作进程对同一工作区发布阶段产物时使用真实文件锁并比较分片内序号，仅允许序号连续推进，落后、重复或跨分片错位发布须被拒绝并返回 E_STALE_CHECKPOINT，缺失前置阶段产物时返回 E_INVALID_STAGE；当检测到表征库快照被整体替换（序号回退、配置指纹或摘要不匹配）时须识别为版本回退并拒绝使用旧索引，不得将新产物与旧索引混用。
8. 提供本地 HTTP 与命令行交互应用及确定性演示：支持导入分片与清单、设置投影与量化配置、触发分阶段构建、执行双向检索并查看相似度分解与误差传播诊断、查询各阶段状态与版本指纹、请求停止、执行恢复、导出检索报告；演示数据至少 4 个分片，覆盖中英混排 caption、至少两种量化位宽与含跨分片近似重复项的样本，一次完整运行生成固定摘要，并演示一次编码变更后的增量重建与一次分片间停止后恢复。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地分片验证双向检索排序、量化误差界随位宽变化及增量重建与全量结果逐字节一致，并演示停止恢复与错误码。
