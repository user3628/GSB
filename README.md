为注意力算子团队从零构建一个可集成的 RoPE（旋转位置编码）算子组件与完整示例，核心问题是按位置分块的旋转计算在多进程并行调度下受资源预算约束，且进程被强制终止后能从已提交分块恢复并与无中断执行逐位一致。输入是本地确定性生成的样本目录：一份张量描述 JSON，声明每条序列的 seq id、批量下标、查询头数、头维（须为偶数）、位置偏移与 Q、K 两个 float32 或 float64 张量分片文件相对路径；一份 RoPE 配置 JSON，声明旋转基频、频率缩放方式（线性或 NTK）、分块尺寸、并行 worker 数与单批内存预算字节数；另有一份位置掩码清单，声明每条序列中需要跳过旋转的位置区间。工作区为空，需从零创建项目：一个 FastAPI 服务提供作业创建、分块计算、快照导出与诊断查询接口，并附可集成组件与本地演示入口。

任务环境与准备：
安装 Python 3.11 及以上版本，并准备 numpy、fastapi、uvicorn、pytest 等依赖，版本以本机可安装的最新稳定版为准。
在工作区准备本地样本目录：确定性生成覆盖非方阵形状、尾块不对齐、不同头维与 dtype 的 Q、K 张量分片文件，以及对应的张量描述 JSON、RoPE 配置与位置掩码清单。
确认可用多进程方式启动服务并可从命令行访问本地回环端口；准备可用 curl 复现的请求示例前置条件。
确认可对服务进程执行强制终止以复现中断恢复场景，并能在重启后访问同一 SQLite 数据库与结果目录。

业务要求：
1. 作业创建接口接收张量描述、RoPE 配置与位置掩码清单，校验 seq id 唯一、头维为正偶数、频率缩放参数为正实数、位置偏移为非负整数、张量分片文件存在且元素数与声明形状匹配、dtype 仅为 float32 或 float64、掩码区间不越出序列长度；任一非法返回 E_PARAM 并指出文件与字段名，不创建任何结果文件或临时目录。
2. 旋转计算须按位置分块执行：块内逐位置按升序、维度按前后半配对计算正弦余弦并旋转 Q 与 K，频率由基频与缩放方式确定性派生并在 float64 下计算，尾块必须走同一路径；任意合法分块尺寸下的结果须与不分块计算在声明容差内一致，超出返回 E_PRECISION 并定位 seq 与位置。
3. 位置掩码须使被跳过的位置保持原始张量不变，且跳过不改变其余位置的旋转角度；同一位置被多个掩码区间覆盖时只记录一次跳过；掩码清单中区间起止倒置或类型非法返回 E_MASK 并定位 seq 与区间序号，跳过位置数须在诊断统计中逐 seq 给出。
4. 并行调度须把位置区间划分为可分片单元交给多进程处理，每个进程同时驻留的张量记录数受内存预算约束；驻留量须由实际分片文件元素数与 dtype 字节宽估算，超预算时先把已完成块结果原子落盘再读取下一批，禁止以固定延迟代替真实预算控制。
5. 每条序列须记录分块内容指纹，指纹由 Q、K 分片内容哈希、基频与缩放参数、分块尺寸、跳过位置集合与累加 dtype 共同决定；配置或掩码变更时须只重算指纹变化的分块及其下游汇总，未受影响分块必须复用已持久化的旋转结果。
6. 每块完成后须把旋转结果以原子替换写入不可分割的结果分片文件，并在 SQLite 中以序列与块粒度提交完成标记与内容哈希；进程被强制终止后重启须核对分片哈希与数据库标记，重算未提交块且不重复消费已提交块，恢复后逐元素结果须与无中断执行一致。
7. 每次完整计算须以整体替换方式生成版本化快照，含配置指纹、逐序列块摘要与结果文件内容哈希；读取快照时若检测到磁盘哈希与数据库记录不一致、配置指纹变化或残留旧版本分片，须返回 E_STALE 并定位到序列与块，禁止汇入旧数据。
8. 须提供确定性本地演示入口与可集成示例：用覆盖尾块不对齐、掩码跳过、两种频率缩放与中断恢复的固定样本，输出逐序列分块数、跳过位置数、两档累加 dtype 差值、实际重算块数、快照版本序列的可重复结果，并给出可用 curl 复现的请求示例。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证分块旋转结果、预算调度、中断恢复与版本快照的一致性及错误码处理。
