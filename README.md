当前是空白工作区，需从零构建一个本地可运行的线性模型正则化训练工作台，交付可交互的专业应用与可重复演示。输入为固定随机种子生成的本地 CSV 样本集，含连续特征列、类别列与一个二分类标签列，按小规模（约 600 行、12 列）与中规模（约 6000 行、40 列，含相关冗余列与少量缺失）两档提供，另附一份声明文件记录每档的文件名、行数、列数与特征语义。工作台以确定性方式实现 L1/L2/弹性网正则化的逻辑回归训练：按配置执行列预处理、正则化强度与混合比例设置、分折交叉验证选择、坐标下降或近端梯度求解，产出系数向量、截距、各折验证目标值与训练轨迹摘要。整个训练被划分为预处理、折划分、逐折求解、汇总四个阶段，每个阶段需持久化检查点；会话中修改正则化强度、混合比例、折数或预处理方式后要按版本指纹定位失效的最早阶段并增量重建；进程被优雅停止后要从最近一致检查点恢复，最终系数与逐字节确定的全量运行结果一致。工作台还需处理多工作进程并发发布、非法超参数、数值发散等异常，并提供可交互接口与固定摘要演示。

任务环境与准备：
安装 Python 3.10 及以上版本，并通过 pip 安装 numpy 与 pytest（版本以本地可离线获得的 wheel 为准），无需 GPU 与外部网络服务。
准备本地确定性样本生成脚本，以固定种子生成两档 CSV 样本与声明文件，并生成含缺失列与冗余列的中规模档；样本与脚本随工作区一同落盘。
确认工作区目录具备可写权限用于检查点与快照文件，准备本地 HTTP 服务端口用于交互接口演示，并准备固定摘要比对脚本用于重复运行验证。

业务要求：
1. 实现预处理与分折阶段：依据声明文件与列统计识别连续列、类别列与含缺失列，连续列做标准化、类别列做独热或目标编码、缺失值按配置填充，并按可配置折数与固定种子做分层划分；同一输入与配置必须产生逐字节一致的预处理产物与折划分，空列或全缺失列须在阶段内以 E_EMPTY_FEATURE 报告而不中断其余列处理。
2. 实现三类正则化的确定性求解核心：支持 L1、L2 与弹性网（混合比例可配置）的逻辑回归训练，采用坐标下降或近端梯度法沿正则化路径求解，逐轮记录目标函数值、系数变化量与迭代步数；当正则化强度为零时须退化为无正则求解且不出现除零；同一输入与配置下系数、截距与轨迹摘要必须逐字节一致。
3. 实现分折交叉验证与选择：对每折独立求解并记录验证目标值，按可配置指标汇总各折均值与标准差，选择指标最优的正则化强度与混合比例；折数少于 2、某折只含单一类别或指标出现 NaN 时须返回带折号与原因的 E_INVALID_CV 或 E_NUMERIC，不得静默跳过该折后继续给出选择结论。
4. 实现持久化阶段检查点：每个阶段与每折完成时以原子方式写入含阶段名、折号、输入内容指纹、配置版本、系数摘要与单调序号的记录，写入过程任意位置中断不得留下半写记录；恢复时必须忽略损坏、不完整或序号重复的记录，从最近一致检查点继续，已完成的折不得重复求解。
5. 实现优雅停止与恢复一致性：进程收到停止请求时完成当前不可拆分的求解轮次单元后退出，不承诺强制终止后生成退出报告；恢复后最终系数向量、截距、各折验证目标值与汇总摘要必须与一次从零完整运行的对应产物逐字节一致，且检查点序号连续推进、无跳跃与回退。
6. 实现版本变化检测与失效传播：当样本内容、标准化方式、编码方式、正则化强度、混合比例、折数或求解器容差任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段，使该阶段及其全部下游产物失效并重建；未受影响上游产物继续复用，失效原因与指纹须在查询接口中可观测，禁止复用旧版本的系数结果。
7. 实现并发发布保护与数值异常链路：多工作进程对同一工作区发布阶段产物时使用文件锁并比较序号，仅允许序号连续推进，落后、重复或跨折错位发布返回 E_STALE_CHECKPOINT；请求非法阶段跳转或缺失前置产物返回 E_INVALID_STAGE；求解中出现 NaN、Inf 或发散（目标函数超出可配置上界）时返回带折号、迭代轮次与超参数的 E_NUMERIC，且该折记录不得被标记为完成。
8. 提供交互式应用与本地确定性演示：命令行与本地 HTTP 接口支持导入样本、设置正则化配置、触发分阶段训练、查询各折状态与版本指纹、查看失效原因、请求停止、执行恢复、导出系数与轨迹；演示数据覆盖两个规模档、含缺失列与相关冗余列，一次完整运行生成固定摘要，并演示在折间触发停止后恢复与注入非法混合比例验证错误码。
