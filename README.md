这项需求没有既有代码，需要为 Windows 主机安全加固团队从零构建一个服务控制与提权面裁决工作台。团队维护同一批 Windows 服务在多代策略版本下的声明：一类是自研紧凑二进制策略包（带魔数与版本头，v1 与 v2 两代布局不同，v2 增加服务账户类型与登录能力字段），一类是扫描器导出的逐行 JSON 服务清单，一类是旧版加固工具产出的带长度前缀文本块。三类来源对服务启动类型、服务账户（LocalSystem、NetworkService、自定义账户）、二进制路径可写性与未加引号路径给出了互不兼容的表述，历史快照也可能由旧版裁决器产生。工作台需把同一服务的多源声明归并为一致的提权面判定，识别未加引号路径、可写目录下的服务映像与高权限账户组合等风险，提交带递增版本号的服务裁决快照，支持整体替换识别、并发多服务裁决与强制终止后的恢复，并通过外部参数注入异常验证互操作边界。

任务环境与准备：
安装 Go 1.22 或更高版本（Windows amd64），确认 go version 可用。
使用 go mod init 初始化模块，依赖仅使用标准库与本地纯 Go SQLite 驱动（如 modernc.org/sqlite），通过 go get 安装，不依赖 CGO 与容器环境。
在 Windows 本地工作目录下运行，无需外部账号、网络服务或真实主机日志；所有样本由程序内置确定性生成器在临时目录中产出。
验证时先执行 go build ./... 与 go test ./...，再运行内置演示子命令生成样本并输出 JSON 报告。

业务要求：
1. 实现三类服务策略源格式的解析与统一规范化：二进制策略包按魔数与版本头区分 v1/v2 字段布局并逐条提取服务名、显示名、启动类型、映像路径、服务账户与登录能力字段，JSON 清单逐行解析，文本块按长度前缀提取记录；统一为内部服务声明模型，非法魔数或未知版本返回稳定业务码 E_FORMAT_VERSION 并记录可跳过的字节范围。
2. 实现服务映像路径的规范化与未加引号路径判定：把映像路径按 Windows 路径规则归一（大小写不敏感、正反斜杠等价、去除多余分隔符），识别含空格且未加引号的路径并给出可执行候选前缀分割结果；路径非法或含未终止引号返回 E_PATH_MALFORMED，判定所用的归一形式须在输出中可见以保证可复核。
3. 实现服务账户权限等级与权限边界建模：把 LocalSystem、NetworkService、LocalService 与自定义账户映射为有序权限等级，结合启动类型与登录能力字段计算服务的有效权限画像；当服务以高权限账户运行且映像位于可写目录时标记 E_PRIVILEGE_EXPOSURE，账户类型未知返回 E_ACCOUNT_UNKNOWN，等级比较必须可传递且不依赖浮点。
4. 实现多来源服务声明的归并与裁决核心：以规范化服务名为归并键，按可配置来源优先级（二进制策略包、JSON 清单、文本块旧工具）选出权威声明；当权威与非权威来源在启动类型、映像路径或服务账户上冲突时标记 E_DECLARATION_CONFLICT 并记录两侧原值与来源偏移，归并结论须按服务名与业务码稳定排序。
5. 实现带版本号的服务裁决快照与版本兼容加载：每完成一轮归并与裁决后在单个 SQLite 事务内提交递增版本号快照，快照记录所依赖的格式版本集合与来源优先级配置；加载旧快照时若其格式版本或优先级配置与当前不兼容须整体拒绝并返回 E_SNAPSHOT_VERSION，版本链跳号或以整体替换方式更新时同样拒绝并回退到最近连续版本，快照比较须识别整体替换而非仅比对版本号。
6. 实现并发多源裁决调度与资源控制：各来源文件在独立裁决会话中处理，会话间服务状态与归并暂存隔离，归并阶段按服务名分区串行以保证结论确定；并发度与单会话服务条数上限可配置，超并发上限的来源进入等待队列而非直接拒绝，单来源服务条数超限时以 E_SERVICE_BUDGET 终止并保留已解析部分，在途会话数须可观测且所有并发错误可追溯至具体来源与偏移。
7. 实现强制终止后的恢复一致性与异常注入验证：归并或快照提交过程中进程被强制终止后重启，依赖 SQLite 已提交事务恢复快照版本与归并进度，已提交快照不回退、未提交事务整体丢弃且该来源可重新裁决，恢复后版本链跳号须以 E_SNAPSHOT_VERSION 暴露；通过外部命令行参数或配置文件构造未知版本头、文本块长度前缀越界、映像路径未终止引号、账户类型未知、声明冲突与快照版本跳号六类样本，分别断言对应业务码、已提交快照版本未被推进、其余服务结论不受污染。
8. 导出确定性 JSON 裁决报告与可交互操作应用：报告包含各源解析摘要、每服务的归一映像路径与权限画像、归并与冲突明细、业务码及来源偏移与快照版本链，按服务名与业务码稳定排序，时间字段仅使用固定采样标记；以子命令方式支持一键运行、按版本回放、查询单服务多源溯源链与切换目标格式版本，重复运行且输入与参数不变时报告字节级一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
