多模态推理链的数值可信度评审需要先有一个可独立运行的验证原型，当前目录只放着一份尚未展开的设想记录，没有任何模块骨架。程序内置固定种子生成器在本地确定性产出文本侧 JSONL（text_id、文本、语言标签、来源通道）与小尺寸灰度 PNG 视觉侧清单（image_id、文件名、为每个视觉条目准备的分块像素摘要与定点中间特征、关联 text_id、来源算子标签），两侧通过 text_id 关联，覆盖中英混排、一对多关联、缺失关联、空文本与含极值特征。与普通相似度审计不同，本任务把审计对象放在推理链的中间张量上：每个视觉条目与文本条目各自经固定哈希与固定线性变换产生一组带形状声明的中间激活张量，量化位宽、变换矩阵与容差由带单调版本号的推理策略快照声明，另有一份以定点量化保存的参考中间张量作为唯一真值来源。管线按像素摘要与文本规范化、中间张量生成与定点量化、逐层误差归因、跨模态张量配对审计四阶段推进，每个阶段的输入摘要、量化参数与产物都要可追溯，误差界必须由显式缩放因子、累加顺序与张量形状推导，不能从缺失信息推断。

任务环境与准备：
安装 Go 1.22 或以上版本并确认 go version 可用；在 WSL Ubuntu 本地工作目录执行 go mod init 初始化模块。
安装 SQLite 开发库并按所选驱动执行 go get，使用源码内置参数启用 WAL 与忙等待；无需容器、GPU 或外部网络。
样本、灰度 PNG 分片与定点参考中间张量全部由程序内置固定种子生成器在本地产出，首次运行即可生成演示数据。

业务要求：
1. 实现像素摘要与文本规范化阶段：对灰度 PNG 解码并校验实际宽高与清单声明一致，不一致返回带 image_id、声明值与实际值的 E_DIM_MISMATCH；对文本做 Unicode NFKC、空白折叠与全半角统一后按中文单字与拉丁连续串切分并保留字符偏移；空文本、全零像素分片或切分后零词项时返回带条目标识的稳定业务码，且同一输入下摘要逐字节一致。
2. 实现中间张量生成与定点量化：按策略声明的变换矩阵与形状为每个视觉与文本条目产出带形状声明的中间激活张量，按位宽与逐维或逐通道粒度量化，逐维记录缩放因子、零点、量化步长与钳制次数；变换矩阵维度与输入不符、形状声明与实际张量不一致或缩放因子为零时返回 E_TENSOR_INVALID 并保留诊断上下文。
3. 实现逐层定点前向并记录累加顺序：量化后的中间张量按声明的层级顺序前向传播，逐层记录累加位宽、溢出钳制次数与参与运算的张量切片来源；累加必须按显式配置的顺序或补偿求和执行，同一输入与策略在任意合法分块方式下逐层输出须逐字节一致，出现 NaN/Inf 时返回带层名与条目标识的 E_NUMERIC。
4. 实现逐层误差归因与误差界推导：把每层输出与定点参考中间张量按显式抽样位置比对，计算逐层绝对偏差与相对偏差，并按一阶敏感度与逐层扰动重放两种方式把端到端偏差分摊到各层；误差界须由缩放因子、量化步长与累加顺序逐层推导并输出有效位数，两种归因排序不一致的层标记待复核并保留两种依据，偏差超容差返回带层名与最大偏差的 E_TOLERANCE_EXCEEDED。
5. 实现跨模态张量配对审计与最小样本集合定位：按 text_id 关联关系把视觉与文本中间张量配对，一对多关联须逐一配对并记录配对依据，缺失关联记为不可配对并计入汇总；审计结论须指明偏差最大的层、条目与配对，并给出受影响的最小样本集合，汇总与逐条审计结果按条目标识排序后累加一致，分母为零时显式记为不适用。
6. 实现版本指纹与阶段级增量失效传播：当文本内容、像素摘要、变换矩阵、量化位宽、层级顺序或容差任一变化时，由各阶段内容摘要构成版本指纹，识别受影响的最早阶段与最小样本集合，仅重建该集合及其下游逐层结果，未受影响上游产物继续复用；增量结果须与从零全量运行逐字节一致，否则返回 E_INCREMENTAL_MISMATCH 并指出首个差异条目与层名。
7. 实现 SQLite 事务化阶段检查点与优雅停止恢复：每个条目每阶段完成时在单个事务内写入含阶段名、条目内容指纹、策略版本、量化参数指纹、产物摘要与单调序号的记录，同一阶段同一条目只允许一条有效记录；收到停止请求时完成当前不可拆分条目单元后退出，被强制终止后重启仅凭已提交事实恢复进度，不承诺生成退出报告，恢复后的逐层输出与审计报告须与一次连续运行逐字节一致。
8. 实现并发发布互斥、快照整体替换识别与本地演示工具：多工作进程对同一库发布阶段产物时使用条件更新与真实文件锁并比较序号，仅允许序号连续推进，落后、重复或跨阶段错位发布返回 E_STALE_CHECKPOINT；检测到记录被整体替换（序号回退、指纹变化或摘要不匹配）时区分正常推进、整体替换与回退，仅正常推进被接受，整体替换使全部派生产物失效重建；提供本地 HTTP 与命令行入口导入样本与策略、查询逐层误差界与失效原因、请求停止与恢复，演示数据至少 3 条文本与 4 个视觉条目，覆盖中英混排、一对多关联、缺失关联、空文本与含极值特征，两次相同配置运行得到逐字节一致的审计摘要。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证中间张量逐层误差界与参考比对、跨模态配对审计，并确认中断恢复后结果与连续运行逐字节一致。
