这项需求没有既有代码，需要为 Windows 主机安全团队从零构建一个本地提权检测的领域可视化与诊断工作台。工作台读取程序内置确定性生成器产出的两类本地样本：一类是进程与服务声明清单（JSON 行格式），记录进程标识、可执行路径、启动账户、继承句柄声明、服务二进制路径与写权限声明；另一类是提权嫌疑事件流（带长度前缀的文本块），记录事件序号、主体、目标对象、操作类型、权限位掩码与相对观察起点的纳秒时间。检测逻辑需要把权限位掩码、路径可写性评分与时间偏移换算为以 1e-6 为最小单位的整数定点数参与打分，禁止浮点，换算与累计中的截断误差必须逐次记账并聚合出有界误差上界，据此区分确定性提权嫌疑与由数值误差导致的不确定性区间。工作台还需维护带递增版本号的检测快照、支持并发会话资源控制、强制终止后恢复与异常注入验证，并以子命令方式提供可视化诊断与确定性 JSON 报告。

任务环境与准备：
安装 Go 1.22 或以上版本，确保 go 命令可在 Windows 命令行直接调用。
在 go.mod 中引入纯 Go 的 SQLite 驱动（如 modernc.org/sqlite）或用 CGO 的 mattn/go-sqlite3，并执行 go mod tidy 拉取依赖。
准备本地临时工作目录用于样本生成与会话隔离，无需网络、账号或外部服务。
确认 Windows 用户对临时工作目录具备读写权限，用于快照库与样本文件的创建与清理。

业务要求：
1. 实现两类本地样本的解析与统一规范化：逐行解析进程与服务声明清单，按长度前缀提取提权嫌疑事件流，统一为含进程标识、可执行路径、启动账户、继承句柄、服务路径写权、事件序号、主体、目标对象、权限位掩码与相对时间偏移的内部模型；解析时校验进程标识唯一性、账户层级合法性与权限位掩码范围，非法输入返回稳定业务码 E_SAMPLE_PARSE 并记录源偏移。
2. 实现定点换算与误差记账层：把权限位掩码权重、路径可写性分级与纳秒时间偏移统一换算为 scale=1e-6 的 int64 定点数，时间偏移归一到观察起点后的秒分值，整数路径禁止出现浮点；每次乘法与截断的误差逐项写入误差账本，按进程与事件聚合出有界误差上界，溢出返回 E_SCORE_OVERFLOW 且账本不被写入。
3. 实现提权嫌疑打分与误差区间裁决核心：对每个进程综合服务路径可写性、继承句柄来源、启动账户等级与提权类事件命中计算整数定点评分，并叠加聚合误差上界得到评分区间；当评分区间下界高于可疑阈值时判为确定性提权嫌疑（E_PRIV_ESCALATION），当区间跨越阈值时判为不确定性区间（E_INDETERMINATE_RANGE），并把区间与依据写入结论。
4. 实现进程关系与继承句柄溯源：依据事件流中的主体与目标对象建立父进程与子进程边和句柄持有边，把越权写操作归因到提供可继承句柄的父进程；对缺失父进程创建事件的孤儿子进程标记 E_ORPHAN_REF 并挂到虚拟根，溯源链须能在诊断视图中逐跳展示且不受归并顺序影响。
5. 实现带版本号的检测快照与整体替换识别：每完成一轮检测后在单个 SQLite 事务内提交递增版本号快照，记录进程结论、评分区间、误差账本摘要与样本版本；快照内容比较须识别整体替换式版本变化而非仅比对版本号，加载时校验版本链连续性，跳号返回 E_SNAPSHOT_VERSION 并回退到最近连续版本。
6. 实现并发检测会话的资源控制与会话隔离：多个样本批次在独立会话中并发检测，会话间进程状态与误差账本隔离；并发度、单会话进程数与单会话事件数上限均可配置，超并发上限的批次进入等待队列而非直接拒绝，单会话进程数或事件数超限时以 E_SESSION_BUDGET 终止该会话并保留已提交快照，不污染其他会话结论。
7. 实现异常链路注入验证与单调时钟观测：通过外部命令行参数或配置文件构造权限位掩码越界、定点乘法溢出、可继承句柄越权、孤儿子进程与快照版本跳号五类样本，分别断言对应业务码、已提交快照未被推进、其余进程结论不受污染；检测耗时以单调时钟差值采样，时间字段只使用固定采样标记，注入仅通过输入与参数进行。
8. 实现强制终止后的恢复一致性与确定性可视化诊断：检测或快照提交过程中进程被强制终止后重启，依赖 SQLite 已提交事务恢复快照版本与检测进度，已提交结论不回退、未提交事务整体丢弃且该批次可重新检测，恢复后版本链跳号须以 E_SNAPSHOT_VERSION 拒绝加载；以子命令方式提供查看进程溯源链、按版本回放快照、展示评分区间与误差账本，并导出按进程标识与业务码稳定排序的 JSON 报告，时间字段只使用固定采样标记。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证定点评分区间裁决、评分区间与溯源结果、快照版本演进、并发隔离、中断恢复与异常注入，输出可重复 JSON 报告。
