当前是 Windows 空白工作区，需从零构建一个面向本地对象存储语义的分段上传元数据索引组件，供上层文件同步客户端集成，交付可集成的领域组件与完整示例。对象以对象键唯一标识，上传被切分为有序分段，每段携带序号、字节大小、SHA-256 摘要与到达毫秒时刻；组件以 SQLite 持久化上传会话、分段记录与对象元数据，并在内存中维护三类派生索引：按会话的分段连续区索引（用于快速判断缺口）、按对象键的会话代际索引（用于并发同键上传裁决）、按内容摘要的分段去重索引（相同摘要分段只存一份引用）。上游客户端会边编辑边上传，中途取消、重传某段、乱序提交或在同键上并发发起多个会话；分段提交后必须增量维护三类索引而非全量重建，并对外暴露带版本的索引视图，查询只能看到某一完整提交版本的分段与索引状态。数据规模从数百段增长到较大批次，去重引用计数与代际索引在成本上存在取舍，交付需附完整示例与可复现验证脚本。核心业务问题不是倒排检索，而是分段清单的结构化索引一致性与去重回收安全。

任务环境与准备：
安装 Python 3.11 或以上，并确认 pip 可用。
在空白工作区创建项目目录，安装 FastAPI、uvicorn、NumPy 与 pytest（版本以 pip 当前稳定版为准）。
准备固定本地样本目录：含乱序分段、重复摘要分段与并发同键会话的批次 JSON，以及强制终止演练所需的批次序号清单。
确认本地回环端口可用，HTTP 服务绑定 127.0.0.1，SQLite 数据库文件置于工作区 data 目录。
强制终止演练由独立脚本在合并或提交中途终止进程，重启后查询恢复报告，恢复信息仅来自已持久化事实。

业务要求：
1. 实现上传会话、分段与对象元数据模型：会话记录对象键、会话标识、分段序号下界与状态；分段记录会话标识、序号、字节大小、SHA-256 摘要与到达毫秒时刻；对象元数据记录键、总大小、分段数、对象摘要与代际序号。解析本地样本时校验序号为正整数、摘要格式合法、字节大小非负并做溢出检查，解析失败返回业务码 E_PART_INVALID 且整批不入库。
2. 实现分段连续区索引的增量维护：每个会话维护已提交序号的有序连续区集合，提交一段时只合并或扩展受影响的相邻区间而非重建全部区间；重复提交同序号且摘要一致视为幂等成功并把重复次数计入统计，摘要不一致返回 E_PART_MISMATCH 并保留首次提交；取消会话后其全部区间失效。
3. 实现按内容摘要的去重引用计数索引：相同摘要的分段只存一份内容记录，各会话分段通过引用计数指向它；提交分段时在同一事务边界内递增引用计数，删除分段或取消会话时递减，计数归零的内容记录先迁移为待回收再真实移除；禁止出现双向索引中一方已更新而另一方仍为旧值的中间可见状态。
4. 实现对象键会话代际索引与同键并发裁决：同一对象键可有多个会话，代际索引记录各会话的代际序号与状态；发起会话时若同键已有进行中会话，按声明策略返回 E_SESSION_CONFLICT 或允许并存但代际递增；合并请求必须基于同一代际，代际不匹配返回 E_SESSION_STALE 并附当前代际。
5. 实现带版本的索引视图与版本回收：每次提交产生严格单调递增的索引版本，查询携带版本并在该版本上执行，不得读取更高版本的索引内容；旧版本查询在增量修改后仍须正确，版本被回收后对应查询返回 E_VERSION_RETIRED；回收以最小活跃查询版本为界，回收后不得再返回已删除分段。
6. 实现对象合并的原子提交与摘要一致性：合并前校验分段序号连续无缺口、各段摘要与已存记录一致、对象总大小等于各分段大小之和；任一项不满足返回对应的业务码（至少含 E_PART_MISSING、E_SIZE_MISMATCH）；合并须在同一事务边界内写入对象元数据与对象摘要并使会话置为完成，同键重复合并只允许一次成功。
7. 实现索引段合并与强制终止恢复：分段索引按会话聚簇为可压缩的索引段，合并把多个索引段压缩为更少段并保持每个版本区间的查询语义与去重引用计数不变，合并前写入意图记录；进程在合并或批次提交中途被强制终止后重启须扫描未完成意图，丢弃未完成的合并产物并把分段、引用计数与索引回滚到最后一个完整版本，恢复报告只基于已持久化事实，不得声称强制终止后仍生成完整退出报告。
8. 提供本地 HTTP API 与可复现验证脚本：API 覆盖发起会话、提交分段、按版本查询分段清单与索引状态、合并、取消会话、查询对象元数据、查询恢复报告，统一错误响应为含业务码的 JSON；脚本使用固定本地样本完成一次全量提交、一次乱序与重复提交交错的增量批次、一次去重引用归零回收、一次索引段合并与一次强制终止后重启恢复，输出版本轨迹、连续区状态、引用计数与恢复差异，供人工核验。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
本地样本验证分段索引增量一致性、按版本查询与强制终止后恢复，附运行结果。
