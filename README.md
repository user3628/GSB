一个单机混合精度训练项目刚进入第一次技术验证阶段，工作区目前为空，需要把检查点分级存储与显存预算调度的设想落成可运行组件，供训练编排器集成。训练按轮次推进，每轮产生按参数分片组织的权重副本：一部分分片以 FP16 形式驻留高速显存池，另一部分以 FP32 主参数形式落在低速持久池，另含优化器动量与损失缩放系数。训练编排器通过本地 HTTP 接口提交带版本号的精度策略快照（分片驻留分配、损失缩放初始值与增长因子、显存池字节上限、每轮写盘字节预算），并以只含受影响分片的增量片段调整。组件需在显存池上限与写盘预算的双重约束下完成驻留、驱逐与分级写盘，并在进程被强制终止后依据 SQLite 持久化事实恢复一致状态。

任务环境与准备：
Windows 开发机，安装 Go 1.22 或以上并确认 go version 可用；无需容器或外部服务。
在空白工作区初始化 Go module，引入 SQLite 驱动（如 modernc.org/sqlite 纯 Go 驱动）并在 go.mod 中固定版本。
组件启动时由内置固定种子生成器在临时目录产出分片样本、精度策略快照与增量片段，无需下载数据集或依赖 GPU。
本地 HTTP 监听端口由启动参数指定，验证脚本使用同一端口完成提交、查询与强制终止后恢复检查。

业务要求：
1. 实现分片与双池存储模型：每个分片记录标识、轮次、精度标记（FP16 或 FP32）、字节大小、内容摘要、所在池与最近访问时刻，FP16 副本须与对应 FP32 主参数分片的摘要满足声明的还原关系；数据由程序内置固定种子生成器产出，解析时校验精度标记在允许集合内、字节数为正整数并做溢出检查，失败返回 E_PARTITION_INVALID 且整批不入库。
2. 实现显存池驻留与驱逐裁决：显存池内分片总字节不得超过策略声明的显存池字节上限，新分片驻留前按最近访问时刻与精度标记计算可驱逐候选并真实驱逐，被驱逐分片回落到持久池且状态迁移为 PERSISTED；当驱逐后仍不足以容纳新分片时返回 E_VRAM_POOL_FULL 并附上限、当前占用与所需字节，不得静默超限。
3. 实现混合精度数值契约与还原校验：由 FP16 副本与损失缩放系数还原参数量时显式声明舍入方式并使用定点或整数表示，输出每个分片的还原偏差与累计舍入误差，并与 FP32 主参数逐元素比较给出最大绝对与相对偏差；损失缩放系数的增长与回退须按声明的增长因子与溢出阈值推进，越界返回 E_LOSS_SCALE_OVERFLOW。
4. 实现带版本号的精度策略快照与增量片段提交：快照携带单调递增版本号、生成时间、显存池上限、每轮写盘字节预算与整体校验摘要，提交时版本号不大于当前已提交版本返回 E_STALE_SNAPSHOT；增量片段只含受影响分片的驻留分配或损失缩放字段并携带基础版本，基础版本不是当前版本时返回 E_STALE_BASE 且不改变任何已提交状态。
5. 实现派生结构的依赖失效与级联原子重建：为每个分片维护主参数派生摘要、参数一致性校验结果、显存占用估算与恢复基线对其精度标记、主参数摘要、动量摘要与损失缩放参数的引用关系；上述任一变化时该分片全部派生结构及依赖它的池占用汇总与恢复基线必须在同一事务边界内原子重建，禁止出现池上限已重算而恢复基线仍为旧值的中间可见状态。
6. 实现写盘字节预算与每轮时间预算的调度取舍：分级写入受每轮写盘字节预算与每轮时间预算共同约束，预算内按分片优先级与轮次顺序取任务，超出写盘预算的分片进入有界等待队列，队列满返回 E_WRITE_QUEUE_FULL；预算耗尽时按确定性规则跳过低优先分片并输出跳过清单、已用写盘字节与剩余预算，不得以延长轮次掩盖预算超支。
7. 实现基于 SQLite 的单写者提交、多读者查询与强制终止恢复：检查点提交、驱逐与派生重建按提交单写者串行执行，多个只读查询（分片清单、池占用、精度偏差、恢复报告）可并发读取某一完整提交版本；所有写操作先落意图记录再提交事务，进程在写盘或驱逐中途被强制终止后重启须扫描未完成意图，把未提交分片回滚为 PENDING、把未完成驱逐标记为已中止，恢复报告只基于已提交事实。
8. 提供本地 HTTP 接口与端到端验证工具：接口覆盖策略快照提交、增量片段提交、检查点提交、按版本查询分片清单与池占用、精度偏差与恢复报告查询，失败响应统一为含业务码与上下文的 JSON（至少覆盖 E_PARTITION_INVALID、E_VRAM_POOL_FULL、E_LOSS_SCALE_OVERFLOW、E_STALE_SNAPSHOT、E_STALE_BASE、E_WRITE_QUEUE_FULL）；附带脚本用固定样本完成一次全量驻留、一次增量调整触发的驱逐、一次写盘预算耗尽跳过与一次强制终止后恢复。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地固定种子样本验证分级驻留、驱逐与写盘预算裁决，核对精度偏差与强制终止后的恢复报告。
