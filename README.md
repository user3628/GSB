算子优化小组在新分配的 Linux（WSL Ubuntu）开发机上从空目录起步，目标是交付一套供训练推理代码集成的激活与转置重排分块算子库及本地诊断应用。全部输入由程序内置固定种子生成器确定性地写出：一组 .json 张量分片涵盖形状 [批量, 头数, 序列长度, 头维度] 与二维矩阵两类布局，含奇数列数、非整除分块、混合极值、全零行与含 NaN/Inf 的异常样本；形状清单声明各分片的形状与 dtype，另一份带单调版本号的算子配置快照声明激活类型 GELU、SiLU、Sigmoid、转置重排模式、分块大小与求和策略。算子按激活计算、转置重排、块级快照、异常验证四阶段推进，要求不整体物化中间张量而逐块完成，并在进程被强制终止后仅凭已持久化的块级事实恢复进度，恢复结果与从零运行逐字节一致。

任务环境与准备：
准备 Linux（WSL Ubuntu）开发机，安装 Go 1.22 及以上版本（如 sudo apt install golang），确认 go version 可用。
使用 Go 标准库与 modernc.org/sqlite 或 mattn/go-sqlite3 作为 SQLite 驱动，执行 go mod tidy 拉取依赖，无需外部服务或网络数据。
内置固定种子生成器在本地写出 .json 张量分片、形状清单与算子配置快照，覆盖奇数列数、非整除分块、极值、全零行与 NaN/Inf 样本；生成器随项目代码提供，不依赖外部数据集。
准备本地 SQLite 数据库文件路径与工作目录，确保进程对目录有读写权限，便于验证事务写入与强制终止恢复。
启动本地 HTTP 接口与命令行演示所需的回环端口，确认未被占用。

业务要求：
1. 实现三种激活函数的统一分块计算内核：GELU（误差函数近似）、SiLU 与 Sigmoid 均按行块与列块组织，先减去块内运行参考最大值再在浮点域求值，支持奇数列数与非整除分块且越界块按形状清单裁剪；同一输入与配置必须产生逐字节一致的激活输出与逐块中间量摘要。
2. 实现转置重排阶段：支持头维度与序列维度互换以及按分块瓦片重排两种模式，重排须依据分块大小把源张量切片搬运到目标布局并记录每块来源坐标与目标坐标，奇数列数与非整除分块时正确裁剪尾块，重排后形状须与形状清单逐项一致。
3. 实现块级快照的版本化持久化：每个分片在每个阶段的小块完成后，以单个 SQLite 事务写入含分片标识、阶段名、块坐标、输入内容指纹、配置版本、块产物摘要与单调序号的记录；同一分片同一阶段同一块坐标只允许一条有效记录，写入中断不得留下半写记录，恢复时忽略损坏或不完整记录。
4. 实现块级增量失效传播与整体替换识别：当分片张量内容、激活类型、重排模式、分块大小或求和策略任一变化时，通过各阶段内容摘要构成的版本指纹识别受影响的最早阶段与块区间，使该区间及其下游块失效重建，未受影响块继续复用；检测到快照记录被整体替换时区分正常推进、整体替换与回退，仅正常推进被接受，其余返回 E_STALE_VERSION。
5. 实现优雅停止与强制终止后的恢复边界：收到停止请求时完成当前不可拆分块后落库并退出，不承诺强制终止后生成退出报告；被强制终止后重启仅凭已提交事务事实重建进度，恢复后的激活输出、重排张量、逐块摘要与异常报告必须与一次从零完整运行逐字节一致，且块序号连续推进、无跳跃无重复。
6. 实现数值稳定性与异常注入验证链路：激活与重排后的归约全程在定点缩放域或对数域进行，出现 NaN、Inf 或全零行时在对应块返回带分片标识、块行列区间与异常值的业务码 E_NUMERIC 并保留诊断上下文；提供参数注入入口，支持注入形状清单与实际张量不符、分块大小为零、重排目标形状越界与配置版本不匹配，各注入在对应阶段返回稳定业务码。
7. 实现误差界推导与高精度参考比对：对每个输出块按显式抽样位置与定点参考实现比对，给出最大绝对偏差、相对偏差与有效位数，误差界须由缩放因子、量化步长与分块累加顺序逐项推导并随结果保留；偏差超出可配置容差时返回 E_NUMERIC_MISMATCH 并附块坐标与推导依据。
8. 实现峰值内存约束下的执行调度并提供本地交互演示：在可配置峰值内存上限内规划行块工作区、列块切片、输出缓冲与中间累加器占用，超预算时按行块或列块拆分执行并记录拆分决策与每步内存估算，或返回带预算明细的 E_MEMORY_BUDGET；提供本地 HTTP 与命令行接口，支持导入分片与配置、触发分阶段计算、查询块级状态与版本指纹、请求停止与执行恢复，演示数据至少覆盖 3 个分片、奇数列数与非整除分块、含 NaN/Inf 的异常样本以及一次强制终止后的恢复。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性分片与配置执行完整四阶段，逐字节核对激活与重排输出、块级快照恢复一致性及异常注入业务码。
