从一个空仓库出发，需要从零构建一个面向本地 SQLite 数据库的 Go 连接池组件，供上层数据访问服务集成，并附带完整示例与可复现的异常注入验证。连接池管理连接生命周期（空闲、使用中、已失效、已关闭）、最大连接数、最大空闲数、连接最大存活时间与最大空闲时间，并支持有界等待队列与获取超时。在并发请求下，同一连接不得被两个调用方同时持有，等待队列的先进先出顺序须稳定，释放与获取之间的唤醒须真实可观测。异常注入用于验证连接池在连接建立失败、查询执行超时、连接被底层强制断开、等待队列溢出和获取超时等情形下的行为符合声明语义。所有验证基于本地确定性样本与本地回环测试服务，SQLite 以本地文件或内存库形式使用，不依赖外部数据库。

任务环境与准备：
安装 Go 1.22 或以上版本，配置 GOPATH 与 GOMODCACHE 可写目录，确认 go env 可正常运行。
在空工作区执行 go mod init 初始化模块，引入纯 Go 的 modernc.org/sqlite 驱动（或 mattn/go-sqlite3，需本地 C 编译器），执行 go mod tidy 拉取依赖。
准备本地确定性样本 JSON 文件，包含连接池配置、并发请求序列与异常注入参数；样本随仓库提交，不依赖外部数据库或网络。
确认本地回环端口可用，示例脚本启动的 HTTP API 与异常注入测试服务均绑定 127.0.0.1，SQLite 使用本地文件库以便强制终止后恢复可被验证。

业务要求：
1. 实现连接池核心模型：维护使用中连接集合、空闲连接有序队列与有界等待队列，配置包含最大连接数、最大空闲数、连接最大存活时间与最大空闲时间；获取时优先复用空闲连接，空闲不足且未达最大连接数时新建，达上限时进入等待队列；释放时按声明策略归还空闲队列或直接关闭，超过最大空闲数时关闭最久未用或最旧的空闲连接，并在响应中给出连接标识、创建时刻与已用次数。
2. 实现等待队列与获取超时的真实唤醒：获取者在无可用连接时进入先进先出等待队列，任一连接释放或有新连接可用时必须真实唤醒队首等待者；获取超时后等待者须从队列中移除并返回业务码 E_ACQUIRE_TIMEOUT，不得继续占用名额或被后续释放误唤醒；等待队列满时返回 E_POOL_EXHAUSTED，且溢出的请求不得留下残留等待条目。
3. 实现连接生命周期与失效判定：连接记录创建时刻、最近使用时刻与使用次数；连接被归还时校验存活时间与空闲时间，超限连接必须关闭且不得重新放回空闲队列；底层连接被强制断开（通过本地回环测试端点主动关闭真实连接模拟）后，该连接不得再被任何获取者取得，必须被替换为新连接或从池中移除，并记录替换原因。
4. 实现可复现的异常注入接口：本地回环测试服务端点支持注入连接建立失败、查询执行超时、连接中途断开、等待队列溢出与获取超时重启五类异常，每类返回互不相同的业务码（至少覆盖 E_DIAL_FAILED、E_QUERY_TIMEOUT、E_CONN_RESET、E_POOL_EXHAUSTED、E_ACQUIRE_TIMEOUT），注入参数与观测结果须绑定记录并可逐项核对，任何一类注入不得改变其余类别的行为。
5. 实现并发安全与单写者状态迁移：连接的获取、归还、失效与关闭按单写者串行执行状态迁移，多个只读统计查询可并发读取某一完整提交版本；同一连接不得被两个调用方同时持有，并发获取时仅一个成功取得该连接，其余进入等待或按超时规则处理；查询只能看到某一完整提交版本，不得看到连接已标记失效而空闲队列仍包含它的中间状态。
6. 实现基于 SQLite 的意图持久化与强制终止恢复：连接获取、归还、失效标记与池配置变更前先写入意图记录再提交事务；进程被强制终止后重启须扫描未完成意图，把未提交的获取回滚为可获取、未提交的归还回滚为使用中，并输出仅基于已持久化事实的恢复报告，不得承诺强制终止后仍生成退出报告，恢复报告须区分可还原的连接状态与无法还原的内存队列顺序。
7. 实现统一的业务错误码与 JSON 错误体，至少覆盖 E_ACQUIRE_TIMEOUT、E_POOL_EXHAUSTED、E_DIAL_FAILED、E_QUERY_TIMEOUT、E_CONN_RESET、E_CONFLICTING_REQUEST 与 E_STALE_CONFIG；所有失败响应须携带业务码与上下文，同一请求标识重复提交只执行一次、其余等待并复用结果，内容不一致时返回 E_CONFLICTING_REQUEST，配置变更携带的版本号不大于当前版本时返回 E_STALE_CONFIG。
8. 提供本地 HTTP API 与端到端示例脚本：API 覆盖获取连接、释放连接、执行查询、查询池统计与连接明细、触发异常注入与查询恢复报告；示例脚本使用固定本地样本完成一次正常并发获取与释放、一次等待队列唤醒、一次获取超时、一次连接中途断开替换与一次强制终止后恢复，输出每步观测结果与池状态快照，不得依赖真实账号、外网或付费资源。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
