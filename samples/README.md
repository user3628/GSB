# Deterministic sample corpus

Generated by `python scripts/generate_samples.py` with NumPy default RNG seed
`20261121`.  The policy topology is fixed; observation arrivals and latency
values are produced by bounded integer RNG calls in a fixed order.

Recommended fresh-state demonstration order:

1. `policy_v1.json`
2. `observations_05_queue_full.json` (must run before any committed scaling round)
3. `observations_01.json`
4. `observations_02.json`
5. `observations_03.json`
6. `observations_04_failover.json` twice with distinct round ids
7. `policy_v2_budget.json` to demonstrate versioned policy update with preserved placements

`round_request_01.json` is a ready-to-POST body combining `round-001` and
`observations_01.json`.

`policy_invalid_unit.json` intentionally contains `-2Gi` and is only used for
`E_SPEC_INVALID` verification.
