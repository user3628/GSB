## 端到端结果

运行：

```text
$ .venv/bin/python scripts/e2e.py
```

报告：`artifacts/e2e/e2e_report.json`。关键结果：

- 格式互转：旧版 JSONL -> 大端 v2 二进制 -> 两分片 JSONL，本次动态回环端口下语义哈希均为 `e079adfae200f91634c5313e625482e113bd1ddef6e9c7cda91a295ac2c5c9b6`，`equivalent=true`。
- 旧版降级：`degraded_accept`，权重 `[733,500,626]`，3 条权重舍入余量、3 条时间余数（456/567/678 微秒），6 条探测参数/窗口降级明细。
- 版本与损坏：v3 返回 `E_FORMAT_UNSUPPORTED`；篡改 CRC 返回 `E_FORMAT_CORRUPT`，记录序号为 1。
- 探测：7 个实例全部提交；HTTP 成功、TCP 成功、租约存活、TCP 拒绝、慢 HTTP 返回 `E_PROBE_TIMEOUT`（实际客户端连接关闭）。
- 队列：并发 4、队列 4，提交 10 个任务，8 个执行，2 个返回 `E_PROBE_QUEUE_FULL`。
- 冲突：跳过依据 `last_registered_at_older`；覆盖依据 `lease_version_higher`；完整平局拒绝 `ambiguous_complete_tie`，同批新记录未落库。
- 导入崩溃恢复：强制退出码 `-9`，批次 `crash-import` 为 `ABORTED`，已提交实例前后状态差异为空。
- 探测崩溃恢复：强制退出码 `-9`，3 个尝试 `ROLLED_BACK`，探测历史提交数 15 -> 15，实例状态差异为空。

## 端口说明

`samples/` 中样本固定写为 `127.0.0.1:28765/28766`，便于人工复现。端到端脚本会先探测空闲回环端口，并把本地样本副本中的端点重写为实际端口，避免与开发机已有服务冲突；原始样本不被修改。
