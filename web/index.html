显式窗口语义

  • 偏移区间为闭区间：min_offset_ms ≤ offset ≤ max_offset_ms；早于下界返回 E_TIMESTAMP_EARLY，晚于上界返回 E_TIMESTAMP_LATE，均附 offset 与触达 boundary。
  • Nonce 区间为左闭右开：[first_seen_ms, first_seen_ms + nonce_window_ms)。
  • 在 as_of = first_seen + window 时右边界不包含，记录已到期，可回收并允许新的首次占用。
  • 所有时刻均为整数毫秒；亚毫秒经过时间按非负时长向零/floor 截断，不产生小数提前到期。
  • 回收依据持久化的 first_seen_ms 与同一配置版本窗口，单调 high-water 防止系统时钟回拨延长窗口。
  • 完整裁决在一个 SQLite 事务中写签名状态、Nonce 占用、结论并提交意图；查询只能看到完整提交版本。
